Alpine Linux minirootfs 3.21.0 (aarch64) — 软件包、许可与源码获取 / Packages, licenses and source code

iOS 版内置的离线沙箱根文件系统（alpine-rootfs.zip）由 Alpine Linux 官方 minirootfs 生成：
  https://dl-cdn.alpinelinux.org/alpine/v3.21/releases/aarch64/alpine-minirootfs-3.21.0-aarch64.tar.gz
生成脚本为本项目仓库的 scripts/prepare-rootfs.sh，只改写若干配置文件（/etc/passwd、/etc/profile、
/etc/motd、/etc/inittab、/etc/resolv.conf、/etc/apk/repositories），不额外安装、不修改任何软件包的程序本身。

The offline sandbox root filesystem bundled in the iOS app (alpine-rootfs.zip) is generated from
the official Alpine Linux minirootfs listed above by scripts/prepare-rootfs.sh in this project's
repository, which only rewrites a few configuration files and does not add or modify any package
binaries.
