# simulation

---

## 1. 一句话本质

simulation 是一面**故意造出来的镜子**——镜子里的世界不是真的，但你盯着它看，是因为你想从中读出真世界的某些东西。关键在于：**造镜子的人知道它是假的**。

---

## 2. 词源考古

### 词根词缀拆解

```
simul-  +  -ation
│            │
│            └─ 拉丁后缀 -ātiō：表示"做某事的过程/结果"（action → 行动，creation → 创造）
│
└─ 拉丁语 simulāre：使之相像、模仿、假装
     │
     └─ 拉丁语 similis：像的、相似的
          │
          └─ 原始印欧语 *sem-：一、同、在一起
```

**\*sem-** 这个根极其能生——它是"same"（同一）、"similar"（相似）、"simple"（单一的）、"simultaneous"（同时的）、"assemble"（聚到一起）、"resemble"（看起来像）、"ensemble"（整体/合奏）的共同祖先。一个"同"的概念，裂变出了半个英语的高频词库。

### 历史流变

**拉丁时代（公元前1世纪—）**：*simulātiō* 的原始含义几乎是纯负面的——**伪装、虚伪、做假**。西塞罗用它的时候，基本在说"这个人在演戏"。在修辞学中，*simulātiō* 和 *dissimulātiō*（掩饰）是一对术语：前者是"装有"（假装你有某种想法），后者是"装无"（假装你没有）。苏格拉底的反讽就被归类为 *dissimulātiō*——装不知道。

**中世纪（13-15世纪）**：经由古法语 *simulation* 进入英语，14世纪的英语文本中，这个词依然带着浓重的道德审判色彩——**伪善、欺骗、装模作样**。中世纪教会尤其爱用它来描述异端的"假虔诚"。

**17-18世纪·转折点**：科学革命带来了关键语义漂移。人们开始用"simulate"来描述一种**中性的建模行为**——不是为了骗谁，而是为了理解。你造一个东西来"模拟"天体运动、水流行为、力学过程。"假"不再是道德缺陷，而是**认知工具**。

**20世纪·爆发**：计算机的出现让 simulation 彻底脱离贬义，变成科学和工程的核心词汇——飞行模拟器、气候模拟、蒙特卡洛模拟。1960年代 simulation 在学术论文中的出现频率暴涨。到了2003年，哲学家 Nick Bostrom 提出"模拟假说"（simulation hypothesis），这个词又获得了一层存在主义的哲学重量。

### 文化地层

这个词经历了一次罕见的**道德极性反转**：

> 从"骗人的假"→"有用的假"→"也许根本没有真"

拉丁时代：假 = 罪。中世纪：假 = 罪（加强版）。近代：假 = 工具。当代：假 = 说不定一切都是假的（simulation theory）。

法国哲学家鲍德里亚（Baudrillard）在《拟像与模拟》中更狠：他说我们活在一个 simulation 已经**取代了原件**的时代——迪士尼乐园比"真实的美国"更"真实"，因为它坦诚自己是假的，而外面的世界假装自己是真的。这是 simulation 概念在20世纪末被推到的极端。

## 3. 故事 / 画面

一个航天局的控制室。屏幕上，一枚火箭正在穿越大气层，尾焰灼亮，分级脱落，每个传感器的数据在跳动。所有人屏息。

然后灯亮了。有人摘下耳机说："这一轮通过。"

火箭没有飞。它从未离开过这个房间。

但房间里每个人的肾上腺素是真的，他们发现的那个阀门压力异常是真的，他们因此修改的设计方案会用在一个月后真正的发射上。

**这就是 simulation 的本质结构：造一个不真实的过程，从中获得真实的知识。** 它和"谎言"的区别在于：谎言要你信以为真，simulation 要你明知是假却依然认真对待。

而 simulation 最诡异的哲学翻转是——如果你在模拟里活了一辈子，你怎么知道外面有没有一个"控制室"，有人正在说"这一轮通过"？

## 4. 多面体：核心义项展开

### 义项 A：模拟、仿真（中性/技术义）

> *The engineers ran a simulation of the bridge under earthquake conditions before approving the design.*
> 工程师在批准设计前，对桥梁进行了地震条件下的模拟。

与本质的关系：造一面镜子——不是真地震，但你从镜子里读出了真结构会怎么断。

### 义项 B：模仿、假装（保留的古义，偏贬义）

> *His concern for her was mere simulation — he was already planning to leave.*
> 他对她的关心不过是假装——他早就在计划离开了。

与本质的关系：这面镜子是用来**骗人**的。它映出一个不存在的感情。这是拉丁语的原始用法，现代英语里偶尔还能碰到，尤其在文学语境中。

### 义项 C：（哲学/存在论）模拟现实

> *If we're living in a simulation, does the question of "what's real" even matter?*
> 如果我们生活在一个模拟中，"什么是真的"这个问题还重要吗？

与本质的关系：镜子大到把你装进去了。你不是在看镜子——你在镜子里面住。

### 义项 D：（生物/医学）模拟症状、伪装疾病

> *The patient's simulation of paralysis was so convincing that it took three specialists to identify the deception.*
> 这位病人对瘫痪的模拟如此逼真，需要三位专家才识破了骗局。

与本质的关系：用身体造一面镜子，让医生看到一个不存在的疾病。

**底层统一性**：所有义项共享同一个结构——**制造一个与真实事物相似但并非真实的东西**。区别只在于**目的**：为了学习（A）、为了欺骗（B/D）、还是这个区别本身就不存在（C）。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 simulation 当 stimulation**
这两个词只差一个字母，但含义天差地别。stimulation 是"刺激、激发"，simulation 是"模拟"。写论文的时候把 "economic simulation" 打成 "economic stimulation"——意思从"经济模型模拟"变成了"经济刺激"，直接换了一个学科。

**❌ simulation ≠ imitation**
"She did a simulation of her boss's voice" ← 这句话不自然。模仿某人说话是 imitation / impersonation。simulation 暗示的是一个**系统性的建模过程**，不是单纯的"学样子"。你模拟一个气候系统，不模拟一个人说话。

### 易混近义词辨析

| 词 | 核心区别 |
|---|---|
| **simulation** | 制造一个**系统级别**的仿制品，通常有目的（研究/训练/测试）|
| **emulation** | 尝试**达到或超越**原件的水平。"I emulated her success" = 我效仿她并追赶她。simulation 不试图超越——它就是个模型 |
| **imitation** | 外在形式的复制。"imitation leather" = 仿皮。比 simulation 浅，不涉及底层机制 |
| **replication** | 制造一个**尽可能一样的**副本。simulation 知道自己是简化版，replication 追求一模一样 |

### 中文母语者陷阱

**"模拟"在中文里太中性了。** 中文说"模拟考试"完全正常，但英语里 "simulation exam" 不说——标准说法是 "mock exam" 或 "practice exam"。simulation 在英语中带有更强的"系统建模"含义，而中文的"模拟"覆盖面更宽。

**"仿真"不等于 simulation 的全部。** 中文"仿真"偏向技术建模（仿真系统），但 simulation 还保留着"假装、伪装"的古义（义项 B/D），这个层面中文通常用"伪装""假装"来翻译，不会用"仿真"。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **computer simulation** | 最高频组合，计算机模拟——科学/工程的面包黄油 |
| **run a simulation** | "跑一次模拟"，动词几乎永远是 run，不是 do/make |
| **flight simulation** | 飞行模拟，航空训练的核心 |
| **simulation model** | 仿真模型，学术论文标配 |
| **Monte Carlo simulation** | 蒙特卡洛模拟，统计/金融/物理的重型工具 |
| **simulation theory/hypothesis** | 模拟假说，哲学/流行文化 |
| **realistic simulation** | 逼真模拟，游戏/训练领域 |
| **simulation software** | 仿真软件，工程/设计工具类 |

### 语域标注

偏**正式/技术**。日常口语中不太会说"let me run a simulation"来决定晚餐吃什么（除非在开玩笑）。它的自然栖息地是：学术论文、工程报告、科技新闻、哲学讨论、游戏评论。

但 simulation theory 近年来被 Elon Musk 和各种播客带火之后，已经渗入了日常闲聊——"we're living in a simulation" 已经是半开玩笑的流行语了。

### 活用示范

> *"The whole interview felt like a simulation of a conversation rather than the real thing — all the right words, none of the warmth."*
> 整场面试感觉像是一场对话的模拟，而非真正的交流——用词全对，温度全无。

这个用法精准地激活了 simulation 的核心张力：**形式上完美复制，本质上空心**。

> *"History doesn't repeat itself, but it does run simulations."*
> 历史不会重复自身，但它会跑模拟。

对马克·吐温名言的改写，把 simulation 拉进了历史哲学的语境——历史事件不是复刻，是参数不同的模拟轮次。

## 7. 跨语言映射

**拉丁语 simulācrum**：同根词，但走了一条更诡异的路。simulacrum 指的是"像"——雕像、肖像、幻影。柏拉图用它（的希腊对应词）来描述"影子的影子"——真实事物的拙劣复制品。鲍德里亚后来把 simulacrum 发展成了一个完整的哲学体系：**没有原件的复制品**。simulation 是过程，simulacrum 是产物。

**日语「シミュレーション」**：直接音译借入，使用场景和英语高度重合——ゲームシミュレーション（游戏模拟）、シミュレーション理論（模拟假说）。

**中文"模拟"vs"仿真"**：中文把 simulation 的两个面切成了两个词——"模拟"偏向过程和方法论（模拟考试、模拟训练），"仿真"偏向技术精度（仿真系统、仿真实验）。但两者都没有覆盖 simulation 的"伪装/欺骗"义——那个要用"假装""伪装"来接。英文一个词跨越了"中性建模"和"道德伪装"两极，中文做不到，这本身就说明 simulation 的语义张力有多大。

**法语 simulation**：同形同源，但法语中保留了更多古义色彩——在法律语境中，*simulation de crime*（伪装犯罪）是一个正式法律术语，指的是捏造犯罪事实。法语没让这个词完全被技术义收编。

**德语 Simulation**：同样直接借入，技术语境为主。但德语有一个自己的词 *Vorspiegelung*（字面：把假象放在前面），专门用来表达 simulation 的"欺骗性模拟"义——比英语切得更干净。

---

**最后一个锚点**：simulation 这个词本身就是一次 simulation——它用拉丁语的零件模拟了一个从"假装骗人"到"科学建模"再到"也许整个宇宙都是假的"的语义旅程。每次你用这个词，你都在选择：**这面镜子，是用来照的，还是用来骗的，还是——你其实就住在里面？**
