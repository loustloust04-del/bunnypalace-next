# specification

## 1. 一句话本质

**specification 是把脑子里那团模糊的"我大概想要这样的东西"钉死在纸面上的那个动作——以及钉完之后那张纸。** 它不是描述你看到了什么，而是规定别人必须做出什么。

---

## 2. 词源考古

### 词根词缀拆解

```
specific-    +    -ation
  ↓                 ↓
"看准的、确定的"    "做……这个动作 / 这个动作的产物"
```

再往下拆 `specific` 本身：

```
spec(ere)  +  -ific  +  -ation
   ↓           ↓          ↓
 "看"      "使之成为"   "动作/结果"
(拉丁 specere)  (拉丁 -ificus < facere "做")
```

三层叠起来的本义：**"使之成为可以被看清的东西"这个动作，以及这个动作的产物。**

这个构造逻辑极其精准——你脑子里有个想法，模模糊糊的，specification 就是把它"做成可以被看见的形状"。不是随便看一眼，是一笔一划地画出来，让任何人拿着这张纸都能还原出你脑子里那个东西。

### 历史流变

| 时期 | 形态 | 含义 |
|------|------|------|
| 古典拉丁语 | *specere* | 看 |
| 晚期拉丁语 | *specificāre* | 提及某个特定的东西 |
| 中世纪拉丁语 | *specificātiō* | 把某物从一般类别中单独指认出来的行为 |
| 17世纪英语 | specification | "详细说明、列举细目" |
| 18-19世纪 | specification | 工程/法律/专利文件中的"技术规格书" |
| 当代 | spec (缩写) | 渗透到日常口语和科技领域 |

**关键转折在18世纪。** 工业革命需要一种语言：你在伯明翰画的图纸，寄到曼彻斯特，那边的工匠必须能造出一模一样的东西。specification 从"说清楚"这个泛泛的动作，硬化成了一种**文体**——有格式、有精度要求、有法律效力的技术文书。

这个词在专利法中也扮演了关键角色。英国1624年《垄断法》之后，发明者必须提交 specification 来换取专利保护——你不能说"我发明了一种更好的蒸汽机"，你必须 specify 到每一个零件的材质和尺寸。**保护的前提是透明。**

### 文化地层

specification 身上沉积着工业文明的核心信念：**可复现性。** 手工时代不需要 spec——师傅带徒弟，手把手教，每件作品都独一无二。specification 的崛起标志着人类开始相信：一个东西可以被完全地、无歧义地、用文字描述清楚，然后被任何具备技能的人精确复制。

这个信念今天看来理所当然，但在人类文明史上是很晚才出现的。

## 3. 故事 / 画面

一个建筑师和一个包工头站在空地上。

建筑师说："我想要一栋温暖的房子。"
包工头说："多温暖？"
"嗯……冬天不冷的那种。"
"墙多厚？用什么保温材料？窗户双层还是三层？朝向？"
"……"

这就是 specification 诞生前的世界——两个人对着同一个词（"温暖"），脑子里的画面完全不同。

然后建筑师回去画了一份文件：外墙240mm加气混凝土砌块，外贴80mm挤塑聚苯板，窗户三层中空 Low-E 玻璃，朝南面窗墙比0.35……

**这份文件就是 specification。它不是在描述一栋已经存在的房子，它是在规定一栋还不存在的房子必须长什么样。** 它是一座桥，一端连着脑子里的愿景，另一端连着现实中的锤子和钉子。

specification 的本质就是这个：**把"我想要"翻译成"你必须做到"。**

## 4. 多面体：核心义项展开

### 义项 A：详细说明的动作

> *The specification of requirements took longer than the actual coding.*
> 需求的详细说明比实际编码花的时间还长。

这是最接近词源本义的用法——specify 这个动作的名词形式。"使之可见"的过程本身。注意这里它是不可数的（或作单数），指的是一个抽象过程。

**与本质的关系：** 就是"钉在纸面上"这个动作本身。

### 义项 B：技术规格文书（最高频义项）

> *The car was built to military specifications.*
> 这辆车是按军用规格建造的。

这是 specification 最常见的面孔。一份文件，列出一个产品/系统/服务必须满足的全部技术参数。注意这里经常用复数 **specifications**（缩写 specs），因为一份规格书包含很多条目。

**与本质的关系：** "钉完之后的那张纸"——动作凝固成了文档。

### 义项 C：单条技术指标

> *One of the key specifications is that the battery must last at least 12 hours.*
> 其中一项关键规格是电池续航必须至少12小时。

从整份文件缩小到其中一条。

**与本质的关系：** 那张纸上的一个钉子。

### 义项 D：（专利法）发明说明书

> *The patent specification must disclose the invention in sufficient detail to enable reproduction.*
> 专利说明书必须充分详细地公开发明以使其可被复制。

专利语境下的专用义。这是 specification 历史上最早被制度化的用法之一。

**与本质的关系：** 回到18世纪的原始交易——你 specify 你的发明，国家 specify 你的独占权。两份"钉死"互为条件。

### 底层统一性

四个义项的公分母：**从模糊到精确的单向转化。** 无论是一个动作、一份文件、一条指标还是一份法律文书，specification 永远在做同一件事——消灭歧义。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 specification 当 description 用**

specification 是**规定性的**（prescriptive）：事物还不存在，我规定它应该是什么样。
description 是**描述性的**（descriptive）：事物已经存在，我描述它是什么样。

> ❌ "Here's a specification of what happened at the meeting."（会议已经发生了，你不是在规定它）
> ✅ "Here's a description of what happened at the meeting."

**❌ specification ≠ requirement**

requirement 说的是"要什么"（*The system must handle 10,000 concurrent users*）。
specification 说的是"怎么做到"（*Use Redis cluster with 6 nodes, each with 32GB RAM...*）。

实际使用中这两个词的边界确实模糊，但概念上：requirement 是目的，specification 是手段。

### 易混近义词辨析

| 词 | 核心差异 | 场景对比 |
|----|---------|---------|
| **standard** | 由权威机构制定，所有人遵守的通用规格 | ISO 9001 is a *standard*; your product's *specification* must meet it. |
| **specification** | 由设计者为特定项目制定的具体技术参数 | 同上——standard 是天花板/地板，specification 是你家的装修方案 |
| **guideline** | 建议性的，不强制 | A *guideline* suggests; a *specification* demands. |
| **criterion** | 单个判断标准 | A *criterion* is one test; a *specification* is the whole exam paper. |

### 中文母语者陷阱

**"规格"的陷阱：** 中文"规格"偏向尺寸、型号等物理参数（手机规格：6.7英寸、256GB……），而 specification 的覆盖面宽得多——行为规范、接口协议、验收标准、性能指标都算。中文里你不太会说"这段代码的规格"，但英文里 *code specification* 或 *API specification* 是完全日常的表达。

**"说明书"的陷阱：** 中文"说明书"通常指使用说明（user manual），但 specification 是**制造说明**，给造东西的人看的，不是给用东西的人看的。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境说明 |
|------|---------|
| **meet / comply with specifications** | 最常见动宾搭配。"满足规格要求"。合同、验收场景的标准措辞 |
| **technical specification(s)** | 技术规格书。工程/IT 领域日常用语 |
| **detailed specification** | 强调精细度。"我要的不是大方向，是每个螺丝钉的参数" |
| **to specification / to spec** | 介词短语，"按照规格"。*built to specification* = 定制生产（不是量产） |
| **draw up / write a specification** | "起草规格书"。动词搭配用 draw up 比 write 更正式 |
| **specification sheet (spec sheet)** | 产品参数表。买电子产品时看的那张纸 |
| **specification document** | 比 spec sheet 更完整的文件，常见于软件开发 |
| **functional specification** | 功能规格书。描述系统应该"做什么"，不涉及怎么实现 |

### 语域标注

**正式偏技术。** 日常口语中几乎总是被缩写成 **spec** / **specs**：

- 正式/书面："The product does not conform to the agreed specification."
- 口语/日常："What are the specs on that laptop?"
- 开发者日常："Have you read the spec?" / "The API spec is outdated."

在学术论文、合同、专利文件中使用全称 specification。在团队沟通、代码注释、日常邮件中用 spec。用全称但场合不对会显得你在"端着"。

### 活用示范

> *"God is in the details," Mies van der Rohe supposedly said. Every architect knows the corollary: so is the devil. A specification is where the two meet.*
> 密斯·凡·德·罗据说说过"上帝在细节中"。每个建筑师都知道推论：魔鬼也在。规格书就是两者相遇的地方。

> *The problem isn't that we don't have a spec. The problem is that we have three specs and none of them agree.*
> 问题不是我们没有规格书。问题是我们有三份，而且互相打架。

## 7. 跨语言映射

**中文"规格"vs"说明书"vs"规范"：** 英文一个 specification 覆盖了中文三个不同的词。"规格"偏物理参数，"说明书"偏文件形态，"规范"偏行为准则。specification 横跨三者——它既是参数集合，又是文件，又暗含"你必须遵守"的强制力。中文没有一个词能同时carry这三层。

**日语「仕様」（しよう, shiyō）：** 非常精准的对应。日语IT行业里「仕様書」（shiyōsho）= specification document，而且有一个著名的梗——「仕様です」（"这是规格"）= "It's not a bug, it's a feature." 这个用法精确地揭示了 specification 的权力本质：**谁写 spec，谁定义什么是对的。**

**德语 Spezifikation / Pflichtenheft：** 德语直接借了拉丁词 Spezifikation，但工程领域更常用 *Pflichtenheft*（义务手册），这个词比 specification 更露骨地展示了它的本质——Pflicht 是"义务"，Heft 是"册子"。一本写满义务的册子。英文把这层强制性藏在了文雅的拉丁外壳下面，德语直接摊开来说。

---

**回看 spec- 家族的考古路线：**

*specere*（看）→ *species*（看出的种类）→ *specific*（看准了的、确定的）→ *specialist*（看准一个领域的人）→ *specialty*（那个被看准的领域）→ **specification**（把看准的东西一笔一划写下来，钉死在纸上）。

从"看"到"写"，从感知到文档，从个人判断到可传递的契约。specification 是这条线的终点站——**视觉变成了文本，直觉变成了制度。**
