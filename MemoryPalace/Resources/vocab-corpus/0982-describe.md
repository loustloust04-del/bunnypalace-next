# describe

## 1. 一句话本质

**describe 是拿笔尖沿着事物的轮廓慢慢描一圈——不是拍照，是素描。** 你得沿着边缘走，该凹的凹进去，该凸的凸出来，走完一圈，看的人就知道那是什么了。

---

## 2. 词源考古

### 词根词缀拆解

```
de-  （向下 / 完全）  ← 拉丁语介词 de
scrib- （刻、写）    ← 拉丁语 scrībere
-e   （动词词尾）
```

核心动力全在 **scrībere**。这个词的老祖宗是原始印欧语 \*(s)ker-/\*skreibh-，意思不是"写"——是 **"刻、划、用尖物划出痕迹"**。写字这件事，在人类最早期就是拿硬东西在软面上刻。楔形文字刻泥板，卢恩字母刻石头，甲骨文刻龟甲。scrībere 记住的是那个动作的触感：**尖端压下去，推过去，留下一道沟。**

**de-** 在这里是强化/完成义（intensive），不是"向下"或"去除"。describere = 彻底地刻画出来。

### 历史流变

| 时间 | 形式 | 含义 |
|------|------|------|
| 古拉丁 | *dēscrībere* | 抄写，誊录（物理意义的"写下来"） |
| 古典拉丁 | *dēscrībere* | 描画轮廓；标记区域；划定界线 |
| 晚期拉丁 → 古法语 | *descrivre* | 开始获得"用文字描绘"的含义 |
| 14世纪中英语 | *describen* | 正式进入英语，同时保留"画"和"说"两个意思 |
| 16-17世纪 | *describe* | "用文字描绘"成为主导义项，"画"退为专业用法 |

### 文化地层——关键转折

**第一层：从手到嘴。** 拉丁语 describere 本来是个视觉动作——在地图上标出一块区域、用笔勾勒一个图形的轮廓。你用的是手，产出的是线条。进入英语后，这个词从手迁移到了嘴——**你不再用笔沿轮廓走，而是用语言沿轮廓走**。但底层结构没变：都是"沿着边缘、一段一段地、把形状勾出来"。

**第二层：数学里的活化石。** 在日常英语里，describe = 用语言描述。但在数学和物理里，"describe a circle"、"the planet describes an ellipse"——这里的 describe 保留了最古老的义项：**用运动轨迹划出一个图形**。这不是隐喻，这是字面义的幸存者。每次你在数学课上听到这个用法，你听到的是 14 世纪的英语在跟你说话。

## 3. 故事 / 画面

一个法医素描师坐在证人对面。

证人说："他的眼睛……很小，但是凶。"素描师的铅笔在纸上走——不是自由挥洒，而是一笔一笔沿着"小而凶"这三个字的轮廓去找形状。证人又说："鼻子很宽，嘴唇薄。"铅笔又走一段。

这就是 describe 的本质动作：**你不是把一张完成的照片啪地甩出来，你是拿着一支笔，跟着事物的形状走，一段一段地让轮廓浮现。** 每一句话是一笔，每一笔让形状更清晰一点。最后那张素描也许不是照片级的精确——但看的人能认出来那是谁。

describe 永远带着"过程感"——它不是瞬间完成的，它是需要展开的。这也是它跟 identify（一个词就能指认）和 name（贴个标签）的根本区别。

## 4. 多面体：核心义项展开

### 义项一：用语言描绘（主导义）

> *She described the accident in vivid detail.*
> 她用生动的细节描述了那场事故。

最核心的用法。注意 describe 天然期待**展开**——你不能说 "She described it as bad" 就算完了（那是 characterize），describe 暗示你要花篇幅，沿着事情的轮廓走一圈。

与本质的关系：**语言版的素描——一笔一笔勾轮廓。**

### 义项二：把……定性为（describe as）

> *He described himself as a self-taught programmer.*
> 他把自己定性为一个自学的程序员。

这个义项微妙地偏移了——不再是"展开描绘"，而是"给出一个概括性的标签"。但底层逻辑依然是素描：你在给一个事物画一个最粗的轮廓——只用一笔，但那一笔定义了整体形状。

与本质的关系：**只用一笔勾出最关键的那条线。**

### 义项三：（运动轨迹）画出、划出（几何 / 物理）

> *The Earth describes an ellipse around the Sun.*
> 地球绕太阳划出一个椭圆。

活化石义项。这里的 describe 完全是物理动作——没有语言参与，一个物体在空间中移动，它的轨迹"画"出了一个形状。这是最接近拉丁语原始含义的用法。

与本质的关系：**笔尖沿着轮廓走——只不过笔尖是行星，纸面是太空。**

### 义项四：（正式 / 法律）对……作出陈述

> *The witness was asked to describe the events of that night.*
> 证人被要求对当晚的事件作出陈述。

法律和正式语境中的 describe 带有"完整性义务"——你被期望**全面地**勾勒，不是挑着说。de- 的强化义在这里最明显：不是随便写两笔，是**彻底地**写下来。

与本质的关系：**de- 发动了——不是速写，是精细素描，不能漏。**

## 5. 裂缝标注

### 常见误用

**❌ describe about**

> ~~He described about his childhood.~~
> ✅ He described his childhood.

describe 是及物动词，直接接宾语，不要加 about。这个错误极其高频，因为 talk about / tell about 的语感会传染过来。

**❌ 把 describe 当 explain 用**

> ~~Can you describe why this happened?~~
> ✅ Can you explain why this happened?

describe 画的是"是什么样"，explain 解的是"为什么"。你可以 describe a symptom（描述症状），但你 explain the cause（解释原因）。

### 易混近义词辨析

| 词 | 核心区别 |
|---|---|
| **depict** | 更偏视觉呈现——绘画、影像、文学中的画面感。describe 可以很干，depict 通常暗示"生动、有画面" |
| **portray** | 侧重"塑造形象"——portray someone as a villain 是在塑造一个角色，describe someone as a villain 只是贴个标签 |
| **narrate** | 有时间轴——narrate 是"按顺序讲一个故事"，describe 不要求时间顺序，可以是静态的 |
| **illustrate** | 目的是"让你理解"，通常通过举例。describe 的目的是"让你看见" |
| **characterize** | 一个词或一句话点出本质特征。describe 展开铺陈，characterize 高度浓缩 |

### 中文母语者陷阱

**"描述"的陷阱：中文的"描述"比 describe 宽。** 中文说"请描述一下你为什么想要这份工作"——没问题。但英文不说 "describe why"，要说 "explain why" 或 "describe your motivation"。中文的"描述"涵盖了 describe + explain + outline 的地盘，英文的 describe 只管"画轮廓"那一块。

**"形容"的陷阱：** 中文"形容一下这个人"≈ describe this person，没问题。但"形容词"= adjective，不是 descriptive word。不要把"形容"和 describe 画等号——中文的"形容"可以是一个词的事（"他很高"），但 describe 暗示展开。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **describe in detail** | "详细描述"——最常见的搭配之一，强化 de- 的"彻底"义 |
| **describe as** | "定性为"——接名词或形容词，一笔定调 |
| **accurately describe** | 学术/法律/医学——强调忠于事实的轮廓 |
| **vividly describe** | 文学/新闻——强调画面感，笔触带色彩 |
| **hard/difficult to describe** | 常用于情感、体验——"这种感觉很难描述"，暗示轮廓太模糊笔抓不住 |
| **describe a situation/scene/process** | 万能场景搭配 |
| **describe a circle/arc/curve** | 数学/物理——活化石搭配 |
| **best described as** | "最好将其定义为"——正式文体中的常客 |

### 语域

**全域通用。** describe 没有正式程度限制——论文里用、法庭上用、跟朋友聊天也用。但不同语域搭配不同的修饰词：学术偏 accurately/precisely，文学偏 vividly/eloquently，日常偏 basically/sort of。

### 活用示范

> *Words can't describe how grateful I am.*
> 语言无法描述我有多感激。

这句话的力量恰恰来自 describe 的本质——你承认你拿着笔，但轮廓太大了、太复杂了，笔跟不上。这不是谦虚，是对 describe 这个动作本身的极限声明。

> *The stock price described a sharp V over the quarter.*
> 该股价在这个季度划出了一个尖锐的 V 形。

金融语境中活用了几何义项——股价的运动轨迹"画"出了一个形状。这种用法在英文商业写作中不罕见，比中文"走出 V 形"更精确地暗示了"轨迹本身就是图形"。

## 7. 跨语言映射

**中文的"描"字本身就是绝佳的映射。**

"描"——拿笔沿着底稿的线条重新走一遍。描红、描花、描眉。跟拉丁语 describere 的"沿轮廓刻画"几乎是同一个身体动作。中文"描述"的"描"和英文 describe 的 scrib-，一个在东亚拿毛笔，一个在地中海拿铁笔，做的是同一件事。

**日文「描写」（びょうしゃ）也走"描"的路线**——用笔"写"出来的"画"。但日文「描写」偏文学性，日常口语更常用「説明する」（说明），而 describe 在英文里日常和文学通吃。

**法文 décrire** 同源同构，用法也几乎一致。有趣的是法文保留了几何义项的活跃度比英文更高——法文数学课上 *décrire un cercle* 的说法非常自然。

**德文 beschreiben**——be- (彻底) + schreiben (写)，跟 de- + scribere 是平行构造。日耳曼语用 be- 做了拉丁语 de- 的活。

---

**最后的锚**：下次你用 describe 这个词，记住那个法医素描师——不是拍照，是一笔一笔沿着轮廓走。你的语言就是你的铅笔，你描述的对象就是坐在你对面的脸。走得越仔细，画像越清晰。走完一圈，轮廓闭合——这就是 describe 完成的那一刻。
