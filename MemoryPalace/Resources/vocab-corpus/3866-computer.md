# computer

---

## 1. 一句话本质

computer 是一个**被机器夺走名字的人**——它本来指坐在桌前、手握铅笔、一行行算数的那个活人，后来机器干了同样的活，就把名字也拿走了。这个词的内核不是"电脑"，是"算"这个动作本身：谁在算，谁就是 computer。

---

## 2. 词源考古

### 词根词缀拆解

```
com-   +   put(are)   +   -er
一起        整理/计算       做…的人
```

**com-**：拉丁前缀，"一起、彻底"。在这里是强化语气（intensive），不是"一起算"，而是"彻底地算清楚"。

**putāre**：这是整个词最有味道的部分。拉丁语 putāre 的原始含义是——**修剪树枝**。对，就是拿剪刀咔嚓咔嚓剪树。

为什么"剪树"变成了"计算"？

逻辑链是这样的：修剪树枝 → 清理、整理 → 清理账目 → 核算 → 思考、判断。一个罗马农民蹲在橄榄树下剪掉多余枝条的动作，经过几百年的隐喻延伸，变成了一个会计在羊皮纸上清理数字的动作。**去掉多余的，留下有用的**——剪枝和算账的底层逻辑是同一个。

同源词验证了这条路径：
- **amputate**（截肢）：am(bi)- 周围 + putare 修剪 → 把周围的剪掉
- **dispute**（争论）：dis- 分开 + putare 判断 → 判断不同
- **reputation**（名声）：re- 反复 + putare 思考 → 反复被人想起/评估
- **impute**（归咎于）：im- 向内 + putare 算 → 算到某人头上
- **deputy**（代理人）：de- 向下 + putare 指派 → 被指定代替的人

**-er**：古英语施动者后缀，做这件事的人（后来也指做这件事的东西）。

### 历史流变

**1610s — 出生：人肉计算器**

computer 首次出现在英语中，意思是 **"a person who computes"**——一个做计算的人。这不是比喻，是字面意义。17世纪的 computer 就是一个职业头衔，就像 teacher 是教书的人、driver 是赶车的人。

**1700s-1800s — 黄金时代：一个真实的职业**

到了18-19世纪，computer 成了一个正经职业。天文台雇 computer 来计算星体轨道，保险公司雇 computer 来算精算表，军队雇 computer 来算炮弹弹道。这些 computer 大多是女性——因为计算工作被认为是"耐心的文书劳动"，薪水比男性科学家低得多。二战期间，美国军方有大量女性 computer，她们手工计算弹道表，每张表需要几周时间。

**1897 — 转折的前兆**

这一年，computer 第一次被用来指"计算设备"（a calculating machine），但还只是偶尔用法。

**1945 — ENIAC 与身份篡夺**

ENIAC 诞生。媒体需要一个词来称呼这个 30 吨重的房间大小的机器。"electronic computer" 出现了——字面意思是"电子的计算者"。请注意：此时 computer 前面必须加 "electronic" 来区分，因为不加的话，computer 默认还是指人。

**1950s — 名字易主**

短短十年内，machine computer 占领了这个词。到1950年代末，说 computer 默认指机器，指人反而需要加限定词——"human computer"。一个词的默认指代对象翻转了。

这可能是英语历史上最快的、最戏剧性的语义篡夺之一：**一个有几百年历史的人类职业头衔，在不到二十年内被机器拿走了。**

### 文化地层

这层语义篡夺里藏着一个更深的故事。那些曾经被叫做 computer 的女性——ENIAC 的六位女性程序员（Kay McNulty、Betty Jennings、Betty Snyder、Marlyn Meltzer、Fran Bilas、Ruth Lichterman）——她们从"人肉 computer"变成了"为 electronic computer 编程的人"。她们的身份从名词本身变成了名词的操作者，而历史在很长时间里甚至忘了提她们。

2016年的电影 *Hidden Figures*（《隐藏人物》）讲的就是NASA的非裔女性 computer 们——她们用铅笔和纸算出了太空轨道，直到电子 computer 来了，她们要么学会编程新机器，要么被新机器替代。

## 3. 故事 / 画面

1943年，费城一间没有窗户的大房间。

八十个女人坐在八十张桌前，每人面前一台手摇计算器，旁边堆着印有对数表的小册子。她们在算弹道——一颗炮弹从炮管里飞出去，风速多少、仰角多少、温度多少，它会落在哪里。每一条弹道需要 750 次乘法运算。一张完整的射表有几千条弹道。算完一张表，要几个星期。

她们的职称写在工资单上：**Computer**。

两年后，同一栋楼的另一个房间，ENIAC 亮了灯。三万个真空管嗡嗡作响，像一面发烧的墙。它30秒算完一条弹道。

没人开会讨论过这件事，但从那以后，当人们说 "computer"，指的不再是那八十个女人。

名字就这么搬了家。旧主人连告别仪式都没有。

## 4. 多面体：核心义项展开

### 义项一：电子计算机（当代默认义）

> *The computer crashed right before I saved my work.*
> 电脑在我保存前崩溃了。

和"一句话本质"的关系：机器取代人做了"算"这件事，于是继承了名字。这是当下最通用的含义，但它其实是这个词最年轻的面孔。

### 义项二：（历史）从事计算工作的人

> *Before electronic machines, the term "computer" referred to a person, often a woman, employed to perform mathematical calculations.*
> 在电子机器出现之前，computer 指的是受雇做数学计算的人，往往是女性。

和"一句话本质"的关系：这是这个词的原始面孔——谁在算，谁就是 computer。从人到机器，底层逻辑没变，变的只是"谁在算"。

### 义项三：（复合词/引申）用于指代类似计算能力的事物

> *The human brain is often called the most powerful computer in existence.*
> 人脑常被称为现存最强大的计算机。

和"一句话本质"的关系：这是一个有趣的回旋——词从人出发，到机器，又被用来反向比喻人。当我们说大脑是 computer，我们其实是在用机器隐喻来形容人本来就有的能力。名字转了一圈回来了，但已经带着机器的味道。

## 5. 裂缝标注

### 常见误用场景

**① 把 computer 等同于"台式电脑"**
严格来说，你的手机是 computer，你的车载系统是 computer，ISS 上的导航模块也是 computer。但日常英语中说 "I'm on my computer" 一般暗指笔记本或台式机，不包括手机。这个含义边界是约定俗成的，不是定义决定的。

**② 用 computer 代替 computing**
"I studied computer at university" ✗ → "I studied **computer science** / **computing**" ✓。computer 是具体的机器/人，computing 是抽象的学科/活动。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **machine** | 泛指任何机械装置，computer 是 machine 的子集。你不会管洗衣机叫 computer |
| **calculator** | 只做算术。computer 能做判断、存储、执行程序——能"思考"（至少模拟思考）。1940年代以前两者几乎同义，ENIAC 之后分道扬镳 |
| **processor** | 指计算机内部做运算的核心部件（CPU），不是整台机器。"The processor is fast" ≠ "The computer is fast"——前者只说芯片，后者说整体体验 |
| **device** | 更泛，任何电子设备。phone 是 device 也是 computer，但 USB 线是 device 不是 computer |

### 中文母语者陷阱

**① "电脑" ≠ "电子大脑"**
中文"电脑"的构词暗示了"电子的大脑"，会让人觉得 computer 天然跟"脑"有关。但英语 computer 的词源跟大脑无关，它只是"算东西的"。日语"電脳"（dennō）同样走了"电+脑"的路，但英语原词没有这层隐喻。这个差异在讨论AI时特别容易造成思维偏差——中文说"电脑能思考吗"自带了"脑"的暗示，英文问 "can a computer think" 其实更冷淡。

**② "计算机"比"电脑"更贴近原义**
大陆用"计算机"做正式术语，台湾/港澳用"电脑"做日常用语。"计算机"几乎是 computer 的直译（计算+机），反而更准确。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **personal computer (PC)** | 1981年 IBM 把这个搭配变成了产品名，从此 PC 成了独立词汇 |
| **computer science** | 学科名，注意不是 "computer study" |
| **computer program / programming** | 程序/编程——这个搭配本身很有趣：program 原指"预先写好的安排"（剧院节目单），用在 computer 上说明机器是按"剧本"走的 |
| **computer-generated** | 电脑生成的（CGI = computer-generated imagery）|
| **computer literacy** | 计算机素养——注意 literacy 本指"读写能力"，嫁接到 computer 上暗示了一种"不会用电脑 = 文盲"的文化焦虑 |
| **on the/a computer** | "在电脑上做某事"，注意介词是 on 不是 in |
| **boot (up) a computer** | 启动——boot 来自 bootstrap（靴子上的提带），"自己把自己拉起来" |
| **quantum computer** | 量子计算机——当代最前沿的搭配，词义又一次扩展 |

### 语域标注

**全语域通行词。** 从日常口语（"my computer's slow"）到学术论文（"distributed computer architectures"）到新闻到法律文件，都能用，没有正式度限制。这是英语中少数真正"无门槛"的技术词——因为它已经变成了日常生活基础设施的名字。

### 活用示范

> *"The real problem is not whether machines think but whether men do."*
> ——B.F. Skinner
>
> 真正的问题不是机器能不能思考，而是人还思不思考。

（这句话之所以有力，是因为 computer 的崛起让"思考"这个本属于人的动词变得可疑了。）

> *She was one of the last human computers at NASA—by the time she retired, the machines had taken not just her job, but her title.*
> 她是NASA最后一批人类 computer 之一——等她退休时，机器不仅拿走了她的工作，还拿走了她的头衔。

## 7. 跨语言映射

| 语言 | 词 | 构词逻辑 | 有趣的差异 |
|---|---|---|---|
| 中文（大陆） | **计算机** | 计算 + 机 | 最忠实的直译，完全对应"computing + machine" |
| 中文（台港澳） | **电脑** | 电 + 脑 | 把"算"偷换成了"脑"——隐含"机器能想"的假设 |
| 日语 | **コンピュータ** (konpyūta) / **電脳** (dennō) | 音译 / 电+脑 | 日常用音译，科幻和亚文化爱用"电脑"（攻壳机动队的世界观基石） |
| 法语 | **ordinateur** | 源自拉丁 ordinare "排列、组织" | 法国IBM在1955年特意造的词，避开了"计算"的含义，强调"整理信息"——这是一个比 computer 更有远见的命名，因为现代计算机做的事情早就超出"计算"了 |
| 德语 | **Rechner** / **Computer** | rechnen = 计算 / 英语借词 | 两个并行使用，Rechner 更正式更"德语" |
| 冰岛语 | **tölva** | tala（数字）+ völva（女先知） | **"数字女巫"**——冰岛语给了 computer 最诗意的名字 |
| 中文古对照 | **算筹** / **筹人** | 算 + 竹棍 / 做筹的人 | 中国古代用竹棍做加减乘除的人，功能上就是 human computer |

冰岛语的 **tölva** 值得单独说一句：冰岛有严格的语言纯化传统，外来词必须用冰岛本土词根重新构造。他们选了"数字"和"女先知"（沃尔娃，北欧神话中能预见未来的女祭司）拼在一起。这个命名暗示了一个深刻的直觉：**计算机不只是算东西的，它是用数字预言未来的。** 1964年造这个词的人恐怕自己都不知道他有多对。

而法语的 **ordinateur** 也是神来之笔——IBM法国公司1955年请巴黎大学教授 Jacques Perret 造词，他故意避开了"计算"，选了"排列、赋予秩序"的词根。理由是：这台机器做的不只是算术，它在给混沌的信息赋予秩序。七十年后回头看，这个词比 computer 更准确地描述了我们每天用电脑做的事。
