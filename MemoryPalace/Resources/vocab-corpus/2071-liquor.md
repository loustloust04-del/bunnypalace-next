# liquor

## 1. 一句话本质

**liquor 是"渗出来的精华液"——骨头熬出来的汤汁、粮食蒸馏出来的烈酒、万物被挤压加热后流出的那一滴浓缩液体。它不是随便什么水，是某个东西"交出"的液态灵魂。**

## 2. 词源考古

### 词根拆解

结构极简，不可再拆：

- **liquor** ← 拉丁语 **liquor**（液体、流质）← 动词 **liquēre**（是液态的、流动的）

这个拉丁动词 **liquēre** 是整个家族的祖宗，从它身上长出来的后代：

| 后代 | 路径 | 含义 |
|------|------|------|
| **liquid** | liquēre → liquidus（形容词后缀 -idus） | 液态的 |
| **liqueur** | 同源，法语二次借入 | 甜味利口酒 |
| **liquefy** | liquēre + facere（做） | 液化 |
| **liquidate** | 中世纪拉丁语 liquidare | 清算（把资产"化成"现金流） |

注意一个重要分裂：**liquor** 和 **liqueur** 是同一个词的两次借入。liquor 在中世纪英语时期（约13世纪）从古法语 **licur / licour** 进入英语；liqueur 是17世纪从现代法语重新借入的。同一个拉丁祖先，隔了四百年进了同一间屋子两次，一次穿工装（liquor），一次穿晚礼服（liqueur）。

### 历史流变

**13世纪**：进入英语时，liquor 的意思是**任何液体**。乔叟（Chaucer）写 *"the licour in which oon was boiled"*——煮东西的那锅汤水。没有半点酒精含义。

**14-15世纪**：开始偏向"提炼出的液体"——药水、汁液、蒸馏液。关键的语义漂移在这里发生：从"随便什么液体"→"经过某种过程萃取出的液体"。一锅白水不叫 liquor，但你用它炖了骨头，那锅汤就是 liquor。

**16-17世纪**：酒精含义开始强势占位。蒸馏技术的普及让 liquor 和烈酒紧紧绑定。到了17世纪末，说 liquor 不加限定词，听众默认你在说酒。

**现代美式英语**：liquor 几乎完全等于 **distilled spirits**（蒸馏烈酒）——whiskey、vodka、rum、gin。啤酒和葡萄酒不算。这是一个极窄的语义收缩：从"一切液体"→"烈酒"，跨度堪比 deer 从"任何动物"收缩到"鹿"。

### 文化地层

美国禁酒令（1920-1933）给这个词刻上了一层道德烙印。**liquor store**（卖酒的店）、**liquor license**（卖酒执照）——这些词组把 liquor 和法律管控绑在了一起。至今美国很多州的法律文书里，liquor 是一个有精确法律定义的术语，特指酒精含量高于某个阈值的饮料。

## 3. 故事 / 画面

一口铸铁大锅，底下文火。你往里扔了猪骨、牛筋、鸡架、洋葱皮、姜片。三个小时后，骨头还是骨头，姜还是姜，但锅里的水已经不是水了——它变稠了，变浑了，变得有重量了。你舀起一勺尝，整锅食材的精气全在这一口里。

这就是 liquor 最古老的含义：**不是"加了东西的水"，是"东西把自己交给了水"。**

烈酒是同一个逻辑的极端版本。粮食发酵、蒸馏、冷凝——谷物把自己最烈的那部分交出来，凝成透明的一小杯。你喝的不是水，是粮食的幽灵。

## 4. 多面体：核心义项展开

### 义项一：烈酒（最常用）

> *He doesn't touch liquor — hasn't had a drop since his daughter was born.*
> 他滴酒不沾——自从女儿出生后就没碰过。

这是现代英语里的默认义项。注意：beer 和 wine 不算 liquor。liquor 特指蒸馏酒——因为蒸馏就是"逼出精华"的过程，完美继承了"萃取液"的底层逻辑。

### 义项二：烹饪中的汤汁 / 锅底液

> *Save the cooking liquor from the mussels — you'll need it for the sauce.*
> 把煮青口的汤汁留着——做酱汁要用。

这个义项在日常口语中不常见，但在烹饪写作和食谱里非常活跃。**pot liquor**（或 potlikker）是美国南方的灵魂食物术语，指炖煮绿叶蔬菜后剩下的那锅浓汤。

和"一句话本质"的关系：最直接的映射——食材把自己的精华渗进了水里。

### 义项三：工业 / 制药中的溶液

> *The black liquor from the pulping process is recycled as fuel.*
> 制浆过程中的黑液被回收用作燃料。

造纸、纺织、制药领域都用 liquor 指某种工艺溶液。**black liquor**（黑液）、**mother liquor**（母液）都是专业术语。

和"一句话本质"的关系：工业萃取——原料经过化学处理后"交出"的液体副产品。

### 义项四：动词——liquor up（灌酒）

> *They liquored him up before breaking the bad news.*
> 他们先把他灌醉，然后才说坏消息。

非正式用法，几乎只以 **liquor up** 的短语形式出现。

## 5. 裂缝标注

### 常见误用

- **把 liquor 当"酒"的统称**。说 *"I had some liquor"* 再补一句 *"it was a nice Chardonnay"*——不对。Chardonnay 是葡萄酒，不是 liquor。在美式英语中，liquor = 蒸馏烈酒，啤酒和葡萄酒要用 **alcohol** 或 **drinks** 来统称。

- **liquor ≠ liqueur**。这是两个不同的词。**Liquor** 是基酒（vodka、whiskey、gin），通常不甜。**Liqueur** 是甜味利口酒（Baileys、Kahlúa、Amaretto），通常是在基酒里加了糖和风味。发音也不同：liquor = /ˈlɪkər/，liqueur = /lɪˈkɜːr/。

### 中文母语者陷阱

- 中文"酒"是一个超级大词，覆盖了 wine、beer、liquor、spirits、alcohol、booze 的全部语义。中文母语者的直觉是"liquor = 酒"，然后在所有需要说"酒"的地方都用 liquor。但英文对酒的分类远比中文细——liquor 只是其中最烈的那一档。

- 另一个陷阱：中文说"白酒"时脑子里想的是白色/透明的烈酒（baijiu），但英文 **white liquor** 是一个造纸工业术语。中国白酒在英文里通常直接写 **baijiu** 或说 **Chinese spirit**。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **liquor store** | 美国卖酒的零售店（英国说 off-licence） |
| **hard liquor** | 强调"烈"酒，和啤酒/葡萄酒对比时用 |
| **hold one's liquor** | 酒量好，喝了不醉不失态 |
| **liquor license** | 合法售酒许可证 |
| **pot liquor / potlikker** | 南方菜汤汁，有文化身份感 |
| **cooking liquor** | 食谱用语，煮食材后的汤液 |
| **malt liquor** | 麦芽酒，酒精度高于普通啤酒的酿造酒 |
| **liquored up** | 喝多了（非正式，略带贬义） |

### 语域

liquor 是一个**中性偏正式**的词。它既出现在法律文本里（*liquor control board*），也出现在日常口语里（*I need to hit the liquor store*）。但它不是俚语——要表达"酒"的更随意说法，美国人会用 **booze**。

### 活用示范

> *She can hold her liquor better than anyone I know — three martinis deep and still arguing tort law.*
> 她的酒量比我认识的任何人都好——三杯马天尼下去还在辩侵权法。

这里 **hold her liquor** 不光是说"能喝"，更是说"喝了还能保持头脑和体面"——liquor 在这个搭配里暗含了"烈度"和"考验"的意味。

## 7. 跨语言映射

- **中文"酒"**：覆盖面远宽于 liquor。但"烈酒"二字和 liquor 比较接近——都强调蒸馏、浓缩、度数高。
- **日文「酒」（さけ）**：和中文一样是超级大词，但「蒸留酒」（じょうりゅうしゅ）对应 liquor。有趣的是日语从英文借了 **リキュール**（rikūru），但这对应的是 liqueur 而不是 liquor。
- **法文 liqueur**：在法语里 liqueur 本身就能指一般液体（古义犹存），但现代法语日常用法和英文的 liqueur（甜酒）一致。法语说烈酒用 **spiritueux** 或 **alcool fort**。

这组跨语言对照揭示了一个规律：很多语言里"酒"是不分的大概念，而英语对酒精饮料的词汇分类异常精细（ale / beer / lager / stout / wine / port / sherry / mead / spirits / liquor / liqueur / cordial...），这和英语世界复杂的饮酒文化与法律管控直接相关。
