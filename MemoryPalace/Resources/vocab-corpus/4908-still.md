# still

---

## 1. 一句话本质

**still 是世界在动，它不动。** 窗外暴风雨，杯子里的水面却纹丝不动——那个水面就是 still。不是"空"，不是"停"，是**周围都在变，它拒绝变**。这个拒绝，延伸出了它所有的脸：身体不动、声音安静、时间里不变（仍然）、逻辑上不让步（然而）。

---

## 2. 词源考古

### 词根词缀拆解

still 没有可拆的词缀，它是一个赤裸的词根词。

- **古英语 stille**（形容词"不动的、安静的"+ 副词"安静地"）
- ← **原始日耳曼语 \*stillijaz**（固定的、不动的）
- ← **PIE 词根 \*stel-**（放置、站定、立住）

这个 \*stel- 是个大家族的祖宗：
- **stall**（畜栏——让动物"站定"的地方）
- **install**（安装——把东西"立"到位）
- **pedestal**（底座——脚下"立"着的东西）
- **apostle**（使徒——被"派去站岗"的人，经希腊语路径）
- 德语 **Stelle**（位置、岗位）

所以 still 的最底层含义不是"安静"，是**"被固定在原地"**。安静只是不动的副产品。

### 历史流变

**古英语时期（~700–1100）**：stille 主要是感官层面的——身体不动、嘴巴不出声。"Be stille!"（别动！/闭嘴！）这两个意思当时就并存。

**中古英语时期（~1100–1500）**：关键漂移发生了。从"空间上不动"滑向了**"时间上不变"**。逻辑链条是这样的：

> 如果一个东西**不动**（still），那它在时间流里就是**持续的、未改变的**（still = 仍然）。

这一步是 still 从物理词变成时间词的转折点。大约 14 世纪起，still 开始稳定地用作"仍然、依旧"。

**近代英语（1500–至今）**：又长出一个面——**转折/让步**。"He was tired, but still he kept going." 这里的 still 不是"仍然"那么简单，它带了一层**"本该变了，但没变"**的语气——也就是"然而、尽管如此"。这其实是"不动"的逻辑化：外力推它，它不让步。

### ⚠️ 蒸馏器的 still 是另一个词

那个做威士忌的蒸馏器叫 still，但它的词源完全不同：
- 是 **distill** 的截短形式
- distill ← 拉丁语 **destillare**（de- + stillare "滴落"），来自 **stilla**（一滴）
- 和"不动"的 still 是纯粹的同形异源词（homonym），血缘关系为零

这是个值得专门标注的陷阱：不要试图用"不动"去解释蒸馏器，它们只是长得一样。

## 3. 故事 / 画面

一个湖。

凌晨四点，天还没亮，风刚刚停。湖面变成一面镜子——不是比喻，是字面意义上的镜子。对岸的山、天上的星星、倒映得分毫不差。你蹲在岸边，甚至能看见自己的脸。

然后一条鱼跳出水面。涟漪扩散，镜像碎了。但涟漪终究会消失。水面会重新**变回那面镜子**。

这就是 still 的全部性格：

- **湖面不动** → still（静止）
- **凌晨的无声** → still（安静）
- **涟漪散去，镜面回来** → still（仍然、依旧——它又回到了原来的状态）
- **风来了它不动，鱼跳了它恢复** → still（然而、尽管如此——外力改变不了它的本性）

记住这个湖面。still 的每一个义项，都是这面镜子的一个角度。

## 4. 多面体：核心义项展开

### 义项一：不动的、静止的（形容词）

> *Hold still — I'm trying to get this splinter out.*
> 别动——我在帮你挑刺。

最原始的含义。湖面不动。身体不动。空气不动。这是 still 的物理层。

与本质的关系：**世界在动，它不动**——最字面的版本。

### 义项二：安静的、无声的（形容词）

> *The house was still. Not a creak, not a whisper.*
> 房子静悄悄的。没有吱嘎声，没有低语。

从"不动"到"无声"的滑移非常自然：不动的东西不发出声音。但注意，still 的"安静"带有一种**凝固感**，不只是音量低——它暗示整个环境像被按了暂停键。

与本质的关系：不动的衍生品。声音是运动的产物，不动则无声。

### 义项三：仍然、依旧（副词）

> *After all these years, she still remembers his voice.*
> 这么多年了，她仍然记得他的声音。

这是 still 使用频率最高的义项。时间在走，事情本该变了，但它**没变**。still 在这里是一个时间锚钉——把过去的状态钉在了现在。

与本质的关系：空间的"不动"被翻译成了时间的"不变"。湖面镜像碎了又恢复——它 still 是那面镜子。

### 义项四：然而、尽管如此（副词/连词）

> *The evidence was weak. Still, the jury convicted him.*
> 证据很弱。然而，陪审团还是定了罪。

这是 still 最高阶的用法。前半句给出了一个"应该改变"的理由，still 把它挡回去：**不，状态不变**。它和 but/however 的区别在于：but 是纯转折，still 的转折里藏着一丝**执拗**——明知该变，偏不变。

与本质的关系：逻辑层面的"拒绝移动"。外力推它，它站在原地。

### 义项五：静物照片（名词）

> *The director picked three stills from the film for the poster.*
> 导演从影片里挑了三张剧照做海报。

电影在流动，still 是从流动中**冻住的一帧**。这个用法完美映射了 still 的核心：时间在跑，它被按了暂停。

### 义项六：更加（副词，用于比较级前）

> *The second exam was still harder than the first.*
> 第二次考试比第一次**还要**难。

这个义项容易被忽略。它的逻辑是：你以为到顶了，但状态**继续不变地往上走**——"仍然在变难"的压缩表达。still 在这里是"持续、延伸"义的自然推导。

## 5. 裂缝标注

### 常见误用场景

**❌ still 和 already 的位置混乱**

still 放在**助动词后、主动词前**（She is **still** working），或者**句首做转折**（**Still**, I think we should try）。中文母语者经常把它扔到句尾，造出 *She is working still* 这种虽然语法不错但听起来像维多利亚时代诗歌的句子。

**❌ still 当"安静"用时，和 quiet 的混淆**

- **still** = 整个场景凝固了，强调的是一种**氛围的冻结**
- **quiet** = 音量低

"The classroom was quiet"（教室很安静，但学生在动、在写字）✅
"The classroom was still"（教室像凝固了一样，所有人一动不动）——这画面更极端。

### 易混近义词辨析

| 词 | 核心区别 |
|---|---|
| **yet** | 时间上"到目前为止还没"，常用于否定/疑问。*Has she arrived yet?* still 不能替换 yet 的这个用法 |
| **however** | 纯逻辑转折，中性语气。still 做转折时多一层"执拗感" |
| **nevertheless** | 书面正式版的 still（转折义）。日常对话用 nevertheless 会显得像在念论文 |
| **motionless** | 只表示"不动"，没有 still 的安静、氛围含义。motionless 是物理描述，still 是感受描述 |
| **calm** | calm 是情绪层面的平静，可以有轻微动作；still 是物理层面的凝固 |

### 中文母语者陷阱

**"还"≠ still**

中文的"还"覆盖范围比 still 大得多：
- "我还想要一杯" → I'd like **another** one（不是 still）
- "他还在睡" → He's **still** sleeping ✅
- "还行吧" → It's **okay** / not bad（完全不是 still）

中文的"还"是个万能胶，still 只管**"原来怎样、现在依旧怎样"**这一条线。

**"静"的翻译陷阱**

中文"安静"是一个词，但英文里 still / quiet / silent / calm / peaceful 各占不同的语义区间。中文母语者倾向于把"安静"全部映射到 quiet，而忽略 still 那种"凝固的、时间暂停的"质感。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **stand still** | 站着别动。军训、医院检查、枪口下——任何需要你冻住的场景 |
| **sit still** | 坐着别动。常对小孩说。*Can you sit still for five minutes?* |
| **still water** | 静水（不流动的水）。对比 sparkling water（气泡水）。在餐厅点水时的标准用语 |
| **still life** | 静物画。美术术语。水果、花瓶、骷髅——那些不会动的东西摆在一起 |
| **still air** | 无风的空气。气象或文学场景 |
| **be still** | 别动 / 安静下来。语气比 be quiet 更庄重，有仪式感，圣经里常见 |
| **still, ...** | 句首转折。Still, I think it's worth trying. 口语和书面都常用 |
| **still more / still better** | 比较级加强。still 在这里 = even，但更书面 |

### 语域标注

still 是**全语域词**——从幼儿园到学术论文，从日常短信到文学作品，处处都能用。它不像 nevertheless（偏书面）或 motionless（偏描写性文本）那样有场合限制。

但有一个微妙的分布差异：
- **副词"仍然"义**：口语和书面均高频，这是 still 的主场
- **形容词"静止"义**：偏文学/描写性语境，日常口语里更常说 "don't move" 而不是 "be still"
- **句首转折义**：口语偏多，书面里 however/nevertheless 更常见

### 活用示范

> *"The world is loud. Be still. Know."*
> ——改编自《诗篇》46:10

这里 still 同时激活了"别动""安静""在喧嚣中保持不变"三层含义。一个词完成了三重工作。

> *"I am still learning."*
> ——据传为米开朗基罗 87 岁时所说（存疑，但广泛引用）

still 在这里的精准度：不是"我又在学了"，是"**我从来没停过**"。一个词浓缩了几十年的连续性。

## 7. 跨语言映射

**德语 still** —— 直系血亲。德语保留了 still 几乎所有的义项，而且权重分布惊人地一致：sei still（安静）、still stehen（站着不动）、still（仍然）。如果你学过德语，这个词基本可以平移。

**日语「静か」(shizuka)** —— 覆盖了 still 的"安静/静止"义，但没有"仍然"的时间义。日语用「まだ」(mada) 来表达"仍然"，这是一个完全不同的词——说明日语没有把"不动"和"不变"绑定在同一个词根上。

**中文"静"** —— 最接近 still 的形容词义（安静、静止），但中文的"静"更偏向一种**审美状态**（静谧、恬静），而 still 更偏向一种**物理事实**（它就是不动）。中文的"静"里有禅意，still 里有钉子。

**拉丁语 tranquillus** —— 英语 tranquil 的来源。tranquil 和 still 的安静义有交集，但 tranquil 多了一层"令人舒适的平静"，still 没有这个温度——still 是中性的，一个谋杀现场也可以是 still。
