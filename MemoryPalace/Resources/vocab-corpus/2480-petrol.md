# petrol

---

## 1. 一句话本质

**petrol 是石头里挤出来的血液**——地球把亿万年的阳光压进岩层，人类把它抽出来点燃，让机器跑起来。这个词的骨子里刻着一个画面：油从石缝里渗出来。

---

## 2. 词源考古

### 词根词缀拆解

petrol 是 **petroleum** 的截短形式，而 petroleum 可以精确拆成两块：

| 部件 | 来源 | 含义 |
|------|------|------|
| **petr-** | 拉丁语 petra ← 希腊语 πέτρα (pétra) | 岩石、石头 |
| **-ol(eum)** | 拉丁语 oleum | 油 |

**Petroleum = petra + oleum = 石头里的油 = 岩油。**

这个构词逻辑极其朴素——古人看见黑色粘稠的液体从岩石缝隙里渗出来，就叫它"石头油"。没有任何修辞，纯粹的"所见即所名"。

### 历史流变

**8世纪**：波斯炼金术士在著作中已经描述了从岩石中渗出的可燃油液。阿拉伯语文献用过类似概念。

**1546年**：德国矿物学家格奥尔格·阿格里科拉（Georg Agricola）在拉丁语著作中正式使用 **petroleum** 一词，指天然从地层渗出的油。这是这个词在西方学术文献中的重要锚点。

**法语中转站**：拉丁语 petroleum → 法语 **pétrole**。法语把词尾简化了，pétrole 在法语中至今指的是**原油/石油**（注意：不是汽油——法语管汽油叫 **essence**）。

**1890年代·关键转折**：英国公司 **Carless, Capel & Leonard** 把提炼后的轻质石油精（用于灯具和早期发动机）注册为商品名 **"Petrol"**。这个品牌名从法语 pétrole 截取而来。

**20世纪初**：随着汽车普及，"petrol" 在英国从品牌名**泛化为通用词**（genericization），专指加进汽车油箱的精炼燃油。这跟 "aspirin"（阿司匹林）、"xerox"（复印）的命运一模一样——商标变成了日常词汇。

### 文化地层：一次关键的语义窄化

这里发生了一次非常有趣的**含义收窄**：

```
拉丁语 petroleum：地底渗出的一切油 → 广义
法语 pétrole：石油/原油 → 中义
英语 petrol：精炼后的汽车燃油 → 窄义
```

同一个词根，从"石头里的油"一路窄化到"加油站的那个东西"。而英语里保留了 **petroleum** 来指代原油/石油这个更广的概念，petrol 则专管那个加进车里、被火花塞点燃的液体。

一个词分裂成了两个：petroleum 管地下的，petrol 管油箱里的。

## 3. 故事 / 画面

公元前某年，美索不达米亚。一个牧羊人赶着羊群走过一片干裂的荒地，脚下的石缝里冒出一缕黑色的液体，粘在他的凉鞋底。他用手指沾了一点，放到鼻子前闻——刺鼻，但不是腐烂的味道。他往篝火边扔了一块沾了这东西的石头。

石头着了。

两千五百年后，伦敦。一个穿马甲的店员把一桶金黄色透明液体贴上标签：**PETROL**。隔壁停着一辆冒黑烟的早期汽车，司机提着空铁桶走进来。

从石缝渗出的黑色粘液，到加油站透明的金黄液体——petrol 这个词记录的就是这段旅程：**从石头的血管里抽出来，炼干净，灌进机器的心脏**。

## 4. 多面体：核心义项展开

Petrol 的义项其实很集中，但它和 petroleum 的关系值得拆开看。

### 义项一：汽油（英式英语核心义）

> *The car's nearly out of petrol — we need to find a station.*
> 车快没油了——得找个加油站。

这是 petrol 最常见也几乎唯一的日常用法。指精炼后的轻质燃油，用于内燃机。和"一句话本质"的关系：石头的血液，炼净了，专门喂机器。

### 义项二：用作形容词修饰（颜色/气味）

> *a petrol blue dress*
> 一条汽油蓝的裙子

Petrol blue 是一种特定的蓝绿色——汽油在光线下反射出的那种带虹彩的深蓝绿。这个用法在时尚和设计领域很常见。和本质的关系：汽油薄膜上的光学干涉色，石头的血液折射出的彩虹。

### 义项三：作为复合词的构件

- **petrol station**（加油站）= 美式的 gas station
- **petrol bomb**（汽油弹）= 莫洛托夫鸡尾酒
- **petrol head**（车迷/汽车发烧友）= 美式的 gearhead

这些复合词都锚定在"汽油"这个核心义上，没有偏离。

底层统一性：petrol 不像 run 或 set 那样义项爆炸。它是一个**高度聚焦**的词——从石头到油到车，一条线拉到底。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 petrol 当 petroleum 用**

> ✗ *"The Middle East has vast reserves of petrol."*（中东有大量石油储量）
> ✓ *"The Middle East has vast reserves of **petroleum** / **oil**."*

Petrol 只指精炼后的汽油，不指地下的原油。说"中东有大量 petrol"就像说"中东地下埋着一堆加油站的油"——逻辑上说不通。

### 易混近义词辨析

**petrol vs. gasoline vs. gas**

| | petrol | gasoline | gas |
|---|---|---|---|
| 语域 | 英式英语 | 美式英语（正式） | 美式英语（口语） |
| 指什么 | 汽车燃油 | 汽车燃油 | 汽车燃油 / 气体（歧义） |

场景对比：
- 在伦敦说 *"I need to get gas"* → 英国人可能以为你要去买煤气/天然气
- 在纽约说 *"I need to get petrol"* → 美国人听得懂但会觉得你很英国
- 在学术论文里写 → 用 **petroleum**（指原油）或 **gasoline/petrol**（指汽油，看目标读者是美式还是英式）

**petrol vs. diesel**

都是车用燃料，但化学成分和使用场景完全不同。Petrol（汽油）是轻馏分，用火花塞点燃；diesel（柴油）是重馏分，靠压缩自燃。加错油是真实会发生的灾难——英国加油站的 petrol 枪嘴和 diesel 枪嘴颜色不同就是为了防这个。

### 中文母语者陷阱

**"石油" ≠ petrol**

中文里"石油"对应的是 **petroleum / oil**（原油），不是 petrol（汽油）。虽然 petrol 的词根就是"石头的油"，但在现代英语中它已经窄化到只指汽油。

这个陷阱很微妙：词源上 petrol 确实等于"石油"，但语义上它已经不是了。就像中文"小姐"的词源是"年轻女子的尊称"，但在某些语境下含义已经漂移了一样。

**"加油" ≠ add petrol**

中文"加油"的英文是 *fill up / refuel / get petrol(gas)*，不要直译成 *add petrol*（虽然语法上没错，但极不自然）。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **run out of petrol** | 没油了（最日常的搭配，开车必会） |
| **fill up with petrol** | 加满油 |
| **petrol station** | 加油站（英式；美式 = gas station） |
| **petrol prices** | 油价（新闻高频词） |
| **unleaded petrol** | 无铅汽油（加油站标识常见） |
| **petrol engine** | 汽油发动机（与 diesel engine 对称） |
| **petrol bomb** | 汽油弹/燃烧瓶（新闻/冲突报道） |
| **petrol blue** | 汽油蓝（时尚/设计用色） |

### 语域标注

**日常口语 + 新闻语域**，主要限于**英式英语圈**（英国、澳大利亚、新西兰、南非、印度、新加坡、香港）。在美式英语环境中使用 petrol 会被标记为"外来用法"。

正式程度：**中性**。不像 petroleum 那么学术，也不像 gas 那么随便。它就是英国人说"汽油"的标准方式，没有正式/非正式的色彩。

### 活用示范

> *"The whole argument ran out of petrol after about ten minutes."*
> 整场争论大概十分钟后就没油了（=失去了动力/不了了之）。

这是 petrol 的隐喻延伸——用"没油"来比喻"失去能量、后劲不足"。很生动，英式英语里偶尔能碰到。

> *"Throwing money at a failing project is like pouring petrol on a fire."*
> 往一个失败的项目里砸钱就像往火上浇汽油。

Pour/throw petrol on a fire（火上浇油）——英式版的"add fuel to the fire"，更具体、更有画面感，因为 petrol 比抽象的 fuel 更能让人"看到"火焰猛窜的瞬间。

## 7. 跨语言映射

这个词的跨语言对照非常有意思，因为不同语言选择了完全不同的策略来命名同一种液体：

| 语言 | 汽油怎么说 | 命名逻辑 |
|------|-----------|---------|
| 英式英语 | **petrol** | 从"石头的油"截短（来源导向） |
| 美式英语 | **gasoline / gas** | 从气态特征命名（物理性质导向） |
| 法语 | **essence** | "精华、精馏物"（工艺导向——蒸馏出来的精华） |
| 德语 | **Benzin** | 来自安息香酸 benzoe（化学导向） |
| 意大利语 | **benzina** | 同德语路径 |
| 日语 | **ガソリン** (gasorin) | 借自英语 gasoline |
| 中文 | **汽油** | 会蒸发成气的油（物理性质导向） |

最有趣的对比是**法语 essence**。法语说加油叫 *faire le plein d'essence*（装满精华）。把汽油叫"精华"——这个命名背后的逻辑是：原油经过蒸馏，最轻、最纯、最易挥发的那一层被抽出来，那就是"精华"。法国人管加油叫"灌满精华"，英国人管加油叫"灌满石头汁"。同一个动作，两种世界观。

而中文的"汽油"也很精确——它抓住的是这种液体最危险也最有用的特性：**它会变成气**（挥发），然后被点燃。中文选了功能面，英语选了来源面。

---

**最后一个记忆锚点**：下次看到 petrol 这个词，想想那个画面——石缝里渗出黑色的液体，被人类抽出来、炼干净、变成金色透明的液体、灌进机器——**石头的血，机器的粮**。从 petra（石头）到 petrol station（加油站），这个词走了两千年，但从没忘记自己从哪块石头里来的。
