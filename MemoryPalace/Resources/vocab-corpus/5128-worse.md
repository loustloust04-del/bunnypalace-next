# worse

---

## 1. 一句话本质

**worse 是一锅汤被搅浑的那一下——不是"坏"，是"比原来更乱了"。**

它的祖先说的不是"坏"，是"混乱"。事情变 worse，是秩序又往熵增的方向滑了一格。

---

## 2. 词源考古

### 词根词缀拆解

worse 没有可拆的前缀后缀——它本身就是一个**比较级词根**，而且是英语里最诡异的语法现象之一的活化石：**补充式变格（suppletion）**。

什么意思？

正常的比较级：tall → tall**er**，dark → dark**er**。词根不变，加 -er。
但 bad → worse？词根整个换了。这就像中文的"好"的反义词不是"不好"而是突然蹦出一个完全不相关的字。

**bad、worse、worst 不是一家人。** worse 和 worst 是亲兄弟（同一个日耳曼词根），但 bad 是半路领养来的。

### 历史流变

| 时间层 | 形式 | 含义 |
|---|---|---|
| **原始印欧语** | \*wers- | **搅混、搞乱、使困惑**（to confuse, to mix up） |
| **原始日耳曼语** | \*wersizô | 更混乱的、更糟的（比较级） |
| **古英语**（约 700-1100） | *wiersa*（形容词）/ *wiers*（副词） | 更坏的——此时它是 **yfel**（evil）的比较级 |
| **中古英语**（约 1100-1500） | *werse / worse* | bad 逐渐取代 evil 成为"坏"的默认词，worse 跟着换了主人 |
| **现代英语** | worse | bad 的比较级（同时兼任形容词、副词、名词） |

### 文化地层：这个词的两次"换主人"

**第一次（古英语时期）**：worse 原本是 **evil（yfel）** 的比较级。当时的英语说的是 "yfel → wiersa → wierrest"（evil → worse → worst）。逻辑自洽——evil 是"坏"的正词，worse/worst 是它的比较级和最高级。

**第二次（中古英语时期）**：bad 这个词杀进来了。bad 的来源至今存疑（可能来自古英语 bæddel，含义与"雌雄同体"有关，后来泛化为贬义，但学界没有定论）。bad 抢了 evil 的地盘，成了日常用的"坏"，但它自己没带比较级——于是 worse 和 worst 被 bad 继承了过来。evil 退居二线，专门表达道德层面的"邪恶"。

这就是为什么 bad-worse-worst 看起来毫无关联：**它们确实毫无关联。** 是历史的拼贴，不是同一棵树上长出来的。

英语里这种"补充式变格"极少，数得过来：
- **good → better → best**（good 和 better/best 也不同源）
- **bad → worse → worst**
- **go → went**（went 本来是 wend 的过去式，被 go 偷了）

每一个都是语言考古的宝藏。

### PIE 词根 \*wers- 的后代

这个"搅混"的词根还留下了一个重要的（存疑的）后代：**war**。

从法兰克语 \*werra（混乱、纷争）→ 古法语 werre → 英语 war。如果这条线成立，那 worse 和 war 共享同一个"混乱"的祖先——"更混乱"和"大规模混乱"，同根不同枝。但这条词源链在学界有争议，标注为**存疑**。

## 3. 故事 / 画面

一杯清水。

有人往里滴了一滴墨。水还能喝吗？大概还行。但你已经看到那一缕黑在水里扭动扩散了。

又滴了一滴。

水变 worse 了。不是说水"坏了"——第一滴墨落下去的时候它就不纯净了，那叫 bad。worse 是**第二滴**。是你眼看着那团浑浊在扩大，秩序在一点一点坍塌，而你知道它回不去了。

worse 永远是一个**方向**，不是一个**位置**。它不描述你在哪，它描述你在往哪滑。这就是为什么 worse 的祖先是"搅混"——浑浊只有一个方向，不可逆。

## 4. 多面体：核心义项展开

### ① 形容词：更坏的（bad 的比较级）

> *The traffic is worse than yesterday.*
> 交通比昨天更糟。

最基础的用法。注意 worse 是**相对的**——它永远需要一个比较对象（than...），或者一个隐含的基准。worse 不能独立存在，就像"第二滴墨"必须有"第一滴"才成立。

### ② 副词：更糟糕地（badly 的比较级）

> *She performed worse under pressure.*
> 她在压力下表现得更差了。

这里 worse 修饰动词。注意：badly → worse → worst，又一组补充式变格（badly 和 worse 也不同源）。

### ③ 名词：更坏的事态

> *I've been through worse.*
> 我经历过更糟的。

worse 名词化，指代"更坏的那个东西/状况"。这个用法在口语中极其高频——用一个词浓缩了整个比较结构。

### ④ 习语核心：for better or for worse

> *For better or for worse, this is the path we've chosen.*
> 不管结果好坏，这就是我们选的路。

婚礼誓词的标准措辞。worse 在这里代表"一切可能的下行空间"——从小波折到大灾难，一个词全兜住。

**底层统一性**：所有义项都指向同一件事——**在"坏"的轴线上再往下移了一格**。worse 不是一个静态的描述，是一个矢量，有方向。

## 5. 裂缝标注

### 常见误用

**❌ "The situation is worse."——没有比较对象的悬空 worse**

严格来说，worse 需要 than 或隐含基准。"The situation is worse" 在口语中可以接受（听者能推断"比之前更糟"），但在正式写作中最好补上 than 从句或明确基准。

**❌ "more worse"——双重比较级**

worse 本身已经是比较级，不需要 more。这个错误初级学习者常犯（类似 "more better"）。但注意：在莎士比亚时代 "more worse" 是合法的（*The Tempest* 里就有），只是现代英语不再接受。

### 易混近义词辨析

**worse vs. worst**

- worse = 两者比较中更差的那个（比较级）
- worst = 所有里面最差的（最高级）

> *This is worse than last time.* ✅（两次比较）
> *This is the worst day of my life.* ✅（所有日子里最差）
> *This is the worse day of my life.* ❌

**worse vs. inferior**

- worse 是日常用语，适用范围广，可以用于任何"更糟"的场景
- inferior 更正式，常用于质量、地位的比较，且搭配 **to** 而非 than

> *This product is inferior **to** that one.*（不说 inferior **than**）

### 中文母语者陷阱

**"更坏"≠ worse 的全部**

中文里"坏"主要指道德上的坏或物理上的损坏。但 worse 的覆盖面宽得多——天气更差、成绩更低、病情更重、心情更糟——这些在中文里不一定都用"更坏"来说，但英文一律可以用 worse。

**"差不多"的反义陷阱**

中文母语者有时会在该用 worse 的地方用 "not as good"。两者方向一样，但力度不同——"not as good" 是委婉的，worse 是直接的。在需要明确传达"情况恶化了"的语境下，worse 更精准。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **get worse** | 最常见的动态搭配——"情况在恶化"。*The pain is getting worse.* |
| **make worse** | 使恶化。*Don't make things worse.* 日常口语高频 |
| **even worse** | 强化语气，"更糟的是"。常用于叙事中追加坏消息 |
| **worse than expected** | 新闻/财报标配。*Sales were worse than expected.* |
| **could be worse** | 安慰用语——"还不算最糟"。语气是乐观的，带点自嘲 |
| **for the worse** | 固定搭配，"往坏的方向"。*Things took a turn for the worse.* |
| **worse off** | 境况更差的（尤指经济状况）。*They're worse off than before.* |
| **none the worse** | 没受影响，安然无恙。*She was none the worse for the experience.* |

### 语域

worse 是**全语域通用词**——从总统演讲到酒吧吐槽都能用。它没有正式/非正式的限制，属于英语核心词汇（盎格鲁-撒克逊底层词汇，不是拉丁借词）。

越是底层的盎格鲁-撒克逊词，语域越宽。bad, worse, worst, good, better, best——这些词像空气一样没有场合限制。

### 活用示范

> *"The only thing worse than being talked about is not being talked about."*
> ——Oscar Wilde
>
> "唯一比被人议论更糟的事，是没人议论你。"

Wilde 用 worse 构建了一个悖论：你以为"被八卦"已经够惨了？worse 告诉你还有更低的一层——被彻底忽视。worse 在这里不是描述客观恶化，而是**重新定义了"糟糕"的坐标系**。

> *"It's going to get worse before it gets better."*
>
> "情况会先恶化，然后才会好转。"

这句话在医疗、政治、工程领域都是常客。worse 在这里是一个**过程中的必经阶段**——不是终点，是谷底之前的下坡。

## 7. 跨语言映射

**中文"每况愈下"**：四个字精准对应了 worse 的矢量感——不是"差"，是"越来越差"。但"每况愈下"是书面语/成语，而 worse 是日常词汇，两者语域差了一截。

**德语 schlimmer**：德语的 bad-worse-worst 是 schlimm → schlimmer → schlimmste，规则变化，没有英语这种"三个词三个来源"的混乱。这反过来说明英语的 bad-worse-worst 多么反常——连同属日耳曼语族的亲戚都没这个问题。

**日语的表达方式**：日语没有形态学上的比较级，说"更糟"用的是「もっと悪い」（motto warui）或「悪化する」（akka suru）——必须加一个额外的词来表达"更"。这让你意识到 worse 作为一个**单词就自带比较级功能**的效率有多高——一个音节完成了"更+坏"两层语义。
