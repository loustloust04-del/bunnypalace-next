# permission

---

## 1. 一句话本质

**permission 是一把别人手里的锁——你想通过，钥匙不在你兜里，你得让持锁人转一下。** 不是"能力"的问题，是"谁说了算"的问题。

---

## 2. 词源考古

### 词根词缀拆解

```
per-  +  miss-  +  -ion
穿过     放/送     名词后缀
```

- **per-**：拉丁前缀，"through, thoroughly"（穿过、彻底地）。跟 permeate（渗透）、permanent（永久）的 per- 是同一个。
- **miss-**（= mitt-）：来自拉丁语 **mittere**，"to send, to let go"（发送、放走）。这是一个巨大的词根家族——**mission**（被派出去的任务）、**missile**（被送出去的东西）、**dismiss**（dis- 散开 + 送 = 打发走）、**submit**（sub- 下 + 送 = 呈交）、**transmit**（trans- 跨越 + 送 = 传输）全出自这里。
- **-ion**：拉丁名词后缀，把动作变成"那个动作的结果/状态"。

合在一起：**per + mittere = permittere**，字面意思是"to let go through"——**让（某物/某人）穿过去**。

这个画面极其精准：一个关卡，有个守卫，他可以拦你也可以放你。Permission 就是他做出了"放你过去"这个动作。

### 历史流变

1. **拉丁语 permittere**（公元前）：本义是物理性的"让通过"，也引申为"容许、不阻拦"。罗马法中已经有了法律意义上的"准许"。

2. **古法语 permission**（约13世纪）：法语从拉丁语直接继承了名词形式 permission。拉丁语词根在法语里保持得几乎完整——这是因为法语本身就是拉丁语的直系后代。

3. **中古英语**（约14世纪传入）：通过诺曼法语进入英语。最初主要出现在法律和宗教文本中——你需要教会的 permission 做某事，需要领主的 permission 使用某块地。这个词从第一天起就带着**权力不对等**的气息：拥有 permission 的那个人，地位高于请求 permission 的人。

4. **现代英语**（16世纪至今）：含义稳定，没有剧烈漂移。但使用范围极大扩展——从法律/宗教领域渗透到日常生活的每一个角落。20世纪计算机时代给了它一个全新的生命：**file permissions**（文件权限）成了每个程序员的日常词汇。

### 文化地层

Permission 这个词的有趣之处不在于含义漂移（它其实非常稳定），而在于它折射出的**权力结构观**。

英语世界的法律和文化默认立场是：**没有被明确允许的事，不一定就是被禁止的**（这跟大陆法系的某些传统不同）。Permission 站在这条线的关键位置——它标记了"明确允许"这个动作的存在。在计算机系统里这被推到了极端：Unix 文件系统的 permission 模型（rwx）就是"没给权限 = 不能做"的强制执行版。

## 3. 故事 / 画面

想象一座中世纪城墙。城墙上有一扇小门，门边站着一个不苟言笑的守卫。

你扛着货物走到门前。你知道门后面是什么，你有腿、有力气、路也认得——你**有能力**过去。但你**不能**过去，因为那扇门上了栓，而守卫的手按在栓上。

你开口说了一句话。守卫打量你，点了点头，"咔嗒"一声，栓被抽开了。

那声"咔嗒"就是 permission。

注意几件事：
- 门是**别人的**门，不是你的。你请求 permission，本质是在承认"这个通道的控制权不属于我"。
- 守卫可以说 yes，也可以说 no。Permission **不是你有权要求得到的东西**，是别人选择给你的东西。
- 一旦栓被抽开，你可以走过去——但守卫随时可以把栓重新插上。Permission 可以被**收回**（revoked）。

这就是为什么 permission 和 right 的体感完全不同：right 是你自己的，谁也拿不走；permission 是别人给的，随时可以收。

## 4. 多面体：核心义项展开

### 义项 A：允许/许可（最核心义）

> "You have my permission to leave early."
> "你可以提前走。"（字面：你拥有了我的许可。）

守卫抽栓——持有权力的人做出了"放行"的动作。这是最基础的那层意思。

注意 "You have **my** permission" 这个说法暗含的权力关系：是"我的"permission，我给了你，你才有。

### 义项 B：正式批准/书面许可

> "The city granted permission for the construction project."
> "市政府批准了这个建筑项目。"

从口头的"你可以"变成了盖了章的公文。同一个守卫，但他不是口头点头了，而是签了一份文件。Permission 可以是一个**动作**，也可以是一个**文件/凭证**——从"放行"的动作变成了"放行令"。

### 义项 C：计算机权限

> "You don't have permission to access this file."
> "你没有权限访问这个文件。"

这是最完美的隐喻实体化：操作系统就是那个不苟言笑的守卫，文件就是门后面的东西，rwx 就是栓的三个档位（read / write / execute）。计算机把 permission 的抽象概念变成了可以用三个 bit 表示的精确状态。

### 义项 D：宗教/道德层面的容许

> "The doctrine of permission — God permits evil without causing it."
> "容许教义——上帝容许恶的存在但不是恶的制造者。"

神学里的 permission 是一个重要概念：上帝作为终极守卫，选择不阻拦某些事发生。不是赞同，不是鼓励，而是"本可以拦但没拦"。这跟日常用法一脉相承——permission 的底层是"有权阻拦的人选择了不阻拦"。

## 5. 裂缝标注

### 常见误用

**❌ "I permitted to go."**

Permission 的动词形式 permit 是及物的：**permit sb to do sth**，或者 **permit doing sth**。不能说 "I permitted to go"（缺了宾语），应该是 "I was permitted to go" 或 "He permitted me to go"。

**❌ 把 permission 当不可数名词然后又想说"一个许可"**

Permission 作为抽象概念是不可数名词（"ask for permission"，不加 a）。但当它指"一项具体的许可/权限"时，可以用可数形式（"file permissions"、"a special permission"）。很多学习者卡在这个双面性上。

**经验法则**：说"允许"这个抽象状态时 → 不可数，不加冠词。说"具体的一条条权限"时 → 可数，能加 a / 能加 s。

### 易混近义词辨析

| 词 | 核心区别 | 场景对比 |
|---|---|---|
| **permission** | 别人给你的允许，权力不对等 | "老师给了我 permission 提前离开" |
| **right** | 你本来就有的，不需要别人给 | "你有 right 保持沉默"——不需要任何人批准 |
| **consent** | 双方关系更平等，强调"同意" | "手术需要患者的 consent"——不是居高临下的批准 |
| **approval** | 偏重"认可、赞同"，含价值判断 | "方案获得了经理的 approval"——不只是"准了"，还有"觉得好" |
| **authorization** | 更正式，通常涉及制度/系统 | "你的 authorization 已过期"——系统级的、可编码的权限 |
| **license** | 正式颁发的、往往有期限的许可证 | "驾驶 license"——许可被凝固成了一张证件 |

最容易混的一对是 **permission** 和 **consent**：

- Permission：我问老师能不能提前走 → 权力不对等，老师有权拒绝。
- Consent：医生问我同不同意做手术 → 关系更平等，我有权拒绝。

两个词的**权力方向**是反的。Permission 是向上请求，consent 是向下征求。

### 中文母语者陷阱

**"允许"和"许可"覆盖了 permission 的大部分语义，但中文里没有一个词精确对应 permission 里隐含的那层"权力不对等"。**

中文说"我允许你走"和"你允许我走"用的是同一个词"允许"，但英文里这两个方向的体感完全不同。Permission 天然带有"求"的姿态——"ask for permission"（请求许可）、"with your permission"（蒙您恩准）。中文母语者往往低估了这个词里的权力落差，把它当成了中性的"可以"。

另一个陷阱：中文"没有经过允许"和英文 "without permission" 的严重程度不同。"Without permission" 在英文里可以是很严重的指控——未经许可闯入、未经许可使用他人作品、未经许可访问系统——每一个都可能是法律问题。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **ask (for) permission** | 最常见用法。"Ask permission before using someone's photo."（用别人照片前要先问。）注意 for 可省略。 |
| **give / grant permission** | 正式批准。"The board granted permission for the merger."（董事会批准了合并。） |
| **get / obtain permission** | 获得许可。"You need to obtain written permission."（你需要获得书面许可。） |
| **deny / refuse permission** | 拒绝。"Permission was denied."（许可被拒绝。）计算机里最常见的那个弹窗。 |
| **revoke permission** | 收回。"The app's permission was revoked."（应用的权限被收回了。） |
| **without permission** | 未经许可。法律语境的高频搭配，语气很重。 |
| **with sb's permission** | 经某人允许。正式场合的礼貌开场："With your permission, I'd like to begin."（承蒙允许，我开始了。） |
| **file permissions** | 计算机权限。"Check the file permissions."（检查文件权限。） |

### 语域

Permission 是一个**全域词**——从日常口语到法律文书到计算机术语，它都能出现，且含义不需要切换。这在英语词汇里其实不太常见（很多词在正式和非正式语域之间会换义或换词）。

- 日常口语：✅ "Can I have permission to use the car?"
- 正式书面：✅ "Written permission must be obtained prior to reproduction."
- 法律语境：✅ "Operating without the requisite permission constitutes a violation."
- 技术文档：✅ "Error: permission denied."

### 活用示范

> *"She didn't ask for permission. She asked for forgiveness."*
> "她没有事前请求允许，她事后请求了原谅。"

这句话（或其变体 "It's easier to ask for forgiveness than permission"）是硅谷文化里的一句名言，通常归于 Grace Hopper 海军少将。它精准地利用了 permission 的核心语义——"事前向掌权者请求放行"——然后用 forgiveness 做了一个漂亮的反转：与其在门前等守卫同意，不如先闯过去，事后再道歉。

> *"You don't need anyone's permission to be yourself."*
> "做你自己不需要任何人的许可。"

这是心理学 / 自我成长语境里 permission 的经典活用。它之所以有力量，恰恰因为 permission 暗含了权力不对等——这句话在说：那个你以为存在的守卫，其实不存在。

## 7. 跨语言映射

**拉丁语 permissio**：现代英语 permission 的直系祖先，含义几乎没变。法律文献中大量出现。

**法语 permission**：拼写完全一样（发音不同），含义完全一样。法语里还有一个军事专用义——"permission" 在法军中指"休假"（从军事义务中被"放行"去休息）。英语里没有这个义项。

**德语 Erlaubnis**：er-（out）+ laub-（相信/信任）+ -nis（名词后缀）。有趣的是，德语走了一条完全不同的构词路线——permission 强调的是"让你穿过"，Erlaubnis 强调的是"对你有信任"。两种语言对同一个概念的建模方式不同：英语/拉丁语看到的是**物理关卡**，德语看到的是**信任关系**。

**日语 許可（きょか）**：汉字"许可"——"许"是答应，"可"是可以。构词方式比 permission 更直白：就是"说了可以"。没有 permission 里那个"穿过关卡"的空间隐喻。

**中文"批准"vs"许可"vs"允许"**：中文在这个语义区间有一组近义词，但没有一个词精确对应 permission 里"钥匙在别人手里"的那种体感。"批准"最接近，因为"批"字有上级审阅的含义——但 permission 不一定涉及"审阅"，守卫不需要看你的材料，他只需要决定让不让你过。
