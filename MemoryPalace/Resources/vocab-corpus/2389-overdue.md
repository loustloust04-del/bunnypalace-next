# overdue

---

## 1. 一句话本质

**overdue 是一种欠债感——不是你欠了什么，是时间欠了你一个交代。** 该来的没来，该发生的没发生，你站在截止线的另一边，手里攥着一张过了期的期待。

---

## 2. 词源考古

### 词根词缀拆解

```
over-  +  due
超过      应得的 / 到期的
```

两层都值得拆：

**due** ← 中古英语 *deu* ← 古法语 *deu/dü*（devoir"欠"的过去分词）← 拉丁语 **dēbitum**（所欠之物）← **dēbēre**（欠）

而 **dēbēre** 本身还能拆：**dē-**（从……离开）+ **habēre**（拥有）。字面意思是"从某人那里拿走了拥有的东西"——你拿了，所以你欠。这个"欠"的基因从拉丁语一路传到了现代英语的 due、debt、debit，全是一家人。

**over-** ← 古英语 *ofer*，日耳曼语族的老居民，意思是"越过、超出"。在 overdue 里，over- 不是"在上方"，是"超出了那个该到的点"。

所以 **overdue = 超出了该到期的时间**。不是"迟到"那么简单——它暗含一个前提：有一个明确的"应当"，而现实越过了那条线。

### 历史流变

overdue 作为合成词出现得并不算早。英语里 due 在14世纪就有了（最初拼 *deu*），但 **overdue 要到1840年代**才开始在书面语中频繁现身，最早的语境几乎全是**商业和金融**——过期的票据、逾期未付的账款。

这不奇怪。19世纪中叶正是英国维多利亚时代工业革命的高峰期，商业信用体系膨胀，"按时还款"成了社会运转的齿轮。需要一个词来精确描述"到期了但没兑现"这个状态——overdue 就填上了这个坑。

从1850年代起，overdue 开始从账本爬出来，进入更日常的语境：**overdue ship**（过了预计到港时间的船）、**overdue letter**（该到没到的信）。到了20世纪，它的使用范围彻底炸开——overdue baby（过了预产期的孩子）、overdue reform（早该推行的改革）、long overdue recognition（迟来的认可）。

### 文化地层

overdue 有一层有意思的语义漂移：它从"中性的时间描述"逐渐带上了**道德压力**。

最初，说一笔账 overdue，只是陈述事实——过了日期了。但到了 *long overdue* 这个搭配成型之后，整个词的情感色彩变了。说 "This conversation is long overdue" 不是在看钟表，而是在说：**我们早就该谈了，拖到现在本身就是一种亏欠。**

这就是 due 里那个"欠"的基因在发作——overdue 不仅仅是"晚了"，它暗示着**有人该为这个"晚"负责**。

## 3. 故事 / 画面

图书馆的自助还书机旁边，有一个塑料箱，上面贴着手写标签："OVERDUE"。

箱子里躺着各种书。有的书脊还很新，是上周借的、这周忘了还；有的已经被翻到卷边，借阅卡上的日期是三个月前。箱子不挑剔，它只认一件事：**你答应过一个日期，那个日期已经过了，而你手里的东西还没归还。**

但你注意到一个细节——箱子里没有从来没人借过的书。overdue 的前提是 **有人在等**。一本从没被期待过的书不可能逾期。一封从没被寄出过的信不可能迟到。overdue 的疼，不是来自时间本身，而是来自**某个被辜负的期待**。

图书馆的罚金是五毛钱一天。但 overdue 真正罚你的，是每次路过还书箱时那一小下心虚。

## 4. 多面体：核心义项展开

### 义项 A：到期未付 / 逾期（原始金融义）

> *Your payment is 30 days overdue.*
> 你的款项已逾期30天。

最原始的脸。一笔债到了该还的日子，但钱没到。overdue 里的 due 在这里是最字面的"到期"——你欠的东西过了期限。

### 义项 B：迟到、过了预计时间

> *The train is twenty minutes overdue.*
> 火车晚了二十分钟。

从"欠款没到"延伸到"任何该到没到的东西"。火车、航班、包裹、来信——它们不欠你钱，但它们欠你一个**准时的到达**。overdue 的底层逻辑不变：有一个约定的时间点，现实超过了它。

### 义项 C：早该发生的（最常用、最有情感重量的义项）

> *This reform is long overdue.*
> 这项改革早就该推行了。

> *A frank discussion about money was overdue between them.*
> 他们之间早就该坦率地谈谈钱的问题了。

这是 overdue 用得最多、最有味道的脸。它不再指向具体的截止日期，而是指向一种**集体共识**——所有人都觉得这件事早该发生了，但它就是一直没发生。long overdue 几乎成了一个固定搭配，自带一股压了很久终于要爆发的张力。

**底层统一性**：三个义项的共同内核是——**一个"应当"被越过了**。不管是账单的到期日、火车的时刻表，还是社会对某件事的心理预期，overdue 永远指向同一个结构：**期待在左，现实在右，中间隔着一段不该存在的空白。**

### 义项 D：过了预产期的

> *She's a week overdue — the doctor might induce labor.*
> 她过了预产期一周了——医生可能要催产。

一个非常具体但高频的用法。这里 overdue 的主语是孕妇或胎儿，due date 就是预产期。整个短语浓缩了等待、焦虑和"怎么还不来"的复杂情绪。

## 5. 裂缝标注

### 常见误用

**❌ 把 overdue 当 "late" 的正式同义词随便换**

overdue 比 late 重。late 只是"晚了"，overdue 带有"本应到期"的结构——它预设了一个 deadline 或 expectation。你可以说 "Sorry I'm late"（抱歉我迟到了），但不会说 ~~"Sorry I'm overdue"~~。overdue 不用于描述人的迟到，除非你是一个过了预产期的胎儿。

**❌ 用 overdue 描述"还没开始"**

overdue 描述的是"该完成/该到达但还没"，不是"该开始但还没开始"。一个项目如果还没启动，你说的是 "We should have started this" 或 "This is long overdue"（指它作为成果早该存在了），但不能说 ~~"Starting this project is overdue"~~——要说的话得是 "This project is overdue" 或 "Starting this is long overdue"。

### 易混近义词辨析

| | overdue | late | belated | delayed |
|---|---|---|---|---|
| 核心差异 | 过了**该到期的点** | 晚了（泛指） | 来得比**合适的时间**晚 | 被**外力推迟** |
| 谁的错？ | 暗示有责任方 | 不追究 | 不追究，但有歉意 | 强调客观原因 |
| 典型搭配 | overdue payment/reform | late arrival/night | belated birthday wishes | delayed flight |

关键区分场景：
- "迟来的生日祝福" = **belated** birthday wishes（我忘了，补上，带歉意）
- "早该有的对话" = **overdue** conversation（不是忘了，是一直在回避）
- "航班延误" = **delayed** flight（不是航空公司故意的，是天气/机械原因）

### 中文母语者陷阱

**"过期" ≠ overdue 的全部**

中文里"过期"可以指牛奶过期、签证过期、优惠券过期——东西失效了。但英文里牛奶过期是 **expired**，签证过期是 **expired**，优惠券过期是 **expired**。overdue 不是"失效"，是"该兑现的还没兑现"——它描述的是一个**悬而未决的状态**，不是终止。

你的图书馆书 overdue 了，书还在你手里，你还得还——它不是"作废了"，是"欠着呢"。

## 6. 搭配与语域

### 高频搭配

- **long overdue** — 最高频搭配，几乎自成一个词组。"早就该……了"。带累积的压力感。*"This apology is long overdue."*
- **overdue payment / bill / rent** — 金融老本行。逾期付款。
- **overdue for** — "早该接受……了"。*"The building is overdue for renovation."*（这栋楼早该翻修了。）
- **overdue library book** — 经典场景，几乎成了 overdue 的代言物。
- **overdue baby** — 过了预产期。口语高频。
- **overdue reform / change / conversation** — 用于社会/政治语境，带批评意味。

### 语域标注

overdue 是一个**中性偏正式**的词，但它的使用范围极广：

- 📰 **新闻/社论**：最爱用 "long overdue" 来表达"这事早该做了"的立场
- 📝 **书面/正式**：商业信函里的 "overdue invoice" 是标准用语
- 💬 **日常口语**：完全可以说 "I'm overdue for a haircut"（我早该去剪头发了）——轻松、自嘲
- 🏥 **医学**：overdue pregnancy / overdue baby 是标准临床用语

### 活用示范

> *"I know this is long overdue, but — I'm sorry."*
> "我知道这句话来得太晚了，但是——对不起。"

这句话里 overdue 的分量不在"晚"上，在"我一直知道该说但一直没说"上。long overdue 的 apology 比 late apology 疼得多——因为它承认了拖延本身就是一种伤害。

> *"He was overdue for some good luck."*
> "老天爷欠他一份好运气太久了。"

这里 overdue 被用来描述命运的"欠债"——不是真的有人记着账，但说话人觉得这个人受够了，universe 该还他一点甜头了。日常口语里这种拟人化用法很有温度。

## 7. 跨语言映射

**中文**里最接近的是**"早该"**和**"逾期"**——但它们各拿了 overdue 的一半。"逾期"精确覆盖了金融/时间义，但太干，没有情感；"早该"覆盖了 long overdue 的那种积压感，但缺少"到期"的结构。中文要表达 overdue 的完整语义，往往需要一整个句子："这件事拖得太久了" / "早就该……了"。

**日语**里 **期限切れ**（kigen-gire）对应"过期"义但偏 expired；**延滞**（entai）对应金融逾期但缺 long overdue 的情感色彩。

**德语**有 **überfällig**——结构上和 overdue 几乎同构：**über-**（over）+ **fällig**（due, 到期的）。用法范围也高度重合，包括 *längst überfällig*（= long overdue）。德语在这里和英语走了一模一样的造词路。

**法语**回到了 due 的老家——**en retard**（迟了）或 **en souffrance**（处于悬而未决的痛苦状态，商业用语，指逾期未兑现的票据）。*en souffrance* 这个说法很有意思：一张逾期的支票在法语里是"在受苦的"——仿佛不是你在等它，是它自己也难受。
