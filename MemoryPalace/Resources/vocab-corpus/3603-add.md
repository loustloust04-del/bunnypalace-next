# add

---

## 1. 一句话本质

**add 是一只手把东西放到已经存在的东西旁边的那个动作——不是从无到有，是从有到更多。**

桌上已经有一杯咖啡了。你拿起糖罐，倒了一勺进去。糖不是凭空出现的，咖啡也不是你造的——你只是让它们在一起了。这就是 add 的全部。

---

## 2. 词源考古

### 词根词缀拆解

```
add = ad- + dare
      ↓      ↓
     "to"  "to give"
     朝向    给予/放置
```

**ad-**：拉丁前缀，"朝向、到……上去"。这个前缀你见过无数次——adapt（使适应）、adhere（黏附）、advance（前进）——全是"朝某个方向去"的意思。

**dare**：拉丁语"给"。注意，这不是英语的 dare（敢），而是拉丁语的 dō, dare, dedī, datum——"给予、放置"。它的印欧语祖先是 *deh₃-（给），这个词根还活在 data（被给出的东西→数据）、date（指定的日期）、donate（捐赠）里。

所以 **addere 的字面意思是"给到……上面去"**——你手里有个东西，你把它"给"到已有的那堆东西上。从"给予"到"添加"，语义漂移只走了半步：当你给某样东西一个伙伴的时候，那就是 add。

### 历史流变

| 时期 | 形态 | 含义 |
|------|------|------|
| 印欧语 | \*deh₃- | 给 |
| 拉丁语 | addere (addō, addidī, additum) | 放到旁边、加上去、接上 |
| 14世纪中叶 | 英语 adden | 从拉丁语直接借入，最初用于"把话接上去" |
| 16世纪 | add | 数学含义出现（受拉丁数学传统影响） |
| 现代 | add | 义项全面展开 |

**关键转折：** add 进入英语的方式很不寻常。大多数英语的基础动词——run、put、take、make、do、eat——都是日耳曼土著词。但"添加"这个概念，古英语没有留下一个存活至今的专用单词。古英语说的是 *tō dōn*（做到上面去）或 *tō lecgan*（放到上面去），全是短语式表达。14世纪从拉丁语借来 add 之后，它一下子填了这个词汇空缺——简洁、精确、一个音节搞定。

### 文化地层

add 的完美动词 addidī 是重叠式（re-duplicated perfect），这是 dare 的标配——dedī → 在复合词中变成 addidī。这个形态上的指纹证明它确实是 dare 的亲生后代，不是后人胡编的词源。

有趣的是，add 的数学义是后来长出来的。最早进入英语时，add 主要是"接着说"的意思——"And," she added, "I don't think so." 这个"追加言辞"的用法比"1+1=2"还要古老。是拉丁数学传统（addere numeros，把数字放到一起）在16世纪带来了算术含义。

## 3. 故事 / 画面

一面墙。

工人已经砌了十二层砖，砂浆还没干透。另一个工人弯腰从地上捡起一块砖，抹上灰浆，压到第十二层上面。

这块砖没有改变下面那十二层的任何一块。墙还是那面墙。但现在它多了一层。

**add 就是这块砖落上去的那一下。** 不需要拆掉旧的，不需要重建，不需要替换——只是让已经存在的东西，多了一个成员。

这面墙还会继续砌。每一块砖都是一次 add。最终它变成一栋房子——但没有任何一次 add 是"建造"，每一次都只是"再放一块上去"。

这就是 add 和 create/build 的根本区别：add 从不宣称自己在做大事，它只做一个动作——**把东西放过去**。

## 4. 多面体：核心义项展开

### 义项一：物理添加（放进去/放上去）

> *Add a pinch of salt to the soup.*
> 往汤里加一撮盐。

最原始的 add——手里有东西，放到已有的东西上/里。和拉丁语 addere 的本义一模一样，两千年没变。

### 义项二：接着说（追加言辞）

> *"I won't be coming back," he added quietly.*
> "我不会回来了，"他轻声补充道。

**add 进入英语时最早的义项。** 对话已经在进行了，你"再放一句上去"。你看——句子是砖，对话是墙。和义项一的结构完全相同，只是从物理世界搬到了语言世界。

### 义项三：数学加法

> *Add 7 and 5 and you get 12.*
> 7 加 5 等于 12。

把两个数"放到一起"，得到一个总和。这个义项是16世纪从拉丁数学传统继承来的。注意：数学的 add 比日常的 add 多了一层——它不只是"放在旁边"，还暗含"合并成一个新的整体"。

### 义项四：增添（抽象的"让某种性质变多"）

> *The flowers add a touch of color to the room.*
> 这些花给房间添了一点颜色。

房间已经在那了，花的存在让某种品质（颜色）"多了一层"。从物理的"放进去"到抽象的"贡献了某种效果"，仍然是同一个底层动作：**在已有之上，再给一个。**

### 义项五：add up（累积 / 说得通）

> *The costs add up quickly.* — 费用很快累积起来。
> *Something doesn't add up.* — 有什么地方不对劲（算不拢）。

两个方向的延伸。字面方向：一块砖一块砖地加，最终加成了一面墙（累积）。隐喻方向：如果你把所有证据"加在一起"却得不出一个合理的总数，那就是"doesn't add up"——账对不上，逻辑通不了。

**底层统一性：** 五个义项，同一个动作——"把一个东西放到已有的东西旁边"。区别只在于"东西"是盐、是话语、是数字、是品质、还是证据碎片。

## 5. 裂缝标注

### 常见误用

**❶ add 不能不说加什么**

> ❌ *The population added.*（人口增加了）
> ✅ *The population increased / grew.*

add 是及物动词居多——你得说清楚加的是什么。"人口增加了"不能用 add，因为你没有说"把什么放到人口上"。用 increase、grow、rise。

唯一的例外是 add up（不及物），但那已经是固定短语了。

**❷ add 不等于 plus**

> ❌ *Add, he's also rude.*（而且他还很粗鲁）
> ✅ *Plus, he's also rude.*

中文思维里"加上"可以当连接词用（"加上他还迟到"），英语的 add 绝对不能这么用。"另外、加上"要用 plus / besides / on top of that。

### 易混近义词辨析

| 词 | 核心区别 |
|---|---|
| **add** | 把 A 放到已有的 B 旁边。A 和 B 共存。 |
| **increase** | 让一个量变大。不关心"是不是放了个新东西进去"。*The price increased*（价格涨了）—— 没有"加了什么"。 |
| **include** | 画一个圈，宣布某东西在圈内。强调"属于"而不是"放入"。*The price includes tax*（价格含税）——税一直在那，不是你加的。 |
| **append** | 专门在**末尾**加。add 可以加到任何位置，append 只能加到尾巴上。写代码的人秒懂。 |
| **supplement** | 原来不够，加一点补上。有"补缺"的含义，add 没有。 |

### 中文母语者陷阱

**"加" ≠ add 的所有用法：**

- "加油"不是 *add oil*（虽然这个 Chinglish 已经被牛津收录为非正式用法了，但正式语境不能用）
- "加班"不是 *add work*，是 *work overtime*
- "增加信心"不是 *add confidence*，是 *boost / build confidence*

中文的"加"比 add 宽得多。add 始终需要一个清晰的"被加的东西"和"被加到的地方"，而中文的"加"可以很虚很泛。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 例 |
|------|------|---|
| **add value** | 商业 | *How does this feature add value for users?*（这功能给用户带来什么价值？）—— 商务黑话排行榜前十 |
| **add fuel to the fire** | 通用/新闻 | *His comment added fuel to the fire.*（他的话火上浇油）—— 几乎是固定成语 |
| **add insult to injury** | 通用 | *To add insult to injury, they charged me for parking.*（雪上加霜的是，他们还收了我停车费）—— 极高频习语 |
| **add up to** | 数学/抽象 | *The donations add up to $50,000.*（捐款总计达五万美元） |
| **add to the list** | 日常 | *Add it to the list.*（加到清单上） |
| **add a touch of** | 美食/设计 | *Add a touch of lemon.*（加一点柠檬）—— 注意 touch 用得精妙，暗示"少量" |
| **nothing to add** | 正式/会议 | *I have nothing to add.*（我没什么要补充的）—— 会议结束语标配 |
| **added bonus** | 日常 | *As an added bonus, it's free.*（额外的好处是，它还免费）—— 注意 added 做形容词 |

### 语域标注

add 是**全频谱词**——从口语到学术、从菜谱到法律文件，到处能用，没有正式度限制。这一点非常少见。大多数拉丁源动词在英语里偏正式（如 commence、facilitate、endeavor），但 add 因为太基础太高频，早就脱掉了拉丁语的"西装"，变成了一个赤脚走路的词。

### 活用示范

> *Each lie added another layer to the wall between them.*
> 每个谎言都在他们之间的墙上添了一层。

——add 在这里既是字面的（加一层），又是隐喻的（制造隔阂）。精准、朴素、有力。

> *"And one more thing," Jobs would add, pausing for effect.*
> "还有一件事，"乔布斯会补上这么一句，然后停顿一下制造效果。

——add 在这种叙事中比 say 高级：它暗示前面已经说了一堆，这句是锦上添花或压轴。

## 7. 跨语言映射

**拉丁语 addere** → 几乎所有罗曼语都保留了这个词的后代：
- 法语 **ajouter**（a- + jouter，从拉丁 juxta "旁边" 重构的，反而丢掉了 addere 的直系血统）
- 西班牙语 **añadir**（从拉丁 *inaddere 变来）
- 意大利语 **aggiungere**（同样从 "放在旁边" 重构）

有意思的是，罗曼语系的亲儿子们反而没有直接继承 addere 的形态，倒是英语这个日耳曼语系的外人，直接从拉丁文本里把 add 抄了过来，形态几乎没变。英语就是这样一个不讲出身的语言——好用就拿。

**德语 hinzufügen**：hin（往那边）+ zu（到）+ fügen（拼接）。三个词素拼出来 add 一个音节就搞定的事。日耳曼语系的"诚实"——每个语义成分都摊在桌面上。

**中文的"加"** 比 add 广得多。"加油"、"加班"、"加速"、"加入"——中文的"加"可以完全不指向一个具体的被添加物，而 add 几乎总是要求你说清楚 add **what**。这是两种语言对"增加"这个概念的不同切割方式：中文用一个字覆盖一大片语义区，英语用 add / increase / boost / supplement / append 等一群词各管一小块。
