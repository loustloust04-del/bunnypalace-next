# data

## 1. 一句话本质

**data 是别人递到你手里的东西——不是你发现的，不是你创造的，是"给定的"。** 它最原始的意思就是"已经摆在那儿的事实"，你拿着它去推理、去计算、去决策。在 data 的世界观里，事实先于思考存在。

---

## 2. 词源考古

### 词根词缀拆解

```
data ← 拉丁语 datum 的复数形式
datum ← 拉丁语动词 dare（给予）的过去分词中性形式
dare ← 原始印欧语 *deh₃-（给）
```

**dare** 是拉丁语里最基础的动词之一，"给"。它的过去分词是 **datum**——"被给出的东西"。**data** 是它的复数：**"那些被给出的东西们"**。

同根词家族极其庞大，很多你想不到的词都是亲戚：

- **date**（日期）——中世纪拉丁语写信落款 *datum Romae*（"给出于罗马"），datum 从"给出"变成了"给出的时间点"，最终缩写成了 date
- **donate**（捐赠）——*donare*，dare 的加强形式
- **pardon**（原谅）——*per-* + *donare*，"完全给予"→ 宽恕
- **tradition**（传统）——*tradere*（*trans-* + *dare*），"递过去"→ 代代相传的东西
- **betray**（背叛）——古法语 *trair* ← 拉丁语 *tradere*，"交出"→"出卖"
- **render**（渲染/递交）——通过古法语，最终也追溯到"给回去"
- **edition**（版本）——*e-* + *dare*，"给出去"→ 出版

一个"给"字，生出了日期、传统、背叛、捐赠、原谅……这棵家族树本身就是一部人类关系史。

### 历史流变

**17世纪**：data 进入英语时，是个哲学/神学术语。在经院哲学里，*data* 指"已知的前提"——逻辑推理的起点，那些不需要证明、直接"给定"的公理。你不质疑 data，你从 data 出发。

**18世纪**：含义扩展到科学领域。实验结果、观测记录开始被叫做 data——"实验给出的东西"。这时候 data 还是严格的复数形式，*"the data are"*。

**19世纪末-20世纪**：统计学兴起，data 成了统计学的核心词汇。它开始从"一组具体的事实"向"可被处理的原材料"漂移。

**1946年之后**：计算机时代来临。这是 data 的命运转折点。它从"给定的事实"变成了"可被机器读取、存储、传输的信息"。含义从哲学的"前提"坍缩成了技术的"比特"。同时，data 作为不可数名词（mass noun）的用法开始碾压复数用法——*"the data is"* 逐渐取代 *"the data are"*。

**21世纪**："Big Data" 时代。data 成了一种隐喻性的资源、货币甚至武器。"Data is the new oil" 这句话标志着 data 完成了从哲学概念到经济概念的全程漂移。

### 文化地层

最戏剧性的转折：**data 原本是推理的"起点"，是人不质疑的东西；现在 data 是人类最不信任的东西之一。** "Data can be manipulated"（数据可以被操纵）这种说法，放在17世纪的哲学家面前，是一句逻辑上的胡话——给定的前提怎么能被操纵？但今天每个人都懂。

这个语义反转本身就是一面镜子：人类从相信"事实是客观给定的"，走到了"所有事实都是被选择性呈现的"。

## 3. 故事 / 画面

一张法庭的证据桌。

桌上摆着一排透明的盒子，每个盒子里装着一样东西：一张照片、一段录音、一份账单、一个指纹。它们不说话，不辩解，不主张。它们只是**被放在那里**。

是检察官把它们摆上桌的。是辩护律师决定要不要反驳它们。是法官判断它们够不够。但这些盒子本身——它们不属于任何一方。它们是**给定的**。

这就是 data 最深处的画面：**不是答案，是被摆上桌的原材料。** 谁摆的、怎么摆的、摆了什么没摆什么——这些问题决定了 data 的命运。但 data 自己，永远是那个沉默的、被给出的东西。

现在把法庭换成服务器机房。盒子变成了字节。桌子变成了数据库。但那个结构没变：**data 是被递过来的，等着被处理的。**

## 4. 多面体：核心义项展开

### 义项一：实验/观察获得的事实（科学义）

> *The data suggest a strong correlation between sleep deprivation and cognitive decline.*
> 数据表明睡眠不足与认知衰退之间存在强相关。

这是最接近拉丁语原义的用法——"实验给出的东西"。注意这里 data 隐含一个前提：**我没有编造它，它是现实递给我的。**

### 义项二：计算机可处理的信息（技术义）

> *The app collects user data including location, browsing history, and purchase records.*
> 该应用收集用户数据，包括位置、浏览记录和购买记录。

从"事实"到"比特流"。这个义项里，data 不再强调"真实性"，而是强调"可被机器读取"。一段乱码也是 data，一条假信息也是 data。**"被给出"的重心从"真实"滑向了"可处理"。**

### 义项三：决策的依据（商业/日常义）

> *We need more data before making this decision.*
> 做这个决定之前我们需要更多数据。

这里 data ≈ evidence（证据）+ information（信息）。它的底层逻辑还是拉丁语那个："先有给定的前提，然后才能推理。"——**你不能凭空决策，你得先有东西摆在桌上。**

### 义项四：datum 的残存（测量基准点）

> *The datum point for elevation measurements is mean sea level.*
> 海拔测量的基准点是平均海平面。

这是 datum（单数形式）在测量学和工程学中的专用义。一个"被给定的参考点"——你不质疑它，你从它开始量。**这是最忠于拉丁语本义的用法，反而成了最冷门的那个。**

## 5. 裂缝标注

### 常见误用场景

**❌ "Data proves that..."（数据证明了……）**

Data 不 prove 任何东西。Data suggest / indicate / show / support。数据是原材料，不是结论。说"数据证明了"是把 data 当成了 conclusion。学术写作里这是硬伤。

**❌ 把 data 和 information 混用**

严格来说：data 是未经处理的原始记录，information 是 data 被组织、解读之后的产物。"37.2°C" 是 data；"患者体温正常" 是 information。日常口语混用没问题，但在技术写作和学术语境里要区分。

### data is vs. data are

这是英语里最著名的语法争论之一。

- **学术/科学写作**：很多期刊仍然要求 *"the data are"*（复数），因为 data 是 datum 的复数形式
- **日常英语 + 科技行业**：*"the data is"*（不可数名词）已经是主流
- **安全策略**：如果你不确定读者的偏好，用 *"the data show / the data suggest"*——动词原形，不暴露单复数

### 中文母语者陷阱

**"数据"和 data 的语义范围不完全对等。** 中文"数据"强烈暗示"数字"——数据分析、数据报表。但英文 data 不一定是数字。一段采访录音是 data，一堆问卷上的文字回答是 data，一组照片是 data。**Data = 任何被收集的原始材料，不限于数字。**

另一个陷阱：中文说"数据很大"指数据量大，但英文不说 *"the data is big"*。你说 *"a large dataset"* / *"a large volume of data"*。"Big Data" 是个专有名词（大数据），不是形容词+名词的自由组合。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **collect data** | 收集数据——最基础的动作搭配，科研/商业通用 |
| **raw data** | 原始数据——未经处理的，强调"刚从现实手里接过来" |
| **data-driven** | 数据驱动的——形容决策方式，商业/科技高频词 |
| **data breach** | 数据泄露——信息安全语境，2010年代后爆炸性增长 |
| **empirical data** | 实证数据——学术写作专用，强调"来自观察而非理论" |
| **anecdotal data** | 轶事性数据——带贬义，暗示"不够严谨、样本不够" |
| **crunch the data** | 处理数据——口语化，带一种"苦力活"的感觉 |
| **data point** | 数据点——单个观测值，也常比喻性地指"一条证据" |

### 语域标注

**全语域通杀。** 从学术论文（*empirical data*）到日常对话（*I don't have enough data to say*）到商业报告（*data-driven decision-making*）到隐私讨论（*who owns my data?*）——data 是少数几个在所有语域都完全自然的词。

没有正式程度限制，但不同语域里它的"味道"不同：学术里它意味着"证据"，商业里它意味着"资源"，日常里它意味着"根据"，隐私讨论里它意味着"你的个人信息"。

### 活用示范

> *In God we trust; all others must bring data.*
> 我们信上帝；其他人请带数据来。
> ——常被归于统计学家 W. Edwards Deming（存疑，可能是后人附会）

这句话精准地展示了 data 的核心张力：**它是世俗世界的"信任替代品"。** 你说的话我不信，但你拿来的 data 我可以检验。

> *The plural of anecdote is not data.*
> 轶事的复数形式不是数据。

这句学术圈的名言，一刀切开了 data 和 anecdote 的本质区别：**不是你收集了很多故事就变成了 data——data 要求系统性、可验证性、可重复性。**

## 7. 跨语言映射

**拉丁语 datum / data** → 原汁原味的"被给出的东西"。今天英语的 data 已经和拉丁语 data 差了十万八千里——拉丁语里 data 是哲学前提，不是硬盘里的字节。

**中文"数据"** → 比 data 窄。"数"字锁定了数字含义。英文 data 包含 qualitative data（定性数据，如文字、图像），中文"数据"很难覆盖这一块——中文会说"资料"或"素材"来补。

**日文「データ」** → 直接从英语借入，发音 *dēta*。有趣的是日语把它当作外来语处理，不像中文翻译成了汉字组合，所以它的语义范围反而和英语更接近。

**德语 Daten** → 同源，来自拉丁语。德语里 *Datenschutz*（数据保护）是个法律术语，比英语的 *data protection* 更早成为正式法律概念——GDPR 的思想根基就在德语区。

**法语 données** → 来自 *donner*（给予），和英语 data 完美同源。法语保留了"被给予的东西"这个语义更清晰——*données* 的词形直接让你看到"给予"的动作，而英语 data 已经看不出 *dare*（给予）了。

---

一个从"给予"出发的词，走了四百年，从哲学的前提变成了经济的石油、隐私的战场、AI 的饲料。但剥开所有这些层，最底下那句话没变：**data 是递到你手里的东西——你没创造它，但你得决定拿它怎么办。**
