# statue

---

## 1. 一句话本质

**statue 是"让一个人永远站着不走"的企图**——把一个活过的身体钉死在一个姿势里，用石头或铜的寿命去对抗遗忘。它的词根就是"站"，而一座雕像做的唯一一件事，就是替一个已经站不起来的人，继续站下去。

---

## 2. 词源考古

### 词根词缀拆解

```
statue
← 古法语 statue（14世纪进入英语）
← 拉丁语 statua（立像、雕像）
← statuere（竖立、使站立、设立）
← status（站立的状态）← sistere（使站立）的过去分词
← 原始印欧语 *sta-（站立）
```

这个词没有词缀可拆——它本身就是词根的直系后代。`statua` 在拉丁语里的字面意思就是"被竖起来的东西"。

### *sta- ：印欧语系最忙的一条根

PIE 词根 *\*sta-* 是整个印欧语系里生产力最恐怖的词根之一。从这一条根上长出来的英语词：

| 词 | 和"站"的关系 |
|---|---|
| **state** | 站定的状态 → 现状 → 国家（一种"站稳了的"政治体） |
| **status** | 你站在哪个位置 |
| **station** | 你站着等的地方 |
| **stature** | 站起来有多高 |
| **statute** | 被"立"下来的规矩（⚠️ 和 statue 只差一个字母！） |
| **static** | 站着不动的 |
| **establish** | 使之站稳 |
| **constitute** | 共同站在一起 → 组成 |
| **institute** | 在里面站起来 → 设立 |
| **prostitute** | pro（在前面）+ stituere（站）→ 站在前面的人 |
| **stable** | 能站住的 → 稳定的；马站着休息的地方 → 马厩 |

statue 是这条词根最"字面"的一个后代——不拐弯、不抽象，就是"站着的东西"。

### 历史流变

**拉丁语时期**：`statua` 专指三维立体的人像或神像，和平面绘画（pictura）严格区分。罗马人用这个词时，脑子里浮现的画面很具体：广场上、神庙前，一个等人大甚至超过人大的石头或青铜人形。

**14世纪进入英语**：经由古法语 `statue` 进入中古英语，含义几乎没有漂移——仍然是"人形立体造像"。这个词罕见地稳定，从拉丁语到现代英语，核心含义走了两千年几乎没拐弯。

**值得注意的**：很多从 *\*sta-* 衍生出的词都经历了剧烈的语义抽象化（state 从"站的状态"变成了"国家"，station 从"站立处"变成了"火车站"），但 statue 几乎没有。它就像自己描述的那个东西一样——站在原地，纹丝不动。

## 3. 故事 / 画面

一个将军死了。

他的部下把他抬回国，清洗遗体，换上铠甲。然后他们去找石匠，描述他的样子：他多高，下巴什么角度，战场上他习惯怎么站——左脚微微前踏，右手搭在剑柄上，目光越过所有人的头顶。

石匠用了八个月。完成的那天，他们把石像竖在城门口。

从那以后，暴风雨来了，石像站着。政权更迭了，石像站着。描述他样子的部下也死了、被人遗忘了，石像还站着。鸽子在他肩膀上拉屎，小孩在他底座上刻字，游客举着手机拍了张照然后走开。

他就站着。

这就是 statue 在做的事情：**用物质的持久性，去替代一个人的存在**。它不是"雕塑"这个工艺的重点——它是"不让他消失"这个执念的产物。每一座 statue 的潜台词都是：**他不该被忘掉，所以让他继续站在这里。**

而这也是为什么推倒一座 statue 是一个政治动作——你不是在砸石头，你是在说"他不配再站着了"。

## 4. 多面体：核心义项展开

### 义项 A：雕像、塑像（核心义）

> *The statue of Lincoln sits inside the memorial, gazing out over the reflecting pool.*
> 林肯的雕像坐在纪念堂里，凝视着倒影池的方向。

一个三维的、通常等人大或更大的人像或动物像，用石头、金属、木头等硬质材料制成。这是"使之站立"的最直接实现——用材料的硬度来保证"站姿"不塌。

### 义项 B：一动不动的人（比喻用法）

> *She stood there like a statue, not even blinking when they announced the verdict.*
> 她像座雕像一样站在那里，当他们宣布判决结果时连眼都没眨。

当说一个人"像 statue"，映射的是雕像最显著的特征——**不动**。不是在说她好看或姿态优雅，是在说她被某种情绪（震惊、恐惧、克制）钉在了原地。

和"一句话本质"的关系：如果 statue 是"被永远定格在一个姿势里"，那么一个人"变成 statue"就是暂时地被定格了——区别只在于，人会解冻，石头不会。

### 义项 C：偶像 / 崇拜对象（古语/宗教语境）

> *Thou shalt not make unto thee any graven image, or any likeness... thou shalt not bow down thyself to them.*
> 不可为自己雕刻偶像……不可跪拜侍奉它们。（出埃及记 20:4-5，KJV）

在圣经英语和古典语境中，statue 常与偶像崇拜（idolatry）挂钩。拉丁语 `statua` 本身就覆盖"神像"这层含义。**一座 statue 的危险在于：它站在那里太久了，人们开始以为它是活的。**

## 5. 裂缝标注

### 🔴 statue vs. statute —— 拼写陷阱，重灾区

这是 **statue 最大的绊脚线**。两个词差一个字母，同源（都来自 *\*sta-*），但含义完全不同：

| | statue | statute |
|---|---|---|
| 含义 | 雕像 | 法令、法规 |
| "站"的方向 | 物理地站着 | 被"立"为规矩 |
| 例句 | a bronze statue | a federal statute |

记忆锚点：stat**ue** 结尾是 ue → 想到 "u（you）在看它"——你在看一个雕像。stat**ute** 结尾多一个 t → t = text → 一段写下来的法律文本。

### 🔴 statue vs. sculpture

中文母语者最容易把这两个词混为一谈（因为中文"雕塑"一词同时覆盖两者），但它们的焦点不同：

- **statue**：强调"像谁"——它是某个人/某个神/某个动物的**再现**。重点是被再现的对象。
- **sculpture**：强调"怎么做的"——它是一件用雕、塑、铸等工艺做出来的**艺术品**。重点是创作过程和形式。

→ 一个抽象的、没有再现任何具体对象的三维作品，可以叫 sculpture，但不叫 statue。
→ 广场上的毛主席像，可以同时叫 statue 和 sculpture，但如果你只想说"那是主席的像"，用 statue。

### 🔴 statue vs. figure vs. figurine

- **figure**：泛指任何人形造型，可大可小，可以是平面也可以是立体（action figure = 手办）
- **figurine**：小型的人像/动物像，通常可以拿在手里（桌上的小摆件）
- **statue**：通常暗示**较大尺寸**，至少半人高以上，且有"纪念性"或"公共性"

→ 书桌上的佛像小摆件 → figurine，不是 statue
→ 灵隐寺里四米高的佛像 → statue

### 🟡 中文母语者陷阱

中文"雕像"和"塑像"按工艺区分（雕 = 减材，塑 = 增材），但英文 statue 不管工艺——石雕是 statue，铜铸也是 statue，泥塑还是 statue。不要试图用 statue/sculpture 来对应"雕"和"塑"的区别，那个映射是错的。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **bronze / marble statue** | 按材质分类时最常见的两个——"一座青铜/大理石雕像" |
| **erect a statue** | 正式用法，"竖立一座雕像"。erect（竖立）和 statue（被竖起来的东西）是天然搭配 |
| **topple / tear down a statue** | 推倒雕像——2020年后在政治新闻里高频出现 |
| **unveil a statue** | 揭幕雕像——正式仪式用语 |
| **a statue of sb** | 某人的雕像——注意介词用 of，不是 for |
| **the Statue of Liberty** | 自由女神像——专有名词，statue 唯一需要大写的场景 |
| **stand like a statue** | 像雕像一样站着——最常见的比喻用法 |
| **living statue** | 活体雕像——街头行为艺术，一动不动站着的真人 |

### 语域

statue 是一个 **语域中性词**——新闻、文学、日常对话、学术论文里都用，没有正式/非正式的限制。它不像 sculpture 带一点"艺术评论"的味道，statue 就是指那个东西，朴素直接。

### 活用示范

> *"Every dictator who ever lived has built a statue of himself. The question is never whether they'll build it — it's how long it stays up."*
> "每个活过的独裁者都给自己立过像。问题从来不是他们会不会立——而是它能站多久。"

这句话把 statue 的物理属性（能被推倒）和它的政治隐喻（权力的脆弱性）焊在了一起。statue 在英语里天然就带有"权力的物化"这层暗语——因为只有有权的人才立得起一座自己的像，而只有失去权力之后它才会被推倒。

## 7. 跨语言映射

**中文**："雕像"和"塑像"按减材/增材工艺区分，但合在一起时用"雕塑"。有趣的是，中文用"像"字（image, likeness），重点落在"像谁"上——和 statue 的拉丁词源"站着"形成对比：**中文关心它长什么样，拉丁语关心它怎么立着。**

**希腊语**：古希腊语中雕像叫 ἄγαλμα（agalma），最初的意思是"令人喜悦之物、荣光"——希腊人觉得神像不是在"竖一个东西"，而是在"呈现一种光辉"。这个差异非常深刻：罗马人造像是为了**让人站着被记住**（statua），希腊人造像是为了**让美被看见**（agalma）。

**日语**：彫像（ちょうぞう），直接从汉字"雕像"来。但日语里另有一个词——お地蔵さん（ojizō-san，地藏菩萨像），路边的小石像，和 statue 的"纪念碑式的宏大感"完全相反。如果说 statue 是权力在广场上的投影，地藏就是慈悲在路边的蹲守。

**拉丁语→意大利语**：statua 在意大利语里原封不动地保留了下来。米开朗基罗完成大卫像后据说对它说了一句"Parla!"（说话啊！）——一座 statua 做得太好了，创作者反而无法忍受它不是活的。这个传说精准地捕捉了 statue 这个概念里埋着的悖论：**它越像活人，它的不活就越刺眼。**
