# corrupt

---

## 1. 一句话本质

**corrupt 是从内部烂掉的苹果——外面看着还行，切开才知道芯已经发黑。** 不是被砸碎，不是被烧焦，是自己长出了腐败，从内而外地坏掉。

---

## 2. 词源考古

### 词根词缀拆解

```
cor-  +  rupt
 ↓        ↓
com-    rumpere
(加强)   (打碎)
```

- **rumpere**（拉丁语）：打碎、撕裂、断裂。这是一个凶暴的动词——骨头断裂、堤坝决口、绳索绷断，都是 rumpere。
- **com-**（拉丁前缀）：在这里不是"一起"的意思，而是**加强语气**——彻底地、完全地。所以 corrumpere 不是"一起碎"，而是"碎得透透的"。
- **-rupt-** 这个词根家族庞大：**rupt**ure（破裂）、e**rupt**（喷发=向外破）、inter**rupt**（打断=从中间破）、ab**rupt**（突然的=断崖式地破）、bank**rupt**（破产=钱柜碎了）、dis**rupt**（扰乱=拆散着破）。

你看，这一家子都在"碎"，但只有 corrupt 是**从里面碎的**。

### 历史流变

**拉丁语 corrumpere**（公元前）→ 含义已经分两条线：
- 物质线：食物腐烂、物质变质
- 道德线：品行败坏、贿赂收买

这两条线从一开始就并存——罗马人用同一个词说"肉烂了"和"官烂了"。这不是后来的隐喻延伸，而是拉丁语母语者的直觉：**物质的腐烂和道德的腐烂，在他们眼里是同一种过程。**

**古法语 corrumpre**（12世纪）→ 经诺曼征服进入英语

**中古英语 corrupten**（14世纪）→ 在英语中稳定下来。宗教语境大量使用：原罪让人的灵魂 corrupt，肉体终将 corrupt（腐朽）。这个时期，"肉身的腐烂"和"灵魂的堕落"几乎是同一个神学命题。

**现代英语**（16世纪至今）→ 多了一个全新的义项：**文本/数据的损坏**。手抄本时代，抄写员笔误导致文本失真，学者说这份文本被 corrupted。到了数字时代，这个义项完美迁移——corrupt file, corrupt data。

### 文化地层：一个关键转折

最值得注意的是 corrupt 从来没有经历过褒贬翻转——它从诞生之日起就是负面词。但它的**重心**变了：

- 中世纪：重心在**肉体/灵魂**——死后肉身的腐烂，灵魂的堕落。《圣经》英译大量使用。
- 近现代：重心滑向**权力/制度**——corrupt politician, corrupt system。工业革命后城市政治腐败成为公共议题，这个词被政治评论家用到发烫。
- 数字时代：重心再加一极——**数据**。corrupt file 成了每个人都可能遇到的日常灾难。

一个词，从尸体的腐烂，到灵魂的堕落，到权力的腐败，到硬盘的损坏——内核始终是：**从内部变质，原本好的东西被自身的某种力量毁掉了。**

## 3. 故事 / 画面

一座老城的供水系统。

管道埋在地下几十年了，外面看不到。某天居民发现自来水有锈味。起初很淡，大家以为是错觉。然后水变黄了。再然后，打开水龙头，流出来的是浑浊的棕色液体。

工程队挖开地面，发现管道内壁长满了铁锈和水垢——不是有人往管子里倒了脏东西，而是管道**自身**在年复一年的氧化中从内部溃烂了。水从水源出发时是干净的，经过这些腐烂的管道，变成了毒液。

这就是 corrupt 的完整结构：
- **从内部发生**（不是外力破坏）
- **渐进式的**（不是突然断裂）
- **有传染性**（烂管道会污染干净的水）
- **表面看不出来**（不挖开就不知道）

贪官不是被人拿枪逼着收钱的，是自己的贪欲从内部蚀穿了底线。硬盘数据不是被人删掉的，是磁性介质自己衰变了。经文不是被人篡改的（那叫 falsify），是在一代代传抄中自己走了样。

## 4. 多面体：核心义项展开

### 义项一：道德/权力腐败（最高频义项）

> *The investigation revealed that corrupt officials had been taking bribes for over a decade.*
> 调查揭露，腐败官员已经收了十多年的贿赂。

这是 corrupt 最强势的义项。注意它和"一句话本质"的关系：官员本应是公共权力的管道，权力从人民流向公共服务——管道从内部烂了，流出来的全变了味。

### 义项二：使堕落、使变质（动词，及物）

> *Power tends to corrupt, and absolute power corrupts absolutely.*
> 权力趋于使人腐化，绝对的权力绝对地使人腐化。（阿克顿勋爵，1887）

这是英语世界引用率最高的格言之一。注意动词用法的核心逻辑：corrupt 的施动者不必是一个有意识的人，**权力本身**就能当主语——它像一种锈蚀剂，侵入人格的内部。

### 义项三：数据/文件损坏

> *The database was corrupted during the power outage and couldn't be recovered.*
> 数据库在断电期间损坏了，无法恢复。

和道德义项的底层统一性：数据没有被人删除或覆写（那是 delete / overwrite），而是数据结构**自身的完整性**在异常状况下瓦解了——比特还在，但排列方式坏了，信息从内部碎了。

### 义项四：文本讹误（学术语境）

> *This manuscript is heavily corrupted; several key passages are illegible or altered by later scribes.*
> 这份手稿严重讹误；几处关键段落已无法辨认或被后来的抄写员改动。

文献学核心术语。一份被 corrupted 的文本不是被故意篡改的（那更接近 falsified / doctored），而是在传抄过程中**自然累积了错误**——一笔一画的偏差，像基因复制中的突变，一代代叠加，最终面目全非。

### 义项五：使腐烂（古/正式，物质层面）

> *The warm, humid climate had corrupted the food stores beyond salvage.*
> 温暖潮湿的气候使食物储备腐烂到无法抢救。

这个义项在现代英语中已经不常用（说食物烂了更常用 spoil / rot / decompose），但它是 corrupt 最古老的面孔——而且你能看到，所有后来的义项都是从这张脸长出去的。

## 5. 裂缝标注

### 常见误用

**❌ 把 corrupt 当作任何"坏"的同义词**

corrupt 的核心是**从内部变质**。一个人被抢劫了，他不是 corrupt 的受害者；一座桥被炸弹炸塌了，桥不是 corrupted。corrupt 要求变质的力量来自**系统内部或事物自身**。

**❌ corrupt vs. broken**

> A corrupt file ≠ a broken file（严格来说）

corrupt file 意味着文件**存在但内容失真**——你打得开，但读到的是乱码或错误数据。broken 更宽泛，可以指"完全打不开"。但在日常口语中，这两者的边界已经模糊了。

### 易混近义词辨析

| 词 | 核心区别 |
|---|---|
| **corrupt** | 从内部烂，渐进的，有传染性 |
| **crooked** | 歪的、不正的——口语化，更像骂人，"那家伙是个弯的"（不正直）。语气更随意 |
| **venal** | 专指"可以用钱买通的"——比 corrupt 窄，只聚焦贿赂这一个维度 |
| **depraved** | 道德彻底堕落——比 corrupt 更极端，几乎到了"丧尽天良"的地步。corrupt 的官员可能只是贪钱，depraved 暗示人格已经扭曲 |
| **tainted** | 被沾染了——可以是被外力污染的（tainted evidence = 被污染的证据），corrupt 更强调**自发性** |

**辨析场景**：

一个法官收了被告的钱判了不公正的判决——他是 **corrupt**（从内部烂了）。
一个证人被威胁后改了口供——证词是 **tainted**（被外力污染了），但证人本身未必是 corrupt 的（他可能是被迫的）。

### 中文母语者陷阱

**⚠️ "腐败"的翻译陷阱**

中文"腐败"几乎只用于道德/权力领域。但 corrupt 的语义范围宽得多——数据 corrupt、文本 corrupt、甚至空气和水 corrupt（古用法）。中文母语者容易把 corrupt 锁死在"贪官"这一个画面上。

**⚠️ "坏了"的过度映射**

中文"文件坏了"对应的英文不一定是 corrupted——如果文件是被误删的，那是 deleted；如果是被加密勒索的，那是 encrypted / compromised。只有**文件还在但内部数据结构乱了**才是 corrupted。

**⚠️ corrupt 做形容词时不需要 be corrupted**

> a corrupt politician（✅ 形容词前置）
> a corrupted file（✅ 过去分词做形容词，强调"被某个过程损坏了"）

两种都对，但语感不同：corrupt politician 是"这个人的品性本身就是烂的"，corrupted file 是"这个文件**经历了**一个损坏的过程"。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **corrupt official / politician** | 新闻/政治评论的核心搭配，"贪官"的标准英语说法 |
| **corrupt practices** | 腐败行为——常出现在法律文本和新闻报道中，复数形式暗示"成系统的腐败" |
| **corrupt data / file / database** | IT 领域日常用语，"数据损坏"几乎是 corrupt 在技术领域的默认搭配 |
| **morally corrupt** | 加了 morally 作为强调——"道德上烂透了"，比单独的 corrupt 更重 |
| **corrupt to the core** | 固定表达，"烂到了核心"——强调腐败不是表面的，是彻底的 |
| **corrupt system / institution** | 不是骂某个人，是说整个制度/机构从结构上就是烂的 |
| **corrupt bargain** | 政治术语，"肮脏交易"——美国历史上有著名的 Corrupt Bargain（1824年总统选举争议） |

### 语域标注

- **正式程度**：中高。新闻报道、学术文章、法律文本的常客。日常口语也用，但语气偏重——你不会对朋友迟到说"你 corrupt 了"。
- **新闻语域**：极高频。政治新闻几乎离不开这个词。
- **技术语域**：高频。程序员/IT 人员天天见 corrupt。
- **口语**：用，但通常是在认真讨论问题时。骂人更常用 crooked（口语感更强）。

### 活用示范

> *"The building hadn't burned down. It hadn't been demolished. It had simply corrupted from within — decades of water seeping through micro-cracks, rusting the rebar, turning concrete to powder."*
> 这栋楼没有被烧掉，没有被拆除。它只是从内部溃烂了——几十年的水渗透微裂缝，锈蚀了钢筋，把混凝土变成了粉末。

这个例子把 corrupt 的物质义项和道德义项的共性结构展示得很漂亮——建筑的"腐败"和权力的"腐败"是同构的。

> *"Every copy corrupts. Every translation corrupts. The question isn't whether the signal degrades — it's how much of the original survives."*
> 每一次复制都会讹变。每一次翻译都会讹变。问题不在于信号是否会衰减——而在于原始信息还能幸存多少。

这是一种哲学化的用法，把 corrupt 用作不及物动词，指信息在传播中的自然失真——非常准确，非常漂亮。

## 7. 跨语言映射

**中文"腐"**——极其精准的对照。"腐"的本义就是肉烂了（月字旁 = 肉），后来延伸到"腐败"（道德/权力）、"腐朽"（物质/制度）、"腐蚀"（化学过程）。和 corrupt 的语义扩张路径几乎完全平行：**从肉体的腐烂出发，走向道德和制度的崩坏。** 这不是翻译的巧合——是因为人类在不同文明中独立地发现了同一个隐喻：物质的腐烂和道德的腐烂，在认知结构上是同一件事。

**拉丁语 putris / putrescere**——corrupt 在拉丁语中有个近亲 putrescere（发臭、腐烂），后来给了英语 **putrid**（腐臭的）。但 putrid 只走了物质路线（臭肉、臭水），没有走向道德。corrupt 两条路都走了，所以活得更久、更宽。

**日语「汚職」（おしょく）**——专指公职腐败，字面"弄脏了职位"。比 corrupt 窄——只覆盖了权力腐败这一个面，没有物质腐烂和数据损坏的维度。日语说数据坏了用「破損」（物理损坏）或「壊れた」（坏了），这些词都不带 corrupt 那种"从内部烂"的意味。
