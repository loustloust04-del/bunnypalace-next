# memorise

---

## 1. 一句话本质

**memorise 是把东西往脑子里按的那个动作——不是自然记住，是你坐在桌前，一遍一遍地把信息往脑壁上钉，直到它不掉下来。**

remember 是你回头发现墙上还挂着那幅画；memorise 是你当初拿锤子把钉子敲进去的过程。

---

## 2. 词源考古

### 词根词缀拆解

```
memorise = memor + -ise
```

- **memor-**：拉丁语形容词 *memor*，意思是"mindful, remembering"——心里装着的、留意着的。
- **-ise / -ize**：动词化后缀，来自希腊语 *-ίζειν*（-izein），经拉丁语 *-izare* 传入。核心含义是"使之成为……"。

所以 memorise 的字面结构 = **"使之成为记忆"**，或者说"把某样东西变成脑子里的东西"。

拼写说明：**-ise** 是英式拼法，**-ize** 是美式拼法。两者完全等价，没有含义差别。牛津大学出版社传统上偏好 -ize（所以叫 Oxford spelling），但日常英式英语里 -ise 更常见。

### 更深的根：PIE \*(s)mer-

拉丁语 *memor* 往上追溯，到原始印欧语根 **\*(s)mer-**，意思是"to remember, to care, to be mindful"。

这条根生出了一整个家族：

| 词 | 路径 | 含义 |
|---|---|---|
| **memory** | memor → memoria | 记忆（名词） |
| **memorial** | memoria + -alis | 纪念的 |
| **memoir** | 法语 mémoire ← memoria | 回忆录 |
| **memorable** | memorabilis | 值得记住的 |
| **memorandum** | memorandus（该被记住的） | 备忘录 |
| **remember** | re- + memorari | 重新想起 |
| **commemorate** | com- + memorare | 共同铭记 |

注意一个有趣的事：**memorise 是这个家族里最"主动"的成员**。memory 是状态，remember 是发现，memorable 是属性，而 memorise 是纯粹的**动作**——你对大脑施加的一个力。

### 历史流变

这个词进入英语比较晚——**16 世纪晚期**才出现书面记录（约 1590s）。这不是巧合。16 世纪是文艺复兴的尾声、印刷术扩散的时期，识字率上升，正规教育开始普及。人们突然需要一个词来描述"坐下来、反复背诵直到记住"这个行为。

在此之前，英语里描述这种行为用的是 **"learn by heart"**（用心学）或 **"con"**（反复读诵，现在已过时）。memorise 的出现标志着一种更"科学化"、更"机械化"的学习观——不是用心灵去感受，是用重复去刻印。

## 3. 故事 / 画面

一个演员坐在后台的折叠椅上。

演出还有四十分钟。她手里拿着剧本，但没在看——眼睛盯着墙上的水渍，嘴唇在动。台词从嘴里流出来，断了，她皱眉，低头看一眼剧本，然后抬头，重新来。

她不是在"读"台词。她是在把台词从纸上**搬运到身体里**。

每重复一遍，那些句子就从"纸上的墨水"变成"嘴巴的肌肉记忆"，变成"某个情绪触发后自动涌出的声音"。这个搬运过程——费力的、机械的、需要你一趟一趟往返的过程——就是 memorise。

关键在这里：她可能根本不理解剧作家为什么写了这句台词。她可能不认同角色的动机。但她能一字不差地说出来。**memorise 不关心你懂不懂，它只关心你装没装进去。**

## 4. 多面体：核心义项展开

memorise 其实义项很窄——它基本上只有一张脸，但这张脸在不同场景里的**光线不一样**。

### 义项一：刻意将信息存入记忆（核心义）

> *She memorised the poem word for word before the recital.*
> 她在朗诵会之前把那首诗逐字背了下来。

这是最标准的用法。注意 **word for word**——memorise 常常暗示**精确复制**，不是大意记住，是一字不差。

### 义项二：通过反复接触而熟记（带"努力"色彩的记住）

> *After driving the same route every day for a year, I've memorised every pothole.*
> 每天开同一条路开了一年，每个坑我都记住了。

这里的 memorise 不是坐下来背的，但说话者用这个词强调的是：**这些信息已经被刻进去了，像被钉子钉住一样牢固**。跟"一句话本质"的联系：即使不是主动按的，结果也像是按进去的。

### 义项三：（计算机/技术语境）存储

> *The device can memorise up to 200 user settings.*
> 该设备可以存储最多 200 个用户设置。

这个用法不算特别常见，但存在。它精准映射了 memorise 的底层逻辑：**把数据写入一个存储介质**。人脑和硬盘在这个词的视角里没有本质区别——都是容器，都需要一个"写入"动作。

## 5. 裂缝标注

### 常见误用场景

**❌ 用 memorise 代替 remember**

> ❌ *I can't memorise where I put my keys.*
> ✅ *I can't remember where I put my keys.*

memorise 是**事前动作**——你还没记住，你正在往脑子里塞。remember 是**事后状态**——你已经记住了（或者试图回忆）。钥匙放哪了不是你"背"出来的，是你"想起来"的。

**简单判断法**：如果能加 "by heart"（by heart = 背下来），用 memorise；如果是"想起/记得"，用 remember。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **remember** | 自然状态的"记得"。你 remember 初恋的脸，但你不会说 memorise 初恋的脸——除非你是在刻意研究一张照片。 |
| **learn** | 比 memorise 宽得多。learn 包含理解；memorise 不一定。你可以 memorise 一段阿拉伯语祷文而完全不懂阿拉伯语。你不能说你 learned 阿拉伯语。 |
| **recall** | 方向相反。memorise 是存入，recall 是取出。"我 memorise 了你的电话号码"→"我能 recall 你的电话号码"。 |
| **retain** | retain 强调"保持住"——信息进去之后没漏出来。你 memorise 是主动装，retain 是装完了还在。 |

### 中文母语者陷阱

**"背"的过度映射。** 中文里"背课文""背单词"的"背"几乎等于 memorise，但中文的"我记住了"可能对应 memorise 也可能对应 remember。中文母语者容易在该用 remember 的地方用 memorise：

> ❌ *I memorised that you don't like spicy food.*（我背下来了你不吃辣？太诡异了）
> ✅ *I remember that you don't like spicy food.*

**另一个坑：memorise 在英语里没有"背诵"的意思。** "背诵"是 **recite**。memorise 是私下的准备工作，recite 是站起来说出来的动作。你 memorise a poem，然后 recite it。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境说明 |
|---|---|
| **memorise lines** | 演员背台词——这是 memorise 最经典的场景 |
| **memorise a poem / passage** | 背诵诗歌/段落，学校场景常见 |
| **memorise facts / dates / names** | 备考时塞信息——带有"死记硬背"的色彩 |
| **memorise a phone number** | 日益少见的行为，但搭配本身还活着 |
| **memorise a speech** | 演讲前的准备——比 memorise lines 更正式 |
| **memorise the layout / route** | 记住空间布局/路线——略微延伸的用法 |
| **try to memorise** | 常见框架，暗示"不容易" |
| **worth memorising** | "值得背下来"——暗示内容精华 |

### 语域标注

memorise 是一个**中性偏正式的日常词**。它在口语和书面语中都自然出现，没有明显的正式/非正式限制。但在学术语境中，讨论"记忆"作为认知过程时，更常见的术语是 **encode**（编码）或 **commit to memory**。

在教育学讨论中，memorise 常常带有**微妙的贬义**——"rote memorisation"（死记硬背）几乎是一个批评术语，暗示不理解、不思考。

### 活用示范

> *"I don't need to memorise the answer. I need to memorise the question."*
> ——某种学习哲学的精辟表达：记住问题比记住答案更有价值。memorise 在这里被用来制造对比张力。

> *She had memorised his face so thoroughly that she could draw it with her eyes closed — but she'd forgotten what his voice sounded like.*
> 她把他的脸记得清清楚楚，闭着眼都能画——但她忘了他的声音是什么样的。这里 memorise 和 forgotten 的并置揭示了记忆的残忍选择性：你用力刻下的和自然流失的，不由你控制。

## 7. 跨语言映射

**中文"背"**：最直接的对应。但中文的"背"有一个 memorise 没有的身体性——"背"的本字是"背负"，像把东西背在背上。英语的 memorise 更像往容器里塞（press into），中文的"背"更像往身上扛（carry on your back）。两个比喻，同一件事。

**日语「暗記」(あんき)**：字面意思是"暗中记住"——把灯关了也能记得。这个"暗"字比 memorise 多了一层意象：不看原文也能复述。memorise 没有这么明确地强调"脱离原材料"，但实际使用中含义几乎完全一致。

**法语 *apprendre par cœur***："用心学"。和英语的 learn by heart 同构。有趣的是，法语也有 *mémoriser*，但日常口语更爱用 *apprendre par cœur*——心的比喻胜过了机械的比喻。英语反过来：memorise 比 learn by heart 更常用、更正式。

**拉丁语 *ediscere***：前缀 e-（彻底）+ discere（学习）= 彻底学会 = 背下来。拉丁语把"背诵"理解为"学习的极致形态"，而现代英语的 memorise 和 learn 反而是割裂的——你可以 memorise 但没有 learn。这个割裂本身就是一段教育史。

---

**收尾一锤**：memorise 是记忆家族里最诚实的成员。它不假装记忆是自然发生的灵光一现，它直说了——这是劳动，是重复，是你坐在那里一遍一遍地把东西往脑子里按。按得够深，就留下了。按得不够，过几天就掉。
