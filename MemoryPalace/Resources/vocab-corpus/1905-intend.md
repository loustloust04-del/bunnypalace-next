# intend

## 1. 一句话本质

**intend 是弓弦拉满但箭还没放出去的那个状态——你的意志已经绷紧、方向已经对准，但动作尚未发生。**

## 2. 词源考古

### 词根词缀拆解

```
in-（朝向、进入）+ tendere（拉伸、绷紧）
```

拉丁语 **intendere**，字面意思是"朝某个方向拉伸"。两个部件都是拉丁血统：

- **in-**：方向性前缀，表示"朝……去"。不是否定的 in-（如 invisible），是运动的 in-（如 inject = 朝里扔）。
- **tendere**：拉伸、绷紧。追到更深处，来自原始印欧语 \*ten-（拉伸）。这个根系极其繁茂——**tension**（绷紧）、**tendon**（肌腱，那根绷着的东西）、**tent**（帐篷，拉开的布）、**tender**（嫩的，一拉就断）、**thin**（薄的，被拉薄了）、**tone**（音调，弦绷紧的程度）——全是同一个 \*ten- 的后代。

### 历史流变

**拉丁语 intendere（公元前）**：纯粹的物理动作。把弓弦拉向目标，把视线投向远处，把手伸向某物。核心意象：**身体的某个部分朝一个方向绷紧了**。

**晚期拉丁语 → 古法语 entendre（约 10-12 世纪）**：这里发生了一次惊人的语义分裂。法语拿到这个词后，把"把注意力拉伸向某物"理解成了——**"听懂、理解"**。今天法语的 *entendre* 意思是"听见"。你把耳朵和心智"拉伸"向对方的话语，就是在听、在理解。

英语呢？从同一个法语词借入，但走了另一条路。中古英语 **entenden**（约 14 世纪）主要保留了"把意志对准某事 → 打算做某事"这层含义。

所以同一个拉丁词根，在法语里变成了"理解"，在英语里变成了"打算"。两条路其实都合理：把心智拉向知识 = 理解；把意志拉向未来 = 打算。只是两种语言各选了一个方向跑远了。

**关键转折（14-15 世纪）**：intend 从"注意力的指向"完全滑向了"意志的指向"。早期用法里 intend 还有"关注、留心"的味道（I intend your words = 我留心你的话），这层意思后来完全消亡，"打算、有意"成了唯一活下来的含义。

### 文化地层

这个词和法律史深度绑定。**intent**（意图）在英美法系中是定罪的核心要素——同样是杀人，有 intent 的叫 murder，没 intent 的叫 manslaughter。一个词的有无，决定了十年还是终身。法律迫使这个词变得极其精确：intent 不是"想了想"，是"形成了具体的心智指向"。

## 3. 故事 / 画面

一个弓箭手站在射击场上。

她抬起弓，搭上箭，开始拉弦。弦越拉越紧，木臂弯曲，手指在震颤中维持着最后的稳定。箭头对准了靶心。

这一刻——弦拉满、方向已定、手指还没松开——就是 **intend**。

注意几件事：
- 箭**还没射出去**。intend 永远是动作之前的状态。"我 intend 去做"意味着我还没做。
- 但弦已经**绷紧了**。这不是随口说说。你的意志已经投入了能量，已经选定了方向。比"想了想"重得多。
- 弦绷得越紧，松手时箭飞得越准。intend 的分量感就在这里——它是一种有张力的尚未。

如果你只是拿着弓晃来晃去，那叫 consider。如果你拉弦但没瞄准，那叫 wish。**intend 是拉满弦、瞄准靶心、但手指还扣着的那个精确瞬间。**

## 4. 多面体：核心义项展开

### 义项一：打算做某事（最核心用法）

> *I intend to finish this book by Friday.*
> 我打算在周五之前读完这本书。

弓弦对准了"周五读完"这个靶心。意志已就位，行动尚未发生。这是 intend 最日常、最高频的脸。

### 义项二：意在表达某含义（intended meaning）

> *I didn't intend that as an insult — I was trying to be helpful.*
> 我那句话不是想侮辱你——我是想帮忙。

你的话是一支箭，但它飞偏了。你的 intend（弓弦瞄准的方向）是善意，但箭落在了冒犯的区域。这个义项解释了为什么 intend 能用于"含义"——**你把意义拉伸向某个目标，但接收者未必站在那个目标上**。

### 义项三：被设计/规划用于（be intended for）

> *This path is intended for emergency vehicles only.*
> 这条路是专为紧急车辆设计的。

设计者在画图纸时，把这条路的用途"拉向"了急救车。这是一种冻结在物体中的意志——设计者的 intent 凝固在了物理结构里。从"人的打算"到"物的用途"，底层逻辑一样：**有一个方向是被预先瞄准的**。

### 义项四：intended = 未婚夫/妻（dated, 略老派）

> *Have you met his intended?*
> 你见过他的未婚妻吗？

这个用法现在偏老式，但逻辑精妙：一个你已经"瞄准"但尚未正式结合的人。订婚就是弓弦拉满、方向已定、但婚礼还没发生。完美呼应 intend 的核心结构——**已选定方向，尚未完成动作**。

**四个义项的底层统一性**：全都是"意志/设计朝一个方向绷紧了，但终点尚未到达"。打算做事、话语的用意、物品的用途、许了婚的对象——每一个都是拉满的弦。

## 5. 裂缝标注

### 常见误用

**❌ "I intend going to the store"**（口语中偶见，但标准用法是 **intend to do** 或 **intend doing**）

严格说 intend to do 和 intend doing 都语法合法，但 **intend to do** 是压倒性的主流选择。intend doing 在英式英语里偶尔出现，美式英语几乎不用。安全策略：永远用 **intend to**。

**❌ 把 intend 用于已经发生的事**

> ~~I intended to call you and I did.~~（语法对，但奇怪——intend 强调的是动作前的状态，一旦做完了，intend 的戏份就结束了，通常没必要再提它。）

正常说法：*I called you, as planned.* 或 *I intended to call you, but forgot.*（后者才是 intend 的典型登场时机——打算了但没做到。）

### 易混近义词辨析

| 词 | 核心差异 |
|---|---|
| **intend** | 意志已就位、方向已选定、有一定的认真程度。"我**打算**减肥"——弓弦已拉。 |
| **plan** | 比 intend 多了具体步骤。plan 不只是拉弦瞄准，还画了弹道图、算了风速。"我**计划**每周跑三次"。 |
| **mean to** | intend 的口语替身，分量更轻。"I mean to clean the kitchen"比"I intend to clean the kitchen"随意得多。后者像在做声明，前者像在自言自语。 |
| **want** | 比 intend 弱一个量级。want 只是欲望，弓可能还没拿起来。"I want to travel"不承诺任何行动；"I intend to travel"暗示你已经在查机票了。 |
| **aim** | 和 intend 最近，也有"瞄准"的物理意象。但 aim 更常用于目标/抱负（aim for the top），intend 更常用于具体计划（intend to leave at 5）。 |

### 中文母语者陷阱

**"打算"的陷阱**：中文"打算"可以非常轻——"我打算去看看"可能只是随口一说。但英文的 intend 分量偏重，带有正式感。日常口语里说 *I'm thinking of going* 或 *I'm going to go* 更自然。**intend 是你站直了身体、认真宣布的那种"打算"。**

**"故意"的陷阱**：中文"我不是故意的"翻成 *I didn't intend to* 是对的，但注意——**intentional（故意的）和 intend（打算）在中文里常被糊在一起**。"他是故意推我的"= *He pushed me intentionally*，不是 *He intended to push me*。后者听起来像"他蓄谋已久地计划了一次推搡"，分量过重。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **intend to do sth** | 最基础结构。*I intend to resign.* 我打算辞职。 |
| **fully intend** | 加强语气：我铁了心要做。*I fully intend to be there.* |
| **never intended** | 最常见的否定形式，常用于辩解。*I never intended to hurt you.* |
| **originally intended** | 最初的打算（暗示后来变了）。*The building was originally intended as a hospital.* |
| **be intended for** | 被设计/规划给某人某用途。*This guide is intended for beginners.* |
| **be intended as** | 本意是……。*The remark was intended as a joke.* |
| **what sb intended** | 某人的本意。*That's not what I intended.* |

### 语域标注

intend 是**中偏正式**的词。法律、商务、政治语境很爱它（*The government intends to introduce new legislation*）。日常口语里更自然的替代品：

- 随意 → *I'm gonna / I'm planning to / I'm thinking of*
- 中性 → *I plan to / I mean to*
- 正式 → *I intend to*（这就是 intend 的地盘）

### 活用示范

> *The novel was intended as a satire, but most readers took it at face value.*
> 这部小说本意是讽刺，但大多数读者照字面理解了。

——这句展示了 intend 最有戏剧性的用法：创作者的意图和接收者的理解之间的裂隙。弓弦瞄准了讽刺，箭却落在了认真的土地上。

> *"I didn't intend for things to end up this way," she said, though everyone in the room knew that was exactly what she intended.*
> "我不是故意让事情变成这样的，"她说——尽管房间里每个人都知道这恰恰就是她的意图。

——intend 的否定形式和肯定形式在同一句话里碰撞，制造出尖锐的反讽。

## 7. 跨语言映射

**法语 entendre** = 听见、理解。同一个拉丁词根，走了完全不同的路。英语的 intend 保留了"意志的方向"，法语的 entendre 保留了"注意力的方向（→ 听 → 理解）"。两种语言像两个人从同一个岔路口出发，一个往北走了意志，一个往南走了认知。

**日语「つもり」**：和 intend 几乎同位。「行くつもりです」= I intend to go。但「つもり」更主观——它强调的是说话者脑中的画面，甚至有"自以为"的用法（「分かったつもり」= 以为自己懂了其实没懂）。intend 没有这层"自欺"的暗面。

**中文"意图"vs"打算"**：intend 跨在两者之间。"打算"偏日常、偏轻；"意图"偏正式、偏重、常带审视感（"你的意图是什么"有审问味）。英文的 intend 占据了这个中间地带——比"打算"重，比"意图"日常。

---

**同族词速览**，帮你看清这棵树的枝干：

| 同族词 | 关系 |
|---|---|
| **intent** | intend 的名词/形容词。名词 = 意图（with intent to kill）；形容词 = 全神贯注的（intent gaze = 专注的目光，弦绷紧了对准你的眼神） |
| **intention** | 更常用的名词形式。比 intent 柔和，日常场景选它 |
| **intentional** | 故意的。和 deliberate 近义但 intentional 更中性 |
| **intense** | 同根。绷紧到极致 = 强烈的 |
| **tension** | 绷紧的状态本身 |
| **attend** | ad- + tendere = 把注意力拉向某处 = 参加、照料 |
| **contend** | con- + tendere = 一起拉 = 争夺、竞争 |
| **extend** | ex- + tendere = 往外拉 = 延伸 |
| **pretend** | prae- + tendere = 在前面张开（一块布）= 假装（遮挡真实）|

一个 \*ten-（拉伸），长出了半个英语词汇表。intend 只是其中一根弦——拉向未来的那根。
