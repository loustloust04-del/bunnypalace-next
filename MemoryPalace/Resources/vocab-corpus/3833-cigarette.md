# cigarette

---

## 1. 一句话本质

cigarette 是一个**被法语缩小过的西班牙烟卷**——它的名字本身就是一个动作：把粗壮的雪茄捏细、裁短、加上一个优雅的法式后缀，变成可以叼在嘴角的东西。它的词源结构就是它的制造工艺：**大的东西被做小了**。

---

## 2. 词源考古

### 词根词缀拆解

```
cigarette = cigar + -ette
              ↑        ↑
          西班牙语     法语小词后缀
          cigarro    "小的那个"
```

**-ette** 是法语里最常见的阴性小词后缀（diminutive suffix），表示"小型版本"。你见过它很多次：
- kitchen → kitchenette（小厨房）
- cash → cassette（小盒子）
- statue → statuette（小雕像）
- usher → usherette（女引座员，旧称）

所以 cigarette 的字面意思极其直白：**小雪茄**。

### 历史流变

**第一层：美洲原住民的烟草**

故事要从烟草本身说起。1492 年哥伦布的船员在古巴看到当地泰诺人（Taíno）把干烟叶卷成筒状点燃吸食。这个东西在泰诺语或加勒比语言中的名称，经过西班牙殖民者的耳朵，变成了 **cigarro**。

这个词的终极来源是词源学的一桩悬案：

- **主流说法**：来自玛雅语 **sik'ar**（意为"吸烟、抽烟"），指抽烟这个动作本身。玛雅人是已知最早种植和仪式性使用烟草的文明之一。
- **民间词源（存疑）**：有人说 cigarro 来自西班牙语 **cigarra**（蝉），因为卷好的烟叶形状像蝉的身体——两端尖、中间鼓。这个说法流传很广但证据薄弱，更像是后人的联想。
- **另一种可能（存疑）**：也有学者认为来自玛雅语 **sik**（烟草）本身。

不管哪种，cigarro 在 16 世纪的西班牙语里稳定下来，指的是**用整片烟叶卷成的粗烟卷**——也就是我们今天说的雪茄（cigar）。

**第二层：法语的精致化处理（18 世纪末–19 世纪初）**

烟草传入欧洲后，西班牙人和葡萄牙人抽的是粗犷的 cigarro。但到了 18 世纪末，法国人和土耳其人开始用**碎烟丝**裹在薄纸里——更细、更短、更便宜、更日常。

这种新东西需要一个名字。法国人没有另造新词，而是做了一件非常法国的事：拿 cigare（cigarro 的法语形式）加上 **-ette**，造出了 **cigarette**——"小雪茄"。

这个词最早的法语书面记录大约在 **1830 年代**。

**第三层：英语的吸收（1840s–1850s）**

英语在 1840 年代前后直接从法语借入 cigarette，拼写原封不动。克里米亚战争（1853–1856）是一个关键传播节点——英国士兵从土耳其和法国盟军那里学会了抽这种纸卷烟，带回了习惯，也带回了这个词。

到 19 世纪后半叶，cigarette 在英语中完全站稳。

### 文化地层

cigarette 这个词的有趣之处在于，**它的文化含义经历了 180 度翻转**：

- **19 世纪末–20 世纪初**：时髦、都市、现代性的象征。抽 cigarette 比抽 cigar 更年轻、更潇洒。女性吸烟运动（1920s）把它变成了自由和反叛的符号。
- **20 世纪中叶**：无处不在的日常消费品。医生代言烟草广告。"More doctors smoke Camels than any other cigarette."
- **1964 年后**：美国卫生总署发布吸烟致癌报告，cigarette 开始被"疾病""成瘾""死亡"的阴影笼罩。
- **21 世纪**：在英语语境中，cigarette 几乎自带负面语气——不需要加任何形容词，这个词本身就隐含了"你知道这东西有害"。

一个词从"优雅的小物件"变成"慢性自杀工具"，只用了不到一百年。这种语义的道德化漂移，在语言学里是很罕见的剧烈程度。

## 3. 故事 / 画面

别想象一个人在抽烟。想象一个**词在被制造**。

1830 年，巴黎某条街上。一个法国工人把土耳其碎烟丝倒在一张薄纸上，卷紧，舔封。旁边一个绅士叼着一根粗壮的哈瓦那雪茄，看了一眼这个细瘦的东西，嘴角一撇：

*"Ah, une petite cigare."*

但法语不说 "petite cigare"。法语有更精确的工具——后缀 **-ette**。像用指尖捏住一个大东西，轻轻一拧，拧成它的缩略版：

**Cigare → cigarette。**

这个画面就是这个词的全部结构：**一根雪茄被语言的手指捏细了。** 粗变细，大变小，阔佬的消遣变成了穷人口袋里的日常。后缀 -ette 做的事，和卷烟纸做的事一模一样——包裹、压缩、使其轻便。

## 4. 多面体：核心义项展开

cigarette 不像 run 或 set 有几十个义项。它的义项很集中，但有几个维度值得注意：

### 义项一：最基本的——纸卷烟

> *She stepped outside for a cigarette.*
> 她走到外面抽根烟。

这是它 95% 的用法。注意英语中说"抽一根烟"最自然的方式是 **have a cigarette** 或 **smoke a cigarette**，而不是 ~~drink a cigarette~~（中文"吸烟"的"吸"容易让人想到 inhale，但 inhale 是更技术性的动作描述）。

和"一句话本质"的关系：纸裹碎烟丝，小型化的烟草消费单位。

### 义项二：作为计量单位和成瘾符号

> *He's down to three cigarettes a day.*
> 他现在一天只抽三根了。

cigarette 在这里不只是一个物件，它是**成瘾程度的计量尺**。英语里 "a pack-a-day smoker"（一天一包的烟民）是一个固定的人物画像标签。

和"一句话本质"的关系：因为被做小了、做便宜了，才能被量化、被计数、被一根一根地消耗——雪茄不会这样被数。

### 义项三：隐喻用法——短暂、消耗性的东西

> *Life is just a cigarette — a puff, a glow, and then ashes.*
> 人生不过一根烟——吸一口，亮一下，然后是灰。

这是文学和歌词里的用法。cigarette 作为隐喻时，它的核心意象不是"烟"而是**"从点燃到烧尽的过程"**——短暂、自我消耗、不可逆。

和"一句话本质"的关系：小东西烧得快。被缩小的代价是寿命变短。

## 5. 裂缝标注

### 常见误用场景

**cigarette vs. cigar 混用**：很多中文使用者把"雪茄"也说成 cigarette。不是。cigar = 雪茄（整片烟叶卷的，粗的），cigarette = 纸卷烟/香烟（碎烟丝裹纸的，细的）。词源上一大一小，物理上也一大一小。

**拼写**：cigarette 的双 t 和结尾 e 容易写错。记住它是法语词，法语 -ette 的双 t 是标准拼法。英式英语偶尔可见 cigaret 的简化拼写，但非主流。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **cigar** | 雪茄。整叶卷的，粗，贵，慢慢抽。关联：权力、庆祝、老派绅士。 |
| **cigarette** | 香烟/纸烟。碎丝裹纸，细，便宜，几分钟抽完。关联：日常、成瘾、蓝领也能抽。 |
| **smoke** | 泛指"烟"或"抽烟"。"Want a smoke?" 比 "Want a cigarette?" 更口语、更随意。也可以指大麻烟卷（语境决定）。 |
| **cig** | cigarette 的口语缩写。"Got a cig?" 日常对话用，书面不用。 |
| **fag** | 🇬🇧 英式俚语 = cigarette（"Can I bum a fag?" = 能借根烟吗？）。⚠️ 在美式英语中 fag 是对同性恋的冒犯性称呼，绝不能在美式语境中用来指烟。这是最经典的英美英语 false friend 之一。 |
| **vape** | 电子烟。不是 cigarette，不燃烧，用雾化液。但 e-cigarette（电子香烟）是 vape 的正式名称。 |

### 中文母语者陷阱

- **"香烟"的"香"**：中文叫"香烟"带了一个"香"字，但英文 cigarette 没有任何"香/fragrant"的含义。不要反推 cigarette 和"好闻"有关系。
- **"卷烟"的干扰**：中文也叫"卷烟"，容易让人以为英文对应是 roll。roll-up / rolled cigarette 确实存在，但那特指**手卷烟**（自己用烟纸和烟丝卷的），不是工厂生产的 cigarette。
- **量词**：一根烟 = a cigarette，一包烟 = a pack of cigarettes（美式）/ a packet of cigarettes（英式）。不是 ~~a box~~。一条烟 = a carton of cigarettes。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境说明 |
|---|---|
| **smoke a cigarette** | 最基础动宾搭配。"抽一根烟。" |
| **light (up) a cigarette** | 点烟。light up 比 light 多一点画面感——火苗亮起来的那一刻。 |
| **put out / stub out a cigarette** | 掐灭。stub out 更具体——在烟灰缸里按灭、碾熄。 |
| **a pack of cigarettes** | 一包烟。美式 pack，英式 packet。 |
| **cigarette butt** | 烟蒂/烟屁股。butt 在这里是"残余的尾端"。 |
| **cigarette smoke** | 烟雾（名词修饰名词）。"The room reeked of cigarette smoke." |
| **cigarette break** | 烟歇。上班中途出去抽烟的短暂休息。 |
| **bum a cigarette** | 口语。蹭一根烟。"Can I bum a cigarette off you?" |

### 语域标注

cigarette 本身是**中性词**，书面口语通用。但它的使用场景在当代英语中自带一层微妙的道德判断——尤其在美国英语中，仅仅提到 cigarette 就暗含了"你知道这不健康"的潜台词。这不是词典会告诉你的，但这是真实的语用层。

口语缩写 **cig** 在随意对话中很常见。正式写作用 cigarette 全称。

### 活用示范

> *"I've never seen anyone make lighting a cigarette look like an act of war."*
> ——"我从没见过谁能把点烟这个动作做得像宣战一样。"

这是 cigarette 最有表现力的领地：**电影和文学里的角色塑造工具**。点烟的方式、掐烟的方式、烟雾吐出的方向——英文叙事中，cigarette 几乎是一个无台词的角色道具。

> *"She offered me a cigarette. I don't smoke, but I took it anyway — it felt like refusing would end the conversation."*
> ——"她递给我一根烟。我不抽烟，但还是接了——感觉拒绝就等于结束了这场对话。"

cigarette 在这里是社交货币，不是烟草制品。

## 7. 跨语言映射

- **中文"香烟"**：带"香"字，暗含了一种对气味的正面描述（哪怕今天已经是中性称呼）。cigarette 没有这层意思——它的名字只说了"小雪茄"，关于气味一个字没提。
- **日语「タバコ」（tabako）**：直接来自葡萄牙语 tabaco（烟草），而不是从 cigarette 这条线走的。日语用的是**原材料的名字**而非**产品的名字**——这反映了烟草传入日本的路径是通过 16 世纪的葡萄牙传教士，比法国人发明 cigarette 早了两百多年。
- **法语 cigarette**：拼写和英语一模一样，因为英语就是原封照搬的。但法语发音是 /si.ɡa.ʁɛt/，重音在最后一个音节；英语发音 /ˌsɪɡəˈɹɛt/ 也把重音放在最后——这是法语借词的典型特征（café, ballet, cliché 都是末音节重音）。
- **德语 Zigarette**：同源，Z 开头是德语对法语 c/s 音的常见替换（跟 Zigarre = cigar 一样）。
- **西班牙语 cigarrillo**：没有用法语的 -ette，而是用了西班牙语自己的小词后缀 **-illo**。cigarro → cigarrillo = 小雪茄。和法语 cigarette 走了完全平行的构词路径，各用各家的缩小工具，殊途同归。

这个对照本身就很有意思：同一个"把雪茄做小"的概念，法语用 -ette，西班牙语用 -illo，各自用母语的小词后缀完成了命名。语言不同，逻辑完全相同。
