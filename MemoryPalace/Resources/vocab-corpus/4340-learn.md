# learn

## 1. 一句话本质

**learn 是一只动物在雪地上反复走同一条路，直到脚印踩成了路——不是"接收知识"，是"踩出自己的轨迹"。**

它的词根指向犁沟、足迹、轨道。学习不是有人往你脑袋里倒水，而是你自己一遍一遍踩过同一块地面，直到地面上留下了属于你的痕迹。

---

## 2. 词源考古

### 词根词缀拆解

learn 是个不可再拆的单语素词，但它的根系深埋在日耳曼语和原始印欧语的泥土里：

- **古英语 leornian**（获取知识、学习）
- ← **原始日耳曼语 \*liznōną / \*liznaną**（学习、跟随轨迹）
- ← **原始印欧语 \*leis-**（轨迹、犁沟、脚印）

这个 PIE 词根 \*leis- 同时催生了几条你想不到的支流：

| 后代 | 语言 | 含义 | 和"轨迹"的关系 |
|------|------|------|----------------|
| **lār** | 古英语 | 教导、学问 → 现代 **lore** | 踩出的路→传下来的知识 |
| **lǣran** | 古英语 | 教导 → 现代英语方言 "learn sb." | 带人走已有的轨迹 |
| **Leiste** | 德语 | 条板、楦头 | 鞋匠的楦头 = 脚的轨迹模型 |
| **last** | 英语 | 鞋楦（shoemaker's last） | 脚形的模具 = 保存下来的形状痕迹 |
| **lira** | 拉丁语 | 犁沟 | 犁在田里划出的线 |
| **delirious** | 英语（← 拉丁） | 神志不清 | de-lira = "偏离犁沟"，脱轨了 |

最后一条值得停下来看：**delirious（谵妄、发疯）的字面意思是"偏离了犁沟"**。正常思维 = 沿着沟走；疯了 = 脱轨了。这反过来验证了 learn 的底层图像——学习就是沿着轨迹走，走到你自己也能犁出同样的沟。

### 历史流变

**古英语时期（5-11世纪）**：leornian 和 lǣran 是一对亲兄弟。leornian = 学（跟着轨迹走），lǣran = 教（带人走轨迹）。同根，方向相反，分工明确。

**中古英语时期（11-15世纪）**：lernen 逐渐吞并了两个方向的意思。很多方言里 learn 既当"学"又当"教"——"I'll learn you a lesson"（我教你个乖）在当时完全合法。

**早期现代英语（15-17世纪）**：teach 从古英语 tǣcan（展示、指出）壮大，逐步接管了"教"的地盘。learn = 教 的用法开始被标记为"方言"、"非标准"。但直到今天，英国和美国的一些方言里，"I'll learn you" 仍然活着。

**现代英语**：learn 被严格限定为"学"的一端。但有意思的是，learned/learnt 这个过去式双形态暗藏历史：**learnt** 是英式传统，**learned** 是美式标准化的产物。而当 learned 做形容词时（a learned professor），读音变成 /ˈlɜːrnɪd/，两个音节——这是中古英语屈折形态的活化石。

### 文化地层

learn 最戏剧性的身份转变不是含义漂移，而是**方向截断**——一个曾经双向的词被砍成了单向。

这背后是英语教育体系的权力结构变化：当"谁有资格教"变成一个需要制度认证的事情，语言也跟着切割了——教和学不能用同一个词了，因为这两件事的社会地位不一样了。teach 成了专业动作，learn 被限定为接收端。但词根不撒谎：在最深处，教和学是同一个动作的两个方向——一个人在前面犁沟，另一个人踩着沟走。

## 3. 故事 / 画面

不要想教室。想一块刚下过雪的田野。

一只狐狸穿过田野，留下一串脚印。第二天它又来了，走了差不多同一条路线，但偏了一点。第三天，第四天，第七天——渐渐地，雪地上出现了一条清晰的小径。不是谁铺的路，是走出来的。

这就是 learn。

脚印还浅的时候，你还在 learning——路线不确定，有时走歪，有时踩到之前没踩过的地方。当脚印深到你闭着眼睛也能走这条路的时候，你 learned 了。

而那只最早走出这条路的狐狸？它在做的事情叫 lǣran——teaching。不是它站在讲台上画路线图，而是它先走了一遍，踩出了第一道沟。

这也是为什么 learn 和 delirious 是远亲——delirious 是犁沟犁歪了，脚印乱了，路线不可追踪了。学习是有轨迹的，疯是轨迹崩塌了。

## 4. 多面体：核心义项展开

### 义项一：获取知识或技能（最核心）

> *She learned French in six months.*
> 她六个月学会了法语。

"踩出轨迹"的最直接用法——通过反复接触和练习，在脑子里犁出了一道沟。

### 义项二：得知、获悉（了解到某个信息）

> *I learned of his death through a friend.*
> 我从一个朋友那里得知了他去世的消息。

这不是"学习"了，而是"踩到了一条已有的轨迹"——信息已经存在，你的脚踩上去了。从"反复踩出路"到"踩到一条路"，是同一个动作的一次性版本。

注意搭配：learn of / learn about / learn that——都是"脚踩到了某条痕迹"的不同介词框架。

### 义项三：learned 做形容词——博学的、有学问的

> *A learned professor gave the keynote speech.*
> 一位博学的教授做了主题演讲。

读音 /ˈlɜːrnɪd/，两个音节。这是一个已经踩了无数条路的人——脑子里的犁沟密密麻麻，像田野被反复耕过。注意这个词带有敬意和正式感，日常不太会说 "my learned friend"（除非你在英国法庭上称呼对方律师）。

### 义项四：learn 的教训义——"吸取教训"

> *He learned the hard way that shortcuts don't pay.*
> 他以惨痛的方式认识到走捷径没有好下场。

learn the hard way / learn one's lesson——这里的"学"不是主动去学，是被现实按着头踩进了沟里。脚印不是你自愿踩的，是被推着摔进去的。但结果一样：轨迹留下了。

### 底层统一性

四个义项全都是"轨迹"的变奏：
- 主动反复踩 → 学会
- 踩到一条现成的 → 得知
- 踩了无数条的人 → 博学
- 被按着踩进去 → 吸取教训

## 5. 裂缝标注

### 常见误用场景

**❌ "I learned him how to swim."**
在标准英语中，learn 不能带双宾语表示"教"。虽然方言里合法，但写作和正式场合这么用会被标记为语法错误。该用 **taught**。

**❌ 混淆 learn 和 study**
"I'm learning for the exam" ← 这在很多欧洲语言里是对的（德语 lernen、法语 apprendre），但英语里应该说 "I'm **studying** for the exam"。learn 强调的是**结果**（学会了），study 强调的是**过程**（在学）。你不能 learn for an exam，因为 learn 的轨迹终点是"会了"，而备考是还在路上。

### 易混近义词辨析

| 词 | 核心差异 | 场景对比 |
|----|---------|---------|
| **learn** | 强调结果：轨迹踩成了 | "I learned to cook."（我学会做饭了——能做了） |
| **study** | 强调过程：正在踩 | "I'm studying cooking."（我在学做饭——还在学） |
| **acquire** | 正式、被动获取 | "She acquired a taste for wine."（更书面，暗示渐进） |
| **discover** | 第一次踩到未知的轨迹 | "Scientists discovered a new species."（learn 不含"首次发现"义） |
| **master** | 踩到了极致，沟深到不可能走歪 | "She mastered the piano."（比 learn 更强调精通程度） |

### 中文母语者陷阱

**1. "学习"≠ learn**
中文的"学习"覆盖了 learn + study 两个区间。"我在学习英语"翻成英文要判断：你是在**学的过程中**（studying English）还是在强调**学会**（learning English）？大多数时候中文说"学习"指的是过程，该用 study。

**2. "学到了"的翻译**
"我从这件事学到了很多" → I learned a lot from this. ✅ 没问题。
"我在课堂上学到了很多" → 如果指具体课堂进行中的过程，I learned a lot **in** class. ✅ 但不能说 I studied a lot in class 来表示"学到了"——study 不承诺结果。

**3. learn 后面跟什么**
- learn + 名词/代词（learn French / learn a skill）
- learn + to do（learn to swim）——不说 ~~learn swimming~~ 来表示"学会游泳"
- learn + that 从句（I learned that he had left）
- learn + 疑问词从句（learn how to / learn what / learn where）

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境说明 |
|------|---------|
| **learn from** (mistakes/experience/sb.) | 最核心搭配。从经验/错误/某人那里学。"Learn from your mistakes" 是英语里最常见的说教句之一 |
| **learn the hard way** | 吃了亏才学会。暗示如果你听劝本来不用受这个罪 |
| **learn by heart** | 背诵、记住。by heart = 用心刻进去（不只是脑子，是心） |
| **learn a lesson** | 吸取教训。常带有"被现实打脸"的语气 |
| **learn the ropes** | 学会门道、上手。ropes 原指帆船上的绳索——新水手得先认绳子 |
| **live and learn** | 活到老学到老 / 人就是这样一路犯错一路学。常用作事后感慨 |
| **learn one's trade/craft** | 学一门手艺。有师徒传承的味道 |
| **a steep learning curve** | 学习曲线陡峭——注意：在日常英语中这通常指"很难学"，但技术上 steep curve 意味着学得快（曲线爬升快），这是一个被普遍"误用"到变成正确的搭配 |

### 语域标注

learn 是**全语域通用词**——口语、书面、学术、新闻、日常对话全能用，没有正式度限制。它是英语中最基础的盎格鲁-撒克逊核心词汇之一，不像 acquire（拉丁系、偏正式）那样有语域门槛。

唯一的语域敏感点是 **learned** 做形容词（/ˈlɜːrnɪd/）：这个用法偏正式/书面/学术，日常口语里说 "a knowledgeable person" 比 "a learned person" 更自然。

### 活用示范

> *"Some things cannot be taught; they must be learned."*
> （有些东西没法教，只能自己学。）

——这句话之所以有力量，恰恰是因为 teach 和 learn 在古英语里本是同根双生：教和学的分裂不是语言的，是经验的。有些沟，没人能替你犁。

> *"I'm still learning."*
> （我还在学。）

——三个字，但在英语文化里是一句非常有力量的谦逊表达。不是说"我不会"，而是说"我的轨迹还没踩完"。

## 7. 跨语言映射

**德语 lernen / lehren**：德语完美保留了古英语的双生结构。lernen = 学，lehren = 教。同根，方向相反。英语把 learn = teach 的用法判了非标准死刑，德语没有——两个词至今并肩而立。

**拉丁语 discere**：拉丁语的"学"走了完全不同的意象路线。discere 和 discernere（辨别）同源，学习 = 辨别事物之间的差异。日耳曼人认为学习是踩轨迹，罗马人认为学习是分辨差异——两种文明对"学"的底层想象截然不同。

**中文"学"**：甲骨文的"學"上面是两只手在摆弄算筹（爻），下面是"子"——小孩在模仿摆弄。中文"学"的原始意象是**模仿**，不是踩轨迹，也不是辨别，而是"照着做"。这和 learn 的"自己踩出路"有微妙的温度差：中文的学暗示有个范本在前面，英文的 learn 暗示那条路是你自己踩出来的。

**日语 習う（narau）**：从"倣う"（模仿）分化而来，和中文"学"一样走的是模仿路线。但日语还有 学ぶ（manabu），来自"真似ぶ"（模仿），依然是模仿。有意思的是，日耳曼语系独独选了"轨迹/犁沟"这个意象——可能和北欧农耕生活有关，犁地是日耳曼世界最核心的日常劳作之一。

---

**收束**：learn 这个词骨子里不是关于课堂、书本、老师的。它是关于一双脚和一块地面的关系。你走过去，再走过去，再走过去——直到地面记住了你，你也记住了地面。那条被踩出来的路，就是你学到的东西。
