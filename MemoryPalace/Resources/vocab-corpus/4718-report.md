# report

---

## 1. 一句话本质

**report 是一个信使的完整动作——出去、带回来。** 不是信息本身，是"把东西从远处搬回原点"这个行为，以及搬回来的那个东西。枪声是空气把震动"搬回"你耳朵；述职是你把成果"搬回"上级面前；名声是别人把你的故事"搬回"各处。一个词，一条回程的弧线。

---

## 2. 词源考古

### 词根词缀拆解

```
re-  （back，往回）
+
portāre  （to carry，搬运）
=
reportāre  （to carry back，带回来）
```

**portāre** 这个拉丁词根是个重量级选手，它的后代遍布英语：
- **transport**（trans- 跨过 + 搬）= 运输
- **export**（ex- 出去 + 搬）= 出口
- **import**（im- 进来 + 搬）= 进口
- **deport**（de- 离开 + 搬）= 驱逐
- **portable**（能搬的）= 便携的
- **port**（搬货的地方）= 港口

所以 report 的兄弟姐妹全是"搬运工"。区别只在方向——export 往外搬，import 往里搬，transport 跨着搬，而 **report 是往回搬**。

### 历史流变

**拉丁语 reportāre**（带回来，物理性地搬回）
→ **古法语 reporter**（13世纪，开始从"搬东西回来"漂移到"把消息带回来"）
→ **中古英语 reporten**（14世纪进入英语，已经稳定在"汇报消息"的含义上）

关键转折点：

**14世纪**：进入英语时，物理搬运的含义已经基本消失，核心义项锁定在"把信息带回来"。这个抽象化在法语阶段就完成了。

**15世纪**：出现"loud noise"义项——枪炮的report。这个含义初看离谱，但逻辑链条很清楚：声音从发出点"传回"（carry back）到听者耳朵。拉丁语里 reportāre 本来就有"回响、回声"的引申义。所以这不是语义漂移，是原始隐喻的另一条分支。

**16世纪**：出现 "report for duty"（报到）。搬运的对象从"消息"变成了"你自己"——你把自己搬回到该在的地方。同期出现 "report to someone"（向某人汇报/对某人负责），从"把信息搬给他"引申为层级关系。

**古义残存**："of good/ill report"（名声好/坏）。这个用法现在带书面语/古雅感，但逻辑完美：你的名声就是别人把关于你的故事"搬来搬去"的产物。

### 文化地层

report 没有经历过褒贬翻转或剧烈语义断裂，但它有一个值得注意的**重心迁移**：在现代英语里，report 的名词用法（一份报告、一篇报道）已经比动词用法更常见、更有存在感。这反映了一个文化事实——我们生活在一个被"报告"淹没的世界里。季度报告、调研报告、新闻报道、成绩报告单……report 从一个动作（带回来）变成了一种文体（那份文件）。信使被遗忘了，只剩下信。

## 3. 故事 / 画面

古罗马。一个斥候骑马冲出营地，消失在晨雾里。

三天后他回来了。马身上全是泥，他自己也是。他翻身下马，走进将军的帐篷，把看到的一切——敌军人数、扎营位置、河流走向——全倒出来。

这个完整的弧线就是 report：**出发 → 到达远处 → 收集 → 折返 → 交付。**

现在把这个弧线压缩到日常生活里：

你的老板让你去调研竞品。你花一周看了十个产品，写了一份 PPT。周五你走进会议室，打开投影，开讲。——这整个过程是 report，那份 PPT 也是 report。

再压缩：一声枪响。声波从枪口出发，穿过空气，**搬回**到你的耳膜上。嘭。——这也是 report。

核心永远是同一条弧线：**从远处带回来。**

## 4. 多面体：核心义项展开

### ① 名词：一份正式的书面/口头叙述

> *The committee published a 200-page report on climate change.*
> 委员会发布了一份200页的气候变化报告。

和本质的关系：报告就是信使带回来的那个东西——信息的容器。

### ② 动词：汇报、报道、叙述

> *She reported the incident to the police.*
> 她向警方报了案。

和本质的关系：最原始的用法。你把一个事件"搬运"到需要知道它的人面前。

### ③ 动词：报到、到场

> *All new recruits must report for duty at 0800.*
> 所有新兵必须于08:00报到。

和本质的关系：搬运的对象从信息变成了你自己——你把自己"搬回"到指定地点。

### ④ 动词：隶属于、向……汇报（组织关系）

> *In her new role, she reports directly to the CEO.*
> 在新职位上，她直接向CEO汇报。

和本质的关系：如果你持续地把工作成果"搬回"给某个人，那个人就是你的上级。一个反复发生的搬运动作，凝固成了一条权力线。

### ⑤ 名词：爆炸声、枪声

> *A


 


loud report echoed across the valley.*
> 一声巨响在山谷中回荡。

和本质的关系：声波从源头"搬运"到你耳朵的物理过程。这个义项现在偏书面/文学，日常口语中说 bang 或 shot 更多。

### ⑥ 名词：名声、风评（书面/古雅）

> *a man of good report*
> 一个风评良好的人

和本质的关系：名声 = 别人把关于你的信息"搬来搬去"后沉淀下来的总体印象。

## 5. 裂缝标注

### 常见误用场景

**❌ "report" ≠ "tell"**

report 带有**正式性、系统性、向上/向权威方向**的语感。你 report 给警察、给老板、给委员会。你不 report 给朋友昨晚吃了什么。

> ✗ *I reported my friend about the movie.* （太重了，像在打小报告）
> ✓ *I told my friend about the movie.*

**❌ report 做"报道"时，主语通常是记者/媒体**

> ✗ *The earthquake reported 7.2 on the Richter scale.* （地震不会自己报道自己）
> ✓ *The earthquake was reported as 7.2…* 或 *Seismologists reported it at 7.2…*

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **report** | 正式、结构化、有接收方。你总是 report **to** 某个权威或 **on** 某件事。带"交差"感。 |
| **account** | 更偏"叙述、描述"，强调的是故事性，不一定有接收方。*Give an account of what happened.* |
| **statement** | 单次正式表态，通常较短，且可以是立场声明，不一定是事实汇报。 |
| **announce** | 公开宣布，方向是"向外广播"，而 report 的方向是"向回传递"。 |

### 中文母语者陷阱

**⚠️ "报告"的中文含义比 report 窄。**

中文"报告"几乎 = 正式文件。但英文 report 可以是动词（汇报、报案、报到），可以是声响，可以是名声。中文母语者容易把 report 当成只能出现在办公室的词。

**⚠️ "report for duty" ≠ "报告！到！"**

军队里喊的那个"报告！"在英文里不是 "report!"，而是不同的表达体系（如 *Sir, Private Smith reporting, sir*）。report for duty 是一个行政概念（到指定地点登记到场），不是一个喊口号的场景。

**⚠️ "据报道" 的翻译惯性**

中文新闻里的"据报道"不一定要翻成 *It is reported that…*——这个结构在英文新闻里是有的，但远不如中文用得频繁。英文新闻更常见的是直接引述来源：*According to Reuters, …* 或 *CNN reports that …*。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **file a report** | 正式提交一份报告（警方、公司、政府）。file 强调"归档"这个动作。 |
| **annual report** | 年报。上市公司必出的那种。 |
| **report back** | 回来汇报。re- 本身就是"回"，再加 back 是双重强调，口语中非常自然。 |
| **reported speech** | 间接引语（语法术语）。"他说他要走了"——你在"搬运"他的话。 |
| **progress report** | 进度报告。项目管理和学校都用。 |
| **news report** | 新闻报道。 |
| **report card** | 成绩报告单。美式英语，英式叫 school report。 |
| **reportedly** | 据报道、据说。新闻写作高频词，表示信息来自转述而非记者亲眼所见。 |

### 语域标注

report 是**全域词**——从最正式的法律文书到日常口语都能用，但在不同语域里偏向不同的义项：

- **学术/商务/政府**：名词为主，正式文件。*The report concludes that…*
- **新闻**：动词为主。*Reuters reports that…*
- **日常口语**：*I need to report this to HR.* / *Report to the front desk.*
- **文学**：枪声义（*the report of a rifle*）几乎只出现在文学和正式叙事中

### 活用示范

> *"Reports of my death have been greatly exaggerated."*
> ——马克·吐温（据传，此句本身的归属也有争议，颇为讽刺）

这里的 reports 是"关于我的消息/传闻"——别人把"我死了"这个信息到处搬运，但搬错了。

> *The gun went off with a sharp report that scattered the birds from every tree for a hundred yards.*

枪响用 report 而不用 bang，瞬间把文字质感从口语拉到文学。这是 report 在"声音"义项上的典型用法——冷、精确、有距离感，像在画面外旁观。

## 7. 跨语言映射

**拉丁语系内部的一致性：**

法语 **rapport**（关系、报告）和 report 是同源双胞胎，但走了不同的路。rapport 在法语里保留了更广的含义（人际关系、联系），英语借入 rapport 时只取了"融洽关系"这一层。于是英语里 report 和 rapport 分了家：report = 带回信息，rapport = 带回情感连接。同一个词根，一个走了事务线，一个走了人际线。

**中文"报"：**

中文的"报"（報）也有类似的弧线结构——"报告""报道""报到""报名""报复""报应"——核心都有一个"回去"的动作。"报复"是把伤害搬回去，"报应"是因果的回旋。这和 report 的 re-portāre 结构惊人地同构。

**日语「報告」（ほうこく）：**

直接借用汉字"報告"，含义和中文几乎一致，偏正式书面。但日语中 report 的片假名形式 **レポート** 也广泛使用，特别是在学术场景（大学里交的小论文叫レポート，不叫報告書）。同一个词，汉字版走正式路线，片假名版走日常路线。
