# computerize

---

## 1. 一句话本质

**computerize 是把人手里的活儿塞进机器肚子里的那个动作——不是"用电脑"，是"让电脑来"。**

它的重心不在电脑本身，而在那个**交接仪式**：一件事原来由人做，现在把钥匙递给了机器。带着一股 1960 年代办公室里打字机被搬走、磁带机被推进来的味道。

---

## 2. 词源考古

### 词根词缀拆解

```
computerize
├── computer     ← 做计算的东西/人
│   ├── compute  ← 计算
│   │   ├── com- (Latin) = 一起、彻底（强化前缀）
│   │   └── putare (Latin) = 修剪 → 清算 → 思考
│   └── -er      = 做这件事的人/物（施动者后缀）
└── -ize (Greek -izein) = 使之成为、使之变成
```

关键在 **putare** 这个拉丁词根——它的原始含义是**修剪树枝**。罗马人修剪果园时要数枝条、估产量，于是 putare 从"剪枝"滑向了"清点、核算"，最终抽象成"思考、认为"（英语里的 reputation、dispute、impute 全是它的后代）。

**com-** 在这里是强化前缀，不是"一起"的意思。computare = 彻底地清算、通盘地计算。

### 历史流变

| 时间 | 事件 |
|------|------|
| 拉丁语 | **computare**：清算、计算。西塞罗用过这个词。 |
| 17世纪 | **computer** 出现——但指的是**人**。"Computer" = 负责做计算的职员。一直到二战时期，"computer"还经常指坐在桌前手算弹道的女数学家们。 |
| 1940s | 电子计算机诞生（ENIAC，1946）。computer 的含义从"算账的人"漂移到"算账的机器"。这是一次**物种替代式的语义转移**——词没变，但词指代的实体从碳基变成了硅基。 |
| 1950s–60s | **computerize** 造出来了。最早的文献使用大约在 1957-1960 年间。IBM 的推销员们需要一个动词来描述"让你的公司用上我们的大型机"这件事，于是 computer + -ize，简单粗暴。 |
| 1970s–80s | 大规模 computerization 浪潮，这个词进入日常英语。银行、医院、政府机构排队"computerize"。 |
| 2000s至今 | 这个词开始显得**有点老**。今天你更可能说 digitize、automate，甚至直接说用 AI。computerize 带着一种复古色彩，暗示的是"从纸质/手工到电子化"这个特定的历史转折。 |

### 文化地层

最有意思的一层：**computerize 这个词本身记录了一个时代的焦虑**。1960-70 年代，"computerize" 在报纸上几乎是个半恐怖的词——"They're going to computerize our jobs"（他们要把我们的工作电脑化了）。它不只是技术术语，还承载着**被取代的恐惧**。某种意义上，今天人们对 AI 的焦虑，和六十年前对 computerization 的焦虑是同一种情绪的复刻。

另一个值得注意的：英式英语也拼作 **computerise**（-ise），但含义完全相同。

## 3. 故事 / 画面

1962 年，某个美国中西部的保险公司。

一楼大厅里原来坐着四十个女职员，每人面前一台手摇计算器，桌上堆着保单和索赔表。她们从早到晚做同一件事：核算、核算、核算。

有一天，搬运工推进来一台比冰箱还大的 IBM 1401。公司经理站在走廊里对员工说了一句话——这句话在那十年里被无数经理在无数公司说过：

**"We're going to computerize."**

不是"我们买了台电脑"。是"我们要**把这件事**交给电脑了"。

四十张桌子，两个月后变成了四张。那台 IBM 在角落里嗡嗡响，磁带转着，打孔卡片一叠一叠地吞进去吐出来。

**computerize 就是那个搬运工推着机器进门、职员往门外走的画面。它是一个过渡动词——有起点（人做），有终点（机器做），中间是一次不可逆的交接。**

## 4. 多面体：核心义项展开

### 义项一：将（流程/系统）改为由计算机处理

> *The hospital decided to **computerize** all patient records.*
> 医院决定将所有病历电子化。

这是最核心的用法。注意：不是"用电脑看病历"，而是"把病历系统**改造成**电脑运行的"。重心在**改造过程**，不在日常使用。

与"一句话本质"的关系：钥匙递出去的那个动作——原来纸质的，现在变成机器管的。

### 义项二：为（场所/组织）配备计算机

> *The government plans to **computerize** every public school by next year.*
> 政府计划明年让所有公立学校都装上电脑。

这个义项偏向"硬件进场"——不只是流程改造，而是物理性地把电脑搬进去。

与"一句话本质"的关系：还是同一个画面的变体——搬运工推着设备进入一个原本没有计算机的空间。

### 义项三：（被动/形容词化）computerized = 由计算机控制的

> *a fully **computerized** navigation system*
> 一套全计算机化的导航系统

这是最常见的遇到形式——你见到 computerized 的频率远高于 computerize。它描述的是交接完成后的状态。

与"一句话本质"的关系：钥匙已经递完了，机器已经在管事了。

## 5. 裂缝标注

### 常见误用场景

**❌ "I need to computerize this document."**

如果你只是想把一份纸质文件扫描存进电脑——那是 **digitize**，不是 computerize。computerize 暗示的是**整个系统/流程**的转换，不是单个文件的格式转换。把一份文件扫描成 PDF ≠ computerize；把整个档案管理系统从纸质改成数据库 = computerize。

**❌ 用 computerize 描述 2020 年代的技术升级**

"We're going to computerize our workflow with AI." 这句话语感上很别扭。computerize 的语义预设是**从非数字到数字**的转换。如果你的流程已经在电脑上跑了，只是要升级到 AI，那应该说 **automate**、**streamline**、或直接说 integrate AI。computerize 在今天更适合描述那些**真的还在用纸和笔**的场景。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **digitize** | 把模拟信号/实体转换成数字格式。扫描一张照片 = digitize。重心在格式转换，不涉及流程改造。 |
| **automate** | 让机器替人做重复性工作。可以不涉及电脑（工厂流水线也是 automate）。范围比 computerize 宽。 |
| **computerize** | 特指把一个系统/流程从"人工/手动"改为"由计算机运行"。兼具硬件进场 + 流程改造。 |

一句话区分：digitize 改的是**格式**，automate 改的是**劳动方式**，computerize 改的是**谁在管这件事**。

### 中文母语者陷阱

**"电脑化"不等于"用电脑"。** 中文语感里"电脑化"可以很随意——"我把笔记电脑化了"听着没问题。但英语里 computerize 的语域更正式、规模更大。你不会说 "I computerized my notes"——那太重了，像是你为了管笔记搭建了一整套数据库系统。轻量级的"放到电脑里"直接说 put it on the computer / type it up 就好。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **computerize records / files** | 最经典：把纸质档案/记录改为电子系统 |
| **computerize operations** | 企业/机构运营流程电脑化 |
| **fully computerized** | 形容已完成改造的系统——"全面电脑化的" |
| **computerized system / database** | 由计算机运行的系统/数据库 |
| **computerized testing** | 计算机化考试（如 GRE、托福 CBT） |
| **computerized billing** | 计算机化账单系统 |
| **plan to computerize** | 新闻/公文里常见的"计划推行电脑化" |

### 语域标注

- **正式程度**：中高。这是新闻报道、商业文件、政府公告里的词，不是聊天用的。
- **时代色彩**：有 1970s–90s 的味道。今天仍然能用，但会让人联想到那个"从纸质到数字"的特定历史阶段。在科技行业内部，这个词已经不太说了（太基础了，就像今天不会说"我们要通电"一样）。在医疗、政府、教育等领域——那些真的还在 computerize 的领域——仍然活跃。
- **写作 vs 口语**：偏书面。口语中更可能说 "put everything on computer" 或 "go digital"。

### 活用示范

> *"The IRS spent $11 billion trying to computerize, and still sends letters by mail."*
> 国税局花了 110 亿美元搞电脑化，结果还在寄纸质信。

——这句里 computerize 不带宾语、独立使用，带着一种苦涩的幽默。暗示 computerize 是一个**大工程**，可以花很多钱、很多年，而且可以失败。

> *"You can't just computerize a broken process and expect it to work."*
> 你不能把一个本来就烂的流程扔给电脑就指望它能跑。

——技术行业里的经典格言。computerize 在这里被用来批评一种思维方式：以为加电脑就能解决问题。

## 7. 跨语言映射

**中文**："电脑化"/"计算机化"——几乎是直译，语感也接近。但中文里"信息化"的使用范围更广，涵盖了英语里 computerize + digitize + informatize 好几个词的领地。中国语境下说"推进信息化建设"，英语不太会说 "push informatization"——更可能分解成 computerize（上系统）+ digitize（数字化）+ go online（联网）。

**日文**：**コンピュータ化**（konpyūta-ka）——也是直译，-化 = -ize。但日语商务场景更常用 **IT化**（IT-ka）或 **デジタル化**（dejitaru-ka），和英语从 computerize 往 digitize 迁移的趋势平行。

**法文**：**informatiser** ← informatique（计算机科学）+ -iser。法国人没有用 "computériser" 这个词——他们从 information 而非 computation 的角度给这件事命名。这个差异很有意思：英语觉得核心是"算"，法语觉得核心是"信息处理"。

---

**收束**：computerize 是一个自带时间戳的词。它精确地标记了 20 世纪后半叶那场把世界从模拟推向数字的大迁徙。今天它仍然能用，但每次用它，你其实是在无意识地致敬那个搬运工推着 IBM 大型机进入办公室的画面。如果你的语境是"从零到有"——从纸到屏幕、从手工到系统——computerize 依然是精准的那个词。如果东西已经在电脑上了只是要升级，那就该换别的词了。
