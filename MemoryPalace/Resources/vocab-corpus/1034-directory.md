# directory

---

## 1. 一句话本质

**directory 是一张"你要找的东西在哪"的地图——不存内容本身，只存"往哪走"。**

它是图书馆前台那块楼层索引牌，是酒店大堂的住客名册，是你手机里"文件夹"这个概念的前世。directory 从不承载实质，它只做一件事：**指路**。

---

## 2. 词源考古

### 词根词缀拆解

```
di·rect·ory
│  │     │
│  │     └─ -ory：拉丁后缀，表"做某事的地方/工具/集合"
│  │         （如 observatory = 观测的地方，inventory = 清点用的东西）
│  │
│  └─ rect：来自拉丁语 regere（统治、引导、拉直）
│      → directus（past participle：已被引导的、笔直的）
│      同根词：rectangle（直角矩形）、correct（一起弄正）、erect（竖直）、rector（管事的人）
│
└─ di-：dis- 的变体，表"分散、彻底"
    → dirigere = dis + regere = "把各方向的东西理清、引向正确的路"
```

所以 directory 的骨架是：**"那个帮你把方向理清的东西"**。

### 历史流变

**14 世纪 · 教堂里的第一本 directory**

这个词最早的身份非常具体——*Directorium*，是天主教会给神父用的一本**礼拜指南**。每天该念哪段经文、哪个圣人的纪念日用哪套仪式，全写在这本书里。神父不需要自己判断，翻开 directorium，它告诉你"今天走这条路"。

这是 directory 的原始人格：**不替你做决定，但告诉你该去哪。**

**17-18 世纪 · 从神圣到世俗**

词义开始从教会扩散到日常。任何一本"帮你找到人/找到地方"的册子都可以叫 directory——商人名录、城市居民册、行业指南。1732 年伦敦出现了早期的 city directory，按街道列出住户。到 19 世纪电话发明后，telephone directory（电话簿）成了这个词最广为人知的面孔。

**1795 年 · 法国大革命的 Directoire**

法国大革命砍完国王头后，1795-1799 年间执政的五人委员会叫 **le Directoire**（英语：the Directory）。"指导国家方向的人"——directory 从"指路的册子"跳到了"指路的机构"。这个用法今天还活着：board of directors（董事会）就是这个脉络。

**1960 年代 · 计算机时代**

当早期操作系统需要一个概念来组织磁盘上的文件时，directory 被选中了。原因精准：它不是文件本身，它是**告诉你文件在哪的索引结构**——和电话簿的逻辑一模一样。后来 Windows 用 "folder"（文件夹）这个更直觉的隐喻包装了它，但底层术语至今是 directory。Unix/Linux 世界从不说 folder，只说 directory。

### 文化地层

注意这条暗线：directory **始终不是内容本身**。教堂的 directorium 不是经文，是"经文在哪"的索引；电话簿不是电话，是"电话号码在哪"的表格；计算机的 directory 不是文件，是"文件在哪"的数据结构。

**它是关于内容的内容，是 meta-information。** 这个性质从 14 世纪到今天没变过。

## 3. 故事 / 画面

一座巨大的火车站，穹顶下挂着一块巨型翻牌信息屏。

屏幕上没有一列火车。没有一个座位。没有一段铁轨。它只有三列内容：**车次、目的地、站台号**。

你不会站在信息屏前说"我到了"——你看一眼，知道该去 7 号站台，然后转身走过去。信息屏的全部价值在于：**它让你不用在 20 个站台之间瞎跑。**

这就是 directory。

它永远是中间人。你不会住在电话簿里，不会把文件存进文件夹名称本身。Directory 是那个你看一眼就走的东西——**但如果它不在，你哪也去不了。**

## 4. 多面体：核心义项展开

### 义项一：名录、通讯簿（最经典）

> *Her number wasn't listed in the directory.*
> 她的号码没有登在通讯录上。

按字母或分类排列的人名/机构/号码清单。电话簿是 20 世纪的标志性物件，厚厚一本 Yellow Pages 就是 directory 最具象的形态。

和本质的关系：帮你找到人——**指路到人**。

### 义项二：计算机目录/文件夹

> *Save the file to the root directory.*
> 把文件存到根目录。

操作系统中用来组织文件的层级结构。`/home/user/documents/` 里每一个 `/` 分隔的就是一层 directory。

和本质的关系：帮你找到文件——**指路到数据**。这是词义最精确的继承：计算机 directory 和电话簿一样，自身不存内容，只存"内容在哪"的指针。

### 义项三：（机构性的）指导委员会/董事会

> *The French Directory ruled for four turbulent years.*
> 法国督政府动荡地执政了四年。

一群负责"指明方向"的人组成的决策机构。如今更常见的形态是 board of directors。

和本质的关系：帮组织找到方向——**指路到决策**。从"指路的册子"到"指路的人"，directory 的动词内核 *direct* 没变。

### 义项四：（建筑物/机构的）楼层指南、导引牌

> *Check the directory in the lobby to find Dr. Chen's office.*
> 看大厅的楼层指南找陈医生的办公室。

商场、医院、写字楼里那种"几楼有什么"的标牌或电子屏。

和本质的关系：帮你在物理空间里找到目的地——**指路到地点**。最原始、最直觉的 directory。

## 5. 裂缝标注

### 常见误用：directory ≠ dictionary

这是最高频的混淆。两个词长得像，都是"一本按顺序排列的东西"，但：

- **dictionary**（词典）：词 → 定义。它**解释**内容。
- **directory**（名录）：名字 → 位置/联系方式。它**定位**内容。

记忆锚点：dictio**n**ary 有个 **n**，n for **meaning**（好吧这个不太管用）。更靠谱的：dictionary 来自 *dictio*（说话、措辞），是关于"怎么说"的；directory 来自 *dirigere*（引导），是关于"去哪找"的。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **catalog** | 侧重"完整列举所有项目"，通常附带描述/图片（产品目录、图书馆目录）。Directory 更轻，只给你"名字+怎么找到它" |
| **index** | 侧重"按关键词定位到具体页码/位置"，是书末那种东西。Directory 是独立存在的完整文档，index 通常依附于另一个文档 |
| **folder** | 在计算机语境中和 directory 几乎同义，但 folder 是 GUI 隐喻（你看到一个文件夹图标），directory 是底层术语（你在终端里 `cd` 进去的东西）。技术写作中用 directory，日常用 folder |
| **register** | 侧重"官方登记在册"，有行政/法律意味（出生登记册、选民登记册）。Directory 没有这层"官方性" |

### 中文母语者陷阱

中文"目录"同时覆盖了英文的 directory、table of contents、catalog 三个概念。当你想说"书的目录"时，**不是** directory，是 **table of contents**。Directory 在中文里更接近"名录""通讯录""指南"——是独立的、可以单独成册的索引，不是附在某个东西后面的列表。

另一个坑：中文"导演"（电影的）英文是 **director**，但 directory 和导演没有直接关系。虽然词根相同（都是"指引方向"），但 director 是"指引方向的人"，directory 是"帮你找到方向的工具/文档"。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **telephone / phone directory** | 电话簿。虽然实体电话簿快绝种了，但这个搭配在语言中还活着 |
| **business directory** | 企业黄页/商业名录，线上版如 Yelp、Google Business |
| **directory listing** | 名录中的一条记录（"他的诊所有一条 directory listing"） |
| **directory structure** | 计算机术语：文件目录的层级结构 |
| **root directory** | 根目录，文件系统的最顶层（`/`） |
| **current/working directory** | 当前目录，终端里你"站"的位置（`pwd` 显示的） |
| **directory assistance** | （电话公司的）查号服务，打电话问接线员"某某的号码是多少" |
| **member directory** | 会员名册（协会、社团用） |

### 语域标注

**中性偏正式。** 日常口语中电话簿更常直接叫 phone book；计算机语境中非技术用户更常说 folder。Directory 在以下场合最自然：

- 技术写作（命令行、文档）
- 商务/机构语境（business directory, company directory）
- 图书馆学/信息科学

不算书面语专属，但也不是随口说的俚语——它带着一种"系统化组织"的气质。

### 活用示范

> *"The internet was supposed to be this grand directory of human knowledge, but it turned into a mall."*
> "互联网本该是人类知识的宏大索引，结果变成了一个商场。"

这里 directory 被隐喻化，精准地用了它"指路而非承载内容"的本质——互联网原本的理想是帮你找到知识，而不是把你困在购物里。

> *"I spent twenty minutes navigating the directory tree before realizing the file was in home all along."*
> "我在目录树里翻了二十分钟，才发现文件就在 home 下。"

程序员日常。directory tree（目录树）这个搭配把 directory 的层级感具象化了——树有根、有分叉、有叶子，和文件系统的结构一一对应。

## 7. 跨语言映射

**中文"目录"** 覆盖面比 directory 宽得多——书的章节列表、文件夹、通讯录都可以叫"目录"。但 directory 只取其中"帮你定位到具体位置"的那个切片。中文的"目录"更像 directory + table of contents + catalog 的叠加态。

**法语 *répertoire***（同源词 *directoire* 另有专指）更日常地表达"名录/通讯录"的意思，而且法语的 répertoire 被英语借走变成了 **repertoire**（保留剧目/技能库），词义漂移得相当远——从"可以按索引查找的列表"变成了"一个人/剧团掌握的全部技能/作品"。两个词分享同一个"有组织的集合"的底层概念。

**日语「ディレクトリ」** 是直接音译，几乎只用在计算机语境中。日常的"电话簿"日语说「電話帳」，"名录"说「名簿」。这说明 directory 这个词在跨语言传播时，是它的**计算机义项**最具穿透力——因为这个义项没有本土替代品。

*最后的检验：如果你只记住"火车站翻牌信息屏"这个画面，和"directory 永远不是内容本身，只是告诉你内容在哪"这句话——你能不能在任何语境下还原这个词的意思？电话簿：人名翻牌屏。文件夹：文件翻牌屏。董事会：组织的翻牌屏。能还原。收工。*
