# log

---

## 1. 一句话本质

**log 是一截被砍倒的木头——它不再生长，但它忠实地记录了年轮。** 从一段死木头，到航海日志，到服务器日志，log 的所有面孔都在做同一件事：把流动的时间砍成一截一截，刻下痕迹。

---

## 2. 词源考古

### 词根拆解

log 本身是个不可拆的单音节词，没有词缀结构。但它的来路很有意思。

**"木头"义**：中古英语 *logge*（14 世纪出现），来源**存疑**。主流猜测指向古挪威语方言——挪威语 *lag* 意为"倒下的树"。也有学者试图追溯到古英语，但缺乏直接文献证据。这个词突然出现在 14 世纪的英语里，像一截木头一样——没有祖先，没有家谱，就那么横在那儿了。

**"记录"义**：这条语义路径是英语史上最漂亮的隐喻迁移之一——

17 世纪的水手需要测船速。方法是：把一块楔形木头（叫 **chip log**，测速木块）绑上一根打了等距绳结的绳子，扔进海里。木头浮在水面不动，船往前走，水手数规定时间内滑过多少个绳结——这就是 **knot**（节）作为航速单位的由来。

每次测完，水手把数据记进一本专门的本子。因为测量工具是那块木头 log，本子就叫 **log-book**（1670 年代首次记录）。再后来，book 被省掉了，直接说 log——"打开 log"不再是"搬一截木头"，而是"翻开记录本"。

一块被扔进海里的木头，最终变成了人类记录一切事物的动词。

**数学义（logarithm 的缩写）**：这个 log 和木头**毫无关系**。1614 年，苏格兰数学家 John Napier 造了 *logarithm* 这个词，拼合自希腊语 *logos*（比率）+ *arithmos*（数）。"比率之数"。缩写成 log 纯粹是数学家嫌写全名太长，和那截木头只是字母的巧合。

### 历史流变时间线

| 时间 | 含义 | 关键事件 |
|------|------|---------|
| ~14C | 一截木头 | 突然出现在中古英语，来源不明 |
| ~17C | 测速木块 | 航海术语 chip log |
| 1670s | 航海日志 | log-book → log |
| 1614 | 对数（缩写） | Napier 造词，与木头无关 |
| 1840s | 泛指任何记录 | 从航海扩展到一般用途 |
| 1960s+ | 计算机日志 | 系统事件记录，完成了从木头到数据的转世 |

### 文化地层

log 的语义漂移有一个深层结构：**从物体到行为的转化**。

木头是死的、静止的、被动的。但 log 作为动词"记录"时，变成了活的、持续的、主动的。这个转化的桥梁就是那块被扔进海里的测速木头——它是物体，但它在执行一个功能：**用自己的静止来测量别人的运动**。

一截不动的木头，量出了船走了多远。这个画面本身就是 log 所有含义的底层逻辑：**用固定的刻度去捕捉流动的东西。**

## 3. 故事 / 画面

1670 年，某个大西洋上的夜晚。

一个水手站在船尾，手里攥着一根绳子，绳尾拴着一块三角形的木板。他把木板扔进黑漆漆的海里。木板落水，浮住了，一动不动。船继续往前走。绳子从他手里滑出去，一个结、两个结、三个结……三十秒沙漏漏完，旁边的人喊"停"。他掐住绳子，数出七个结。

然后他转身，走进昏暗的船舱，翻开一本被海风吹皱的本子，在今天的日期下面写：**7 knots**。

这本本子，就叫 log。

四百年后。凌晨三点，一个程序员盯着黑色终端，打下 `tail -f server.log`。绿色的字一行行滚上来，每一行都带着时间戳。服务器不会说话，但它像那块浮在海上一动不动的木板——忠实地标记着每一个经过它的请求、每一次崩溃、每一个错误。

程序员在日志里找到了一行异常。就像那个水手在绳子上数到了不该出现的第八个结。

木头变了。海变了。但 log 做的事情从来没变——**在流动中做一个不动的锚点，然后把经过的一切刻下来。**

## 4. 多面体：核心义项展开

### 面 ① 名词：一截木头 / 原木

最古老的含义。不是活着的树，是砍倒的、不再生长的、沉重的一段。

> *We sat on a fallen log by the creek and watched the water go by.*
> 我们坐在溪边一截倒下的原木上，看着水流过。

与"一句话本质"的关系：log 最原始的身份——从流动的生命中截下来的一段固定物。

### 面 ② 名词：日志 / 记录

从航海日志扩展到一切系统性的记录。强调的是**按时间顺序、持续地记**。

> *The captain's log noted unusual currents at 14:00.*
> 船长日志记录了 14:00 的异常洋流。

> *Check the error log — something crashed at midnight.*
> 查一下错误日志——半夜有东西崩了。

与"一句话本质"的关系：年轮就是树的 log——一圈一圈地刻下时间。日志是人造的年轮。

### 面 ③ 动词：记录

to log = 把某件事写进记录里。

> *The system logs every API call with a timestamp.*
> 系统给每个 API 调用都打上时间戳记录下来。

与"一句话本质"的关系：不是"创造"，是"刻痕"。log 作为动词不产生新东西，它只是把已经发生的事固定住。

### 面 ④ 动词短语：log in / log out（登录 / 登出）

这个用法直接来自航海日志——水手上船时在日志上签到（log in），下船时签退（log out）。数字时代完整继承了这个隐喻。

> *You need to log in before accessing the dashboard.*
> 你得先登录才能访问控制台。

与"一句话本质"的关系：在记录上刻下"某人到了"或"某人走了"——log 的核心还是"留痕"。

### 面 ⑤ 名词/动词：log（对数 / 取对数）

数学里 logarithm 的缩写。和木头没有词源关系，但缩写形式完全一样。

> *The algorithm runs in O(n log n) time.*
> 这个算法的时间复杂度是 O(n log n)。

与"一句话本质"的关系：这张面孔是个"假亲戚"——长得一样，但血统完全不同。学习者要知道的就是：**看到 log，先看语境。数学里的 log 不是木头变来的。**

## 5. 裂缝标注

### 常见误用

**❌ 把 log 当成"随手记"**
log 暗含**系统性、时间线性**的意味。你随手在便签上写个备忘，那不是 log，那是 note。log 是持续的、有时间戳的、按顺序的。写日记（diary/journal）和 keep a log 有重叠但气质不同——diary 可以跳着写、可以抒情；log 冷峻、完整、不漏。

**❌ log in 和 sign in 不分**
两者在日常使用中几乎可互换，但技术文档和 UI 中有微妙区别：sign in 更偏"身份验证"（你证明你是你），log in 更偏"进入记录"（系统记下你来了）。Apple 和 Google 官方 UI 用 sign in，很多传统系统用 log in。

### 易混近义词辨析

**log vs. record**
record 是上位词——任何形式的记录都可以叫 record。log 更窄：**时间线性的、持续的、通常是机器或系统产生的记录**。法庭记录是 record 不是 log。服务器产生的运行记录是 log。

**log vs. journal**
journal 有"反思"的意味——写 journal 的人在思考。log 纯粹是"记下发生了什么"，不带分析不带感情。ship's log 里写"14:00, wind NNW, 12 knots"，不会写"今天的海真美"。

**log vs. diary**
diary 是私人的、感性的。log 是职业的、工具性的。"我 log 了今天的心情"——不对。"我在日记里写了今天的心情"——对。

### 中文母语者陷阱

**"日志"的误映射**：中文"日志"已经内含了 log 的意思，但中文学习者容易把"日志"的"日"理解成"每天写一次"——不是。log 可以每秒写一条。它的核心是"按时间顺序持续记录"，不是"每日记录"。

**"登录"的反向干扰**：中文说"登录"，学习者可能觉得 log in 的 log 是个没意义的虚词。实际上它是有实义的——你 log in，字面意思是"在记录里标注自己进来了"。理解这层意思有助于记住 log in/out/off 这一族短语动词。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 说明 |
|------|------|------|
| **keep a log** | 通用 | "保持记录"，最经典的动词搭配 |
| **log file** | 计算机 | 系统产生的记录文件 |
| **error log** | 计算机/工程 | 专门记录错误的日志 |
| **log in / log out** | 数字系统 | 登录/登出 |
| **captain's log** | 航海/影视 | 船长日志（也是《星际迷航》的经典开头） |
| **sleep like a log** | 口语 | 睡得像一截木头——沉、死、不动 |
| **log cabin** | 日常/历史 | 原木小屋，美国拓荒史的标志性意象 |
| **log jam** | 通用（引申） | 原指河里原木堵塞，引申为"僵局、阻塞" |

### 语域

log 跨越了极宽的语域光谱——

- **日常口语**：sleep like a log, log cabin（完全不正式）
- **技术/计算机**：log file, logging framework, debug log（技术写作标配）
- **航海/军事**：ship's log, flight log（专业正式）
- **数学**：log₂, natural log（学术）

很少有单词能同时活跃在营火旁（log cabin）和终端里（server.log）。log 是语域的通勤者。

### 活用示范

> *Star Trek, every episode opening: "Captain's log, stardate 41153.7..."*
> 《星际迷航》每集开头：「船长日志，星历 41153.7……」

这个用法让 "captain's log" 成了英语文化中最有辨识度的 log 搭配。它完美保留了 log 的原始气质：冷静、编年、不带感情地记录正在发生的事——即使那件事是外星人正在攻击飞船。

> *"I've been logging my runs for six months. The numbers don't lie — I'm getting slower."*
> 「我记录跑步数据已经六个月了。数字不说谎——我越来越慢了。」

log 作为动词在健身/量化自我领域的活用。注意 log 在这里的冷峻感——数字不说谎，不带安慰。

## 7. 跨语言映射

**中文"日志"**：几乎是 log 的完美对应词，但"日"字暗示了"每日"的频率，而 log 没有这个限制。更精确地说，log 对应的是"志"——记录、标记。"日"是中文自己加上去的。

**日文「ログ」（rogu）**：直接音译自英文 log，主要用在计算机语境。日语保留了传统的「航海日誌」（kōkai nisshi）来指航海日志。有趣的是，日语选择在数字时代直接借 log 的音，而在传统语境里用自己的词——这本身说明 log 的"计算机记录"义已经独立到足以作为一个新概念被借入。

**拉丁语 codex**：原意是"树干"（木头！），后来变成了"册子、法典、记录册"。和 log 走了惊人相似的语义路径——从木头到记录。但 codex 是因为罗马人在木板上刻字（蜡板 codex），而 log 是因为水手把木头扔进海里。两条路，同一个目的地。这可能不是巧合——人类似乎总是从"固定的物质材料"出发，抵达"记录流动的时间"这个概念。

---

**收尾**：log 是英语里最安静的词之一。它不尖叫，不修饰，不评判。它只是躺在那里——不管是作为一截木头躺在森林地面上，还是作为一行行文字躺在你的服务器里——等着有人来读出它刻下的痕迹。
