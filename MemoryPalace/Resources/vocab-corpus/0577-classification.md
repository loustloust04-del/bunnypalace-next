# classification

## 1. 一句话本质

**classification** 是在一堆乱七八糟的东西面前划格子、贴标签、把每个东西按进它该待的那一格——不是随手分堆，是拿着一套规则和刻度尺，郑重地宣布"你是这个，你属于那个"。

---

## 2. 词源考古

### 词根词缀拆解

```
class·i·fic·ation
  │     │    │
  │     │    └─ -ation：名词后缀，表"做……的过程/结果"
  │     └────── -fic-：来自拉丁语 facere（做、制造）
  └──────────── class-：来自拉丁语 classis（等级、类别、舰队）
```

合起来的字面意思：**"把东西做成一个个 class 的动作"**——分类这个行为本身。

### classis 的前世：罗马军队点名册

**classis** 这个词的源头是拉丁语 **calare**——"召唤、大声喊"。公元前 6 世纪罗马塞尔维乌斯改革（Servian reforms），把所有罗马公民按财产多少分成六个等级（classis），决定你交多少税、扛什么装备、排第几排上战场。

所以 class 一开始不是一个中性的"类别"概念——它是一套**按等级排座次**的制度。你被"分类"了，意味着国家知道你值多少钱、该给你什么待遇。

classis 后来还衍生出"舰队"的意思（一支被召集起来的船队），这个义项今天还活在意大利语里。

### 从 classis 到 classification

- **拉丁语 classis** → "被召集到一起的一群人"→ "等级/类别"
- **新拉丁语 classificare**（18 世纪造词）→ classis + facere = "把东西造成各个类别"
- **法语 classification**（约 1752 年）→ 启蒙运动时期法国自然学家大量使用
- **英语 classification**（约 1770s）→ 从法语借入

### 文化地层：启蒙运动的执念

这个词诞生在一个特定的历史时刻：**18 世纪的欧洲人忽然疯狂地想给全世界编目录。**

林奈（Linnaeus）1735 年发表《自然系统》，用界-门-纲-目-科-属-种的层级结构给所有生物编号。布丰（Buffon）在编百科全书式的《自然史》。狄德罗在编《百科全书》。整个启蒙运动的底色就是：**世界是可以被理性地分类、编排、掌控的。**

classification 这个词，就是从这股"给万物编号"的狂热里冒出来的。

到了 20 世纪，这个词又长出了一张新面孔——**安全等级**。"Classified information"不是"被分类的信息"，而是"被划入保密等级的信息"→ 所以"机密"。这个语义漂移很精妙：本来是"分入某个类别"，因为那个类别恰好叫"机密级"，久而久之，classified 就直接等于 secret 了。

## 3. 故事 / 画面

想象一个巨大的邮局分拣室。

传送带上源源不断地滚来包裹——大的小的、方的圆的、写着不同地址、贴着不同颜色标签的。分拣员站在传送带两侧，手里拿着一本厚厚的规则手册。每个包裹到他面前，他扫一眼，翻手册，然后果断地把它推进某一条滑道——左边这条去北区，右边那条去南区，中间那条是加急件，角落那条是"危险物品"。

**classification** 就是这整个过程——不是随手一扔（那叫 sort），而是按照一套**事先定好的规则体系**，给每个东西判定身份，安排去处。

关键在于：**格子是提前画好的**。分拣员不是看到包裹才临时决定"嗯这个应该放哪"，而是规则手册早就规定了——重量超过 20 公斤的走 A 道，标注"易碎"的走 B 道，收件地址以 100 开头的走 C 道。classification 的权力感就来自这里：**是规则在分类，不是个人好恶在分类。**

但反过来想——谁写的规则手册？谁决定了格子怎么画？这就是 classification 这个词暗藏的政治性。

## 4. 多面体：核心义项展开

### 义项一：分类的行为/过程（最基础义）

> *The classification of plants by their reproductive structures was Linnaeus's great innovation.*
> 按生殖结构对植物进行分类，是林奈的伟大创新。

和"一句话本质"的关系：最直接的——给东西划格子的那个动作。

### 义项二：分类的结果 / 类别本身

> *What classification does this species fall under?*
> 这个物种属于什么分类？

这里 classification 从"动作"滑向了"格子本身"。不是"分的过程"，而是"分出来的那个位置"。就像邮局分拣室里的滑道编号——"你被分到了 B-3 道"，B-3 道就是你的 classification。

### 义项三：保密等级（安全/军事语境）

> *These documents have a top-secret classification.*
> 这些文件具有最高机密等级。

这是 20 世纪长出来的脸。逻辑链条是：信息被分入（classified into）某个保密等级 → classified information → classified = 机密。这个义项已经独立到很多英语使用者不会意识到它和"分类"有关。

### 义项四：（机器学习）分类任务

> *Image classification accuracy improved dramatically with the introduction of deep learning.*
> 深度学习的引入大幅提升了图像分类的精度。

ML 语境下的 classification 是个精确的技术术语——给输入数据分配一个离散的类别标签（相对于 regression 的连续输出）。本质还是"划格子"——只不过划格子的是算法。

### 底层统一性

四张脸共享同一个内核：**用一套预设的框架，给个体判定归属。** 无论是给蝴蝶编号、给文件标密级、还是让神经网络判断一张图是猫还是狗——都是同一个动作的变体。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 classification 当成任何"分类"行为。**

日常生活中"我把袜子按颜色分了一下"不太用 classification——那太隆重了。classification 暗示**系统性、规则性、正式性**。你整理衣柜是 sorting/organizing，林奈给 10000 种植物编号才是 classification。

**❌ 混淆 classification 和 category/class。**

classification 侧重**过程和体系**，而 category 和 class 侧重**结果和类别本身**。"This book belongs to the fiction category"可以，但说"This book belongs to the fiction classification"就怪——除非你在讨论图书馆的编目体系。

### 易混近义词辨析

| 词 | 核心差异 | 场景 |
|---|---|---|
| **sorting** | 按某个标准排列，不一定有预设框架 | 把文件按日期排序 |
| **categorization** | 分组，可以是临时的、主观的 | "我把这些问题分成了三类" |
| **classification** | 按一套正式的体系归类，有制度感 | 生物分类、安全密级、图书编目 |
| **taxonomy** | 分类的**学科/体系本身**，不是动作 | "林奈建立了现代生物学的 taxonomy" |

一句话区分：**categorization 是你随手分的，classification 是制度替你分的。**

### 中文母语者陷阱

**"分类"的覆盖面比 classification 宽得多。** 中文的"分类"可以用在从"垃圾分类"到"生物分类"的全部场景，但英文中：
- 垃圾分类 → waste **sorting**（日常行为感）
- 生物分类 → biological **classification**（学科体系感）

如果你把中文的"分类"一律翻成 classification，会在很多场景显得过于正式，像是在跟人宣读政府文件。

## 6. 搭配与语域

### 高频搭配

- **classification system** — 分类体系（最常见搭配之一，强调整个框架）
- **classification scheme** — 分类方案（偏设计/规划阶段）
- **security classification** — 安全等级（军事/政府语境）
- **classification criteria** — 分类标准（学术/科学语境）
- **job classification** — 职位分类（HR 语境，决定薪资级别）
- **classification accuracy** — 分类精度（ML 技术术语）
- **racial classification** — 种族分类（敏感政治话题，南非种族隔离时期的核心词汇）

### 语域标注

**中偏正式。** 这不是口语词。你在日常对话中几乎不会说 classification，除非你在讨论技术话题（ML）、学术话题（生物学）、或制度话题（安全密级、职位等级）。

在学术写作、政府文件、科学论文中极其高频。新闻中常见于安全/军事报道（"The classification of the documents was lowered from top-secret to confidential"）。

### 活用示范

> *The very act of classification is an exercise of power — to name a thing is to claim authority over it.*
> 分类本身就是一种权力行使——给事物命名，就是宣称对它的支配权。

这句话揭示了 classification 这个词在人文社科中的批判性用法——从福柯到萨义德，"谁在分类、按什么标准分类"一直是权力分析的核心问题。

> *In machine learning, classification is deceptively simple: you're just asking the model to pick a label. The hard part is teaching it what each label means.*
> 在机器学习中，分类看起来骗人地简单：你只是让模型选个标签。难的是教会它每个标签意味着什么。

## 7. 跨语言映射

**中文"分类"** 覆盖了 classification + categorization + sorting 的大部分领域，语义边界比英文模糊得多。这导致中文母语者在英文写作中倾向于过度使用 classification。

**日语「分類」（ぶんるい）** 和中文"分类"的覆盖面类似，但在学术/技术场景中日语也会直接借用英文 classification（クラシフィケーション），暗示更正式的体系。

**德语 Klassifikation / Einteilung** — Klassifikation 几乎是英文的直接借词，用在正式场景；日常分组用 Einteilung（"划分"），手感更轻。这组对比和英文 classification vs. categorization 的张力非常相似。

**值得注意的政治维度：** 南非种族隔离时期的 **Population Registration Act (1950)** 把所有公民强制 classification 为 White/Coloured/Black。这个词在南非英语中至今带着这层暗影。中文的"分类"没有这种历史创伤的共振——这是翻译时容易丢失的语义层。
