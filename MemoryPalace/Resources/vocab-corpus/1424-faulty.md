# faulty

## 1. 一句话本质

**faulty 是"看着没问题、用着出问题"的那种不可靠——东西没坏透，但你已经不敢信它了。**

不是废品，不是残次品，是那种外观正常、十次里有九次好使、但你永远不知道第十次什么时候来的东西。一盏偶尔不亮的灯，一段听起来顺畅但经不起追问的推理，一段你自以为记得清楚但其实已经走样的记忆。faulty 的核心不是"坏"，是"不值得信赖"。

---

## 2. 词源考古

### 拆骨骼

```
faulty = fault + -y
```

**-y**：古英语 *-ig*，最普通的形容词后缀，意思是"具有……特征的、充满……的"。salt → salty, dirt → dirty, guilt → guilty。所以 faulty 就是"带着 fault 的"。

关键在 **fault** 本身。

### fault 的前世

上一轮刚考古过 fault，这里压缩回顾核心脉络：

```
Latin fallere（欺骗、使绊倒、失灵）
  → Vulgar Latin *fallita（一次失灵、一个缺口）
    → Old French faute（缺少、过失、错误）—— 注意：没有 l
      → Middle English faute（13世纪借入，也没 l）
        → 15-16世纪文艺复兴学者"修复"拼写，塞回了 l → fault
```

那个 **l** 是后来硬装回去的。跟 assault（← 法语 assaut）、vault（← 法语 voute）一个套路——文艺复兴时期的拉丁癖，觉得法语把拉丁文的 l 丢了不像话，给补上。但发音上，英语里这个 l 后来反而真的读出来了（/fɔːlt/），而法语 faute 至今没有 l。

### fallere 家族

faulty 的祖宗 *fallere* 是个大家族，值得摊开看一眼：

| 后裔 | 路径 | 核心义 |
|------|------|--------|
| **fail** | fallere → 法语 faillir → 英语 | 失败 |
| **false** | fallere → falsus（被欺骗的）→ 英语 | 虚假 |
| **fallacy** | fallere → fallacia → 英语 | 谬误 |
| **fallible** | fallere → fallibilis → 英语 | 可能犯错的 |
| **default** | de- + fallere → 法语 defaute → 英语 | 缺省、违约 |
| **fault/faulty** | fallere → *fallita → faute → 英语 | 缺陷、有缺陷的 |

一个动词"使人绊倒"，生出了半个英语的"不可靠"词族。

### ⚠️ 和前几天的 fatal / fate / fatigue 不同源

这几天连着考古了 fatal → fate → fatigue → fault → faulty，看起来像一家人——但 **fault/faulty 跟 fatal/fate 是假亲戚**：

- fatal / fate ← Latin *fatum*（命运，被说出的话）← *fari*（说）
- fatigue ← Latin *fatigare*（使疲惫）
- fault / faulty ← Latin *fallere*（使绊倒、欺骗）

三条完全不同的拉丁根。只是法语这个中间商碰巧把它们的拼写磨得很像了。

### faulty 的时间线

- **14世纪**：faulty 首次出现在英语中，最初主要形容人的道德——"有过失的、犯了错的"（moral sense）
- **15-16世纪**：随着 fault 的含义从"过失"扩展到"物理缺陷"，faulty 也跟着漂移，开始形容物品的缺陷
- **17世纪起**：进入逻辑/推理领域——faulty reasoning, faulty argument
- **20世纪**：工业化和消费主义让 faulty 成了产品投诉的核心词——faulty wiring, faulty product, faulty design

方向很清晰：**从人的道德缺陷 → 物的物理缺陷 → 抽象的逻辑缺陷**。越来越去人格化，越来越技术化。

## 3. 故事 / 画面

一台自动售货机。

你投了硬币，按了按钮，听到机器内部嗡嗡响了一下——然后什么都没掉出来。你拍了拍机身，又按了一次，这回一瓶可乐哐当掉了下来。你松了口气。

第二天你又来了。投币，按钮。正常。第三天。正常。第四天——又卡了。这次拍也没用，你又投了一次硬币，掉出来两瓶。

这台机器没坏。它的灯亮着，屏幕显示着，制冷还在工作。如果有人检修，可能什么问题也查不出来。但你站在它面前的时候，你已经在心里做好了"这次可能不行"的准备。

**这就是 faulty 的精确频率：不是死机，是抽风。不是不能用，是不能放心用。**

它和 broken 的区别恰恰在这里——broken 的东西你不会再试了，faulty 的东西你会试，但带着不信任试。而这种"带着不信任"的感觉，就是 faulty 这个词的底色。

## 4. 多面体：核心义项展开

### 义项一：（物品/设备）有缺陷的、有故障的

最高频用法。指产品、设备、零部件存在缺陷，无法正常、可靠地工作。

> *The fire was caused by **faulty wiring** in the basement.*
> 火灾是地下室有缺陷的电线引起的。

和"一句话本质"的关系：电线看起来接着，通着电，但某个接头没接牢，某段绝缘层磨损了——"看着没问题，用着出问题"。

### 义项二：（推理/逻辑/判断）有漏洞的、站不住脚的

用来形容论证、推理、假设中存在逻辑缺陷。不是"完全错误"，而是"看起来说得通但经不起推敲"。

> *His argument is based on a **faulty** assumption that all users behave rationally.*
> 他的论证建立在一个有缺陷的假设上——所有用户都会理性行事。

和"一句话本质"的关系：一段推理听起来很流畅、结论也像那么回事，但底下藏着一个前提是歪的——跟那台售货机一样，表面正常，内部有裂缝。

### 义项三：（记忆/感知）不准确的、靠不住的

形容记忆、回忆、感知不可信赖，可能已经走样变形了。

> *Eyewitness testimony is notoriously unreliable because of **faulty** memory.*
> 目击者证词出了名地不可靠，因为记忆本身就靠不住。

和"一句话本质"的关系：你以为你记得清清楚楚，但你的记忆已经在不知不觉中被改写了——你的大脑给你呈现了一个"看着没问题"的版本，但它已经不是真的了。

### 底层统一性

三个义项共享同一个内核：**表面完整性与实际可靠性之间的落差**。无论是电线、论证还是记忆，faulty 指向的都是"它声称自己是好的，但它其实不是"。这也呼应了祖词 *fallere* 的本义——**欺骗、使人绊倒**。faulty 的东西，本质上是在骗你。

## 5. 裂缝标注

### 常见误用场景

**❶ 把 faulty 用在"完全坏掉"的东西上**

> ❌ *The phone is faulty — the screen is completely shattered and it won't turn on.*

屏幕碎了、开不了机——这叫 **broken / dead / non-functional**，不叫 faulty。faulty 暗示的是"部分失灵"或"间歇性问题"，是"有缺陷"不是"报废了"。

> ✅ *The phone is faulty — sometimes the touchscreen doesn't respond in the lower-left corner.*

**❷ 把 faulty 用于形容人**

现代英语中 faulty 几乎不用来形容人了。说 *He's faulty* 会让人觉得你在说他是个有缺陷的产品，非常不礼貌。中世纪可以这么说（= at fault, guilty），现代不行。

形容人有缺点用 **flawed**：*He's a deeply flawed person.*

### 易混近义词辨析

| 词 | 区别 | 场景对比 |
|---|---|---|
| **broken** | 彻底坏了，不能用了 | 灯泡烧了 = broken；灯泡时亮时不亮 = faulty |
| **defective** | 更正式/技术/法律用语，常用于制造业和召回通知 | 消费者投诉 = faulty product；官方召回公告 = defective unit |
| **flawed** | 更文学化、更中性，可以带同情色彩 | faulty reasoning = 你的推理有漏洞（在批评）；flawed reasoning = 推理有瑕疵（更温和的评估） |
| **wrong** | 强调正确性（对/错），不强调可靠性 | wrong answer = 答案不对；faulty method = 方法不可靠（可能有时得出对的答案，但方法本身有问题）|
| **malfunctioning** | 正在出故障（进行时感），强调此刻不正常工作 | faulty = 这东西本身有缺陷（属性）；malfunctioning = 这东西此刻在犯病（状态）|

### 中文母语者陷阱

**❶ "错误的" ≠ faulty**

中文的"错误的"是个大筐，对应英文好几个词。"错误的答案" = wrong answer，"错误的电线" = faulty wiring，"错误的信息" = incorrect / inaccurate information。faulty 强调的不是"错"，是"有缺陷、不可靠"。

**❷ "坏了" ≠ faulty**

中文说"这东西坏了"覆盖面极广——从"有点毛病"到"彻底报废"都能说"坏了"。英文里这两者区分得很清楚：faulty = 有毛病但还能用；broken = 坏透了。

**❸ "有问题的" ≈ faulty，但要小心**

"有问题的"在中文里也可以指"有争议的"（problematic），而 faulty 不含"有争议"的意思。faulty 是客观的"存在缺陷"，不是主观的"我觉得有问题"。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境说明 |
|------|---------|
| **faulty wiring** | 最经典搭配。新闻报道火灾原因时几乎是套话 |
| **faulty equipment / product** | 消费者投诉、产品召回的标准用语 |
| **faulty logic / reasoning** | 学术、辩论、评论文章中批评论证漏洞 |
| **faulty memory** | 心理学、法律（证人证词）、日常自嘲 |
| **faulty assumption / premise** | 指出某个论证的根基就是歪的 |
| **faulty design** | 工程、UX、建筑——设计本身有缺陷 |
| **faulty construction** | 建筑质量问题，法律诉讼常见 |
| **faulty goods** | 英国消费者权益法律文本中的标准术语（比美式英语更常用这个搭配） |

### 语域标注

**中性偏技术**。日常对话、新闻报道、消费者投诉、学术论文都能用。不算特别正式，也不算口语化——是那种你写邮件投诉也能用、跟朋友吐槽也能用的词。

在英国英语中使用频率略高于美国英语，尤其在消费者权益语境下（英国有专门的 *Sale of Goods Act* 条款涉及 "faulty goods"）。

### 活用示范

> *We like to think our perceptions are windows onto reality, but they're more like **faulty** translations — close enough to be useful, never quite right enough to be trusted.*
> 我们喜欢以为自己的感知是现实的窗口，但它们更像是有缺陷的翻译——够用，但永远不够准确到值得完全信任。

这句话展示了 faulty 最有表现力的用法：不是简单地说"有缺陷"，而是用它揭示一种**系统性的不可靠**——你依赖的工具本身就是歪的，但你别无选择只能继续用。

> *"My memory isn't bad — it's just **faulty** enough to make life interesting."*
> "我的记忆力不差——只是刚好不靠谱到能让生活变得有趣。"

自嘲式用法。faulty 在这里带着一种"差到刚刚好"的幽默感。

## 7. 跨语言映射

**中文"有毛病"** 是 faulty 最传神的对应。"这东西有毛病"——没坏，但有毛病。"他的逻辑有毛病"——不是全错，但有漏洞。"有毛病"完美地捕捉了 faulty 那种"不致命但不可信"的语感。

**日语「不具合」（ふぐあい）** 也很接近，专指设备/系统的"不良状态"——承认它还能运转，但运转得不对。日本产品召回通知中的标准用语。

**法语 "défectueux"** 是 faulty 在产品语境下的直接对应，但法语保留了 "fautif" 用来形容人（= 有过错的），而英语的 faulty 已经几乎不这么用了——这正好印证了前面说的那条语义漂移路线：faulty 离开了"人的道德"，专攻"物的缺陷"。

**德语 "fehlerhaft"** 拆开看是 Fehler（错误）+ haft（-ful），结构和 fault + -y 完美对映。但德语这个词比 faulty 用得更广，可以形容人的行为（英语用 faulty 形容人会很怪，德语用 fehlerhaft 形容人的做法完全正常）。
