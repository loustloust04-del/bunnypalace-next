# example

## 1. 一句话本质

**example 是从一堆东西里"抽出来的那一个"——被挑中，摆到台面上，让所有人看。**

它可以是展台上被挑出来的样品，可以是班里被老师叫起来示范的那个学生，也可以是被拎出来当众处罚的那个倒霉蛋。核心动作只有一个：**从群体中取出，放到聚光灯下。**

---

## 2. 词源考古

### 词根词缀拆解

```
ex-  （拉丁语：向外，出来）
+
emere（拉丁语：拿，取，买）
=
eximere → 取出来
→ exemplum（被取出来的东西 → 样本、范例）
```

**emere** 这个词根你可能觉得陌生，但它的后代你天天用：
- **premium**（pre- + emere）= 预先拿/买 → 溢价、保费
- **redeem**（red-/re- + emere）= 买回来 → 赎回、挽回
- **exempt**（ex- + emere 的过去分词 emptus）= 被取出来的 → 豁免的

没错——**example 和 exempt 是亲兄弟**，同一对父母（ex + emere），一个被取出来"展示"，一个被取出来"排除"。一个站在聚光灯下，一个站在规则之外。

### 历史流变

| 时期 | 形态 | 关键事件 |
|------|------|----------|
| 古典拉丁语 | **exemplum** | "被取出的样本"，兼指修辞学中的"例证"——演说家用故事说服听众 |
| 古法语（12c） | **essample / example** | 进入法语，拼写开始漂移 |
| 中古英语（14c） | **ensample → example** | 两种拼法并存了两百年，ensample 最终败退 |
| 现代英语（16c起） | **example** | 拼写定型，含义稳定 |

### 一个被吃掉的亲戚

**sample** 就是 example 被砍了头。

语言学术语叫 **aphesis**（词首脱落）：essample → sample。所以当你说"give me a sample"和"give me an example"的时候，你说的其实是同一个词的两个版本——一个保留了全身，一个只剩了下半截。

区别在于：sample 后来专化成了"实物样品"（你尝的那口试吃、你拿的那管血），example 则保留了更抽象的"例证、典范"含义。

### 文化地层：修辞学的专业术语

在古罗马修辞学中，**exemplum** 是一个正式术语——指演说中引用的"先例故事"，用来说服听众。西塞罗、昆体良都大量使用这个技法。所以 example 从出生起就带着"被精心挑选出来、用于说服"的基因——它不是随便拿一个，是**有目的地拿**。

## 3. 故事 / 画面

一个水果摊。几百个苹果堆在那。

摊主伸手，在堆里翻了翻，挑出一个——个头最正、颜色最均匀、没有磕碰的那一个——放在最前面，转向你。

**"你看，都是这样的。"**

这就是 example 的原始动作。

但换一个场景。同一个水果摊，城管来了，抓到一个缺斤少两的商贩，当街罚款，还让旁边所有摊贩都看着。

**"都看好了。"**

这也是 example。

被挑出来的那一个，命运完全不同——取决于挑你出来的人想让别人**学你**，还是想让别人**怕你**。但动作是同一个：从群体中取出，放到所有人面前。

## 4. 多面体：核心义项展开

### 义项一：代表性的实例（"比如这个"）

> *Can you give me an example of what you mean?*
> 你能举个例子说明你的意思吗？

从一堆可能性中取出一个具体的，让抽象变得可触摸。这是最基础的用法——"取出来给你看"。

### 义项二：值得效仿的榜样（"照着它来"）

> *She sets a good example for her younger siblings.*
> 她给弟弟妹妹们树立了好榜样。

被取出来的那一个，不只是展示品，而是**标杆**。所有人被要求向它看齐。从"看"到"学"，多了一层力量。

### 义项三：杀鸡儆猴的警示（"别学它"）

> *The judge decided to make an example of him with a harsh sentence.*
> 法官决定对他严厉判决，以儆效尤。

同样是被取出来，但方向反了——不是让你模仿，是让你恐惧。"make an example of"这个搭配里，被拎出来的那个人是祭品。

### 义项四：习题、范例（数学/教学）

> *Work through the example on page 42 before attempting the exercises.*
> 在做练习之前，先做完第42页的范例。

教科书里被挑出来的"示范题"——它被解过一遍，步骤摊开给你看，然后你照着它的路径自己走。依然是"取出一个，给你看怎么做"。

**底层统一性：** 四个义项，全是"从群体中被取出、放在所有人面前"的变体。区别只在于取出来之后的用途——展示、效仿、震慑、教学。

## 5. 裂缝标注

### 常见误用

**❌ "example" 当 "sample" 用**
> ~~Can I have an example of this perfume?~~
> ✅ Can I have a **sample** of this perfume?

example 是抽象的例证，sample 是实物的一小份。你不能"拿走"一个 example，但你可以拿走一个 sample。

**❌ "for example" 位置不当**
> ~~I like fruits for example apples.~~
> ✅ I like fruits — for example, apples.

for example 后面必须有逗号（或破折号），不能直接粘上去。

### 易混近义词

| 词 | 核心区别 |
|---|---|
| **instance** | 更中性、更学术——"某类事物的一次出现"。没有 example 的"被挑选出来"的感觉。*This is an instance of system failure.* 只是在记录，不是在展示。 |
| **illustration** | 强调"让抽象概念变得可视化"。比 example 更侧重解释功能。*Let me give you an illustration of how this works.* |
| **sample** | 实物的一小部分。*a blood sample*、*a fabric sample*。你可以带走一个 sample，带不走一个 example。 |
| **case** | 更强调具体事件的完整性。*a case of fraud* 是一桩完整的欺诈案，不只是一个"例子"。 |
| **model** | 比 example 更强调"完美到值得复制"。*a model student* 比 *a good example* 更高一档。 |

### 中文母语者陷阱

**"举例" ≠ 所有场景都用 example**
中文里"举个例子"太万能了。但英文里：
- 学术论文偏好 *instance* 或 *case*
- 口语里 *like* 就够了（"I like spicy food, like Sichuan hotpot"）
- 正式演讲用 *to illustrate* 比 *for example* 更流畅

**"以儆效尤" 的 example 容易漏**
中文母语者很少想到 example 有"惩罚性示众"的含义。*make an example of someone* 这个搭配需要专门记。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **set an example** | 树立榜样。*Parents should set an example.* 家长言传身教的语境。 |
| **make an example of** | 杀鸡儆猴。带惩罚性质，通常主语是权力方（法官、老师、老板）。 |
| **a prime/classic example** | 最典型的例子。*This is a classic example of bureaucratic waste.* 语气通常带批评。 |
| **a shining example** | 闪光的榜样。正面。*She's a shining example of perseverance.* |
| **follow someone's example** | 学某人的做法。 |
| **by example** | 以身作则。*Lead by example.* 管理学和育儿的高频用语。 |
| **for example (e.g.)** | 举例。书面常缩写为 e.g.（拉丁语 *exempli gratia*，"为了例子的缘故"）。 |
| **a cautionary example** | 前车之鉴。和 *make an example of* 方向相同但更书面。 |

### 语域

example 是一个**全语域通吃**的词——口语、书面、学术、新闻、日常全能用。这恰恰是它的难点：因为太常见，反而容易用得平庸。高手会根据场合换用 instance / illustration / case 来更精准。

### 活用示范

> *He was the walking example of everything wrong with the system.*
> 他就是这个体制所有毛病的活标本。

"walking example"——活的、走动的例子。把抽象的制度批评钉在了一个具体的人身上。

> *History doesn't repeat itself, but it does offer examples.*
> 历史不会重复，但它提供先例。

这句话里 example 用的是最古老的那层含义——修辞学中的 exemplum，从过去取出故事来照亮当下。

## 7. 跨语言映射

**拉丁语 exemplum → 几乎所有欧洲语言的同源词：**
- 法语 **exemple**
- 西班牙语 **ejemplo**
- 意大利语 **esempio**
- 德语 **Beispiel**（这个不同源——Bei + Spiel = "在旁边 + 玩/展示"，即"放在旁边给你看的东西"，但语义路径惊人地相似：都是"取出来展示"）

**中文的对照很有意思：**

中文把 example 的几个义项拆成了完全不同的词——**例子、榜样、典型、范例、以儆效尤**——而英文用同一个词覆盖所有。这不是翻译问题，是两种语言对"从群体中取出"这个动作的切割方式不同。中文更在意"取出来之后干什么"（展示？模仿？警告？），英文更在意"取出来"这个动作本身。

日语的 **例（れい）** 和中文的"例"同源，但日语有一个精妙的表达：**見せしめ（みせしめ）**= 给别人看的惩罚，精确对应 *make an example of*。"见 + 示 + 締め"——让别人看到、以此约束。和 example 的"取出来让所有人看"异曲同工。
