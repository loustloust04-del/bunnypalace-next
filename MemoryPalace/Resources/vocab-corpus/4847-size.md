# size

---

## 1. 一句话本质

**size 是一个法官坐下来、敲一锤、宣布"这东西该有多少"的那一下。** 不是"大"，不是"小"，是你拿起一个东西、掂量它、给它判定一个位置的那个动作和结果。

---

## 2. 词源考古

### 词根词缀拆解

现代英语 **size** 看起来无从下手——没有明显前缀后缀。但它是一个被砍掉了头的词：

| 层级 | 形式 | 含义 |
|------|------|------|
| 拉丁语 | **assidēre** (ad- + sedēre) | "坐到旁边去"——引申为"出席、评估" |
| 古法语 | **assise** (asseoir 的过去分词) | "一次开庭"、"一次裁定" |
| 中古英语 | **sise / syse** | 砍掉 as-，只留 sise——"法定标准" |
| 现代英语 | **size** | "尺寸、大小、规格" |

关键操作叫 **aphesis**（词首脱落）：assise → sise → size。就像 "alone" 来自 "all one"，"size" 是 "assise" 掉了脑袋。

### 历史流变

**12-13 世纪：size = 法令裁定的标准量**

中世纪英格兰有一套叫 **Assize of Bread and Ale**（面包与麦酒法令）的制度——法庭坐下来（assize，字面意思就是"坐堂"），规定：一条面包该多重、一杯麦酒该多少。"Size" 最早就是这个意思：**被权威机构裁定的标准量**。不是描述"这东西有多大"，而是宣判"这东西应该有多大"。

**14-15 世纪：从"法定标准"漂移到"实际尺寸"**

当你天天说"这面包够不够 size"、"那匹布达不达 size"，这个词慢慢就从"标准是什么"变成了"实际是什么"。核心语义从**规范性**（应该多大）滑向了**描述性**（实际多大）。这是一个非常典型的语义世俗化——法律术语进入日常生活后褪去权威色彩。

**16 世纪至今：全面抽象化**

不再局限于重量和体积，可以说 the size of the problem、the size of the opportunity。"Size" 完成了从面包秤到万物尺的跃迁。

### ⚠️ 另一个 size：胶水

英语里还有一个 **size**，指涂在纸张或织物表面的胶状物质（浆糊、涂胶）。这个词**很可能是不同来源**——可能来自古法语 *sise*（某种粘合物的设定/凝固），也有学者认为与意大利语 *sisa* 有关。两个 size 在现代英语里拼写完全相同，但语义世界互不相干。**词源学界对"胶水 size"的确切来源存疑，不宜断言。**

## 3. 故事 / 画面

1284 年，英格兰某个小镇的集市。

面包师傅把今天烤的面包一排排摆在木台上。镇上的 assize 官员走过来——不是来买面包的，是来**审判**面包的。他拿出一杆铜秤，把面包放上去。秤砣是法令规定的标准重量。

面包师屏住呼吸。

秤臂倾斜。面包不够重。

"Not to size."（不合标准。）

官员在账簿上划一笔。面包师要挨罚了。

——**这就是 size 最初的样子**：不是你随口说的"大小"，而是一锤定音的裁决。每一个 size，背后都有一杆秤、一个标准、一次判定。

你今天走进鞋店说 "I'm a size 42"，你在做的事跟那个 assize 官员一模一样：**把脚放上一套标准体系，找到它的位置。**

## 4. 多面体：核心义项展开

### 义项 A：物理尺寸 / 大小

> *The size of the apartment surprised me—it was much smaller than the photos suggested.*
> 公寓的大小让我吃了一惊——比照片里小多了。

最基础的用法。直接继承了"对某物进行度量判定"的核心——你在心里拿一把无形的尺子量它。

### 义项 B：标准化规格（鞋码、衣码、型号）

> *Do you have this in a size medium?*
> 这件有中号吗？

这是**最接近原始词义**的用法。Size 8 的鞋、Size M 的衣服——每一个编号都是某个标准体系坐下来裁定的"assise"。你不是在描述鞋有多大，你是在把脚**归类**到一个法定格子里。

### 义项 C：size up——打量、评估

> *She sized him up in three seconds and decided he wasn't worth her time.*
> 她三秒钟打量完他，判定此人不值得浪费时间。

这个义项把"审判面包"的动作完美复活了——你盯着一个人看，心里有一杆秤，在判定他"够不够格"。size up 不是随便看一眼，是**带着标准去衡量**。

### 义项 D：规模 / 量级（抽象用法）

> *You don't understand the size of the problem we're facing.*
> 你不明白我们面对的问题有多大。

从面包的重量到问题的严重程度——size 的秤可以量任何东西。这个义项的核心仍然是"把抽象的东西放到秤上，逼它显出分量"。

### 义项 E：that's about the size of it——大致就是这么回事

> *"So we're broke, behind schedule, and the client is furious?" "Yeah, that's about the size of it."*
> "所以我们没钱了、进度落后、客户暴怒？""对，大致就是这么回事。"

一个精妙的俚语用法：**用"尺寸"来比喻"事情的全貌"**。"这就是这件事的 size"——你把整件事的轮廓量完了，就长这样。

## 5. 裂缝标注

### 常见误用

**❌ "The size is very big."**

size 本身是中性的量度概念，不需要用 big 来修饰——说 "The size is large" 或直接 "It's very large" 更自然。"Big size" 在口语中偶尔出现但略显冗余，正式写作应避免。

**❌ 把 size 和 amount/number 混用**

- 可数的东西用 **number**（the number of students）
- 不可数的东西用 **amount**（the amount of water）
- **size** 是指整体的"规模/尺寸"——the size of the class（班级大小），不是 the size of students

### 易混近义词

| 词 | 核心区别 |
|---|---|
| **size** | 整体的大小/规格，带"可度量、可分类"的暗示 |
| **magnitude** | 偏学术/科学，强调"量级"——地震的 magnitude、问题的 magnitude，比 size 正式得多 |
| **dimension** | 指具体的某一"维度"——长×宽×高中的某一项。"dimensions" 复数可以约等于 size，但单数 dimension 不行 |
| **scale** | 强调相对参照系——"on a large scale" 是说相对于某个基准很大，而 size 是绝对的度量 |
| **volume** | 专指三维空间的体积，size 比它宽泛得多 |

### 中文母语者陷阱

**"大小"的陷阱：** 中文说"大小"天然带有"大和小"的二元对立感。但英文的 size 是一个**连续谱**——它不暗示大也不暗示小，它只是"量度"。所以 "What's the size?" 不是在问"大不大"，是在问"量度值是多少"。

**"号" vs "size"：** 中文说"大号""中号"的"号"就是 size，但中文的"号"听起来像一个标签，而英文的 size 背后有"标准体系"的重量。这就是为什么英文可以说 "one size fits all"（一个标准适用所有人）——这个短语的 size 不是"号"，是"标准"。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境说明 |
|------|----------|
| **size of the population** | 学术/统计语境，讲总体规模 |
| **sample size** | 研究方法论里的核心术语，样本量 |
| **life-size / full-size** | "跟实物一样大的"——life-size portrait（等身画像） |
| **size up** | 打量、评估——常带一点"暗中判断"的意味 |
| **one size fits all** | 万能方案（常带讽刺意味：真的能 fit all 吗？） |
| **cut/trim to size** | 按需裁剪——也可比喻"把某人的嚣张气焰削一削"（cut sb down to size） |
| **size matters** | 大小很重要——日常和广告中高频出现，常带双关 |
| **bite-size** | 一口大小的——引申为"容易消化的"（bite-size lessons） |

### 语域

**全语域通吃。** size 是英语中极少数在所有场合都自然的词之一——论文里写 sample size、超市里问 what size、朋友间说 size up——没有正式度限制。这很罕见，大多数词都有自己的"地盘"，但 size 真的到处都住得下。

### 活用示范

> *The silence in the room had a size to it, pressing against the walls.*
> 房间里的沉默有一种体积感，挤压着四面墙壁。

——把 size 用在"沉默"上，瞬间让一个抽象的东西有了物理存在感。这就是 size 这个词的超能力：**它能把无形的东西变成可以被秤量的实体。**

> *He was a man who knew the exact size of his own ambition, and it terrified him.*
> 他是一个精确知道自己野心有多大的人，而这让他恐惧。

## 7. 跨语言映射

**中文"大小"vs. 英文 size：** 前面提过，"大小"是二元的（大-小两端的合称），size 是一元的（一个连续刻度）。更有趣的是：中文问"多大？"暗示你在期待一个"大"的方向的答案，而 "What size?" 完全中性。

**法语 taille：** 法语用 taille（来自 tailler，切割）表示尺寸。有趣的是，英法两种语言各自用了不同的隐喻来锚定"尺寸"这个概念——法语选了"切割"（你切出来的形状就是你的大小），英语选了"裁定"（法庭坐下来宣判的标准就是你的大小）。一个是手工匠人的视角，一个是法律官僚的视角。

**日语 サイズ (saizu)：** 直接外来语借词，只用于服装、商品规格等标准化场景。日语自己的"大きさ"（ōkisa）覆盖 size 的大部分义项，但有趣的是——"大きさ"字面拆开是"大+程度"，跟中文的"大小"一样，暗示的基准偏"大"。英文 size 没有这个偏向。

---

**收尾：** size 这个词最迷人的地方，是它伪装成了全世界最平凡的日常词汇——谁会觉得"大小"有什么值得琢磨的？但它骨子里是一个法庭术语，每次你说 "what size"，你都在不知不觉地重演一场 800 年前的面包审判。秤还在，标准还在，只是法官换成了你自己。
