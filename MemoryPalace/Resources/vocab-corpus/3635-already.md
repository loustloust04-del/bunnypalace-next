# already

## 1. 一句话本质

**already 是你推开门准备宣布"我来了"，发现所有人已经到齐了——它捕捉的不是时间本身，而是"比预期快了一拍"的那个落差感。**

---

## 2. 词源考古

### 词根词缀拆解

already 的骨架极其透明，拆开就两块：

- **all**（Old English *eall*）= 完全地、彻底地
- **ready**（Middle English *redy*，可追溯至 Old English *rǣde* "已安排好的"，同源于古日耳曼语 *raidijaz* "准备就绪的"）

直译：**完全准备好了。** 一个彻底进入就绪状态的东西。

### 历史流变

**14世纪之前**：*all ready* 是两个独立的词，字面意思就是 "completely prepared"。你可以说 *The army is all ready*（军队全部就绪）。这和今天的 "all ready"（两个词）是同一个意思。

**14世纪**：关键转折。*all ready* 开始粘合成一个词 *already*，语义开始漂移——从"完全准备好了"滑向"在某个时间点之前就已经完成了"。为什么会漂？想想看：当你说"一切都准备好了"，潜台词是什么？是**事情已经到位了，不用再等了**。"就绪"天然暗示了一个时间节点——在你来问之前，在你预期之前，它就已经是那个状态了。

**15-16世纪**：语义漂移完成。*already* 彻底脱离了 "prepared" 的含义，变成一个纯粹的时间副词，表示"在某个参照时间点之前"。原来的"完全准备好"这个意思被留给了两个词的写法 *all ready*。

**20世纪**：美式英语里出现了一个有趣的用法——*Enough already!*（够了够了！）这个用法带有强烈的不耐烦感，直接受 **意第绪语（Yiddish）** 影响。意第绪语里的 *shoyn*（שוין）在句尾有催促、不耐烦的功能，犹太裔移民把这个语法模式嫁接到了英语的 *already* 上。

### 文化地层

这个词的演化史藏着一个深刻的语言学规律：**空间/状态词向时间词漂移**。"准备好了"是一种状态描述，但状态天然蕴含时间——"已经是那个状态了"。英语里很多时间标记都是这样从非时间概念里长出来的（比如 *yet* 最早也是"此外、再"的意思，不是时间概念）。

## 3. 故事 / 画面

别"想象"——直接给你一个你一定经历过的场景：

你加班到很晚，终于提交了一个文件，发了消息给同事："搞定了，刚发给你。"

同事秒回："I know. I've already reviewed it."

——你还沉浸在"我终于完成了"的成就感里，对方已经看完了。你以为自己在终点线，人家在你前面一个身位。

这就是 already 的内核：**它标记的不是"过去"，而是"比你以为的更早"。** 它永远携带一个隐形的参照系——某个预期的时间点——然后告诉你：事情在那个点之前就发生了。

如果 already 是一种表情，它是你还没开口对方就点头的那个瞬间。

---

## 4. 多面体：核心义项展开

### 义项一：在预期之前已完成（最核心用法）

> *I've already finished the book you lent me.*
> 你借我的书我已经看完了。

和本质的关系：说话者预设对方觉得"应该还没看完"，用 already 标记"比你想的快"。

### 义项二：带惊讶的"这么快/这么早"

> *Is it December already?*
> 都十二月了？！

和本质的关系：说话者的主观时间钟比现实慢了一拍，already 精确捕捉了这个落差。注意：这里没有明确的"完成"，但有一个隐含的"到达"——时间到达了一个比你预期早的点位。

### 义项三：强调性催促/不耐烦（美式口语，Yiddish 影响）

> *Come on already, let's go!*
> 快点啦，走不走啊！

> *Enough already!*
> 够了够了！（行了行了！）

和本质的关系：这里 already 的意思是"这件事早就该发生了 / 早就该停了"——它标记的不是"已经发生"，而是"应该已经发生了但还没有"，是预期和现实的反向落差。这个用法和前两个义项刚好是镜像关系：前两个是"事实跑在预期前面"，这个是"预期跑在事实前面"。

### 义项四：暗示"不必再做"

> *I already told you — don't touch that.*
> 我跟你说过了——别碰那个。

和本质的关系：表面是时间标记（"之前说过"），但真正的力量在于潜台词：**既然已经说过了，你不该再需要我说第二遍。** already 在这里携带了责备的语气。

## 5. 裂缝标注

### 常见误用场景

**❌ already 和完成时混淆位置：**

很多学习者会写 *I already have finished* 而不是 *I have already finished* 或 *I've already finished*。already 在完成时态中通常夹在 have 和过去分词之间。放到 have 前面不是语法错误，但读起来别扭，像在特意强调。

**❌ 用 already 替代 yet（否定/疑问句）：**

- ✅ *Have you finished yet?*（你做完了没？——中性询问）
- ⚠️ *Have you finished already?*（你已经做完了？——带惊讶，暗示"这么快？"）

两者都合语法，但语气完全不同。中性地问"做没做完"，用 yet；带着"不会吧这么快"的惊讶，才用 already。

### 易混近义词辨析

**already vs. yet vs. still**——这三个是中国学习者的三角地狱：

| 场景 | 正确用法 | 为什么 |
|------|---------|-------|
| 事情已经发生了 | I've **already** eaten. | 标记"在某参照点前完成" |
| 事情还没发生（中性询问） | Have you eaten **yet**? | yet 问的是"到目前为止有没有" |
| 事情还在持续 | I'm **still** eating. | still 标记"状态未改变" |
| 事情不该还在持续但确实还在 | Are you **still** eating?! | still 带惊讶 = "怎么还在" |

关键区分：**already 的参照点在过去**（已经发生了），**yet 的参照点在现在**（到目前为止），**still 的参照点跨越过去到现在**（一直是这样且还是这样）。

**all ready vs. already**——拼写陷阱：

- *We're **all ready** to go.* = 我们全都准备好了。（all 修饰 we，ready 是形容词）
- *We've **already** gone.* = 我们已经走了。（already 是副词，修饰动词）

测试方法：把 all 去掉，句子还成立吗？*We're ready to go* ✅ → 两个词。*We've ~~al~~ready gone* ❌ → 一个词。

### 中文母语者陷阱

**"已经"≠ already 的全部：**

中文的"已经"确实覆盖了 already 最核心的义项，但 already 的**惊讶语气**和**不耐烦语气**在中文里不是靠"已经"实现的：

- "都十二月了？" → *Is it December already?*（中文用"都"表惊讶，不用"已经"）
- "够了够了！" → *Enough already!*（中文根本不用"已经"）

反方向的坑：中文说"我已经三十岁了"，英语不太说 *I'm already thirty*（除非你想表达"天哪我怎么就三十了"的惊讶）。如果只是陈述年龄，英文就是 *I'm thirty*，不需要 already。

## 6. 搭配与语域

### 高频搭配

- **already know** — 最高频搭配之一。"I already know" 往往带有一丝"你不用告诉我"的潜台词
- **already have/has** — 完成时态标配。*She's already left.*
- **already been** — 常用于被动或完成时。*It's already been decided.*
- **already mentioned** — 书面语/演讲中回指前文。*As already mentioned, …*
- **already in place** — 正式语境，表示"已到位"。*The measures are already in place.*
- **already too late** — 叙事性用法，制造紧迫感。*By the time they arrived, it was already too late.*

### 语域标注

already 是**全语域通用词**——口语、书面、学术、新闻都能用，没有正式程度限制。但特定搭配会锁定语域：

- *As already noted/mentioned* → 学术/正式书面
- *Enough already / Come on already* → 美式口语，带 Yiddish 味，正式场合不用
- *already underway* → 新闻报道常见

### 活用示范

> *"The future is already here — it's just not evenly distributed."* — William Gibson
> 未来已经到了——只是分布不均。

这句话之所以成为名言，正是因为 already 的力量：它把"未来"从一个遥远的概念拽到了此刻，制造了一个认知错位。如果换成 *The future is here*，力量减半——缺了那个"你以为它没来但其实已经来了"的落差。

> *She was already gone when the apology arrived.*
> 道歉到的时候，她早就走了。

这里 already 的叙事功能：它用一个词就建立了"来不及了"的悲剧感——事件的顺序被锁死了，不可逆。

## 7. 跨语言映射

**中文"已经" vs "都" vs "早就"：**

英语一个 already 覆盖的语义空间，中文切成了三块：
- 中性陈述 → 已经（我已经吃了）
- 惊讶/比预期快 → 都（都十二月了？）
- 强调早就完成 → 早就（我早就跟你说过了）

already 把这三种情绪缝在一个词里，靠语境区分。中文说话者要注意：不是所有"已经"都翻译成 already，也不是所有 already 都翻译成"已经"。

**德语 *schon*：**

德语的 schon 和 already 几乎是镜像——它也从"美好的/准备好的"（和 *schön* 美丽 同源）漂移成了时间副词"已经"，也有口语中催促/强调的用法（*Komm schon!* = Come on already!）。两种语言独立走出了几乎相同的语义路径。

**日语「もう」：**

日语的 もう 和 already 的覆盖范围高度重叠：もう食べた（已经吃了）、もう12月？（都十二月了？）、もういい（够了）。但もう还能表达"马上就要"（もうすぐ），这是 already 不覆盖的领域。

---

**收尾自检**：如果只留下"already 是你推开门发现所有人已经到齐了"这个画面，加上"它标记的是事实和预期之间的时间落差"这句话——一个从没见过这个词的人能还原出它的核心语义吗？能。它不是"过去"，不是"完成"，是"比你以为的更早"。这就是 already 的全部性格。
