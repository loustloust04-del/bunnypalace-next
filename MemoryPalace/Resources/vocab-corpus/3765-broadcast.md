# broadcast

---

## 1. 一句话本质

**broadcast 是农夫抓一把种子向天空撒出去的那个动作——你不瞄准任何一块土，你让种子自己去找落点。** 从田野到电波，这个词的灵魂从没变过：不指定接收者，向所有方向同时释放。

---

## 2. 词源考古

### 词根词缀拆解

```
broad（宽的） + cast（抛、撒）
```

两个都是日耳曼血统的老词：

- **broad**：古英语 *brād*，原始日耳曼语 \**braidaz*，意思就是"宽阔的"。这个词从一千多年前到现在，含义几乎没漂移过——罕见的语义钉子户。
- **cast**：来自古诺斯语 *kasta*（投掷、抛撒），维京人带到英语里的。注意不是拉丁系的"throw"——cast 天生带着一种"不精确的、散射式的"投掷感。你 throw 一个球是瞄着扔，你 cast 种子是撒出去不管它落哪。

合在一起：**宽宽地撒出去。**

### 历史流变

**17-18 世纪 · 农业本义**

broadcast 最初是个纯粹的农业术语。在条播机（seed drill）发明之前，播种的主要方式就是农夫把手伸进种子袋，抓一把，大臂一挥，种子呈扇形散落在田里。这个动作就叫 broadcast sowing（撒播）。

它同时做形容词和副词用：*sow broadcast* = 撒播式地种。

**1767 年**左右，broadcast 的用法开始从田地扩展到抽象领域——"广泛散布信息"。但这时候还是个比喻用法，不是技术术语。

**1920s · 关键转折：无线电劫持了这个词**

这是 broadcast 生命中最戏剧性的时刻。

1920 年代，商业广播电台诞生。工程师需要一个词来描述"向所有方向同时发射无线电信号"这件事——他们没有造新词，而是直接从农田里借了 broadcast。

为什么是这个词？因为无线电信号的物理传播方式和撒种子惊人地相似：**从一个点出发，向四面八方扩散，不指定接收者，谁在覆盖范围内谁就收到。** 天线就是那只撒种子的手。

这个借用太成功了，以至于今天大多数英语母语者已经不知道 broadcast 的农业出身——反而觉得它天生就是个"媒体词"。

**20 世纪后半叶至今 · 语义固化**

broadcast 的"媒体传播"义已经完全碾压了农业本义。现代英语里说 broadcast，99% 的人第一反应是电视、广播、直播。农业义只在技术文献里苟延残喘。

但底层逻辑从未变过：**一对多、不定向、覆盖式地释放。**

### 文化地层

有意思的是，broadcast 的语义演化方向和技术革命完全同步：

- 农业时代 → 撒种子
- 无线电时代 → 发射信号
- 电视时代 → 播放节目
- 互联网时代 → broadcast 开始和 narrowcast（窄播/定向推送）对立。算法推荐本质上是 narrowcast，是 broadcast 的反义词。这让 broadcast 在数字时代反而获得了一层新的语义张力：**不加选择地对所有人说同样的话——这到底是民主，还是低效？**

## 3. 故事 / 画面

傍晚，一个老农站在刚翻过的田中间。他左手挎着一个帆布袋，右手伸进去，抓出一把麦种。手臂划一个半圆，五指在最高点松开——种子像一把金色的雨，在夕阳里散成扇形，落进土里。

他不数有多少颗，不管它们落在哪一行。他只管撒，土地负责接。

三百年后，一个工程师坐在匹兹堡 KDKA 电台的发射塔下，把话筒推到嘴边。他说的每一个字变成电磁波，从天线顶端向四面八方散出去——不知道谁在听，不知道有多少台收音机亮着，不知道信号最远到了哪片玉米田。

他只管发，空气负责送。

**同一个动作。同一种信任。同一个词。**

## 4. 多面体：核心义项展开

### 义项 A：广播 / 播出（动词，最常用义）

通过电视、广播、网络等媒介向公众传送节目或信息。

> *The president's speech will be broadcast live at 8 p.m.*
> 总统的讲话将在晚上 8 点现场直播。

和"一句话本质"的关系：信号从发射塔向所有方向散出去，不指定谁来接——这就是撒种子。

### 义项 B：广泛传播 / 散布（动词，泛化义）

不通过媒体，而是通过口头、行为等方式让信息被很多人知道。

> *I don't want to broadcast my personal problems to the entire office.*
> 我不想把个人问题闹得全办公室都知道。

和"一句话本质"的关系：把私事"撒"出去，让所有人都接收到——你失去了对信息流向的控制。这个义项经常带贬义，因为有些东西不该被 broadcast。

### 义项 C：广播节目（名词）

一档具体的电视或广播节目。

> *We watched a live broadcast of the concert.*
> 我们看了那场演唱会的现场直播。

和"一句话本质"的关系：名词化——那把被撒出去的种子本身。

### 义项 D：撒播（农业原义，动词/形容词）

不用条播机，直接将种子撒在地面上。

> *Broadcast the grass seed evenly over the prepared soil.*
> 将草籽均匀撒播在整理好的土壤上。

和"一句话本质"的关系：这就是本体——词义的出发原点。

### 底层统一性

四个义项，一条线：**从一个源头出发，不加选择地、覆盖式地释放到整个范围。** 种子是物理的释放，信号是电磁波的释放，八卦是社会性的释放——broadcast 不在乎你释放的是什么，它在乎的是"释放的方式"。

## 5. 裂缝标注

### 常见误用场景

**❌ 过去式误写 broadcasted**

broadcast 的过去式和过去分词最标准的形式是 **broadcast**（不变），不是 broadcasted。虽然 broadcasted 在一些语料库里偶尔出现（尤其美式英语），但在正式写作和新闻行业中，broadcast 作过去式是压倒性的标准。

> ✅ The game was broadcast yesterday.
> ⚠️ The game was broadcasted yesterday. （能理解，但不够标准）

**❌ 把 broadcast 用于精准定向传播**

broadcast 的核心是"不定向"。如果你在说"专门给某个人发消息"或"定向推送给特定群体"，broadcast 就不对了。

> ❌ I broadcast the file to John.（你只发给一个人，这不是 broadcast）
> ✅ I sent the file to John.

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **broadcast** | 一对多，不指定接收者，覆盖式。农夫撒种子。 |
| **transmit** | 强调"传送"这个物理过程，可以是点对点的。电线传电流。 |
| **air** | 特指电视/广播播出，比 broadcast 更口语化、行业化。"The show airs on Friday."你不会说"The show broadcasts on Friday." |
| **stream** | 互联网时代的词，强调持续流动的数据传输。broadcast 是撒出去就完了，stream 是一直在流。 |
| **disseminate** | 书面正式词，多用于信息/知识的传播，有"有意识地散布"的含义。学术论文发布叫 disseminate，不叫 broadcast。 |

### 中文母语者陷阱

**"广播"的窄化陷阱**

中文"广播"几乎只指收音机广播，偶尔指学校/社区的喇叭广播。但英文 broadcast 覆盖面大得多：电视播出、网络直播、甚至"把消息散布出去"都可以用。中文母语者容易把 broadcast 只和"FM/AM 广播"绑定，看到电视节目语境里的 broadcast 就困惑。

**"播"和"撒"的翻译混淆**

broadcast 的农业义在中文里是"撒播"，但中文"播种"本身就包含了 broadcast 和 drill（条播）两种方式。如果你在农业语境里把 broadcast 翻成"播种"，就丢失了"散撒式"这个关键信息。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **broadcast live** | 现场直播。新闻/体育/演唱会的标配用法。 |
| **broadcast a message** | 广泛传播一条信息。可以是媒体也可以是比喻。 |
| **nationwide broadcast** | 全国播出。通常指重大事件——总统讲话、灾难预警。 |
| **broadcast network** | 广播电视网（ABC, NBC, CBS 等），和 cable network 对立。 |
| **broadcast journalism** | 广播电视新闻业。和 print journalism 对立。 |
| **broadcast signal** | 广播信号。偏技术/工程语境。 |
| **live broadcast** (名词) | 现场直播。最常见的名词搭配。 |
| **emergency broadcast** | 紧急广播。美国人听到这个词条件反射想到 EBS 那个刺耳的嘟嘟声。 |

### 语域标注

broadcast 是个**中性偏正式**的词。新闻、学术、技术文献中高频出现。日常口语中，人们说电视节目更常用 **air** 或 **show**（"it airs tonight" / "it's showing tonight"），而 broadcast 更像行业用语。

不过"别把我的事 broadcast 出去"这种比喻用法在口语中很常见——带轻微戏谑或抱怨的口气。

### 活用示范

> *"She has a habit of broadcasting her opinions before anyone asks."*
> 她有个毛病，没人问就把自己的观点撒得到处都是。

这里 broadcast 的活力在于它唤起了"不加选择地散布"的画面——像农夫撒种子一样撒观点，不管有没有人想听。

> *"The scandal was broadcast across every platform within minutes."*
> 丑闻在几分钟内被散布到了每一个平台。

这里 broadcast 同时激活了"媒体播出"和"不可控扩散"两层含义——信息一旦被 broadcast 出去，就像种子落地，你收不回来了。

## 7. 跨语言映射

**中文"广播"** 在日常用法中比 broadcast 窄得多（基本只指收音机/喇叭），但如果你拆开看——"广"（广泛地）+"播"（撒播）——它的造词逻辑和 broad+cast 几乎是**镜像翻译**。两种语言独立地选择了同一个比喻结构来命名这件事：宽宽地撒出去。

**日语「放送」（ほうそう）** 的构词是"放"（释放）+"送"（送出），重心在"把东西放出去送走"——更像是从发射者视角描述。broadcast 和"广播"都偏"覆盖面"的视角，日语偏"释放动作"的视角。微妙的区别。

**计算机科学中的 broadcast** 值得一提：在网络协议里，broadcast 是一种严格定义的通信方式——发送方将数据包发送到网段内的**所有设备**，和 unicast（单播，点对点）、multicast（组播，一对多但有指定组）构成三位一体。这个技术定义完美保留了 broadcast 的农业基因：不指定接收者，网段就是田地，数据包就是种子。
