# disqualify

---

## 1. 一句话本质

**disqualify 是裁判走到你面前，把你胸前的号码牌摘下来的那个动作——你本来已经站在赛道上了，但现在被请出去。**

不是"你不够格"，是"你的资格被剥夺了"。这个词里有一个隐含的时间线：你曾经有（或本该有）入场券，然后有人——或某条规则——把它从你手里抽走了。

---

## 2. 词源考古

### 词根词缀拆解

```
dis·qualify
 │    │
 │    └─ qualify ← 中世纪拉丁语 qualificāre
 │         │          │
 │         │          ├─ quālis「什么样的、具有什么性质的」
 │         │          └─ -ficāre ← facere「做、使成为」
 │         │
 │         └─ → 字面义：「使之具备某种性质」→「使之够格」
 │
 └─ dis- ← 拉丁语前缀，表"取消、逆转、剥除"
         （不是简单否定，是把已有的东西拿走）

→ disqualify = 逆转「使之够格」= 剥夺资格
```

**dis- 在这里的精确含义：** 英语里 dis- 有三种用法——①否定（disagree）②分离（disassemble）③逆转/剥除（disqualify、disarm、disconnect）。disqualify 属于第三种：不是说"不合格"，而是说"把合格的状态撤销掉"。这就是为什么 disqualify 和 unqualified 不是同一件事——unqualified 是从来没拿到入场券，disqualified 是入场券被没收。

### 历史流变

**qualify** 大约 16 世纪初从法语 *qualifier* 进入英语，最初是学术用语，意思很抽象——"赋予某种性质"，比如"这个因素 qualifies 了那个判断"（给判断加了限定条件）。到 16 世纪中后期，它长出了我们今天最常用的那个义项："使具备资格/使胜任"。

**disqualify** 晚了大约一百年，17 世纪中叶（约 1650s）才出现。这个词一出生就带着法律和竞争的味道——最早的使用场景是法律文书里，说某人因为利益冲突而"被取消"担任陪审员或法官的资格。

到 **18-19 世纪**，赛马和体育运动蓬勃发展，disqualify 在竞技领域彻底扎根。赛马裁判宣布某匹马 disqualified，观众秒懂——这匹马犯规了，成绩作废。这个场景太鲜明、太常见，以至于今天一听到 disqualify，大多数人脑子里第一反应还是运动员被罚出局。

### 文化地层

有趣的是，qualify 本身经历了一次"变窄"。它最初是个很宽泛的哲学词（"赋予性质"），后来越来越窄，变成了"满足准入条件"这种行政意味浓厚的用法。而 disqualify 继承的恰恰是这个变窄后的义项——它一出生就不是哲学词，是制度词、规则词、裁判词。

## 3. 故事 / 画面

一场百米决赛。八条跑道，八个人。

发令枪还没响，3 号道的选手抢跑了。裁判举起红牌。3 号道的选手站在原地，其他七个人重新归位。他没有受伤，没有退赛，体能状态完美——他只是再也不被允许跑了。

这就是 disqualify 最残酷的地方：**不是你不行，是你不被允许证明自己行。**

你的能力还在，你的训练还在，你穿着钉鞋站在塑胶跑道上，但号码牌被摘了。你从"参赛者"变成了"在场的无关人员"。那条跑道在物理上还是你的，但在规则上，它已经不认识你了。

再推远一点：disqualify 有时甚至不需要你犯了什么错。赛前药检查出违禁成分——可能是你吃的感冒药里含的；利益冲突让你不能担任评委——可能你根本不认识那个参赛者，只是恰好同姓。disqualify 不总是惩罚，有时只是制度在运转，而你被卷进了齿轮。

## 4. 多面体：核心义项展开

### 义项 A：因违规剥夺参赛/竞争资格（最常见）

> *The runner was **disqualified** for a false start.*
> 那名跑者因抢跑被取消了比赛资格。

这是 disqualify 的主场。从体育赛事到招标竞争，只要有"规则"和"参与者"的场景，违规 → disqualify 这个链条就会启动。和"一句话本质"的关系：号码牌被摘，从赛道上被请出去。

### 义项 B：因某种条件/身份而不具备资格（制度性排除）

> *A criminal record **disqualifies** you from holding public office in some states.*
> 在某些州，有犯罪记录就不能担任公职。

注意这里的主语不是人，是"犯罪记录"——某个条件本身就是 disqualifying factor。你没有犯赛场上的规，而是你的"属性"让规则自动把你排除了。和本质的关系一样：入场券被抽走，只不过抽走它的不是裁判，是制度本身。

### 义项 C：使人在主观判断上被排除（延伸用法）

> *His lack of empathy **disqualifies** him as a leader, in my opinion.*
> 在我看来，他缺乏同理心，这让他不配当领导。

这个义项更软、更主观，常带 "in my view / as far as I'm concerned" 之类的限定。说话人把自己当成了裁判，宣布某人"出局"。底层逻辑没变：有一个标准（领导力需要同理心），你没达到，资格被撤。

### 义项 D：形容词化 disqualifying — 某个因素足以一票否决

> *For many voters, that scandal was a **disqualifying** factor.*
> 对很多选民来说，那个丑闻是一票否决的因素。

disqualifying 作形容词时特别好用，意思是"光这一条就足以让你出局"。这是一种极端表态——不是扣分，是直接淘汰。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 disqualify 当成 "不合格" 的高级说法**

> ~~He is disqualified for the job because he has no experience.~~

如果他从来就没申请过这份工作，也没人在评估他的资格，用 disqualified 就奇怪了——没人给他发过入场券，何来"摘号码牌"？正确说法应该是 *He is **unqualified** for the job* 或 *He doesn't **qualify** for the job*。

**disqualify 需要一个隐含的制度/规则/裁判在运作。** 如果只是你个人觉得某人不够格，要么用 unqualified，要么在 disqualify 前面加上你的主观立场（"in my view, this disqualifies him"）。

### 易混近义词辨析

| | disqualify | unqualify | ineligible | exclude |
|---|---|---|---|---|
| **核心** | 剥夺已有/应有的资格 | ❌ 不是标准英语 | 不符合条件 | 排除在外 |
| **谁在操作** | 规则/裁判/制度 | — | 条件自然不满足 | 任何主体 |
| **语气** | 正式裁决感 | — | 中性陈述 | 范围更广 |

- **disqualified vs. ineligible**：你在赛场上犯规，你被 disqualified；你年龄不够报名条件，你是 ineligible。前者有"资格被撤"的戏剧性，后者只是"不满足条件"的平静陈述。一个是"出局"，一个是"没入局"。

- **disqualified vs. excluded**：exclude 更广——可以出于任何原因把某人排除在外（主动选择、偏见、无意遗漏）。disqualify 专指基于规则/标准的排除，带有正式裁定的味道。

### 中文母语者陷阱

**陷阱 1："取消资格" vs "不合格"**

中文里"他不合格"和"他被取消资格"是两句完全不同的话，但中文母语者写英文时容易把两者混用 disqualify。记住：**disqualify ≈ 取消资格（有一个撤销动作），unqualified ≈ 不合格（一种状态描述）。**

**陷阱 2：主语搞反**

中文说"他被取消了资格"（人做主语），但英文中 disqualify 的主语经常是**原因/条件**，不是人：

> ✅ *His age **disqualifies** him from competing.* （他的年龄让他失去了参赛资格）
> ✅ *He **was disqualified** from competing.* （他被取消了参赛资格）

两种都对，但前者在书面英语中非常常见，中文思维不太习惯让"年龄"当主语去"取消"别人的资格。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **disqualify from** + 名词/动名词 | 最基本的句型：*disqualified **from** the competition / from competing* |
| **automatically disqualified** | 不需要裁判判定，规则自动触发：*You are automatically disqualified if you test positive.* |
| **grounds for disqualification** | 正式用语，"取消资格的理由"：法律、体育、招标文件常见 |
| **disqualifying factor / offense** | 形容词化，"足以一票否决的因素"：政治评论和新闻里高频 |
| **self-disqualify** | 自己退出（主动或因自知不符条件）：*He self-disqualified from the investigation due to a conflict of interest.* |
| **disqualify a bid / entry** | 商业/竞标场景："废标" |
| **disqualify a juror / judge** | 法律场景：取消陪审员或法官的审理资格 |

### 语域标注

**正式偏中性。** disqualify 不是口语词，也不是纯学术词。它活在规则明确的场景里——体育转播、法律文书、新闻报道、政治评论。日常对话中你不太会说"I disqualify you from being my friend"（虽然语法上没错，但听着像角色扮演）。

在政治语境中，"disqualifying" 作形容词已经变成了一个非常流行的评论用语——*"That comment should be disqualifying"*（那番话本身就该让他出局），这种用法在美国政治评论中尤其常见，几乎成了一种修辞套路。

### 活用示范

> *In any other era, this level of corruption would have been **disqualifying**. Today, it barely makes the news.*
> 换在任何别的时代，这种程度的腐败足以让人彻底出局。如今，连新闻都懒得报。

这句话里 disqualifying 的力量在于它和后半句的反差——"本该一票否决"和"连新闻都不算"之间的距离，就是说话人想表达的荒诞感。

> *I don't want to **disqualify** the idea entirely, but there are serious concerns.*
> 我不想把这个想法完全否掉，但确实有严重的顾虑。

这个用法更温和，disqualify 被拉到了"否决一个提案/想法"的抽象层面，常见于会议和学术讨论。

## 7. 跨语言映射

**中文"取消资格"** 是最精确的对照，几乎一一对应。但中文还有一个更口语化的表达——**"判出局"**，抓住了 disqualify 里那种"裁判的手一挥，你就不在了"的动感。

**日语「失格」（しっかく）** 几乎完美对应 disqualification。太宰治的小说《人間失格》（*No Longer Human*）用的就是这个词——"失去做人的资格"。这个标题精确地展示了 disqualify 最深的一层含义：不是能力问题，是**资格问题**。你可以有一切技能、一切条件，但资格这东西，是别人（或制度，或你自己）给的，也是可以被拿走的。

**法语 *disqualifier*** 直接借自英语（反向借词——英语从拉丁语借材料造了这个词，法语又从英语借了回去），用法基本相同，也偏体育和法律。
