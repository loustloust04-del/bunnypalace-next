# specify

---

## 1. 一句话本质

**specify 是用手指从一堆模糊的东西里，精准地戳中一个点——不是"说清楚"，是"把模糊逼退到无处藏身"。**

"说清楚"太温和了。specify 的动作更像是拿一束极细的光照进一团雾气——每照一下，就有一块模糊凝固成确定的形状。直到整团雾都变成了有棱有角的物体。

---

## 2. 词源考古

### 词根词缀拆解

```
specify = spec- + -ify
         │        │
         │        └─ 拉丁 -ificare ← facere「做、制造」
         │           → "使之成为……"
         │
         └─ 拉丁 species「外观、种类、具体形态」
            ← specere「看」
```

**-ify** 这个后缀是英语里最高产的"动词制造机"之一：simplify（使简单）、clarify（使清晰）、purify（使纯净）。它的本质动作是 **"使某物变成某种状态"**。

所以 specify 的骨骼结构是：**"使之成为一个具体的种类/形态"**——把一团没有形状的东西，逼成一个有清晰轮廓的东西。

### 历史流变

| 时间 | 语言 | 形式 | 含义 |
|------|------|------|------|
| 古典拉丁 | specere | 看 | 用眼睛辨别 |
| 晚期拉丁 | specificare | 提及、列举 | 把某物从泛指变为特指 |
| 13世纪 | 古法语 especifier | 详细说明 | 法律/契约中列明条款 |
| 14世纪 | 中古英语 specifien | 明确指出 | 进入英语，最初用于法律和学术文本 |
| 17世纪起 | 现代英语 specify | 详细规定/指明 | 扩展到工程、科学、日常语境 |

### 文化地层：从"看"到"说"的跳跃

这个词最深的底层是 **specere（看）**——但 specify 的动作已经完全不是"看"了，而是"说"。

这个跳跃怎么发生的？逻辑链是这样的：

**看清楚** → **能区分种类（species）** → **说出具体是哪一种（specify）**

"看"是输入端，"说出来"是输出端。你必须先看清，才能说准。specify 继承的不是"看"的动作，而是"看"之后的那个结果——**辨识出具体形态的能力**。

另一个有意思的文化地层：specify 最早大量使用的场景是 **法律文书和契约**。中世纪的法律要求你不能笼统地说"给他一些财产"，你必须 specify——"北边那块三英亩的地，靠着河，旁边是约翰家的篱笆"。这个词从诞生起就带着一种 **"模糊不被接受"** 的严厉感。

## 3. 故事 / 画面

一个建筑师拿着图纸站在工地上。工人问："这面墙用什么材料？"建筑师说："石头。"工人又问："什么石头？"建筑师说："花岗岩。"工人再问："什么颜色？多厚？表面磨光还是粗凿？"

每一个追问都在逼退一层模糊。直到建筑师说出："芝麻灰花岗岩，厚度 30 毫米，表面火烧面处理，倒角 2 毫米。"——这时候，这面墙才从一个"想法"变成了一个"可以被建造的东西"。

**这整个追问过程就是 specify。**

不是一句话的事。Specify 是一个持续施压的动作——对模糊性施压，每一轮都把颗粒度推细一档，直到对方拿着你的描述，不需要再问任何问题就能执行。

## 4. 多面体：核心义项展开

### 义项 A：明确指出（最核心义项）

> *"The contract specifies that payment must be made within 30 days."*
> 合同明确规定付款必须在 30 天内完成。

这是 specify 最日常的脸：把某个要求或细节 **从隐含变为显式**。"说了"不算，"说到不可能误解"才算 specify。

**与本质的关系**：光照进雾气——把模糊的"得付钱"压实成"30 天内"。

### 义项 B：详细列举 / 逐项规定

> *"Please specify your dietary requirements when booking."*
> 预订时请详细说明你的饮食要求。

注意这里不是"提一嘴"，而是要你 **逐项列出**：不吃猪肉、对花生过敏、乳糖不耐受……每一条都是一束光。

**与本质的关系**：不是照一下就走，是把整片雾扫干净。逐项列举 = 扫射式消除模糊。

### 义项 C：（技术/工程语境）给出规格参数

> *"The engineer specified a torque of 45 Nm for the bolt."*
> 工程师指定了螺栓的扭矩为 45 牛米。

这是 specify 在技术语境里的专用面孔——给出一个 **精确的数值或参数**，使得执行者可以照做而不需要自己判断。这也是 specification（上一个词）的动词态。

**与本质的关系**：最极端的"逼退模糊"——不是用文字描述，是直接给数字。数字是模糊的反义词。

### 义项 D：（逻辑/哲学）从一般到特殊的限定

> *"The theory specifies the conditions under which the effect occurs."*
> 该理论指明了效应发生的条件。

在学术写作中，specify 经常用来描述 **从一般性命题到特定条件的收窄过程**——不是在说"这个理论是什么"，而是说"这个理论在什么边界内成立"。

**与本质的关系**：给一个宽泛的命题画上围栏——specify 的动作就是画围栏。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 specify 当"说"用**

> ~~*"He specified that he was tired."*~~（他说他累了）

specify 不是 say/mention/state。你不能 specify 一个感受或一个事实陈述。Specify 的宾语必须是 **可以被模糊也可以被精确化的东西**——要求、条件、参数、细节。你的疲劳没有"模糊版"需要被精确化。

**❌ 混淆 specify 和 describe**

Describe 是"画全景"：*Describe the scene*（描述这个场景）。
Specify 是"戳细节"：*Specify the color*（指定颜色）。

你可以 describe 一个场景但不 specify 任何东西（全是印象派的模糊描述）。你也可以 specify 一个参数但不 describe 任何东西（直接说"红色，#FF0000"）。

### 易混近义词辨析

| 词 | 核心动作 | 场景 |
|---|---|---|
| **specify** | 逼退模糊，给出精确细节 | "请指定尺寸：M 号" |
| **indicate** | 指向、暗示 | "数据表明趋势向上"（不需要精确） |
| **define** | 划边界、下定义 | "我们先定义什么算'成功'" |
| **determine** | 经过调查/计算得出结论 | "调查确定了事故原因" |
| **stipulate** | 以条款形式规定（更正式，常用于法律） | "合同stipulate了违约金" |

**specify vs. stipulate**：specify 可以很日常（"specify your preferences"），stipulate 几乎只出现在法律/正式协议中。Stipulate 多了一层"你必须遵守"的强制性，specify 本身不包含强制性——它只负责把事情说清楚，至于你听不听，那是别的词的事。

### 中文母语者陷阱

**"指定" vs. "说明" vs. "规定"**

中文里这三个词的边界比英文清晰得多。但 specify 同时横跨这三个中文词的领地：

- "请**指定**一个颜色" = Please specify a color（选择+明确）
- "请**说明**你的需求" = Please specify your requirements（详细列举）
- "合同**规定**了期限" = The contract specifies the deadline（正式条款）

中文母语者容易根据中文译法把 specify 切成三个不同的词，实际上它们是同一个动作的不同场景——都是"把模糊逼退"。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 说明 |
|------|------|------|
| **specify + requirements** | 商业/技术 | "请列明需求"——最高频搭配之一 |
| **specify + conditions** | 学术/法律 | "规定条件"——理论成立的边界 |
| **specify + details** | 日常/商务 | "说明细节"——最通用的用法 |
| **clearly specify** | 正式文件 | "明确指出"——强调不容模糊 |
| **fail to specify** | 法律/投诉 | "未能说明"——指责对方的模糊 |
| **as specified (in/by)** | 技术/合同 | "按照规定"——引用已有的精确描述 |
| **unless otherwise specified** | 合同/说明书 | "除非另有规定"——法律/技术文本的常见套话 |
| **specify + that-clause** | 所有语域 | "明确指出……"——后接具体内容 |

### 语域标注

Specify 是一个 **中高正式度** 的词。它在以下场景密度最高：

- 📄 **法律/合同文本**：最原始的栖息地
- 🔧 **技术文档/工程规范**：specification 的动词态
- 📊 **学术论文**：描述理论的适用条件
- 💼 **商务邮件**：请对方提供具体信息

日常口语中不常用。你不会对朋友说 *"Can you specify what you want for dinner?"*——你会说 *"What exactly do you want?"* 或者 *"Be more specific."*（用形容词而非动词）。

### 活用示范

> *"The law specifies nothing about digital assets—which is precisely the problem."*
> 法律对数字资产没有任何规定——而这恰恰就是问题所在。

这句话的力量在于：用 specify 的 **缺席** 来制造论点。法律的本职就是 specify，当它在某个领域"specify nothing"，就等于承认那里是一片无法可依的雾区。

> *"You don't get to specify the terms after the deal is done."*
> 交易结束后你没资格再来定条件了。

口语化但有力——specify 在这里带上了一层"权力"的意味：谁有资格 specify，谁就有控制权。

## 7. 跨语言映射

**中文"指定"** 和 specify 最接近，但"指定"多了一层"选择"的意味（"指定某人为负责人"），而 specify 的重心不在选择，在 **消除模糊**。

**日文「明記する」（めいきする）** 非常精准地对应 specify 的"在文件中明确写出"这个义项——"記"字强调了"落到纸面"的动作，这和 specify 在法律/合同语境中的本质一致。

**德文 spezifizieren** 直接从拉丁语借来，用法几乎完全平行，包括技术文档中的高频使用。

**法文 spécifier** 同源同义，但法语日常中比英语更常用这个词——法国人说 *"Il faut spécifier"*（必须说清楚）的频率比英美人说 *"You need to specify"* 高。法语对精确性的文化执念可能是原因之一。

### spec- 家族定位

你已经走过了这个家族的四个成员。回头看一眼它们的关系：

| 词 | 角色 | 一句话 |
|---|---|---|
| **species** | 名词·原点 | "看出来的种类"——specere 的第一个孩子 |
| **specialty** | 名词·领地 | "你扎根最深的那块地" |
| **specific** | 形容词·性质 | "不是那团雾，是雾散后露出的那个东西" |
| **specification** | 名词·产物 | "把模糊杀死后留下的尸检报告" |
| **specify** | 动词·动作 | "杀死模糊的那个动作本身" |

Specify 是这个家族里唯一的 **动词**——它是 specific 的执行态，是 specification 的生产过程。没有 specify 这个动作，就不会有 specification 这个产物，事物也无法从 general 变成 specific。

它是整个 spec- 家族的 **发动机**。
