# preference

## 1. 一句话本质

**preference 是你在超市货架前伸出手的那个方向——不是因为另一个不好，而是你的手"自己"就往那边去了。**

它不是激烈的选择，不是理性的判断，是一种温和的、已经内化了的倾斜。天平两端都有重量，但有一端总是微微低一点。

---

## 2. 词源考古

### 词根词缀拆解

```
pre-  (= prae-)   拉丁语"在……之前"
fer              拉丁语 ferre "携带、承载"
-ence            名词后缀，表示状态/行为

合体：praeferre → "把……提到前面去"
名词化：praeferentia → "提到前面的那个状态"
```

**ferre** 这个词根极其高产，是拉丁语里的"搬运工"——

- transfer = trans(跨过) + fer → 搬过去 → 转移
- differ = dis(分开) + fer → 各搬各的 → 不同
- offer = ob(朝向) + fer → 搬到你面前 → 提供
- suffer = sub(在下面) + fer → 在下面扛着 → 承受
- refer = re(回) + fer → 搬回去 → 参考/指向
- infer = in(向内) + fer → 搬进脑子里 → 推断

所以 **prefer** 的画面就是：你面前有一排东西，你把其中一个**搬到最前面**。

### 历史流变

| 时间 | 形态 | 含义 |
|------|------|------|
| 古典拉丁语 | praeferre | 物理动作："把某物举到前面/端在前面"（真的是搬东西） |
| 中世纪拉丁语 | praeferentia | 抽象化："优先考虑的状态" |
| 15世纪 | 法语 préférence | 进入法语，已完全抽象——"偏好、优先" |
| 1432-1509 | 英语 preference | 从法语借入英语。最初主要用在法律和行政语境——"给予某人优先权" |
| 17-18世纪 | — | 从"制度性优先权"扩展到个人心理——"我个人的偏好" |
| 19世纪至今 | — | 经济学/心理学术语化："消费者偏好""显示性偏好" |

### 文化地层：一个关键转折

早期 preference 更多是一个**权力词**——谁有 preference，谁就有优先权。国王给你 preference，是给你特权。关税里的 "preferential treatment"（优惠待遇）至今保留这层"制度性偏向"。

大约 17 世纪起，这个词开始**向内转**——从"制度赋予你的优先"变成"你内心自发的倾向"。这个转折很重要：它标志着现代个体主义意识的崛起。你的偏好不再需要外部授权，它是你**自己的**。

到了 20 世纪经济学里，preference 被进一步技术化：萨缪尔森的"显示性偏好"（revealed preference）理论说——别问人喜欢什么，看他**花钱买了什么**。preference 从主观感受变成了可观测的行为模式。

## 3. 故事 / 画面

想象一张很长的餐桌，上面摆了十二道菜。你不讨厌任何一道，但你总是先夹那盘醋溜土豆丝。

不是因为别的菜难吃。不是因为你深思熟虑过。甚至不是因为你"最爱"它——如果有人问你最爱什么菜，你可能答不上来。但你的筷子就是会先往那个方向伸。

这就是 preference。

它不是 **love**（那是把整桌菜都推开只吃一道的执念），不是 **choice**（那是菜单上打勾的动作），而是那种**不自觉的微微倾斜**——gravity 一样安静，但确实在起作用。

## 4. 多面体：核心义项展开

### 义项 A：个人偏好（最日常）

> *"I have a preference for window seats — I like watching the clouds."*
> 我偏好靠窗座位——我喜欢看云。

这是"筷子自动伸过去"的那层意思。注意不是"我只坐靠窗"，而是"有得选的话，我会选靠窗"。preference 自带一个隐含前提：**有别的选项存在**，我只是倾向其中之一。

### 义项 B：优先权/优先待遇（制度层面）

> *"Preference will be given to candidates with prior experience."*
> 有相关经验的候选人将被优先考虑。

这是它的老灵魂——"把某人/某物搬到队列前面"。这里的 preference 不是心理偏好，是**位置操作**：你被制度性地往前挪了一步。关税中的 "trade preference"、招聘中的 "preference for veterans"，都是这一层。

和"一句话本质"的关系：天平的那一端不是自己沉下去的，是有人在那端加了砝码。

### 义项 C：偏好设置（技术/数字语境）

> *"You can change your notification preferences in Settings."*
> 你可以在设置中更改通知偏好。

这是 preference 在数字时代的具象化：你的偏好被翻译成了一组开关和选项。"Preferences" 在 macOS 里曾是"系统偏好设置"的标准名称（后来改成了 Settings）。

和"一句话本质"的关系：你在每个开关上做的选择，就是你的筷子在数字世界里伸向的方向。

### 义项 D：（计算机科学/经济学）偏好排序

> *"The algorithm learns user preferences from browsing history."*
> 算法从浏览历史中学习用户偏好。

在推荐系统和经济学里，preference 被量化了——它不再是模糊的"我喜欢这个"，而是一个**排序函数**：给定 A 和 B，你 prefer A 的概率是多少。

和"一句话本质"的关系：那只"自动伸过去的筷子"被统计学捕获了，变成了一条曲线。

## 5. 裂缝标注

### 常见误用场景

**❌ "I have a preference of jazz."**
**✅ "I have a preference for jazz."**

preference 后面搭的介词是 **for**，不是 of。这是最高频的错误。偶尔在 "in preference to"（优先于）结构中用 to，但核心搭配永远是 for。

**❌ 把 preference 当成 "favorite" 用**

*"Jazz is my preference."* 语法没错，但语感奇怪。preference 强调的是**在比较中倾向某一边**，不是"我的最爱"。说 "Jazz is my preference" 就像说"爵士乐是我的倾斜方向"——太机械了。日常口语直接说 "I prefer jazz" 或 "Jazz is my favorite"。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **preference** | 温和的倾向。"有得选的话我选这个"。不排斥其他选项 |
| **choice** | 动作本身。你做了一个 choice，可能完全违背你的 preference（比如为了省钱选了过道座位） |
| **taste** | 更深层、更审美化。taste 是你长期养成的感受力，preference 可以是临时的（"今天我 prefer 喝热的"） |
| **inclination** | 更强调"被拉过去"的感觉，像地心引力。preference 更中性理性，inclination 更本能 |
| **predilection** | preference 的正式/文学版。带一点"偏心、偏爱"的暗示，语气更强 |

### 中文母语者陷阱

**"偏好"≠ preference 的全部**

中文的"偏好"几乎只覆盖义项 A（个人偏好）。但 preference 还有"优先权"的意思——"preferential treatment" 翻译成"优惠待遇"而不是"偏好待遇"。中文母语者容易忘记这层制度性含义。

**"比起 A 更喜欢 B"的翻译陷阱**

中文说"比起咖啡我更喜欢茶"，英文是 "I prefer tea **to/over** coffee"，不是 "I preference tea"。preference 是名词，prefer 是动词——这不难，但在口语中容易混。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 说明 |
|---|---|---|
| **personal preference** | 日常/通用 | "这纯粹是个人偏好"——最常见的组合，用来强调主观性 |
| **preference for** | 通用 | 核心介词搭配。"a preference for simplicity" |
| **in preference to** | 书面/正式 | "她选了 X in preference to Y" = 她优先选了 X 而非 Y |
| **give/show preference (to)** | 制度/正式 | "公司给了本地供应商优先权" |
| **stated preference** | 经济学/调查 | 你说你喜欢什么（对比 revealed preference：你实际买了什么） |
| **sexual/gender preference** | 社会议题 | ⚠️ 当下语境中 "sexual preference" 被认为不恰当，因为暗示性取向是一种"选择"。正确用法是 "sexual orientation" |
| **preference shares** | 金融 | 优先股——分红时排在普通股前面 |
| **user preferences** | 技术/UI | 用户偏好设置 |

### 语域标注

preference 是一个**中性偏正式**的词。它在以下场合都很舒服：

- ✅ 学术写作（"consumer preferences"）
- ✅ 商业/法律文本（"preferential terms"）
- ✅ 日常对话（"I don't have a strong preference"）
- ✅ 技术文档（"Preferences panel"）

但在非常随意的口语里，人们更倾向于直接说 "I like X better" 或 "I'd rather..." 而不是拽出 preference 这个名词。

### 活用示范

> *"The algorithm doesn't care about your stated preferences — it watches what you actually click."*
> 算法不在乎你嘴上说喜欢什么——它看你实际点了什么。

这句话精准地展示了 stated preference 和 revealed preference 的张力——也是 preference 这个词在当代最有哲学深度的用法：**你以为的偏好，和你用行为暴露的偏好，是两回事。**

> *"I have no preference — whatever works for you."*
> 我没有偏好——你方便就好。

日常口语中最高频的 preference 句式之一。注意这句话的潜台词往往不是真的没偏好，而是"我的偏好没有强到值得坚持"——preference 的温和本性在这里完美体现。

## 7. 跨语言映射

**中文"偏好" vs preference**

"偏好"的"偏"字很妙——它直接告诉你这是一种**偏离中心**的状态。但中文的"偏"暗含"不够正/不够公"的微妙判断（"偏心""偏见"），而英文的 preference 完全中性，甚至正面——你有 preference 是正常的、健康的、值得被尊重的。

**日语「好み」(konomi)**

日语的「好み」更接近 taste/liking，比 preference 更感性。而 preference 的制度义在日语里要用「優先」（yūsen）另行表达——一个词裂成了两个概念。

**法语 préférence**

英语直接从法语借来的。法语中 préférence 的用法几乎完全对应英语，包括 "donner la préférence à"（give preference to）。值得一提的是，法国有一句老话："La préférence est la politesse de l'amour"（偏爱是爱情的礼貌）——在法语语感里，preference 比英语里多了一丝浪漫色彩。

**拉丁语 praeferentia → 德语 Präferenz / Vorliebe**

德语有两个对应词：**Präferenz**（直接拉丁借词，偏学术正式）和 **Vorliebe**（vor=前 + Liebe=爱，"把爱放在前面"——比 Präferenz 更暖更日常）。这个区分恰好映射了 preference 的双层身份：理性的排序 vs 感性的倾斜。
