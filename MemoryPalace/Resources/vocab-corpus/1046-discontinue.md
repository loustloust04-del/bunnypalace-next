# discontinue

## 1. 一句话本质

**discontinue 是流水线上那只按下红色停机按钮的手——不是暂停，不是故障，是有人在上面做了一个决定：这条线，到此为止。**

它不是东西自己停了，是有一个制度性的、冷静的意志介入，把一条本来还在跑的线掐断了。

---

## 2. 词源考古

### 词根词缀拆解

```
dis-  +  con-  +  tin-  +  -ue
 ↓        ↓       ↓        ↓
否定/     一起    持、握    动词后缀
逆转
```

三层套嵌，从里往外拆：

- **ten- / tin-**：拉丁语 *tenēre*，"持、握、保持"。这个词根你见过无数次——retain（保留）、contain（容纳）、maintain（维护）、tenant（租户，"持有"房子的人）。
- **con- + tin- → continu-**：拉丁语 *continuus*，"不间断的"，来自 *continēre*（"共同持住"→ 连成一体）。Continue 的画面是：很多环节手拉手，链条不断。
- **dis- + continue**：把那条链条剪断。dis- 在这里是"逆转"义——本来连着的，现在不连了。

### 历史流变

| 时期 | 形态 | 含义 |
|------|------|------|
| 拉丁语 | *continuāre* | 使不间断 |
| 古法语（14c） | *discontinuer* | 中止、停止 |
| 中古英语（15c） | *discontinuen* | 终止某种持续的事物 |
| 现代英语 | *discontinue* | 正式地停止（某产品/服务/做法） |

这个词从进入英语那天起，含义就没怎么漂移过。它天生就是个行政词汇——不是描述自然发生的中断，而是描述**有组织的、有决策权的实体做出的终止行为**。法律用语中很早就占了一席：15 世纪英格兰法庭里，*discontinuance* 是一个正式术语，指原告放弃诉讼。

### 文化地层

有意思的一点：**discontinue 是现代商业和医疗语境里最常用的"体面的死刑宣告"。**

苹果公司不会说"we killed the iPod"，他们说"the iPod has been discontinued"。药企不说"we stopped making this drug"，而是"the medication has been discontinued"。这种措辞把一个可能伤感、可能引发争议的事实，包裹进了程序正义的灰色外套里。被动语态 "has been discontinued" 甚至连谁按的按钮都省了——没有凶手，只有结果。

## 3. 故事 / 画面

你走进一家超市，推着购物车直奔那个货架——你用了三年的那款洗发水，绿色瓶子，橘子味。

货架上那个位置现在插着一张小小的白色标签：

> **DISCONTINUED**

没有解释。没有道歉。没有"我们推荐您试试这款替代品"。就一个词。

你站在那儿，盯着空出来的那一小格货架，旁边的瓶子已经向中间倾斜了过来，准备填上那个空位。整个超市的灯光嗡嗡地亮着，广播里在报打折信息。

没有人觉得这是一件大事。只有你知道，每天早上那三十秒——挤出来、搓开、那个橘子味弥漫在浴室里——那个小小的日常，从今天起没了。

这就是 discontinue 的质感：**一个系统级的决定，优雅地抹去一样东西的存在，不需要向任何个体解释。**

## 4. 多面体：核心义项展开

### 义项一：停止生产/提供（商业）

最高频用法。一家公司决定不再制造或销售某产品。

> *"Samsung has officially discontinued the Galaxy Note series."*
> 三星已正式停产 Galaxy Note 系列。

和"一句话本质"的关系：流水线按了红色按钮——产品线到此为止。

### 义项二：停止使用/执行（医疗/行政）

医生让你停药、机构终止某个项目或政策。

> *"The doctor advised her to discontinue the medication immediately due to severe side effects."*
> 由于严重副作用，医生建议她立即停药。

和"一句话本质"的关系：这里的"流水线"是治疗方案或行政流程。掐断的不是生产线，是你身体里正在运转的一个化学链条。注意——不是"吃完就不吃了"，是**中途叫停**。

### 义项三：放弃/终止（法律）

原告撤诉或法院终止案件审理。

> *"The plaintiff moved to discontinue the lawsuit after reaching a settlement."*
> 原告在达成和解后申请撤诉。

和"一句话本质"的关系：法律程序也是一条流水线——立案、举证、庭审、判决。Discontinue 就是在这条程序链上按下终止。

### 底层统一性

三个义项的共同结构：**有一条正在持续运转的线（产品供应链 / 治疗方案 / 法律程序），由一个有权威的决策者（公司 / 医生 / 原告）主动切断。**

不是自然消亡，不是意外中断，是蓄意的、正式的终止。

## 5. 裂缝标注

### 常见误用场景

**❌ 用 discontinue 描述个人习惯的改变**

> ~~"I decided to discontinue eating junk food."~~

这句话语法上没错，但非常奇怪——你又不是一家公司。Discontinue 自带"制度性决策"的语感，个人行为用 **stop / quit / give up** 更自然。除非你是在模仿公文腔故意搞笑。

**❌ 用 discontinue 描述暂时中断**

> ~~"We'll discontinue the meeting for a 15-minute break."~~

Discontinue 意味着**永久终止**，不是暂停。暂停用 **suspend / pause / interrupt**。

### 易混近义词辨析

| 词 | 核心区别 | 场景对比 |
|---|---|---|
| **stop** | 最通用，不挑场合 | "I stopped running." ✅ / "I discontinued running." ❌ 除非你是专业运动员宣布退役 |
| **cease** | 正式，但比 discontinue 更强调"动作本身的终结" | "Cease fire!" 是命令停止射击动作；discontinue 更强调终止一个**持续性的供给/服务** |
| **suspend** | 暂停，有恢复的可能 | "Service is suspended" = 之后可能恢复；"Service is discontinued" = 别等了 |
| **terminate** | 更猛烈、更有终结感，常带负面色彩 | "Terminate the contract" 比 "discontinue the service" 更像拔插头 |
| **abolish** | 废除制度/法律 | 你 abolish 奴隶制，但 discontinue 一款产品——规模和性质不同 |

### 中文母语者陷阱

**「中断」≠ discontinue**

中文的"中断"暗示意外性和临时性（网络中断、通话中断），而 discontinue 是**蓄意的、永久的**。"中断"更接近 interrupt 或 disrupt。

**「停止」太宽泛**

中文"停止"覆盖了 stop / cease / discontinue / halt 的全部领地。当你想表达"一家公司正式停产某产品"时，discontinue 是最准确的选择——它自带了"这是一个官方决定"的信号。

**被动态的陷阱**

"This product has been discontinued" 是英语里极其高频的句式。中文母语者容易直译成"这个产品已经被停止了"——语法怪异。自然的中文是"这款产品已停产"或"这款产品已下架"。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **discontinue a product/line** | 商业：停产某产品或产品线 |
| **discontinue a service** | 公司终止某项服务（流媒体、公交线路…） |
| **discontinue a medication/treatment** | 医疗：停药/停止治疗 |
| **discontinue use of** | 正式通知：停止使用某物 |
| **discontinue a practice/policy** | 行政/机构：废止某做法或政策 |
| **has been discontinued** | 被动态万能句式，商业和医疗里铺天盖地 |
| **effective immediately / as of [date]** | 常见的时间限定搭配 |
| **discontinue support for** | 科技领域：停止对某版本/平台的技术支持 |

### 语域标注

**正式偏书面**。这不是你和朋友聊天会用的词。它的自然栖息地是：
- 公司公告、新闻稿
- 医嘱、处方说明
- 法律文书
- 产品页面的告示

在口语中说 "I'm going to discontinue..." 会给人一种你在读 PowerPoint 的感觉。日常口语用 stop / quit。

### 活用示范

> *"Apple quietly discontinued the last iPod model in 2022, ending a 21-year run that redefined how the world listens to music."*
> 苹果于 2022 年悄然停产了最后一款 iPod，为这个重新定义全球听歌方式的产品线画上了 21 年的句号。

这句里 "quietly discontinued" 是一个经典用法——quietly 加上 discontinue 的被动和克制，完美呈现了大公司那种"不想搞得太隆重但你懂的"的气质。

> *"If symptoms persist after discontinuing the drug, consult your physician."*
> 停药后症状若持续，请咨询医生。

注意 "after discontinuing"——动名词形式在医疗文本里非常高频。

## 7. 跨语言映射

### 中文

中文里没有一个词能精确覆盖 discontinue 的全部语义：

- **停产**：只对应"停止生产"这一义项
- **停售/下架**：只对应"不再销售"
- **停药**：只对应医疗义项
- **中止**：最接近，但中文"中止"可以暗示"有可能恢复"，discontinue 通常不含这层意思
- **废止**：太正式，通常指法规层面

Discontinue 的妙处在于：它用一个词完成了中文需要根据语境换词才能表达的意思。**它描述的不是具体动作，而是一种决策模式——"某个持续供给，被权力中心判了死刑"。**

### 日语

日语中 **廃止**（はいし）和 **打ち切り**（うちきり）比较接近。廃止偏向制度、路线的废除；打ち切り偏向节目、连载的"腰斩"。后者更有 discontinue 那种"本来还在连载，突然被砍"的意味。
