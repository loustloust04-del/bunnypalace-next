# description

---

## 1. 一句话本质

**description 是你蹲下来，用手指在沙地上把眼前的东西一笔一笔描出来——不是那个东西本身，是你划下的那个轮廓。**

关键不在"说"，在"勾勒"。你拿着一根看不见的笔，把事物的边界线慢慢画给别人看。

---

## 2. 词源考古

### 词根词缀拆解

```
de-  +  scrib-  +  -tion
↓       ↓          ↓
向下/    刻/划      名词化
彻底地   （写）     （行为→产物）
```

**scrib-** 来自拉丁语 **scribere**，意思是"写"，但更原始的含义是"刻、划、用尖东西在表面上留痕迹"。追溯到原始印欧语 \**skreibh-*，意思是"切割、刮擦"——蜡板时代的"写字"就是拿铁笔往蜡上刻。所以 scribere 的骨头里住着一个物理动作：**一笔一划地刮出形状**。

**de-** 在这里既有"向下"（笔落到面上）的方向感，也有"彻底、完整"的强调意——不是随便画两笔，是**把轮廓描完整**。

**describere**（拉丁语原动词）在古罗马有两层意思：
1. **抄录、誊写**——把文本从一处"刻"到另一处
2. **画出、勾勒**——在几何中 describere circulum 就是"画一个圆"

这两层合在一起就是 description 的基因：**用可见的痕迹把一个东西的样子复刻出来**。

### 历史流变

| 时间 | 事件 |
|------|------|
| 拉丁语 | **descriptio** = 抄写行为；图形勾画；文字描摹 |
| 13-14世纪 | 经古法语 **description** 进入中古英语，主要义项是"用文字描绘" |
| 16世纪 | 开始出现 **"种类、类型"** 的义项——"of every description"（各种各样的）。逻辑是：你描述一个东西，就等于给它画了一个分类的框 |
| 17世纪 | 几何学中保留了拉丁语的"画图"义：the description of a circle（圆的作图） |
| 现代 | 核心义稳定在"用语言勾勒事物的样子"，"种类"义仍活跃于正式文体 |

### 文化地层

最值得记的转折：从 **物理动作** 到 **语言行为** 的跳跃。

拉丁语的 describere 你可以真的用手做——画一个圆、抄一份文件。但进入英语之后，那个"笔"变成了语言本身。你不是在蜡板上刻，你是用句子在听者的脑子里刻出一幅画面。这个跳跃恰好捕捉到了 description 最深层的本质：**它不是那个东西，它是用来"代替"那个东西的一套痕迹。**

词族里的亲戚也印证这个骨架：
- **scribe**（抄写员）——专业刻字的人
- **script**（脚本/手稿）——刻下来的东西
- **prescribe**（开处方）——"预先写下"该怎么做
- **inscribe**（铭刻）——"刻进去"
- **subscribe**（订阅）——"在下面签名"

全家族都住在同一条街上：**在某个表面上划下痕迹**。

## 3. 故事 / 画面

一个目击证人坐在警察局里。

探员递来一支笔和一张白纸："你看到的那个人，画给我看。"

目击证人不会画画。但他开始说：高个子，瘦，左眼角有一道疤，穿深蓝色外套，走路微微偏右……

旁边的素描师一边听，一边在纸上落笔。每说一句，轮廓清晰一点。说到最后，纸上出现了一张脸——不是那个人本身，但足够让别人**认出他**。

**那张素描就是 description。**

不是照片（那是事物本身的投影），是有人**选择了哪些线条该画、哪些该省**之后留下的东西。每一个 description 都是一次选择：你觉得什么值得被描下来，什么可以不提。所以 description 永远带着描述者的视角——同一个人，不同的证人会给出不同的 description。

## 4. 多面体：核心义项展开

### 义项 A：用语言描绘事物的样子（最核心）

> *The witness gave a detailed **description** of the suspect.*
> 目击者对嫌疑人做了详细的**描述**。

和"一句话本质"的关系：这就是最原始的"在沙地上画轮廓"——用嘴代替手，用词句代替线条。

### 义项 B：书面说明、文字介绍

> *The job **description** listed five required skills.*
> 岗位**说明**列了五项必备技能。

和本质的关系：job description 是给一个岗位"画肖像"——不是让你去体验那份工作，而是用文字把它的轮廓勾出来，让你看了就知道它长什么样。

### 义项 C：种类、类型（正式文体）

> *The harbor was full of boats of every **description**.*
> 港口停满了各种**各样**的船。

这个义项最容易让人意外。逻辑链是这样的：你描述一个东西 → 你就给它画了一个分类框 → "属于某个 description" = "属于某个类型"。"of every description" 等于"你能描述出的每一种"——什么样的都有。

### 义项 D：（几何学）作图、绘制

> *The **description** of a regular hexagon using only a compass.*
> 仅用圆规**作**正六边形。

这是拉丁语原义的直接存活：describere circulum，用圆规在纸上画出一个圆。这个义项现在只活在数学和技术文献里，但它是 description 最古老的一张脸。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 description 当"解释"用。**

> ~~Can you give me a description of why this happened?~~
> ✅ Can you give me an **explanation** of why this happened?

description 是画外表，explanation 是拆内部。你描述一个人长什么样（description），你解释他为什么迟到（explanation）。一个画轮廓，一个挖原因。

**❌ "description about"**

> ~~a description about the city~~
> ✅ a description **of** the city

description 后面跟 **of**，不跟 about。这是介词搭配硬规则，没有为什么。

### 易混近义词辨析

| 词 | 核心区别 | 场景 |
|---|---|---|
| **description** | 用语言画轮廓——偏"外表、特征、样子" | 给没见过这东西的人讲它长什么样 |
| **depiction** | 用视觉手段呈现——画、照片、影像 | 一幅画对战争的 depiction |
| **account** | 对事件的叙述——有时间线、有因果 | 对事故的 account（从头讲到尾） |
| **portrayal** | 对人或角色的塑造——有深度、有解读 | 演员对哈姆雷特的 portrayal |
| **explanation** | 揭示原因/机制 | 对量子纠缠的 explanation |

一句话：description 画的是"what it looks like"，account 讲的是"what happened"，explanation 拆的是"why"。

### 中文母语者陷阱

**"描述"在中文里的宽度比 description 大。**

中文说"你能描述一下当时的情况吗？"——这里的"描述"其实更接近 account（叙述事件经过），不是 description（勾画外观特征）。英文里如果你想让人讲事情经过，用 "Can you give me an account of what happened?" 比 description 更精准。

另一个坑：中文的"说明"可以是 description，也可以是 explanation 或 instruction——得看语境拆。"产品说明"= product description，"使用说明"= instructions，"原因说明"= explanation。中文一个词糊了三个英文词的边界。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **detailed description** | 最常见的形容词搭配。"给一个详细的描述" |
| **brief/short description** | 简短描述，常见于表格、标签、元数据 |
| **vivid description** | 生动的描述——文学评论高频词 |
| **accurate description** | 准确的描述——法律/新闻语境 |
| **fit/match a description** | 符合描述——警方通缉令语境，"嫌疑人与描述吻合" |
| **beyond/defy description** | 无法用语言描述——强调极端程度（美到/惨到无法描述） |
| **job description** | 岗位说明——职场基础词，缩写 JD |
| **of every description** | 各种各样的——正式书面语 |

### 语域标注

**全语域通用。** 从日常口语（"Give me a description of the guy"）到学术论文（"a description of the methodology"）到法律文书（"the description of the property"）都在用。没有正式度限制，但 "of every description"（各种各样的）明显偏书面/正式。

### 活用示范

> *The sunset was **beyond description** — the kind of sky that makes you stop talking and just stand there.*
> 那场日落**无法用语言描述**——是那种让你停止说话、只能站在那里的天空。

beyond description 是这个词最有力量的时刻：它宣布了自己的失败。一个专门用来"画轮廓"的词，承认有些东西画不出来——这个反转本身就有修辞力。

> *He didn't just match the **description**; he **was** the description — tall, scarred, blue coat, the works.*
> 他不只是符合**描述**；他**就是**那个描述本身——高个子、有疤、蓝外套，一个不差。

这里把 description 从"替代品"升格成了"本体"，用得很活。

## 7. 跨语言映射

中文的**"描"**和 description 的词源惊人地对称：

- **描**的本义是"依照原样画"（描红、描摹），强调的也是**临摹、勾轮廓**
- **述**的本义是"循、遵照前人说的来传达"

"描述"合在一起 = "画轮廓 + 传达"——和 de-scribere（向下 + 刻画）的结构几乎是镜像。

但差异在延伸义：中文"描述"没有发展出"种类"这层意思（不会说"各种描述的船"），而英文 description 发展出了 "of every description"。中文走了另一条路——"形形色色""五花八门"这类四字格承担了这个功能。

日语的「描写」（びょうしゃ）也是画 + 写，和 description 的文学性描绘对应得很好，但日语另有「記述」（きじゅつ）偏向 account（事件叙述），分工比中文"描述"清晰。

拉丁语系里，法语 **description**、西班牙语 **descripción**、意大利语 **descrizione** 基本保留了同样的义项范围——毕竟是拉丁语的直系后代，没经历太大的语义漂移。
