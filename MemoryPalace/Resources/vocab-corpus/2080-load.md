# load

---

## 1. 一句话本质

**load 是"放上去"之后身体感受到的那个沉——不是东西本身重，是它被你扛上了，现在你得带着它走。**

一块石头躺在地上不是 load。搬到你背上，它才成为 load。load 的核心不在"重量"，在"重量+承载者"这对关系。

---

## 2. 词源考古

### 词根词缀拆解

load 是个不可拆的单音节词，但它的身世极其有趣——它和 **lead**（引领）是同一个词根劈出来的两条命。

- **古英语 lād**：意思不是"重物"，而是 **"路途、行程、运送这个动作"**
- **原始日耳曼语 \*laidō**：way, course, journey
- **PIE 词根 \*leit-**："前行、出发"

也就是说，load 的起点根本不是"重"，是"走"。

### 历史流变

| 时期 | 形式 | 含义 |
|------|------|------|
| 古英语 | lād | 路途；运送的行为 |
| 中古英语 | lode | 运送行为 → **被运送的东西** |
| ~1590s | load | 拼写变化（可能受 road 类比影响，oa 拼法定型） |
| 现代英语 | load | 负荷、装载物、负担 |

**关键转折：** 从"运送的动作"到"被运送的东西"——这是一个经典的 **转喻漂移**（metonymic shift）。你反复说"走这一趟"（lād），说着说着就开始指"这一趟背的东西"。动词的宾语吞掉了动词本身。

### 文化地层

**load 和 lode 是同一个词的分裂体。** 中古英语里它们都写作 lode：

- **lode** 保留了"路径、矿脉"的意思 → lodestar（北极星，"引路之星"）、lodestone（磁石，"引路之石"）、mother lode（主矿脉，"母路径"）
- **load** 走向了"负重、装载"

同一个词根还生出了 **lead**（引领）。lead 保留了"走在前面"的主动性，load 保留了"路上扛着的东西"的被动沉重感。一个往前看，一个往下沉。

⚠️ 注意区分：load 和 **lade / laden** 词源不同。lade 来自古英语 hladan（堆积、装载），和 load 无血缘关系，但因为意思太近，两者在历史上互相渗透，现代英语里 laden 经常被当成 load 的高级版。

## 3. 故事 / 画面

一头驴站在集市边上。

它身上什么都没有的时候，四条腿轻快，耳朵竖着，尾巴甩苍蝇。商人走过来，放上第一筐橘子——驴的脊背微微下沉，但没什么。第二筐，腿稍微往外撑了撑。第三筐，第四筐。驴低下了头，耳朵耷拉下来，每走一步蹄子都要在土里多踩半秒。

它背上的所有东西加在一起，就是 load。

但你注意——关键不是橘子有多重。关键是橘子在驴背上。同样的橘子堆在地上，那只是 weight。放到驴背上，才变成 load。

**Load 永远是某个承载者的 load。** 没有主语的 load 不存在。

这也解释了为什么 load 能跳进计算机领域（CPU 的 load）、跳进电路（electrical load）、跳进心理（emotional load）——它描述的从来不是物体本身，而是 **承载者身上那种被压着、被占用、必须处理的感觉**。

## 4. 多面体：核心义项展开

### ① 物理负重——扛在身上/车上的东西

> *The truck was carrying a full load of timber.*
> 卡车满载着一车木材。

最直觉的义项。一句话本质的直接体现：东西被放到了承载者（卡车）上。

### ② 工作量 / 精神负担

> *She's been carrying a heavy load at work since two colleagues resigned.*
> 两个同事辞职后，她的工作负荷一直很重。

橘子从驴背上挪到了人的肩膀上——不是物理的，是时间和精力的。workload（工作量）已经复合成了一个词。"a load off my mind"（心里一块石头落地）是这个义项最生动的表达。

### ③ 装载（动词）——把东西放上去

> *Load the dishwasher before you go to bed.*
> 睡觉前把碗碟装进洗碗机。

动词用法。注意方向性：load 是"往里/往上放"，不是随便放。你 load a gun（装子弹入膛）、load a truck（往卡车上装货）、load software（把程序装进内存）。都有一个"从外部进入内部"的动作。

### ④ 计算机/电气负荷——系统被占用的程度

> *The server can't handle this load — we need to scale horizontally.*
> 服务器扛不住这个负载——我们得水平扩展。

CPU load、electrical load。这是 load 最精妙的延伸：承载者变成了机器或电路，load 描述的是"有多少需求压在它身上"。一台空闲的服务器 load 为 0，满负荷运转时 load 拉满。

### ⑤ 一大堆（口语）

> *We've got loads of time — don't rush.*
> 时间多的是——别急。

口语中 loads of = lots of。从"一车的量"泛化成"很多"。注意这个用法偏口语/非正式，学术写作里不用。

### ⑥ 结构载荷——建筑/工程

> *The bridge was designed to withstand a maximum load of 50 tons.*
> 这座桥的设计最大承载量为 50 吨。

load-bearing wall（承重墙）。这里 load 回到了最纯粹的物理含义：作用在结构上的力。

**底层统一性：** 所有义项都是同一个结构——**某个承载者（人/车/CPU/墙/心理）+ 被放上去的东西（货物/数据/压力/任务）= load**。

## 5. 裂缝标注

### 常见误用

**❌ "The load is very heavy" 当成 weight 用**
load 和 weight 不完全等同。weight 纯粹描述重量，load 描述的是"压在某个承载者身上的重量"。一块铁的 weight 是 50kg，但只有放到桥上时才是桥的 load。单独说 "the load of this stone" 有点奇怪——石头本身有 weight，不是 load。

**❌ 把 load 和 download 混用**
load a program = 把程序从硬盘加载到内存。download = 从网络下载到本地。方向和距离不同。你 download 一个文件，然后 load 它到内存里运行。

### 易混近义词辨析

| | load | burden | cargo | weight |
|---|---|---|---|---|
| 感情色彩 | 中性 | 负面 | 中性偏专业 | 中性 |
| 场景 | 通用 | 精神/道德/义务 | 运输业 | 物理测量 |
| 例句 | a load of laundry | a burden of guilt | the ship's cargo | the weight of the box |

- **load vs burden**：burden 永远带苦味。a load of work 可能只是客观上活儿多，a burden 意味着你不想扛、扛得痛苦。"Tax is a burden" 有怨气，"tax load" 是会计术语。
- **load vs cargo**：cargo 专指运输中的商品，范围窄得多。你不说 "the cargo on my mind"。
- **load vs charge**：在电气领域，load 是消耗端（用电设备），charge 是存储端（给电池充电）。方向相反。

### 中文母语者陷阱

**"负载"的中文习惯会让你高估 load 的正式程度。** 中文说"负载"听起来很技术，但英文 load 是日常词。 "a load of laundry"（一堆待洗的衣服）完全是厨房级别的用语。

**"装"的多义性。** 中文的"装"可以是装载、安装、假装——英文里这三个是 load、install、pretend，完全不搭界。load software ≈ 加载软件（到内存），install software ≈ 安装软件（到硬盘），别搞混。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境说明 |
|------|----------|
| **heavy load** | 物理或比喻义的"重负"。最高频的 load 搭配。 |
| **bear / carry a load** | 承受负荷。bear 偏书面，carry 偏日常。 |
| **a load of** | 口语="一大堆"。a load of rubbish（一堆废话）带轻蔑。 |
| **load-bearing** | 建筑术语，承重的。load-bearing wall = 承重墙，拆了房子塌。 |
| **workload** | 已复合成一个词。工作量。几乎每个职场英语场景都会用。 |
| **take a load off** | 口语，"坐下歇歇"（把腿上的 load 卸掉）。 |
| **peak load** | 电力/计算领域，高峰负荷。 |
| **load up (on)** | 大量囤积。"load up on snacks"——囤零食。 |

### 语域

load 是一个**全频谱词**——从菜市场到学术论文都能用，但姿态不同：
- 日常口语：a load of laundry, loads of fun, take a load off
- 工程/技术：load capacity, load testing, system load
- 新闻/商业：workload, caseload, debt load
- 文学/修辞：the load of grief（较少见，文学里更常用 burden 或 weight）

### 活用示范

> *"Get a load of this guy."*
> "你看看这人。"（口语，带调侃或不屑——让对方把注意力"装载"到某个值得围观的人身上）

> *"That's a load off."*
> "这下轻松了。"（某件悬着的事解决了，背上的筐卸掉了一个。）

## 7. 跨语言映射

中文的"负"和 load 有精妙的对应。"负"的甲骨文是一个人背着东西的象形——这和 load 的核心结构（承载者+被扛的东西）完美吻合。中文的"负重""负荷""负担"分别对应了 load 不同义项的领地。但"负"在中文里多了一层"亏欠"的道德含义（负债、负心、忘恩负义），这是 load 完全没有的维度。

日语的「荷」（に）也有意思——物理上的行李（荷物 nimotsu）和精神上的重荷（重荷 jūka），覆盖了 load 的物理义和比喻义。「荷が重い」（荷太重）和 "the load is heavy" 几乎是镜像。

德语 Last 和 Ladung 分担了 load 的两面：Last = 负担/重荷（偏 burden），Ladung = 装载物/一批货（偏 cargo/charge）。英语 load 一个词干了两个德语词的活。
