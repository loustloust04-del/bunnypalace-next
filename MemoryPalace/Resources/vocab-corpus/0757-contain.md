# contain

---

## 1. 一句话本质

**contain 是一双手合拢的动作——把东西围在里面，不让它跑出去。**

不是"装着"那么静态。它骨子里有一股张力：里面的东西想出来，外面的力在压住。一个杯子 contain 水，是因为杯壁在挡；一个人 contain 愤怒，是因为理智在压。没有这股"里面往外顶、外面往里收"的对抗感，就不是 contain。

---

## 2. 词源考古

### 词根词缀拆解

```
con-  （拉丁前缀，"一起、共同、完全"）
+
tenēre （拉丁动词，"握住、持有"）
=
continēre — "一起握住" → "围住、包住、控制住"
```

**tenēre** 是一个超级高产的拉丁词根，它的后代遍布英语：
- **tenant**（租户）= 握着租约的人
- **tenacious**（顽强的）= 死死握住不放
- **tenure**（任期）= 握住这个位置的时间
- **maintain**（维护）= 用手（manu-）握住
- **detain**（拘留）= 向下（de-）抓住
- **retain**（保留）= 往回（re-）抓住
- **sustain**（维持）= 从下面（sub-）托住
- **entertain**（娱乐）= 在中间（inter-）握住 → 留住人的注意力

你看出来了吗？这一整族词全是"抓住"的变体，只是方向和力道不同。contain 是"合拢起来抓"——从四面八方围住。

### 历史流变

**13世纪**：经古法语 *contenir* 进入英语，最初意思很物理——"把某物围在边界之内"。

**14世纪**：开始抽象化——从物理的容器扩展到"包含某种内容"。"This book contains 12 chapters" 这种用法在这时期成型。

**15-16世纪**：情感控制义爆发。"contain oneself"（克制自己）成为常用表达。这个语义漂移极其自然——你的身体就是容器，情绪是里面的流体，克制就是不让它溢出来。这不是比喻，在中世纪的体液学说（humoralism）里，人们真的相信情绪是体内液体。

**冷战时期（1947-）**：contain 获得了一个改变世界格局的专用义——**containment**（遏制政策）。乔治·凯南提出对苏联的"遏制战略"，这个词从此带上了地缘政治的色彩。把一个国家的影响力"装在"它的边界内不让扩张——contain 的核心结构完美适配。

### 文化地层

contain 身上有一种非常盎格鲁-撒克逊的价值观——**克制是美德**。英语文化里 "unable to contain his laughter"（忍不住笑出来）暗含"本来应该忍住的"这层判断。contain 背后站着一整套关于自控的文化期待。

## 3. 故事 / 画面

不用想象。去看你手边的任何一个压力锅。

锅盖压住，里面蒸汽在涨，压力在升。锅壁是 contain 的实体化身——它不只是"有东西在里面"，它是在**对抗**内部的力量。如果锅壁够厚、锅盖够紧，食物煮熟。如果压力超过临界点——

**砰。**

这就是为什么 "I can't contain myself" 是一句那么生动的话。你就是那个压力锅。情绪是蒸汽。contain 是锅壁。当你说"我 contain 不住了"，画面自动出现：有什么东西正在你体内膨胀，你的理智外壳快要裂开。

同样的结构解释了为什么大坝 contains 洪水、防火带 contains 山火、隔离区 contains 病毒——它们全是"压力锅壁"。

## 4. 多面体：核心义项展开

### 义项 A：物理包含——容器里有什么

> *The box contains three books and a letter.*
> 盒子里装着三本书和一封信。

最基础的一层。容器的边界围住了内容物。注意这里 contain 是一个冷静的陈述——盒子并没有在"努力"装住那些书，它只是事实上包含了它们。

**和本质的关系**：合拢的手里握着东西——最字面的版本。

### 义项 B：抽象包含——组成部分

> *The report contains several factual errors.*
> 这份报告包含几处事实错误。

从物理容器到抽象容器。报告是"容器"，错误是"内容物"。这个义项已经没有任何物理压力了，纯粹是"在……之内"。

**和本质的关系**：手合拢的形状还在，但力道消失了，只剩"在范围之内"这个空间关系。

### 义项 C：情感克制——把爆发压回去

> *She could barely contain her excitement when she heard the news.*
> 她听到消息时几乎抑制不住自己的兴奋。

这是 contain 最有戏剧性的面。你就是容器，你的情绪是里面膨胀的东西。"barely contain" 意味着快要裂开了。

**和本质的关系**：这就是压力锅——手在用力合拢，里面的东西在挣扎要出来。这是 contain 所有义项里唯一有**对抗感**的，也是最接近这个词原始生命力的。

### 义项 D：阻止扩散——遏制

> *Firefighters struggled to contain the blaze.*
> 消防员努力控制火势。

火想蔓延，消防员在画边界线。这层义和冷战时期的 containment policy 同构——不是消灭，是画一个圈说"你不许出来"。

**和本质的关系**：手合拢不是为了握住什么珍贵的东西，而是为了**困住**一个危险的东西。同样的动作，动机反转了。

### 义项 E：数学/逻辑——集合包含

> *Set A contains all prime numbers less than 20.*
> 集合 A 包含所有小于 20 的质数。

最抽象、最冷的一层。纯粹的逻辑边界关系，没有物理实体，没有情感，没有对抗。

**和本质的关系**：手合拢的形状被抽象成了一个圆圈。只剩下"内/外"的二分法。

## 5. 裂缝标注

### 常见误用场景

**❌ "The room contained 50 people"（说房间里有50人）**
语法上不算错，但英语母语者几乎不这样说。说人的时候用 hold 或 seat 更自然："The room held 50 people"。contain 偏向物品和抽象内容，用在活人身上有一种"关押"或"把人当物品"的奇怪感。除非你就是想说"关住"——"The prison contains 2000 inmates" 可以，因为监狱确实是在困住人。

**❌ 把 contain 当 include 用**
"The package contains free shipping" ✗ — 免运费不是包裹里装着的东西。这里应该用 include。contain 是物理或结构上"在里面"，include 是"算在范围内"。

### 易混近义词辨析

| | contain | include | hold | comprise |
|---|---|---|---|---|
| 核心画面 | 容器围住内容物 | 把某项纳入清单 | 手握住 / 承载 | 整体由部分组成 |
| 方向 | 从容器看内容 | 从集合看元素 | 从承载者看被承载物 | 从整体看部分 |

**contain vs include**：
- *The box contains a surprise.* ← 惊喜在盒子的物理边界内
- *The price includes tax.* ← 税被算进了价格里（不是物理上在里面）
- 判断方法：能不能画一个框把它圈住？能 → contain。是一个列表/范围的一部分？→ include。

**contain vs hold**：
- *The jar contains honey.* ← 陈述事实：罐子里是蜂蜜
- *The jar holds 500ml.* ← 强调容量：这个罐子装得下 500ml
- contain 侧重"里面有什么"，hold 侧重"装得下多少"

**contain vs comprise**：
- *The kit contains a hammer, nails, and tape.* ← 工具箱里有这些东西
- *The kit comprises a hammer, nails, and tape.* ← 这个工具箱由这些东西组成
- comprise 是"由……构成"（从整体到部分），contain 是"里面有"（从容器到内容）。comprise 暗示穷举，contain 不一定。

### 中文母语者陷阱

**"包含"的过度映射**：中文"包含"几乎只有"里面有"这一层，而 contain 的情感克制义（义项 C）和遏制义（义项 D）在中文里不叫"包含"。"她包含住了自己的兴奋"——中文不这么说。所以中文母语者往往忽略 contain 最有力量感的那两张脸。

**"含有"和"包含"不分**：中文里"这瓶水含有矿物质"和"这套工具包含一把锤子"用的是近义词，但英文里前者是 contain，后者可以是 contain 也可以是 include。当你想说"算在内"（not physically inside）时，别选 contain。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 说明 |
|---|---|---|
| **contain information** | 报告/文件 | "The file contains sensitive information." 最常见的书面搭配之一 |
| **contain a threat** | 安全/军事 | "measures to contain the threat" 遏制威胁——冷战基因 |
| **contain the spread** | 流行病/山火 | 2020 年后这个搭配的使用频率暴增 |
| **contain one's anger/excitement/laughter** | 情感描写 | 几乎总和 barely / hardly / couldn't 连用——暗示快要失控 |
| **contain costs** | 商业/财务 | "We need to contain costs." 控制成本——把"膨胀的花销"压回去 |
| **self-contained** | 日常/技术 | "a self-contained unit" 自成一体的、不依赖外部的 |
| **contain multitudes** | 文学引用 | 来自惠特曼 "I contain multitudes"——已成文化梗 |
| **contained environment** | 科学/技术 | 受控环境——实验室、隔离舱 |

### 语域标注

contain 是一个**全语域通用词**——日常口语、新闻报道、学术论文、法律文件里都能见到它。没有正式程度限制。但不同义项的语域偏向不同：

- 物理包含（义项 A/B）→ 全场景通用
- 情感克制（义项 C）→ 叙事文学、口语中偏多
- 遏制扩散（义项 D）→ 新闻、政策、军事语境偏多
- 数学包含（义项 E）→ 学术/技术

### 活用示范

> *"Do I contradict myself? Very well then I contradict myself. I am large, I contain multitudes."*
> —— Walt Whitman, *Song of Myself*

惠特曼这句话是 contain 最壮丽的用法。一个人的内在空间大到可以装下自相矛盾的所有面向。这里 contain 既是字面的"包含"，又是"承载/容纳"，还暗含"这些矛盾没有撑破我"——三层义同时在场。

> *"The situation was contained but fragile."*

新闻里常见的句式。注意这个过去分词用法——contained 作形容词意味着"已控制住但随时可能再爆发"。一个 contained situation 不是一个 resolved situation。里面的压力还在，只是暂时被压住了。

## 7. 跨语言映射

**中文"容"**：最对应 contain 骨架的中文字其实是"容"——容纳、包容、容器。"容"也有从物理到抽象的全光谱：容器（物理）→ 容纳（包含）→ 包容（接受差异）→ 容忍（压住不满）。尤其"容忍"这一层，和 contain oneself 的情感克制义几乎同构——都是"把不想接受的东西关在边界之内"。

**日文「封じ込める」（ふうじこめる）**：封（seal）+ 込める（push into）。这个词专门对应 contain 的"遏制"义——把东西封进去不让出来。日文把 contain 的"对抗感"拆成了两个动作：先推进去（込める），再封上（封じ）。比英文更显暴力，但精准。

**法文 *contenir***：直系亲属，同源同形。法文里 "se contenir"（克制自己）的用法和英文几乎一模一样，因为英文这个用法本来就是从法文借来的。

**德文 *enthalten***：ent-（从内部）+ halten（握住）。有趣的是 "sich enthalten" 意思是"弃权/克制"——和 contain oneself 的路径一致，但德文走到了"从内部抽手、不参与"这个方向，更消极。英文的 contain oneself 是在用力压住，德文的 sich enthalten 是在主动退出。同一个词根，两种克制哲学。
