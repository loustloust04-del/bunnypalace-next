# simulate

---

## 1. 一句话本质

**simulate 是一面故意造出来的镜子——镜中的东西不是真的，但它的行为方式和真的一模一样。** 你造它不是为了骗人，而是因为你动不了真的那个。

---

## 2. 词源考古

### 词根词缀拆解

```
simulate
  └─ simul-  ← 拉丁语 simulāre（使像、模仿）
       └─ similis（像的、相似的）
            └─ PIE *sem-（一、同一）
  └─ -ate    ← 拉丁语动词后缀，表"使……成为"
```

核心引擎就一个：**\*sem-**，原始印欧语里"一"的概念。不是数字的"一"，而是"同一个""合在一起"的那个"一"。从这颗种子长出了一整片森林：

- **similar**（相似的）——像同一个东西
- **simultaneous**（同时的）——在同一个时间
- **simple**（简单的）——sim- + -plex，"一折的"，没有折叠的
- **ensemble**（整体/合奏）——放在同一处
- **resemble**（类似）——再次看起来像
- **semblance**（外表/假象）——表面上像

还有一个重量级亲戚：**simulacrum**（拟像/幻象）——柏拉图和鲍德里亚都爱用的那个词，指"看起来像真的但本体不存在的复制品"。

### 历史流变

**拉丁语时期**：simulāre 从出生就带着双面基因。它既可以是中性的"模仿、再现"（一个画家 simulate 自然风景），也可以是贬义的"假装、伪装"（一个人 simulate 疾病来逃兵役）。这两张脸从来没分开过。

**16世纪进入英语**：直接从拉丁语借入（不是经法语转手），最初主要用贬义面——"假装拥有某种感情或状态"。莎士比亚时代说 "he simulates grief"，意思是"他装出悲伤"，语气带指控。

**17-18世纪**：中性面开始占据技术语域。自然哲学家用 simulate 描述实验中对自然现象的"再现"——你不是在骗谁，你是在可控条件下复刻一个过程。

**20世纪中叶（关键转折）**：计算机出现。simulate 被计算机科学彻底征用，成为一个核心术语：用模型在机器上"跑一遍"现实中太贵、太危险或太慢的过程。flight simulator、Monte Carlo simulation、circuit simulation——这些用法把 simulate 从"假装"彻底推向了"建模-运行-预测"这条正道。

**今天**：技术义远远压过了"假装"义。日常对话里说 "simulate" 几乎默认是"模拟"，不是"伪装"。但"假装"义没死，只是收窄到了特定搭配里（simulate illness, simulate an emotion）。

### 文化地层

simulate 最有意思的文化地层不在英语里，在法国哲学里。鲍德里亚（Baudrillard）在《仿真与拟像》（*Simulacra and Simulation*）中区分了三个阶段：

1. 复制品反映现实（地图代表领土）
2. 复制品遮蔽现实（地图比领土更"真"）
3. 复制品取代现实（地图就是领土，原件不存在了）

他用的核心词就是 simulation/simulacrum。在他的框架里，simulate 不是"像不像"的问题，而是"真还有没有意义"的问题。迪士尼乐园是一个 simulation——不是因为它是假的，而是因为它的存在是为了让你觉得乐园外面的世界是"真的"。

这层含义已经渗透进了日常文化语感：当我们说"我们生活在一个 simulation 里"（simulation hypothesis），simulate 已经远远超出了"假装"或"模拟"，变成了一个存在论级别的词。

## 3. 故事 / 画面

**风洞里的飞机。**

1940年代，你造了一架新飞机。你不知道它会不会空中解体。把真飞机飞上去试？飞行员可能死。于是你造一个缩比模型，放进风洞里。风洞模拟高空气流，模型承受和真飞机按比例相同的力。模型的翅膀在风里颤抖、弯曲——你看着仪表盘上的数字跳动，知道了真飞机在哪个速度会出问题。

**风洞里的那架飞机不会飞。但它替真飞机死过一次。**

这就是 simulate 的骨头：你造出一个**行为上等价**但**存在上不等价**的东西，让它替真品去承受你不敢让真品承受的事。它不是真的，但它的"不真"恰恰是它的价值——正因为它不是真的，你才可以把它推到极限、搞坏它、从头再来。

（这个画面同时覆盖了 simulate 的贬义面：如果一个人 simulate grief，他就是在内心搭了一个"悲伤的风洞"——外面看起来气流正确、数据一致，但里面没有真飞机。）

## 4. 多面体：核心义项展开

### 义项 A：用模型再现一个过程（技术核心义）

> *The software can **simulate** the spread of a wildfire across different terrain types.*
> 这款软件可以模拟野火在不同地形上的蔓延过程。

和"一句话本质"的关系：造一面镜子（计算模型），让镜中的火替真火烧一遍，你看着镜子里的结果做决策。

### 义项 B：假装拥有某种状态或感情（古义，贬义色彩）

> *She **simulated** surprise, but her eyes gave her away.*
> 她装出惊讶的样子，但眼神出卖了她。

和本质的关系：还是那面镜子，但这次目的变了——你不是为了研究真品，而是为了让别人以为镜中的是真品。镜子的结构一样，动机反转。

### 义项 C：复制某物的外观/条件以供测试

> *The exam is designed to **simulate** real-world problem-solving under time pressure.*
> 这场考试旨在模拟现实中限时解决问题的场景。

和本质的关系：考试是一个"安全的镜子"——你在镜中犯错不会真的出事。错误的代价被模拟降低了，但挑战的结构被保留了。

### 义项 D：（材料/产品）仿制外观

> *The flooring is made to **simulate** natural hardwood.*
> 这种地板的设计模仿了天然硬木的外观。

和本质的关系：镜子被做成了物理产品。它不是硬木，但它的表面纹理、色泽、触感都在说"我是硬木"。simulate 在这里 = "在感官层面对齐"。

**底层统一性**：四个义项都是同一个操作——**制造一个行为上对齐但本体上不等同的替代品**。区别只在于：替代的目的是什么（研究/欺骗/测试/装饰），以及对齐到什么程度（全流程/单一感官/表面特征）。

## 5. 裂缝标注

### 常见误用场景

**❌ simulate ≠ stimulate**
这是最高频的拼写/听力混淆。simulate（模拟）和 stimulate（刺激）只差一个字母，发音也接近。但一个是"造镜子"，一个是"戳一下让它动起来"。

> ❌ *Exercise simulates brain activity.* → ✅ *Exercise **stimulates** brain activity.*

**❌ 不要用 simulate 描述"简化版"**
simulate 强调的是**行为的忠实再现**。如果你只是做了一个简化版、缩略版，那不是 simulate，是 approximate 或 simplify。一个只有三道题的"模拟考试"不 simulate 真正的高考——它太简了。

### 易混近义词辨析

| 词 | 核心区别 |
|---|---|
| **imitate** | 模仿外在行为，通常是人模仿人。你 imitate 一个人的走路方式，但你 simulate 一场地震。imitate 是镜子照人，simulate 是镜子照系统。 |
| **emulate** | 带"追赶/超越"的意图。emulate a hero = 以英雄为榜样努力追赶。simulate a hero = 假装自己是英雄。方向感完全不同。 |
| **replicate** | 强调结果的精确复制，不关心过程。你 replicate 一个实验结果（精确重现数据），但你 simulate 一个实验过程（用模型跑一遍流程）。 |
| **mimic** | 偏表面、偏外观。壁虎 mimic 树叶的颜色。但你不会说壁虎 simulate 树叶——它没有"运行一个树叶的模型"。 |
| **feign** | simulate 的贬义面的同义词，但 feign 只用于"假装"，没有技术义。feign ignorance ≈ simulate ignorance，但 feign a flight path ❌。 |

### 中文母语者陷阱

**"模拟"的语义范围比 simulate 窄。** 中文"模拟"已经几乎完全失去了"假装/伪装"这一层，所以中文母语者遇到 "She simulated enthusiasm" 会愣住——"她模拟了热情？"不对，是"她假装热情"。这个义项中文要翻成"假装"或"佯装"，不是"模拟"。

反过来，中文"模拟考试"的"模拟"比 simulate 弱。英文说 mock exam 或 practice test 更自然。说 simulated exam 会让人觉得这场考试在非常严格地复刻真实考试的每一个条件（时间、环境、评分标准一模一样）。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境说明 |
|---|---|
| **simulate conditions** | 最经典搭配。实验室里模拟极端温度、零重力、深海压力…… |
| **simulate an attack** | 军事/网络安全：模拟攻击来测试防御系统。"红队"做的事。 |
| **simulate growth/decay** | 科学建模：用数学模型模拟生长或衰减曲线。 |
| **closely simulate** | 强调模拟的精确度：这个模型非常逼真地再现了…… |
| **computer-simulated** | 复合形容词：电脑生成的模拟。computer-simulated crash test |
| **simulate real-world (scenarios)** | 教育/培训：模拟真实场景供练习。 |
| **designed to simulate** | 产品/系统设计的目的就是模拟某种体验。 |
| **difficult to simulate** | 某些现象太复杂，模型跑不准。humility is difficult to simulate. |

### 语域标注

simulate 是一个**中偏正式**的词。日常口语里不太常说"I'll simulate it"——你会说"I'll try it out / run a test / fake it"。它主要活跃在：

- **学术/科研论文**（高频）
- **工程/技术文档**（高频）
- **新闻报道**（中频，尤其科技和军事新闻）
- **日常口语**（低频，除非在聊技术话题）

口语里想说"假装"更常用 fake / pretend / put on。simulate 说出来会有一种"我在分析你的行为"的距离感。

### 活用示范

> *"We don't experience reality. We simulate it."*
> —— 神经科学的一句经典表述：人脑不是在"接收"现实，而是根据感官输入在内部"模拟"一个现实的模型。你看到的世界是你大脑的 simulation。

> *"Any sufficiently advanced simulation is indistinguishable from reality."*
> —— 对克拉克定律的改写，simulation hypothesis 的通俗表达：如果模拟的精度足够高，你从内部无法判断自己是不是在模拟之中。

## 7. 跨语言映射

**中文"模拟"** 和 simulate 的技术义高度重合，但缺了"伪装"义。中文要表达贬义面得换词：佯装、假装、装出。这个分裂本身就是一个记忆点——英文一个词包住了"诚实地建模"和"不诚实地表演"两端，中文把它们拆开了。

**法文 simuler** 保留了拉丁语的双面性，和英文几乎平行。simuler une maladie = 装病。

**德文 simulieren** 同样双义，但口语里贬义面更活跃——德国人说 "Er simuliert" 第一反应是"他在装"（尤其指装病逃工作），而不是"他在跑模型"。

**日文 シミュレーション (shimyurēshon)** 是直接音译，只保留了技术义。日文要说"假装"用 ふりをする (furi wo suru)。和中文一样，贬义面被本土词接管了。

一个有趣的对照：中文"仿真"比"模拟"更精确地对应 simulate 的技术核心义——"仿"（复制外在）+"真"（对标真实）。但"仿真"在中文里只用于技术领域（仿真实验、仿真软件），不能说"她仿真了热情"。

---

**自检**：如果只留下"故意造的镜子——不是真的但行为一样"和"风洞里替真飞机死过一次的模型"，学习者能不能还原词义？能。镜子 = 模拟的本质（行为对齐、本体不同），风洞 = 模拟的价值（用不真的东西替真的承受风险）。两个方向的义项（研究型/欺骗型）都能从"镜子"这个意象里推出来。通过。
