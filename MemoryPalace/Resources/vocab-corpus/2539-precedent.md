# precedent

## 1. 一句话本质

**precedent 是第一个人在雪地上踩出的脚印——后面的人不一定要踩着它走，但每个人都会低头看它在哪。**

它不是规则本身，而是"曾经发生过一次"这件事所产生的引力。

---

## 2. 词源考古

### 词根词缀拆解

```
prae-   （前面，在……之前）  ← 拉丁语
ced-    （走，行进）        ← 拉丁语 cēdere
-ent    （正在做……的）      ← 拉丁语现在分词后缀 -ēns/-entem
```

**praecēdere** = 走在前面。它的现在分词 **praecēdēns**（正在走在前面的）→ 古法语 **précédent** → 中古英语 **precedent**。

注意：**ced-** 这个词根是个超级生产者。proceed（向前走）、recede（退回去走）、exceed（走出界外）、concede（一起走 → 让步）——全是它的孩子。precedent 的核心就是"走在前面的那个东西"。

### 历史流变

- **14世纪**：进入英语，最初就是 **praecedent** 的直译——"先行的、在前的"，既当形容词也当名词。早期用法很朴素：the precedent year = 前一年。
- **15-16世纪**：法律语境开始吞噬这个词。英国普通法（Common Law）的核心运作逻辑是**遵循先例**（stare decisis，拉丁语"遵守已决定之事"）。法官判案不是从天上找原则，而是回头看：以前遇到类似情况，前辈怎么判的？这个"前辈的判决"就是 precedent。这个法律含义逐渐成为主力义项。
- **17世纪起**：从法律扩散到日常——任何"第一次这样做，后人可能照着来"的事，都可以叫 set a precedent。

### 文化地层

最关键的一层：**precedent 不只是"先例"，它自带一种隐性的约束力。** 这和英美法系的底层逻辑有关——过去发生的事不是中性信息，它对未来有引力。中文说"开了先河"偏中性甚至褒义，但 precedent 经常带着焦虑：一旦你做了这件事，后面就很难收回去了。

这种"不可逆感"是 precedent 最容易被忽略的语义暗层。

## 3. 故事 / 画面

法庭。一位年轻法官坐在审判席上，面前摆着一个棘手的案子。

她翻开法律文书，发现这种情况从来没人判过。没有先例。她可以自由裁量——但她也知道，她今天怎么判，会被装进档案柜，变成一块路标。以后每个遇到类似案子的法官都会翻到这页，说："看，1987年 Johnson 法官是这么判的。"

她写下判决的那一刻，不只是在解决今天的问题——她在铺一段路。这段路修好后，后来的人要么沿着它走，要么花巨大的力气证明"这条路方向错了"才能绕开它。

**这就是 precedent 的力学：你以为你只做了一次决定，但那个决定活得比你久。**

## 4. 多面体：核心义项展开

### 义项 A：法律先例（最核心）

> *The Supreme Court's ruling set a precedent that would shape civil rights law for decades.*
> 最高法院的裁决树立了一个先例，在此后几十年里塑造了民权法的走向。

和本质的关系：这就是雪地上最深的那个脚印——不只是"有人走过"，而是"后面的人被期望沿着它走"。在法律语境中，precedent 有近乎制度性的约束力。

### 义项 B：惯例、先例（泛化用法）

> *There's no precedent for canceling the event — we've held it every year since 1965.*
> 取消活动没有先例——我们从1965年起年年办。

和本质的关系：从法庭扩展到了日常生活。核心逻辑不变——"以前没这么干过"本身就构成了一种压力。precedent 的缺失（no precedent）和存在一样有力量。

### 义项 C："开先例"的警告义（set a precedent）

> *If we let him work from home permanently, it'll set a precedent — everyone else will expect the same.*
> 如果我们让他永久在家办公，这就开了先例——其他人都会有同样的期待。

和本质的关系：这是 precedent 最日常的用法，也是暗层最浓的一个。set a precedent 几乎总带一种焦虑感：**你不是在做一个决定，你在创造一种模式。** 脚印踩下去了，你擦不掉。

### 义项 D：形容词用法（较古/正式）——"先前的"

> *precedent conditions must be met before the contract takes effect.*
> 先决条件必须满足，合同才能生效。

和本质的关系：这是最古老、最字面的用法——"走在前面的"。现代英语中已经比较少见，大多出现在法律文本的固定搭配 **condition precedent**（先决条件）中。注意这里 precedent 放名词后面，是法律法语的遗留语序。

## 5. 裂缝标注

### 常见误用场景

**❶ 把 precedent 当 "previous" 用**
> ❌ *In the precedent chapter, we discussed...*
> ✅ *In the previous/preceding chapter, we discussed...*

precedent 的形容词义在现代英语中几乎只活在 condition precedent 这个法律搭配里。日常说"前一个"用 **previous** 或 **preceding**。

**❷ 搞混 precedent 和 precedence**
- **precedent**（名词）= 先例，一个具体的案例/事件
- **precedence**（名词）= 优先权，排在前面的地位

> *Safety takes precedence over speed.* （安全优先于速度）——这里用 precedence，不是 precedent。
> *There's no precedent for this decision.* （这个决定没有先例）——这里用 precedent，不是 precedence。

**一个是"先走过的脚印"，一个是"谁先走的资格"。** 长得像，意思完全不同。

**❸ 发音陷阱**
precedent 作名词：**PREH-suh-dent**（重音在第一音节）
president（总统）：**PREH-zuh-dent**

区别只在中间那个辅音——/s/ vs /z/。很多非母语者会读成一样的。

### 中文母语者陷阱

**"先例"的翻译遮蔽了 precedent 的引力感。** 中文说"史无前例"是在描述一个事实（以前没有过），语气偏中性甚至壮烈。但英文 *without precedent* 或 *unprecedented* 经常暗含"没有参考系，我们在盲飞"的不安感。

同样，中文"开了先河"偏褒义（创新、勇气），但 *set a precedent* 在英文中经常偏负面（"你开了这个头，后面收不住了"）。**不要把中文"先例"的情感色调直接投射到 precedent 上。**

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 说明 |
|------|------|------|
| **set a precedent** | 各场合通用 | 最核心搭配。"开先例"，经常暗示后果不可逆 |
| **set a dangerous precedent** | 政治/法律/职场 | 带明确警告语气——"这么做很危险因为以后收不回来" |
| **without precedent / unprecedented** | 新闻/正式文体 | "史无前例"。unprecedented 是派生形容词，高频到已经独立成大词 |
| **legal precedent** | 法律 | 法律先例，普通法核心概念 |
| **follow/break (with) precedent** | 法律/制度 | 遵循先例 vs 打破先例 |
| **establish/create a precedent** | 正式文体 | 和 set 同义但更正式 |
| **binding precedent** | 法律 | 有约束力的先例（上级法院判决，下级必须遵循） |
| **historical precedent** | 学术/评论 | 历史上是否有类似情况可参照 |

### 语域标注

**中偏正式。** precedent 不是口语高频词——日常聊天你不太会说"这设了一个 precedent"。它活在：
- 法律文本（本家）
- 政治评论和新闻（"总统的行为开了危险先例"）
- 职场决策讨论（"如果我们批准了他的请求，就是在开先例"）
- 学术写作（"历史上有无先例可循"）

口语中更常见的是它的衍生词 **unprecedented**——这个词反而已经渗透到日常对话了（"unprecedented times" 在2020年被用到人人喊烦）。

### 活用示范

> *"Every act of justice is a precedent for the next."* — 这句话精准地展示了 precedent 的力学：正义不是一次性事件，每一次公正的行为都在为下一次铺路。

> *Letting interns skip the review process would set a precedent we'd regret by Q3.* — 职场实战用法。注意"we'd regret"——set a precedent 后面几乎总跟着一个关于后果的从句。

## 7. 跨语言映射

**中文"先例"** 是最直接的对应，但如上所述，情感色调不完全重叠。中文"先例"是中性偏褒的事实陈述；英文 precedent 自带"引力/约束/不可逆"的暗层。

**日语「前例」（ぜんれい）** 和英文 precedent 的法律含义高度对齐，因为日本近代法律体系大量借鉴了西方判例法概念。「前例がない」（没有先例）的使用场景和 *without precedent* 几乎一一对应。

**拉丁语 stare decisis**（遵守已决定之事）——这不是 precedent 的翻译，而是它的制度性伴侣。理解 precedent 的法律力量，必须知道 stare decisis 这个原则：**先例不只是参考，在特定条件下它就是法律。** 这就是为什么最高法院推翻先例（overturning precedent）是天大的事——你不是在改一个判决，你是在拆一块地基。

**法语 précédent** 形义都和英文几乎一致（毕竟英语从法语借来的），用法也类似：*créer un précédent* = set a precedent。不过法语里这个词的形容词义（"前一个的"）比英语中活跃得多——*le jour précédent*（前一天）在法语里很自然，英语中你不会说 *the precedent day*。
