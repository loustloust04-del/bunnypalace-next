# emit

---

## 1. 一句话本质

emit 是茶杯口升起的那缕热气——不是泼出去的，不是喷出去的，是从源头内部**自然地、持续地溢出来**。源头还在那儿，但有什么东西正从它体内向外走。

---

## 2. 词源考古

### 词根词缀拆解

```
e-（向外）+ mit（送）
```

**e-** 是 **ex-** 的元音前简化形态。方向感极强：从内到外。

**-mit-** 来自拉丁语 **mittere**——"送、发、放"。这是拉丁语里最能生孩子的动词，没有之一。它的后代名单读起来像半本英语词汇书：

| 前缀 + mittere | 字面义 | 活下来的词 |
|---|---|---|
| e-（向外）+ mittere | 向外送 | **emit** |
| trans-（跨越）+ mittere | 送过去 | **transmit** |
| ad-（朝向）+ mittere | 送进来 | **admit** |
| sub-（向下）+ mittere | 从下往上递 | **submit** |
| per-（穿过）+ mittere | 让它穿过 | **permit** |
| com-（一起）+ mittere | 交托出去 | **commit** |
| dis-（散开）+ mittere | 打发走 | **dismiss** |
| ob-（对面/挡）+ mittere | 放它过去不管 | **omit** |
| pro-（向前）+ mittere | 提前送出 | **promise** |
| re-（回）+ mittere | 送回去 | **remit** |

mittere 的过去分词是 **missus**，所以这棵家族树还挂着 **mission**（被送出去执行的任务）、**missile**（被发射出去的东西）、**message**（被传送的内容）。

emit 是这个家族里最"物理"的一个——它关心的是：**有什么东西正在从一个源头往外跑。**

### 历史流变

**拉丁语 ēmittere**（约公元前 1 世纪已有记录）：用法非常宽。河流 emit 支流，人 emit 声音，权威机构 emit 法令，弓 emit 箭。核心语义就是"从内向外放出"。

**16 世纪末进入英语**（约 1620 年代首次记录）：最初偏正式和科学化。不是日常口语会用的词。

**17-18 世纪**：在自然哲学（早期科学）文献里大量出现——太阳 emit 光，火山 emit 气体，身体 emit 热量。科学写作把 emit 从一个普通的拉丁动词锻造成了一个**精密的物理学动词**。

**20-21 世纪**：两个重大扩展——
1. **环境语境**：碳排放（carbon emissions）让 emit 变成了气候变化叙事里的核心动词
2. **编程语境**：事件驱动架构里，emit 成了"触发事件信号"的标准术语（Node.js 的 EventEmitter, Vue 的 `$emit`）

这个编程义其实是对拉丁原义的精确复刻：一个源头（event source）向外发出一个信号（event），不关心谁在听，只管往外发。

## 3. 故事 / 画面

别想茶杯了。想一只深海水母。

它在黑得什么都看不见的海底，身体边缘一圈一圈地脉动，每一次收缩，就有一层冷蓝色的荧光从它体内渗出来，扩散到周围的海水里。

它不是在"发射"光——那是 launch。
它不是在"扔出"光——那是 throw。
它不是在"释放"光——那太刻意了，那是 release。

它是在 **emit**。光从它身体内部**自然地、持续地、几乎是被动地**往外走。就好像它的身体是一扇只能向外开的门，光从那扇门里一缕一缕地飘出来。

这就是 emit 的触感：**不费力的向外流出**。源头不需要使劲。它只需要存在，东西就从它那里出来了。

太阳 emit 光，不是因为它在努力，而是因为那就是太阳在做的事。
烟囱 emit 烟，不是因为有人在推，而是燃烧本身的副产品在往外走。
程序员写 `emitter.emit('click')`，是因为事件源只管发信号，不管有没有人在监听。

emit 的性格是一个**不自觉的给予者**——它不选择给谁，不控制方向，不在乎回应。它只是持续地、稳定地，从内部往外溢。

## 4. 多面体：核心义项展开

### 义项一：释放物质（烟、气体、辐射）

最常见、最"物理"的用法。源头是物质实体，emit 出去的也是物质或能量。

> *The factory emits over 500 tons of sulfur dioxide per year.*
> 这家工厂每年排放超过 500 吨二氧化硫。

和本质的关系：烟囱口的气体往外走——标准的"从内向外自然流出"。这是 emit 最原始的画面。

### 义项二：发出光或热

和义项一本质相同，但对象换成了光和热这种无形能量。

> *The dying star emits radiation across the entire electromagnetic spectrum.*
> 这颗垂死的恒星在整个电磁波谱上都在发射辐射。

和本质的关系：恒星不是在"瞄准"什么方向发光，它是全方位地、不受控地往外辐射——emit 的"不定向溢出"性格。

### 义项三：发出声音

这个义项更文学化。日常说"发出声音"用 make a sound / let out a cry 更自然，但 emit 会给这个动作加上一种**不由自主、几乎是身体本能反应**的色彩。

> *She emitted a low groan and turned over in her sleep.*
> 她发出一声低沉的呻吟，在睡梦中翻了个身。

和本质的关系：呻吟从喉咙深处"溢"出来，不是刻意发声，是身体内部的东西自然流出。用 emit 而不是 made 或 let out，暗示这声音几乎是无意识的。

### 义项四：发行（金融 / 官方文件）

较正式，现代英语里 issue 更常用，但在法律和金融文本中 emit 仍然出现。

> *The central bank emitted a new series of banknotes.*
> 央行发行了新系列纸币。

和本质的关系：货币从央行内部"流出"到市场——和烟从烟囱流出是同一个结构，只是对象换成了抽象物。

### 义项五：触发事件（编程）

现代英语的新义项，在程序员群体中几乎是日常词。

> *When the user clicks the button, the component emits a 'submit' event to its parent.*
> 当用户点击按钮时，组件向父级 emit 一个 'submit' 事件。

和本质的关系：事件源往外发信号，不管有没有 listener 在听——这和太阳发光不管有没有人看是同一种"不定向的向外释放"。编程社区选 emit 这个词，选得精准到可怕。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 emit 当 "说" 用**

> ~~*He emitted a few words about the situation.*~~

emit 用于声音时，是**非语言性的、本能性的声音**——呻吟、尖叫、叹息。用它来描述"说了几句话"是语义越界。要说"说了几句话"用 uttered / said。

**❌ 把 emit 用于有目标的、定向的发送**

> ~~*She emitted the letter to her friend.*~~

emit 的东西是**散射的、无定向的**。有明确接收者的"发送"用 send / transmit / direct。

### 易混近义词辨析

| | emit | release | discharge | radiate |
|---|---|---|---|---|
| **核心差异** | 从源头自然向外溢 | 有意识地放开/放出 | 正式地排放/释放（带完成感） | 从中心向四面八方扩散 |
| **场景** | 烟囱冒烟 | 释放人质、发布报告 | 排放废水、出院 | 暖气片散热 |
| **语感** | 物理的、中性的、持续的 | 刻意的、有决策的 | 正式的、有终点的 | 均匀的、温暖的 |

具体对比：

- **The volcano emitted ash**（火山在冒灰）vs **The volcano released a cloud of ash**（火山释放了一团灰云）——emit 是持续状态，release 是一次性事件。
- **The pipe discharged wastewater into the river**（管道把废水排进河里）——discharge 有一个明确的终点（河里），emit 没有方向。
- **The heater radiates warmth**（暖气片辐射热量）——radiate 强调"均匀地向四面八方"，emit 不强调均匀性。

### 中文母语者陷阱

**"排放" ≠ emit 的全部**

中文里一听到 emit 就想到"排放"（碳排放、尾气排放），但 emit 的语义范围比"排放"宽得多。太阳 emit 光、伤口 emit 一股气味、程序 emit 事件——这些用"排放"都翻不了。

**"发出" 的陷阱**

中文"发出"太万能了：发出声音、发出信号、发出邀请、发出警告。但英文里只有前两个能用 emit。"发出邀请"是 issue / send，"发出警告"是 issue / give。emit 只管**物理/准物理性质的向外流出**。

**"辐射" 的精度陷阱**

emit radiation 常被翻译成"辐射出辐射"（很尬），所以很多人会直接把 emit 等同于"辐射"。但 radiate 是"辐射"，emit 是"发射/释放"。一个放射源 emits radiation（释放辐射），但辐射本身 radiates outward（向外辐射）。两个动作，两个动词。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **emit light / radiation** | 物理学、天文学：光源或辐射源的标准描述 |
| **emit gases / fumes / smoke** | 环境科学、工业：烟气排放 |
| **emit carbon dioxide (CO₂)** | 气候变化讨论的核心搭配，新闻里出现频率极高 |
| **emit a sound / cry / groan** | 文学叙事：非自主性声音 |
| **emit signals / pulses** | 电子学、通信：信号发射 |
| **emit an event** | 编程：事件驱动架构的标准用语 |
| **emit a frequency** | 物理/无线电：在某个频率上发射 |
| **emit heat / energy** | 热力学：能量释放 |

### 语域标注

**偏正式、偏技术。** 日常口语几乎不用 emit——你不会说 "my phone is emitting a weird sound"，你会说 "my phone is making a weird sound"。

emit 的主场是：
- 科学论文（物理、化学、环境科学）
- 新闻报道（特别是气候相关）
- 技术文档（编程）
- 文学作品（作为 said / made 的高级替代，表示声音的非自主性）

### 活用示范

> *The old radio emitted nothing but static, as if the past it once channeled had finally dissolved into white noise.*
> 那台老收音机只 emit 出一片杂音，好像它曾经传送过的那些过去终于溶解成了白噪音。

这个句子里 emit 比 "played" 或 "produced" 好在哪？——它暗示收音机不是在主动"播放"什么，而是有什么东西从它残损的内部自然渗出来。带一种衰败感。

> *Every mass in the universe emits gravity. You don't get to opt out.*
> 宇宙中每个有质量的物体都在 emit 引力。你没法选择退出。

这里 emit 的"不由自主、不可关闭"的语感被用到了极致——引力不是你选择释放的，是你存在就会往外溢的。

## 7. 跨语言映射

**拉丁语 ēmittere** → 法语 **émettre**、西班牙语 **emitir**、意大利语 **emettere**。罗曼语族基本原封不动地继承了它。法语 émettre 的使用范围比英语 emit 还广——émettre une hypothèse（提出一个假设）、émettre un avis（发表意见）——这些抽象用法英语已经丢了。

**日语「放出（ほうしゅつ）」** 和 emit 的物理义几乎完全重合——光を放出する、ガスを放出する。但日语还有 **「発する（はっする）」**，覆盖 emit 的声音义和抽象义。

**中文的困境：** 中文没有一个词能同时覆盖 emit 的所有义项。"排放"只管废气，"发射"偏定向，"散发"偏气味，"发出"太泛。最接近 emit 内核的中文表达可能是 **"溢出"**——但"溢"暗示超过了容器边缘，emit 不需要"满"才往外走。这个词在中文里是一个翻译空洞：你知道它是什么意思，但没有一个对应词能让你一对一锚定。

---

### 和 emission 的关系

你刚考古完 emission（emit 的名词形态）。放在一起看：**emit 是那个动作本身——从内部往外溢；emission 是那个动作的产物或过程——溢出来的那团东西，或者"正在溢"这件事。** 动词给你动态感，名词给你可量化性。工厂 emits（在冒烟），它的 emissions（排放量）可以被测量和监管。一个是画面，一个是数据。
