# each

## 1. 一句话本质

**each 是点名簿上的那根手指——不是扫视全班说"都到了吧"，而是停在每一个名字上，把目光给到那个人，然后才移到下一个。**

不是强调"全部"，是强调"逐一"。

---

## 2. 词源考古

### 词根词缀拆解

each 的长相朴素，但骨架里埋着三层化石：

```
ā (ever, always) + ge·lic (alike)
   ↓                  ↓
   永远               相似的
        ā·gelic → ǣlc → each
        "永远-相似的" → "每一个（都同等对待）"
```

**ge-** 是日耳曼语的集合前缀（德语至今保留：ge·stern, Ge·schwister），表示"一起、关联"。**-lic** 是"身体、形态"（德语 Leiche "尸体"、英语 -ly 的祖宗），合在一起 gelic 就是"同形的、相似的"。

所以 each 的原始含义是 **"永远一样的"**——面对一群东西，你对它们的态度是"always alike"：每一个都同等对待，不厚此薄彼。

### 历史流变

| 时期 | 形态 | 备注 |
|------|------|------|
| 原始日耳曼语 | \*ainaz-ga-līkaz | "一-同-像"，重构形式 |
| 古英语 | ǣlc / ylc | 同时表 each 和 every，界限模糊 |
| 中古英语 | ech, ilk | 北方方言保留 ilk（苏格兰英语至今说 ilk） |
| 现代英语 | each | 从14世纪起与 every 分工 |

**关键转折：each 和 every 的分家**

古英语里 ǣlc 一个词包办了"每一个"的全部语义。但到了中古英语时期，一个新词挤进来了——**every**。

这是最好玩的部分：every 来自古英语 **ǣfre ǣlc**，字面意思是 **"ever each"——"永远的每一个"**。换句话说，**every 就是 each 的加强版，是"each"自己生出来的孩子**。

儿子出生后，父子分了工：
- **each** 退守"逐一、分别"的领地——聚光灯打在个体上
- **every** 接管了"全部、无一例外"的领地——强调的是集合的完整性

一个词分裂成两个，各自发展，最终面对面站着，成了所有英语学习者的辨析噩梦。

### 同源亲戚

- 荷兰语 **elk**（each）——几乎一模一样的演化路径
- 古弗里斯兰语 **ellik**
- 苏格兰英语 **ilk**（"of that ilk"= 同名同族的）——这是 each 的北方表亲，活到了今天
- 德语里这个词死掉了，被 **jeder** 替代

## 3. 故事 / 画面

一条传送带。

工厂质检员坐在传送带旁边。罐头一个一个从面前滑过。她不是远远瞥一眼说"这批没问题"——她拿起第一个，转一圈，放下；拿起第二个，转一圈，放下；第三个、第四个……

**each 就是那只拿起罐头的手。** 它承认群体的存在，但拒绝打包处理。它的基本姿态是：你们确实是一群的，但我要一个一个来。

这就是为什么 each 后面永远跟单数——因为在 each 的世界观里，一次只有一个东西在聚光灯下。

## 4. 多面体：核心义项展开

### 义项 A：限定词（determiner）——"每一个（逐一地）"

> **Each student received a different topic.**
> 每个学生拿到了不同的题目。

注意这里不能换成 every——如果说"every student received a different topic"，语义会微妙地偏移。each 强调的是"我一个个发的，你的和她的不一样"，every 强调的是"所有人都拿到了"。

与本质的关系：传送带上的手，一个一个拿起来看。

### 义项 B：代词（pronoun）——"各自"

> **Each of the rooms has its own bathroom.**
> 每间房都有自己的卫生间。

each of + 复数名词，但动词用**单数**。因为 each 的视角永远是"我现在看的这一个"。

与本质的关系：虽然你说的是"这些房间"，但 each 把相机推到了单间门口。

### 义项 C：副词（adverb）——"每个……地"（分配义）

> **The tickets cost $50 each.**
> 票价每张50美元。

这个用法最容易被忽视。each 跑到了句尾，变成了分配器——把总价拆成单价。

与本质的关系：传送带上每个罐头贴一个价签，不是整箱报价。

### 义项 D：固定搭配 each other——"彼此"

> **They looked at each other and smiled.**
> 他们看着彼此笑了。

这是 each 最古老的用法之一，古英语就有。字面拆解：each（每一个）other（另一个）——"每一个人对另一个人"，就是"互相"。

与本质的关系：两个人站在传送带的两端，同时拿起对方。

## 5. 裂缝标注

### 🔴 常见误用场景

**误用 1：each + 复数动词**

> ❌ Each students have a locker.
> ✅ Each student **has** a locker.

each 永远把镜头推到个体上，所以动词必须单数。但口语中 "each of them have..." 已经半被接受——考试别这么写。

**误用 2：把 each 用在三个以上才合适的 every 位置**

> ⚠️ Each corner of the room（✓ 房间有四个角，each 合理）
> ⚠️ Each citizen should vote（语法没错，但 every citizen should vote 更自然——强调"全体"义务时用 every）

### 🟡 易混近义词辨析

**each vs. every：**

| 场景 | 选 each | 选 every |
|------|---------|----------|
| 数量小且具体 | Each of the three brothers（三兄弟分别） | ⚠️ 勉强 |
| 强调个体差异 | Each case is unique | ❌ every 暗示同质 |
| 强调无一例外 | ⚠️ 弱 | Every student must attend |
| 频率/规律 | ❌ | every day, every time |
| 句尾分配 | $5 each | ❌ 不说 $5 every |

**记忆口诀：each 是放大镜，every 是广角镜。**

"I know each of my students" = 我了解我的每一个学生（个个不同，我都认识）
"I know every student in this school" = 这学校的学生我全认识（强调覆盖面）

**each other vs. one another：**

传统语法书说"两个人用 each other，三个以上用 one another"。实际使用中这个区分已经基本消亡，混用完全没问题。但如果你想显得讲究，遵守这个规则不会错。

### 🟠 中文母语者陷阱

**陷阱 1：中文"每"不区分 each/every**

中文说"每个学生都要来"，翻译时 each 和 every 都行，但味道不同。中文母语者倾向于全用 every（因为"每"更接近"全部"的语感），而忽略 each 的"逐一"感。

**陷阱 2："各自"的表达**

中文说"他们各自回家了"，不能翻成 "They each other went home" ❌。
正确：**They each went home.** 或 **Each of them went home.**

each other 只表示"互相"，不表示"各自"。

**陷阱 3：each 的位置灵活性**

中文"每个"只能放名词前面。英文的 each 可以：
- 前置：**Each** student has a book.
- 中插：The students **each** have a book.（注意这里 have 变复数了！因为主语是 students）
- 后置：The books cost $10 **each**.

中间位置那个用法最容易被中文母语者忽视。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 说明 |
|------|------|------|
| **each and every** | 正式/强调 | "each and every one of you"——双重强调，演讲常用，日常会显得隆重 |
| **each other** | 全语域 | 最高频搭配，互相/彼此 |
| **each time** | 全语域 | 每次，比 every time 多一丝"一次次累积"的感觉 |
| **each of + 复数** | 中性偏正式 | each of the participants, each of us |
| **$X each** | 口语/商务 | 分配单价，"three for $10 each" |
| **each day/week/year** | 全语域 | 和 every day 差别微弱，each 稍强调"日复一日"的节奏感 |
| **each in turn** | 书面 | 轮流，依次 |
| **on each occasion** | 正式 | 每一次（场合） |

### 语域标注

each 是 **全语域通用词**——口语、书面、学术、新闻全能用，不存在正式程度的限制。它是英语中最基础的功能词之一，没有语域标记。

唯一的例外是 **each and every**，这个搭配带有演讲/正式场合的色彩。日常对话里说"each and every one of you"会有一种"在台上发言"的感觉。

### 活用示范

> **"We die each day. Every act of living is an act of dying."**
> ——这里选 each 而不是 every，是因为作者要你感受到每一天的重量，不是笼统的"天天都在死"，而是"今天，死一点；明天，又死一点"。

> **"They sat across each other, saying nothing, each holding a cup that had long gone cold."**
> 两个 each 在一句话里分别做了不同的事：each other 是"面对面"，第二个 each 是"各自"。安静画面里两个人被分别照亮。

## 7. 跨语言映射

**中文"每" vs. each：**

中文的"每"更像 every 而不是 each——"每个人都要来"强调的是全体性。要翻出 each 的"逐一"感，中文得加辅助词：**"一一""逐个""分别""各自"**。

"我逐一检查了每份文件" ← 这个"逐一"就是 each 的灵魂，"每"自己扛不动。

**日语「それぞれ」(sorezore)：**

日语的"それぞれ"比英语的 each 更明确地指向"各自不同"。英语的 each 是中性的（可以各自相同也可以不同），日语的"それぞれ"暗含"各有各的"差异感。

**拉丁语 quisque：**

拉丁语用 quisque 表达 each，它和英语 each 一样要求单数搭配，但拉丁语走了不同的构词路径——quisque 来自疑问代词 quis 的重叠，字面意思像是"谁谁谁"，通过重复来表达"每一个"。有趣的是，英语选择了"always alike"（永远一样），拉丁语选择了"who-who-who"（一个个点名问），两种语言从不同角度抵达了同一个概念。
