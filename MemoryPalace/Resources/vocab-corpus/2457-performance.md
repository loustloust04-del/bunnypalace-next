# performance

---

## 1. 一句话本质

**performance 是"把活儿交出来"的那个瞬间——不管你内心经历了什么，世界只看你端上桌的那盘菜。**

它同时包含两层：你确实做了（完成），以及别人在看你做（展示）。一个厨师在后厨切菜不叫 performance，端到食客面前、被评价的那一刻才是。

---

## 2. 词源考古

### 词根词缀拆解

这个词的身世有一层精彩的"误会"。

表面上看，perform 似乎是 **per-（通过）+ form（形式/塑造）**，多整齐——"通过某种形式来呈现"。很多词源书早年也这么写。

**但真正的祖宗不是 form，是 fournir。**

- **古法语 parfournir**：par-（彻底地，来自拉丁语 per-）+ fournir（供给、完成，日耳曼语源）
- 原始含义：**彻底地供给 = 把事情做完、交付到位**
- 中古英语 **parformen** → 后来拼写被拉丁语 forma（形状）影响，改成了 **performen**

这个拼写漂移不是小事——它让后人以为这个词天生跟"形式""塑形"有关，但它的 DNA 其实是**"把东西备齐、做到底"**。一个关于"完成交付"的词，被误认为是关于"形式展演"的词。而讽刺的是，这个误解反而帮它长出了"表演"这层含义。

**-ance** 后缀：表示"……的行为/过程/状态"（拉丁语 -antia），跟 attendance、resistance 同款。

### 历史流变

| 时期 | 含义 | 关键转折 |
|------|------|----------|
| 14世纪 | "执行、完成某项任务" | 纯粹的"做完"，没有观众 |
| 15-16世纪 | 开始指"履行仪式、执行典礼" | 宗教/法律场景——perform a ceremony, perform a duty |
| 16世纪 | 进入戏剧领域——"演出" | 莎士比亚时代剧场兴起，perform = 在舞台上呈现 |
| 18-19世纪 | "表现/效能"义项萌芽 | 工业革命——机器的 performance 被量化评估 |
| 20世纪至今 | 计算机/商业/体育全面扩散 | high performance, performance review, performance art |

### 文化地层

最关键的转折发生在 **16世纪**：从"做完一件事"到"在人前做一件事"。

这个转折的推手是**英国戏剧的爆发**。当 perform 进入剧场，它获得了一层原来没有的属性：**被观看**。从此，performance 永远携带着一个隐形观众。哪怕你说"the engine's performance"，那台发动机也是在"被评判"的——你在衡量它交出来的结果。

20世纪后半叶，学术界（尤其是朱迪斯·巴特勒的性别理论）又给了这个词一层哲学炸弹：**身份本身就是 performance**——你不是"拥有"一个性别/身份，而是每天在"表演"它。这让 performance 从一个动作名词变成了一个认识论概念。

## 3. 故事 / 画面

一个杂技演员站在钢丝上。

她练了三千个小时。她的脚底板有老茧，膝盖有旧伤，她知道每一步应该怎么踩。但这些都不叫 performance。

Performance 是灯亮了、音乐起了、下面三百个人抬头看她的那一刻——她踩上钢丝，所有练习消失，只剩下"正在发生"。

现在把这根钢丝换成别的东西：

- 换成一台服务器——它在流量高峰期撑不撑得住，就是它的 performance
- 换成一个员工——年底老板看她交出来的成绩单，就是她的 performance
- 换成一个演员——观众看到她在舞台上哭，不知道那是真哭还是演的，这就是 performance 最迷人的模糊地带

**钢丝不变，变的是谁在走、谁在看。但结构永远是那个结构：有人在做，有人在评。**

## 4. 多面体：核心义项展开

### 义项一：演出、表演（舞台/音乐/戏剧）

> *Her performance as Lady Macbeth left the audience in stunned silence.*
> 她饰演麦克白夫人的演出让观众哑然。

和本质的关系：最直观的一面——在观众面前"交付"一个角色。

### 义项二：表现、工作成果（职场/学业/体育）

> *His performance this quarter has been consistently above expectations.*
> 他这个季度的表现一直超出预期。

和本质的关系："端上桌的菜"——不看你多努力，看你交出来什么。这是 performance 最冷酷的一面。

### 义项三：性能、效能（机器/系统/技术）

> *The new chip delivers a 40% improvement in performance over its predecessor.*
> 新芯片性能比前代提升了 40%。

和本质的关系：机器的"交付能力"——给它一个任务，它多快多好地完成。工业革命给 performance 装上了秒表和温度计。

### 义项四：履行、执行（合同/职责/仪式）

> *Non-performance of the contract may result in legal action.*
> 不履行合同可能导致法律诉讼。

和本质的关系：最接近词源本义的用法——"把该做的做完"。法律和宗教场景保留了这层古老的"完成交付"义。

### 义项五：做作、装腔作势（口语贬义）

> *Oh, stop making such a performance about it — just take the medicine.*
> 别这么小题大做了——把药吃了就行。

和本质的关系：当"展示"成分压倒"完成"成分，performance 就变味了——你不是在做事，你是在演给别人看。

**底层统一性**：五个义项共享一个结构——**有一个行为被执行，并且这个行为的结果暴露在某种评价体系之下**（观众的眼睛、老板的考核表、跑分软件、法庭、或者旁人的白眼）。

## 5. 裂缝标注

### 常见误用场景

**❌ "She made a good performance."**
→ ✅ "She gave / delivered / put on a good performance."
Performance 不跟 make 搭配。这是因为 performance 不是你"制造"出来的物件，而是你"呈上"的行为——动词选择要体现这层"交付"感。

**❌ 把 performance 当"节目"用**
"The performance was a magic show." — 这句语法没错，但如果你想说的是"那个节目是魔术表演"，更自然的说法是 "The show / act was magic." Performance 强调的是"某人的演出行为"，不是"一台节目"本身。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **performance vs. show** | performance 聚焦于"做的质量"（她的 performance 很差 = 她演得烂），show 聚焦于"那台节目本身"（那场 show 很无聊 = 节目无聊）。同一场演出，performance 评价人，show 评价事件 |
| **performance vs. execution** | execution 是冷的、机械的"执行"（execute a plan），performance 带评价维度——有好坏之分。你不会说 "good execution of Hamlet"，但你会说 "good performance of Hamlet" |
| **performance vs. act** | act 可以暗示"假的"（put on an act = 装），performance 更中性——它可以是真情流露的演出，也可以是做作，取决于语境 |

### 中文母语者陷阱

**最大的坑：中文把 performance 拆成了至少三个完全不搭界的词。**

- 表演/演出 → 舞台义
- 表现/成绩 → 职场义
- 性能 → 技术义

中文母语者很难直觉性地感受到"一台服务器的性能"和"一个演员的表演"是**同一个词**。结果就是每次碰到 performance 都要在脑子里做一次"它这次是哪个中文意思"的翻译查表，而不是直接抓住它"交付+被评"的统一内核。

**第二个坑："表演"在中文里偏贬义（"你在表演"≈你在装），但 performance 本身是中性的。** 说 "What a performance!" 可以是真心赞叹，也可以是讽刺——看语气，不看词本身。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 说明 |
|------|------|------|
| **deliver a performance** | 舞台/体育 | 最正式的"呈现演出"，暗示高水准 |
| **peak performance** | 体育/健康/商业 | 巅峰状态——你能交出的最好成果 |
| **performance review** | 职场 | 绩效评估——每个打工人的定期审判 |
| **performance anxiety** | 心理/日常 | 上场焦虑——怕自己交不出好活儿 |
| **high-performance** (adj.) | 技术/体育 | 高性能的——形容词化，修饰机器或人 |
| **put on a performance** | 口语 | 可褒可贬——精彩演出 / 小题大做 |
| **performance art** | 艺术 | 行为艺术——"做"本身就是作品 |
| **performance metrics** | 商业/技术 | 绩效/性能指标——量化你的交付 |

### 语域标注

**全频段通用词。** 从论文到酒吧都能说。但不同语域下它穿不同的衣服：

- **学术论文**："performativity"（表演性）、"performative utterance"（施行语）——巴特勒、奥斯汀的术语
- **商业/职场**：偏冷、偏量化——performance KPIs, underperformance
- **日常口语**："What a performance!"（真夸张！）——带调侃
- **技术领域**：完全去人格化——CPU performance, runtime performance

### 活用示范

> *"All the world's a stage, and all the men and women merely players."*
> ——莎士比亚没用 performance 这个词，但他定义了 performance 的哲学底色：人生本身就是一场交付。

> *She knew the tears were a performance, but she cried anyway — and somewhere between the first sob and the last, the performance became real.*
> 她知道那些眼泪是表演，但她还是哭了——在第一声抽泣和最后一声之间，表演变成了真的。

这第二句展示了 performance 最迷人的裂缝：**做着做着，假的变成了真的。**

## 7. 跨语言映射

**日语「演技」（えんぎ）** 只覆盖 performance 的"表演"面，而且比英语更明确地指向"技巧"——日语问的是"演技好不好"，英语的 performance 问的范围更宽，包括"这个人/这台机器交出来的整体结果"。

**法语 performance** 直接借回去了，但法语里它偏向体育竞技——"une belle performance"通常指运动成绩，而不是舞台演出（舞台义用 **représentation** 或 **interprétation**）。有趣的是，这个词从法语出发、在英语里膨胀出十几个义项、又以瘦身版回到法语。

**中文没有一个词能统摄 performance 的全部语义。** 这不是翻译缺陷，是认知框架不同：中文把"做"和"演"分得很开（"他在表演"和"他在表现"是两件事），而英文的 performance 认为这两件事本质上是**同一个动作的不同面**——你永远同时在做和在被看。

**德语 Leistung** 覆盖了 performance 的"成果/效能"面（Leistung 的词根是 leisten = 完成/交付），但完全不沾"表演"义。德语的"表演"用 **Aufführung**（上演）或 **Vorstellung**（呈现）。德语诚实地承认：干活和演戏是两码事。英语的 performance 则坚持说：不，你干活的时候也在演。

---

**收尾一锤**：performance 这个词的全部张力浓缩在一个问题里——**你是在做，还是在演？** 而它给出的回答是：**没有区别。你做的每一件事，在它被交付出去的那一刻，就已经是一场演出了。** 这就是为什么"服务器性能"和"钢琴演奏"可以是同一个词——它们都是在说：给你一个任务，你交出了什么。
