# mock

## 1. 一句话本质

mock 是一面哈哈镜——它照出你的样子，但故意歪掉，让你看起来可笑。从这个"歪曲的复制品"出发，你就能理解它为什么既是"嘲笑"又是"假的"又是"模拟"。

## 2. 词源考古

**词根拆解：**

mock 不可再拆——它是一个单音节借词，没有拉丁词缀系统。但它的来源本身很有故事。

**历史流变：**

- **15世纪**：从古法语 *mocquer*（嘲弄、取笑）进入英语。法语这个词的更早来源有争议。
- **争议路径一**：源自通俗拉丁语 *\*muccare*，字面意思"擤鼻子"——朝人擤鼻子是中世纪欧洲的蔑视手势（类似今天的竖中指）。从身体动作演变为抽象的"表示轻蔑"。
- **争议路径二**：可能与中古荷兰语 *mokken*（嘟嘴、做鬼脸）有关，指面部扭曲的模仿。
- **16世纪**：从动词"嘲笑"衍生出形容词义"假的、模拟的"——逻辑链条是：嘲笑的核心动作就是模仿，模仿就是造一个假版本，所以 mock = 假的。这是一次"从动作到属性"的词义漂移。
- **17世纪**：mock-heroic（模拟英雄体）成为文学术语——用庄严的史诗格式写鸡毛蒜皮的小事，整个体裁就是一面"哈哈镜"。
- **20世纪末-21世纪**：程序员把这个词接管了。mock object、mock server——不是为了嘲笑，是为了模拟。这是一次"贬义→中性工具义"的漂白，但底层逻辑没变：它仍然是"一个假的复制品"。

**文化地层：**

最戏剧性的转折在于：mock 的情感色彩从"恶意"走向了"实用"。

中世纪的 mock 充满攻击性——我模仿你是为了羞辱你。莎士比亚用 mock 的时候，几乎全是带刀子的。但到了现代软件工程，mock 变成了一个完全中性的技术概念——我造一个假数据库不是为了嘲笑真数据库，是为了测试能跑起来。

这个转变的中间站是 "mock-up"（模型/草稿）——20世纪初工业设计领域开始用这个词指产品原型。原型不嘲笑最终产品，它只是一个"还没做完的假版本"。

## 3. 故事 / 画面

小学教室。一个孩子在讲台前做自我介绍，有点结巴。后排有个坏小子在他身后精确地复制他的每一个动作——同样的结巴、同样的手势，但夸张了30%。全班都在笑。

坏小子做的事情包含 mock 的全部基因：
- **他在模仿**（imitate）
- **他模仿的目的是让原版显得可笑**（ridicule）
- **他创造了一个假版本**（counterfeit）
- **这个假版本有原版的外形但没有原版的灵魂**（hollow replica）

现在把场景切到一间办公室。一个设计师把 app 的界面草稿钉在墙上——按钮是画的不能点，数据是编的不是真的。这叫 mockup。同样的逻辑：外形在，灵魂不在。但没有人被嘲笑。

mock 的本质就是这个：**形似而神不同的复制品**。至于这个"神不同"是恶意的扭曲还是务实的简化，取决于语境。

## 4. 多面体：核心义项展开

### 义项一：嘲笑、嘲弄（动词，最古老的脸）

> *"Are you mocking me?"* she said, her voice going cold.
> "你在嘲笑我？"她的声音冷了下来。

和"一句话本质"的关系：哈哈镜的攻击性用法——我模仿你是为了让你难堪。

### 义项二：使……落空、辜负（动词，书面/文学色彩）

> *The calm sea mocked the sailors' fears.*
> 平静的海面嘲弄了水手们的恐惧（= 让他们的恐惧显得可笑/多余）。

和本质的关系：现实成了一面哈哈镜，把你的期待/情绪照得荒谬。这个义项不是人在嘲笑人，而是事实本身在嘲笑人——"你怕了半天，结果什么都没发生"。

### 义项三：假的、模拟的（形容词）

> *a mock trial / mock exam / mock battle*
> 模拟审判 / 模拟考试 / 模拟战斗

和本质的关系：外形完全复制，但不是真的——没有真实后果的复制品。模拟考试不决定你的命运，模拟审判不送人进监狱。

### 义项四：模拟对象（名词，技术领域）

> *We wrote mocks for the payment API so we could run tests without hitting production.*
> 我们给支付 API 写了 mock，这样跑测试就不用打到生产环境。

和本质的关系：程序员造的假替身——长得像真 API，回应方式像真 API，但里面是空的。形似神不在，为测试服务。

### 义项五：mockingbird 的缩写 / mock- 前缀（假……）

> *mock turtle soup*（仿甲鱼汤，用牛头肉代替）
> *mocktail*（无酒精鸡尾酒）

和本质的关系：外观/体验模仿正版，但核心原料换了。

## 5. 裂缝标注

**常见误用场景：**

- ❌ "He mocked to be a doctor."——mock 做"假装"时不这么用。要说"冒充医生"用 impersonate 或 pose as。mock 的"假"是形容词修饰（mock exam），不是动词"假装成为"。
- ❌ 把 mock 当成温和的"开玩笑"——mock 做动词时几乎总带恶意或居高临下的态度。朋友间无恶意的打趣用 tease，不用 mock。

**易混近义词辨析：**

| 词 | 核心区别 |
|---|---|
| **ridicule** | 纯粹的"使可笑"，不一定通过模仿。可以是语言攻击、公开羞辱。mock 的核心手段是**模仿** |
| **tease** | 轻量级，常带善意。"逗你玩"。mock 没有善意的空间 |
| **mimic** | 中性的"模仿"，不带嘲讽意图。鹦鹉 mimic 人说话不是为了嘲笑你 |
| **imitate** | 最中性的"模仿"，可以是学习、致敬、复制。mock 是带恶意的 imitate |
| **simulate** | 技术语境下和 mock 最近，但 simulate 强调"重现行为/过程"，mock 强调"替代真实对象" |

**中文母语者陷阱：**

- "嘲笑"在中文里可以很轻（"别嘲笑我嘛"），但 mock 在英文里分量比较重——接近"当面学你说话来羞辱你"的程度。中文的轻量级"嘲笑"更接近 tease 或 make fun of。
- 技术领域的"mock 数据"常被翻译成"模拟数据"，但注意：mock 和 simulation 不完全相同。mock 是"假替身"（只关心接口对不对），simulation 是"真模拟"（尽量还原真实行为）。

## 6. 搭配与语域

**高频搭配：**

- **mock exam / mock test**——模拟考试（英式英语极高频，美式说 practice test 更多）
- **mock trial**——模拟审判（法学院的必修课）
- **mock-up**——草稿/原型（设计和工业领域）
- **make a mockery of**——使……沦为笑柄 / 完全糟蹋了（"The verdict made a mockery of justice."）
- **mock horror / mock outrage**——假装的惊恐/愤怒（嘴上说着"天哪！"但明显在演）
- **in mock seriousness**——装正经地（实际在开玩笑）

**语域标注：**

- 动词"嘲弄"义：略书面偏正式，口语中更常说 make fun of / laugh at
- 形容词"假的/模拟的"义：中性，各语域通用
- 技术名词"mock object"义：纯技术领域（软件测试）
- mock-heroic：文学批评专用术语

**活用示范：**

> *The sunlight mocked him through the hospital window — warm, golden, obscenely alive.*
> 阳光透过病房窗户嘲弄他——温暖、金黄、活得不像话。

这个用法把 mock 的"使落空/使显得荒谬"发挥到极致：不是人在嘲笑人，是生命本身在嘲笑将死之人。

> *She did a mock curtsy and said, "Your Majesty," in a voice dripping with sarcasm.*
> 她假模假样地行了个屈膝礼，用满得溢出来的讽刺语气说："陛下。"

## 7. 跨语言映射

**中文"学"字**：中文口语里"你别学我！"——这个"学"精确对应 mock 的核心动作（通过模仿来激怒/嘲弄），但中文的"学"没有独立发展出"假的/模拟的"形容词义。

**日语「茶番」（ちゃばん）**：字面"茶水番（看门人演的闹剧）"，指假模假样的表演/走过场。和 mock trial 的"模拟审判"不同——茶番带有"大家都知道是假的但还在装模作样"的贬义，更接近 mockery（笑话/闹剧）。

**法语 se moquer de**：mock 的直系祖先还活着。法语日常用"Tu te moques de moi?"（你在耍我？）的频率极高，比英语的 mock 口语化得多——英语的 mock 略正式，法语的 se moquer de 就是日常抱怨。

---

**记忆锚点回收：** 哈哈镜。它照出你，但不是你。可以用来嘲笑你（你看你多可笑），也可以用来替代你（测试的时候用假的就行）。形似，神不在。
