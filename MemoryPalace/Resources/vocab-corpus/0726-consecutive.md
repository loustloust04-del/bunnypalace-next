# consecutive

---

## 1. 一句话本质

**consecutive 是多米诺骨牌倒下去的那条线——每一块紧贴前一块，中间不许有空格，不许有人插队。**

不是"很多"，是"一个接一个，队形没断过"。重点不在数量，在**无间断的接力关系**。

---

## 2. 词源考古

### 词根词缀拆解

```
con-   +   secut-   +   -ive
一起/加强    跟随(sequī)    形容词后缀
```

核心引擎是拉丁语动词 **sequī**（跟随）。这个词根是英语里的超级生产线：

| 前缀 | 组合 | 含义逻辑 |
|------|------|----------|
| con- (一起) | **con**sequī → consecutive | 一起跟上 → 紧随不断 |
| sub- (在下/在后) | **sub**sequī → subsequent | 从后面跟上 → 随后的 |
| per- (穿过/彻底) | **per**sequī → persecute | 追到底 → 迫害 |
| ex- (出来) | **ex**sequī → execute | 追出结果 → 执行 |
| pro- (向前) | **pro**sequī → prosecute | 向前追 → 起诉 |
| 无前缀 | sequī → **sequence**, **sequel** | 跟随本身 → 序列、续集 |

甚至 **sue**（起诉）、**suit**（套装/诉讼）、**suite**（套房）都是 sequī 的后裔——"跟随"的意象在几百年里分化成了完全不同的概念。

### 历史流变

- **拉丁语 consequī**：原义是"跟上、赶上"，强调追随的动作
- **晚期拉丁语 consecutīvus**（约 4-5 世纪）：语法术语化——用来描述"表示结果的从句"（consecutive clause），即"事件 A 导致事件 B 跟着发生"
- **中古法语 consécutif**（14 世纪）：从语法术语扩展到一般用法，"接连发生的"
- **进入英语**（17 世纪初）：定型为"连续的、不间断的"

**关键转折**：这个词从拉丁语法学家的专业术语，变成了日常描述"接连"的普通形容词。它的出身其实很学术——一开始描述的是句子之间的逻辑关系（因果接续），后来才扩展到时间上的物理接续。

## 3. 故事 / 画面

一条窄巷。十二扇木门，编号 1 到 12，紧挨着排列。

你从 1 号门开始敲，有人开门。你走到 2 号门，敲，有人开门。3 号、4 号、5 号……每一扇门都紧贴着上一扇，你不需要走回头路，不需要跳过任何一扇，不需要拐弯。

这就是 consecutive：**逐门推进，不跳号，不回头。**

如果你敲完 3 号跳到 7 号——那不是 consecutive，那叫 scattered。
如果你敲完 5 号停下来喝了杯咖啡再敲 6 号——严格说这段时间里，sequence 断过了。

consecutive 对"断裂"零容忍。它描述的不是"大致按顺序"，而是**逐个紧贴、无缝衔接**。

## 4. 多面体：核心义项展开

### 义项一：时间上连续的（最常用）

> *She won the championship for three consecutive years.*
> 她连续三年赢得冠军。

"连续三年"——不是"三年里赢了三次"（那可能是第1、3、5年），而是**年年都赢，中间没断**。这是 consecutive 最高频的用法：修饰可数的时间单位（天、周、月、年），强调每一个都没缺席。

与"一句话本质"的关系：多米诺骨牌——每一年紧贴前一年倒下去。

### 义项二：事件/动作上连续的

> *The team scored on four consecutive possessions.*
> 球队在连续四次持球进攻中都得了分。

不仅限于时间，任何可以编号排列的事件都行。四次进攻，每次都得分，没有一次空手而归。

与"一句话本质"的关系：还是多米诺骨牌，只是骨牌从"年份"换成了"事件"。

### 义项三：（数学/逻辑）相邻的、连号的

> *The sum of five consecutive integers starting from 3 is 25.*
> 从 3 开始的五个连续整数之和是 25。（3+4+5+6+7）

数学语境里，consecutive integers 就是"连号整数"——3, 4, 5, 6, 7，差值恒为 1，不跳号。这是 consecutive 最纯粹的用法：**编号紧邻，间距为零**。

### 义项四：（语法/逻辑，学术）表示结果的（偏古/专）

> *A consecutive clause expresses the result of the action in the main clause.*
> 结果从句表达主句动作的结果。

这是 consecutive 的老本行——拉丁语法术语。现在只在语言学讨论里偶尔出现，日常不用。但知道它的存在能帮你理解：consecutive 的底层逻辑不只是"排队"，还有**"前一个导致后一个"**的因果暗示。

## 5. 裂缝标注

### 常见误用

**❌ 把 consecutive 用在不可数/不可编号的事物上**

> ~~consecutive rain~~（雨是连续状态，不是一个一个的）
> ✅ consecutive rainy days（天是可数的）

consecutive 需要"可以编号的离散单元"。你不能说"连续的水流"用 consecutive——那是 continuous 的活儿。

**❌ 混淆"连续"和"总共"**

> *He missed three consecutive meetings.* ≠ *He missed three meetings.*

前者：第 5、6、7 次会议全没来（连号缺席）。后者：可能是第 2、5、9 次没来（散装缺席）。中文"连续三次"和"三次"的区别。

### 易混近义词辨析

| 词 | 核心区别 | 场景 |
|---|---|---|
| **consecutive** | 离散单元逐个排列，**强调不跳号** | three consecutive wins（连胜三场） |
| **successive** | 意思极近，但**语气更宽松**，可容忍微小间隔 | successive governments（历届政府，不一定无缝交接） |
| **continuous** | **不可数的连续状态**，没有断点概念 | continuous noise（持续不断的噪音） |
| **sequential** | 强调**按顺序排列**，不强调"不跳号" | sequential steps（按顺序的步骤，但步骤间可能有间隔） |

**最容易搞混的一对：consecutive vs. successive**

- *consecutive days* = 周一、周二、周三（铁定连号）
- *successive attempts* = 第一次试、第二次试、第三次试（一次接一次，但两次之间可能隔了一周）

successive 像"接力赛"——下一个人确实接上了，但交接可以有缓冲。consecutive 像"火车车厢"——挂钩连着，一格都不许空。

### 中文母语者陷阱

中文的"连续"同时覆盖了 consecutive 和 continuous 的语义区间：

- "连续三天下雨" → consecutive（三天是可数的离散单元）
- "连续下了三天的雨" → continuous（强调雨没停过）

中文母语者最常犯的错是把 consecutive 用在本该用 continuous 的地方，因为中文的"连续"不区分"离散接续"和"持续不断"。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **consecutive days/weeks/months/years** | 最常见，时间单位连号：*absent for five consecutive days* |
| **consecutive wins/losses/games** | 体育新闻标配：*ten consecutive wins*（十连胜） |
| **consecutive terms** | 政治语境：*served two consecutive terms*（连任两届） |
| **consecutive quarters** | 财经语境：*growth for six consecutive quarters*（连续六个季度增长） |
| **consecutive integers/numbers** | 数学语境：*three consecutive even numbers*（三个连续偶数） |
| **consecutive sentences** | 法律语境：刑期**接续执行**（不是同时服刑）——这个搭配经常让人意外 |

### 语域标注

**中性偏正式**。新闻、学术、法律、体育报道高频出现。日常口语中不算罕见，但人们更常说 *in a row*：

- 书面/正式：*He won three consecutive championships.*
- 口语/日常：*He won three championships in a row.*

两者意思完全一样，*in a row* 是 consecutive 的口语替身。

### 活用示范

> *After four consecutive all-nighters, his code started looking like modern art — abstract and incomprehensible.*
> 连续四个通宵之后，他的代码开始像现代艺术——抽象且不可理解。

这里 consecutive all-nighters 不只是说"好几个通宵"，而是强调**每一夜都没睡、中间没有恢复**。正是这种"无间断"的含义让后面的崩溃显得顺理成章。

> *The judge ordered the sentences to run consecutively, not concurrently.*
> 法官判决刑期接续执行，而非同时执行。

法律语境中 consecutively 和 concurrently 是一对生死对头：前者是排队服刑（5年+3年=8年），后者是叠加服刑（5年和3年同时跑，实际只蹲5年）。一个副词的差别，决定了被告多蹲几年。

## 7. 跨语言映射

**中文「连续」vs. consecutive**

如前所述，中文的"连续"语义区间比 consecutive 宽得多。consecutive 只管"离散单元接力"，而"连续"还包括"不间断的状态"。这是翻译中最常见的失配点。

**日语「連続（れんぞく）」**

和中文类似，連続 同时覆盖 consecutive 和 continuous。但日语体育报道中有一个精准对应：**連勝（れんしょう）**= consecutive wins，这个词天然包含了"不跳号"的含义。

**法语 consécutif**

直系亲属，用法几乎完全对应。*trois jours consécutifs* = three consecutive days。法语里这个词同样偏正式，口语更常说 *de suite* 或 *d'affilée*（相当于英语的 *in a row*）。

**拉丁语 able to help here：consequī 家族的"追赶"意象**

值得注意的是，整个 sequī 家族在拉丁语里都围绕"追"这个动作。consecutive 的底层画面是：后面的人**追上**前面的人，紧贴着他的后背——不是平行，不是远远跟着，是**贴身追随**。这个"追"的力度，正是 consecutive 比 successive 更紧密的原因。
