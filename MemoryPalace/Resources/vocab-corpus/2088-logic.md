# logic

## 1. 一句话本质

**logic 是思维的骨骼——你把肉（情感、直觉、偏见）剥掉之后，那个让论证能站起来、不塌的硬结构。**

不是"聪明"，不是"正确"，是"这一步到下一步之间的关节是不是真的接得上"。一个结论可以完全合乎 logic 但完全错——只要前提是错的。logic 不管你说的是不是真话，它只管你的话**自不自洽**。

## 2. 词源考古

### 词根拆解

```
logic ← 拉丁 logica ← 希腊 logikḗ (tékhnē) ← lógos + -ikḗ
```

- **lógos (λόγος)**：这是西方思想史上负载最重的词之一。本义是"被说出的东西"（来自动词 légein "说、收集、挑选"）。但它从不只是"话"——它同时是**言说的内容**（道理、论证、理由）和**言说的能力**（理性、思维）。一个词同时装着"语言"和"理性"，因为希腊人认为这两件事是同一件事的两面：你能把想法说出来，证明你真的想过了。
- **-ikḗ (-ική)**：希腊语形容词后缀，表"与……相关的技艺"。logikḗ tékhnē = "关于 lógos 的技艺"，后来 tékhnē 省略，logikḗ 独立成名词。

### 历史流变

**公元前 4 世纪 · 亚里士多德**
logic 作为一门学科在亚里士多德手里诞生。但有意思的是，亚里士多德本人从没用过 "logikḗ" 这个词来指他的这套东西。他管自己搞的叫 **analytikḗ**（分析术）——把论证拆开看零件。"logic" 这个标签是后来的斯多亚学派（Stoics，约前 3 世纪）贴上去的。斯多亚派把哲学分三块：physics（自然）、ethics（伦理）、**logikḗ**（逻辑/论证），他们的 logikḗ 范围比亚里士多德的宽，包括修辞学和语法学。

**中世纪拉丁化**
经阿拉伯学者保存、翻译，亚里士多德的逻辑学著作回流欧洲，拉丁化为 **logica**。中世纪大学把它列为"三艺"（trivium）之首——grammar、**logic**、rhetoric。注意顺序：先学语法（怎么说），再学逻辑（怎么想），再学修辞（怎么说服人）。Logic 在中世纪是知识分子的入场券。

**17-18 世纪 · 日常化转折**
logic 从"一门专业学科"开始下沉为"一种思维品质"。人们开始说 "Where's the logic in that?"（这有什么道理？）——这时候 logic 已经不是亚里士多德的三段论了，而是"说得通"这个日常概念的文雅说法。

**20 世纪 · 计算化**
数理逻辑（弗雷格、罗素、哥德尔）重新把 logic 拉回硬核技术领域。然后计算机来了——逻辑门（logic gate）、布尔逻辑（Boolean logic）、"业务逻辑"（business logic）。这最后一个用法特别值得注意：程序员说的 logic 指的是"决定程序行为的那堆规则"，和亚里士多德的"分析论证结构"已经隔了很远，但底层内核没变：**if A then B, not A therefore not B——一套不带感情的推导链条。**

### 文化地层：lógos 的幽灵

logic 的祖先 lógos 在基督教神学里变成了"道"（《约翰福音》开头 "In the beginning was the Logos"，和合本译"太初有道"）。这意味着 logic 这个词的 DNA 里，藏着一种古老的信念：**宇宙是有道理的，万物背后有一个可被言说、可被理性把握的秩序。** 你每次说 "That's logical"，你都在不自觉地站在这个两千多年的哲学赌注上。

## 3. 故事 / 画面

你见过法医验尸吗——不是电影里那种，是真正的尸检报告。

法医不关心死者生前是好人还是混蛋，不关心他的遗愿，不关心他妻子在走廊里哭。法医只看：**伤口的角度和凶器形状对不对得上，血液里的毒物浓度和死亡时间吻不吻合，胃内容物的消化程度和最后一餐的间隔说不说得通。**

每一条证据和下一条证据之间，必须有一条看得见的线。线断了——不管死者多惨、嫌疑人多可疑——结论就不成立。

Logic 就是这个法医。

它不反对你有情感，不反对你有立场，但它要求你给出的每一步推论之间，**关节必须是实的**。你可以用 logic 证明一个荒谬的结论（"所有猫是液体，我是猫，所以我是液体"），只要你的前提和推导规则咬得上——logic 不管内容，只管**结构是否承重**。

这也是为什么 "logical" 和 "right" 不是同义词。一栋建筑结构完美但盖在沼泽上，它合乎力学但注定下沉。Logic 管骨架，不管地基。

## 4. 多面体：核心义项展开

### 义项 A：推理的规则体系（学科/方法论）

> *Aristotle is considered the father of formal logic.*
> 亚里士多德被视为形式逻辑之父。

这是 logic 最原始的脸——一套关于"什么样的推理是有效的"的规则系统。和"一句话本质"的关系：这就是那副骨骼的**设计图纸**，告诉你哪种关节连接方式能承重。

### 义项 B：某件事的内在道理 / 合理性

> *I fail to see the logic behind this decision.*
> 我看不出这个决定背后的道理在哪。

这是日常用得最多的脸。这里 logic 不是指一门学科，而是指"某个选择或现象背后那条说得通的因果链"。和骨骼的关系：你摸一个东西，发现里面没骨头——**it has no logic**，它立不住。

### 义项 C：某个系统/领域自己的运作规律

> *The logic of war is different from the logic of diplomacy.*
> 战争的逻辑和外交的逻辑不一样。

这个义项特别有意思——它承认不同的游戏有不同的骨骼。战争的"骨骼"是暴力效率最大化，外交的"骨骼"是利益交换。同一个行为在一套 logic 里合理，在另一套里荒谬。

### 义项 D：程序/系统中的控制规则（技术用法）

> *We need to separate the UI from the business logic.*
> 我们需要把界面和业务逻辑分开。

程序员日常。这里 logic = "决定系统行为的那组 if-then 规则"。和骨骼的关系最直白：logic 是藏在皮肉（UI）下面的骨架，你看不见它但它决定了一切动作。

## 5. 裂缝标注

### 常见误用

**❌ "His argument is very logic."**
→ ✅ "His argument is very **logical**."
logic 是名词，做形容词要变成 **logical**。这个错误频率极高。类似的：**logically**（副词），**logician**（逻辑学家）。

**❌ 把 logic 等同于 truth**
"That's logical" ≠ "That's true"。一个论证可以逻辑完美但前提全错，结论也就全错。Logic 保证的是**推导过程的有效性**，不保证结论的真实性。

### 易混近义词

| 词 | 区别 |
|---|---|
| **reason** | 更宽。reason 包含 logic 但不限于 logic——reason 还包括判断力、常识、经验。"Use your reason" 不等于 "Use logic"，前者允许你调用直觉，后者要求你走严格推导。 |
| **rationality** | 指一个人**运用理性的能力或倾向**。logic 是工具，rationality 是使用这个工具的人的品质。一道数学证明有 logic，做这道证明的人有 rationality。 |
| **sense** | "That makes sense" 比 "That's logical" 温和得多——sense 允许直觉参与，"说得通"可以是一种感觉。logic 要求你能把"为什么说得通"一步步拆出来。 |

### 中文母语者陷阱

**"逻辑" 在中文里的语义已经比英文的 logic 宽。** 中文说"你这个人没逻辑"，意思接近"你说话没条理/不讲道理"，带贬义。英文的 logic 更中性——"the logic of the market" 不含任何褒贬，纯粹指市场运作的内在规律。

另外，中文"逻辑"本身就是 logic 的音译（清末传入），所以这是个假性熟悉——你以为你懂了，但中文"逻辑"的使用范围和英文 logic 并不完全重叠。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **the logic behind / of** sth | 最万能搭配。"某事背后的道理"。*The logic behind the policy is simple.* |
| **follow the logic** | 沿着一条推理链走下去。*If you follow that logic, we should never take any risks.* |
| **defy logic** | 违反常理，不可思议。*The outcome defied all logic.* |
| **flawed logic** | 有漏洞的推理。*His argument rests on flawed logic.* |
| **apply logic (to)** | 用理性分析。*Try applying some logic to the problem.* |
| **business / game / program logic** | 特定领域的运作规则。技术和商业语境高频。 |
| **cold / hard logic** | 不带感情的纯推理。暗示残酷但无可辩驳。*Cold logic says we should shut it down.* |
| **internal logic** | 一个体系内部自洽的规则。*The film has its own internal logic.* |

### 语域

logic 是个**全语域词**——学术论文用它、日常对话用它、代码注释用它、新闻评论用它。但不同语域侧重不同的义项：学术偏义项 A，日常偏义项 B，编程偏义项 D。

### 活用示范

> *"The heart has its reasons which reason knows nothing of."* — Pascal
> 这句话的力量恰恰在于它把 logic 的领地画出来——logic 管得了论证，管不了心。

> *There's a certain logic to his madness.*
> 他的疯狂里藏着某种道理。——这句话好在"certain"的犹豫：说话人承认那个 logic 存在，但不完全买账。

## 7. 跨语言映射

**中文"理"**：比"逻辑"更古老也更深的对应。"天理""道理""理路""条理"——中文的"理"和 logic 一样，同时指"事物的内在纹路"和"人的推理能力"。但"理"比 logic 多了一层**道德宇宙论**色彩（"天理昭昭"），而 logic 始终保持工具中性。

**日文「筋」（すじ, suji）**：字面义是"筋腱"，引申为"事情的脉络、道理"。"筋が通る"（逻辑通顺）、"筋が通らない"（说不通）。这个身体隐喻和本文用的"骨骼"异曲同工——都把 logic 理解为一种**结构性的支撑组织**。

**希腊语 lógos → 德语 Logik / 法语 logique**：直系后代，用法几乎一致。但值得注意的是，德语思想传统里 Logik 和 Vernunft（理性）的区分比英语更严格——黑格尔写了整本《逻辑学》（*Wissenschaft der Logik*），把 Logik 上升为"存在本身的运动规律"，远远超出了英语 logic 的日常含义。
