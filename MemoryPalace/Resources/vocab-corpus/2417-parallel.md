# parallel

---

## 1. 一句话本质

parallel 是两条铁轨——各走各的路，永远保持同样的距离，永远不碰面。不是"一样"，是"一样的姿态各自走，走到天涯也不交汇"。

---

## 2. 词源考古

### 词根词缀拆解

```
parallel
├── para-（παρά）：旁边、沿着
└── allēlōn（ἀλλήλων）：彼此、互相
    └── allos（ἄλλος）：另一个、其他的
```

**para-** 这个前缀你见过无数次：parachute（para + chute = 沿着坠落 → 减缓坠落）、paramedic（在医生旁边辅助的人）、paranormal（在正常之旁 → 超自然的）。它的核心语感是"在……旁边、沿着……"。

**allēlōn** 是希腊语"彼此"的属格形式，来自 **allos**（另一个）。allos 是个大族长——英语里的 **else**（别的）、**alter**（改变，变成另一个）、**alias**（化名，另一个名字）、**alien**（外星人，另一类存在）全是它的后代。

所以 parallel 的字面意思直白得惊人：**"沿着彼此走"**。两条线，肩并肩，永远沿着对方走，但永远是"对方"——不合并、不碰触。

### 历史流变

**公元前 5 世纪 · 希腊**
欧几里得之前的希腊数学家就在用 parallēlos（παράλληλος）了。这是个纯几何概念：同一平面上永不相交的两条直线。欧几里得在《几何原本》里给了它经典定义，并提出了著名的"平行公设"——两千年后人们还在为这条公设吵架（非欧几何就是从质疑它开始的）。

**16 世纪 · 进入英语**
经拉丁语 parallelus、法语 parallèle 传入英语。最初严格用于几何和地理（纬线 = parallels of latitude）。

**17 世纪 · 关键漂移**
意义开始从几何滑向修辞。人们开始说 "draw a parallel between A and B"（在 A 和 B 之间画一条平行线 → 类比 A 和 B）。注意这个隐喻的精妙之处——不是说 A 和 B 相同，而是说它们像两条平行线：走着各自的路，但方向相同、结构相似。**这个"结构相似但本体独立"的语感，是 parallel 区别于 similar 的灵魂。**

**20 世纪中叶 · 计算机时代**
parallel processing（并行处理）、parallel computing——多个任务同时运行，各走各的路径，但步调一致。又是那条铁轨：各自独立、同时前进。

### 文化地层

parallel 有一个有趣的文化维度：它暗含一种**宿命式的不可能**。两条平行线永不相交——在文学和日常表达中，这成了"注定无法相遇"的隐喻。中文里"我们就像两条平行线"这个说法，其实是 parallel 的几何语感在情感维度的映射。这种"明明如此相似却永远不能在一起"的张力，是这个词最有诗意的一面。

## 3. 故事 / 画面

一条高速公路。双向六车道。

中间那道水泥隔离带，把南行和北行分成两个世界。你从车窗往对面望——对面也是三条车道，也有车在跑，速度差不多，甚至有一辆和你一模一样的白色轿车。你们同时经过同一块路牌，同时穿过同一座收费站的影子。

但你往南，它往北。

你们共享了整条公路的所有特征——路面、标线、路牌、天气——你们的体验结构完全一致。但你们之间隔着那道水泥墙，而且这道墙从公路的起点一直延伸到公路的终点。

这就是 parallel。不是"一样"，是"结构一样但本体各自独立"。不是"一起"，是"同时但永远隔着一道墙"。

## 4. 多面体：核心义项展开

### 义项 A：几何学的平行

> *The two lines are parallel and will never intersect.*
> 这两条线是平行的，永远不会相交。

铁轨原义。同一平面、等距、不交。这是所有引申义的地基。

### 义项 B：类似的、可类比的（形容词）

> *Her career path ran parallel to mine — same industry, same milestones, but we never crossed paths.*
> 她的职业轨迹和我的平行——同一个行业，同样的节点，但我们从没交集。

从几何到修辞的第一跳。注意不是说"她和我一样"，而是"结构相似、方向相同、但各自独立"。parallel 强调的是**对照中的同构性**。

### 义项 C：对应物、类似事物（名词）

> *It's hard to find a parallel in modern history for what happened.*
> 很难在现代史中找到与此事对应的先例。

当 parallel 做名词时，它指的是"另一条轨道上的那个对应物"。draw a parallel（做类比）是最高频的搭配。

### 义项 D：纬线（地理名词）

> *The 38th parallel divides North and South Korea.*
> 三八线（北纬38度线）将朝鲜半岛一分为二。

地球仪上的纬线就是一组平行圆。the 38th parallel（三八线）是最著名的用例——冷战的那道水泥隔离带。和义项 A 的画面完全一致：一条看不见的线，把两个世界隔开。

### 义项 E：并行的、同时进行的（现代/技术）

> *The team ran parallel experiments to save time.*
> 团队同时跑了多组平行实验来节省时间。

计算机时代的主力义项。parallel processing、parallel universe——多条轨道同时运转，各自独立。和最初的几何义相比，多了一层"效率"的意味：因为互不干扰，所以可以同时来。

### 底层统一性

每个义项都是同一个画面：**多条轨道，同向延伸，结构一致，互不接触。** 无论是两条线、两段历史、两个实验还是两个宇宙——parallel 永远在说：它们是同构的，但它们是各自的。

## 5. 裂缝标注

### 拼写雷区

**parallel 的拼写是英语学习者的噩梦。** 到底几个 l？记忆法：**a**ll**e**l——中间的 **allel** 就像两条平行线之间的轨道，两头各一个 l，中间一个 l。总共三个 l。别写成 ~~parallell~~（四个 l）或 ~~paralel~~（两个 l）。

### 常见误用

❌ *"Our opinions are parallel."*（我们的观点是平行的）
这在英文里很别扭。parallel 强调的是"轨迹/结构"的同构性，不适合用来说两个人意见一致。意见一致该说 **aligned**（对齐的）或 **in agreement**。

parallel 的精确语感是"同向但独立"——如果你想表达"我们想法一样"，parallel 反而暗含了一种微妙的隔离感。

### 易混近义词辨析

| 词 | 核心语感 | 例句场景 |
|---|---|---|
| **parallel** | 结构相似、方向相同、但本体独立 | 两段历史轨迹惊人相似但发生在不同国家 |
| **similar** | 有共同点 | 泛泛地说两个东西像 |
| **analogous** | 在某个特定维度上可类比 | 学术论证中说"A 之于 B，如同 C 之于 D" |
| **comparable** | 可以放在一起比较（水平相当） | 两款手机的性能可以相提并论 |
| **simultaneous** | 时间上同时发生 | 两个事件恰好同时发生（不要求结构相似）|

关键区别：**simultaneous 只管时间，parallel 管结构。** 两个人同时打喷嚏是 simultaneous；两个国家在同一时期经历了同样的工业化路径是 parallel。

### 中文母语者陷阱

中文里"平行"几乎就是 parallel 的直译，这反而造成了一个陷阱：中文母语者太习惯"平行线不相交"的消极意象，容易忽略 parallel 在英语中的**积极/中性用法**。

英语里 "run parallel to"（与……平行运行）经常是好事——意味着"步调一致、互不干扰"。parallel processing（并行处理）是效率的象征。别把中文里"我们是两条平行线"的伤感情绪自动代入每一个 parallel。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 说明 |
|---|---|---|
| **draw a parallel** (between A and B) | 修辞/学术 | 做类比。最经典的 parallel 搭配 |
| **run parallel to** | 通用 | 与……平行延伸（物理或比喻） |
| **parallel universe** | 科幻/日常 | 平行宇宙。日常用来开玩笑"在另一个平行宇宙里我已经……" |
| **parallel processing** | 技术 | 并行处理 |
| **without parallel** | 正式/文学 | 无与伦比（= unparalleled）|
| **in parallel** | 通用/技术 | 同时进行、并行 |
| **parallel structure** | 语法/写作 | 平行结构——修辞学术语，指句子中对称的语法结构 |
| **parallel lines** | 几何 | 平行线。基础义 |

### 语域标注

parallel 是个**语域万能词**。从小学几何课到《自然》期刊到科幻小说到商业报告，它在每个场合都自然。没有正式度限制，没有使用禁区。少数英语单词有这个待遇。

但注意：**unparalleled**（无与伦比的）偏书面和正式。口语中你更可能说 "nothing like it" 而不是 "unparalleled"。

### 活用示范

> *"History doesn't repeat itself, but it often rhymes."* — 这句常被归于马克·吐温的话，本质上就是在说 parallel：历史不是同一条线走两遍，而是两条平行线走出了相似的轨迹。

> *She lives a parallel life on social media — same name, same face, but a version of her that never has a bad day.*
> 她在社交媒体上过着一种平行人生——同名同脸，但那个版本的她从来没有糟糕的一天。

这个用法精准地击中了 parallel 的所有语感：结构相同、本体独立、永不交汇。

## 7. 跨语言映射

**中文"平行"** 几乎是完美对应——几何义、比喻义、"平行宇宙"……覆盖率极高。但中文"平行"带了一层"井水不犯河水"的疏离感，而英文 parallel 在技术语境中更强调"高效协同"（parallel processing 的语感是"兵分多路一起干"，不是"各管各的"）。

**日语「パラレル」** 直接外来语，主要用于"平行世界（パラレルワールド）"这种二次元/科幻场景。日语原生词"平行（へいこう）"覆盖正式用法。

**拉丁语 parallelus** 几乎只在数学文本中出现，是直接从希腊语搬来的技术术语，没有发展出比喻义。英语在引申义上远远超出了拉丁语的使用范围。

**德语 parallel** 拼写和用法与英语几乎一致（德语直接借了这个词），但德语里"Parallelgesellschaft"（平行社会）是一个带政治色彩的重要概念——指移民群体在主流社会旁边建立了结构完整但互不交融的社会系统。这个词完美地展示了 parallel 最深层的张力：**结构一致，但永远是两个世界。**
