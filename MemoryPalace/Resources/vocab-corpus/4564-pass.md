# pass

---

## 1. 一句话本质

**pass 是那个"穿过去的瞬间"——不是出发，不是抵达，是你正好经过门框时身体两边都被触碰到的那一刹那。** 一切义项都从这个"越过某个界限/节点"的动作生长出来：手递出去是 pass，时间流过去是 pass，考试过线是 pass，山脉的缺口能让你穿过去也叫 pass，甚至死亡——也是"过去了"。

---

## 2. 词源考古

### 词根词缀拆解

pass 的结构异常简洁，没有前缀后缀，就是一个光秃秃的词根。但它的来路并不简单：

- **拉丁语 passus**（一步，步幅）——这是名词，来自动词 **pandere**（展开、伸展）的过去分词。想象一下：你迈出一步，本质上是把腿"展开、伸出去"。所以 passus 的原始画面不是"走路"，而是**"把腿伸展出去的那个动作"**。

- **俗拉丁语 \*passāre**（迈步、走过）——从名词 passus 反向造出的动词。"一步"变成了"走一步"，再变成"走过去"。

- **古法语 passer**（经过、穿过、度过）——诺曼征服（1066）后带进英语。法语给了它更丰富的抽象义：不只是物理上走过，还有"时间过去""状态转变"。

- **原始印欧语 \*pet-h₂-**（展开、伸展）——同根词包括 **patent**（敞开的，专利——"敞开供公众查看的文件"）、**pace**（步伐）、**expand**（ex- + pandere，向外展开）。

### 历史流变

| 时期 | 发生了什么 |
|------|-----------|
| **古典拉丁语** | passus 只是"一步"，一个测量单位（罗马一步 ≈ 1.48米，mille passuum = 一千步 = 一英里 mile 的来源） |
| **俗拉丁语（5-8世纪）** | \*passāre 从名词反造出动词，开始有了"走过、经过"的动态含义 |
| **古法语（11-13世纪）** | passer 大爆发——物理穿越、时间流逝、转手递送、越过标准线，核心抽象义在法语阶段就基本长齐了 |
| **中古英语（13世纪起）** | 进入英语后迅速扩张。14世纪出现"pass away"（死亡委婉语）、"pass judgment"（下判断）。地理上的"山口"（mountain pass）义也在这时期固定——山脉的一个"可以走过去的缺口" |
| **16-17世纪** | 纸牌游戏中出现 "I pass"（我不出牌/跳过），这个"放弃、不参与"的义项是个有趣的翻转——不是"穿过去"，而是"让这一轮从我身边过去" |
| **近现代** | pass 成为英语中义项最密集的单词之一，牛津词典列了 60+ 义项 |

### 文化地层

一个关键的语义漂移值得注意：**"pass for / pass as"（冒充、被当作）**。

这个义项大约在16世纪成型，到19-20世纪的美国获得了沉重的种族含义。"racial passing"指浅肤色的非裔美国人在白人社会中"pass as white"——穿过种族边界，被接受为白人。Nella Larsen 1929年的小说就叫 *Passing*。这个词在这个语境下同时承载了"穿越""被接受""伪装""越界"等全部层次，是 pass 所有义项的一次悲剧性汇聚。

## 3. 故事 / 画面

想象一座古老的石头城门。

城门不宽，刚好一辆马车的宽度。城门本身不移动、不说话，它只做一件事：**存在于那里，作为一条线**。

所有的故事都发生在穿过这道门的那一秒：

商人推着货物穿过去——pass through。守卫在门口检查，摇摇头放行——pass inspection。商人把通行证递给守卫——pass something to someone。一个逃亡的人化了妆，守卫没认出来，放过去了——pass as / pass for。门口刻着一条线标注最低高度，你的马车刚好够高——pass the bar。一个老人的棺材从城门抬出去，再也不回来——pass away。而你站在门洞里犹豫了一下，决定不进去——I'll pass。

城门不动。**动的是你、你的决定、你手里的东西、你的时间。**

这就是 pass 的全部秘密：它永远需要一个"门"——一个界限、一个标准线、一个交接点、一个时间节点——然后某个东西从这边到了那边。

## 4. 多面体：核心义项展开

### 义项一：物理穿过/经过

> *We passed through a small village without stopping.*
> 我们穿过了一个小村庄，没有停留。

最原始、最字面的义项。passus 的"迈出一步"放大到"走过一个空间"。这是所有其他义项的母体。

### 义项二：递、传

> *Could you pass me the salt?*
> 能把盐递给我吗？

物体从一只手**穿过空间**到达另一只手。你的手是起点，我的手是终点，pass 描述的是中间那段旅程。篮球场上的 pass（传球）更生动——球在空中飞过两个人之间的距离。

### 义项三：通过（考试/检验/标准）

> *She passed the bar exam on her first try.*
> 她一次就通过了律师资格考试。

有一条线（标准/及格线），你的表现**越过了那条线**。注意：pass 不关心你过了多远——刚好擦线和远超标准都叫 pass。它只在乎"过没过"这个二元判定。

### 义项四：（时间）流逝

> *Three years passed before they met again.*
> 三年过去了，他们才再次相遇。

时间从你身边"走过去"。英语的时间隐喻很有意思——中文说"时间流逝"（水的意象），英语说 time passes（行走/穿过的意象）。你站着不动，时间是那个经过你身旁的行人。

### 义项五：去世（委婉语）

> *My grandfather passed away last spring.*
> 我祖父去年春天去世了。

死亡 = 穿过了生与死之间的那道门，到了"另一边"。几乎所有文化都有"死亡是一次穿越"的隐喻（渡冥河、过奈何桥），pass away 是这个隐喻的英语版。注意：单独用 "He passed" 也可以表示去世，但加 away 更常见、更温和。

### 义项六：放弃/跳过

> *"Do you want dessert?" "I'll pass."*
> "要甜点吗？""我就算了。"

这个义项的画面：轮到你了，机会来到你面前——你让它**从你身边过去**，不伸手抓。从纸牌游戏来的：轮到你出牌，你说 pass，意思是"这一轮让它过去"。

### 义项七：山口/通道

> *Hannibal led his army through the Alpine passes.*
> 汉尼拔率军穿过了阿尔卑斯山的山口。

名词用法。山脉的一个缺口，是你**可以穿过去**的地方。山口之所以叫 pass，是因为它的功能就是"让人 pass"。功能即名字，粗暴直接。

### 义项八：通行证/入场券

> *You need a backstage pass to get in.*
> 你需要后台通行证才能进去。

名词。一张让你**能够 pass（通过）**的凭证。passport（护照）就是 pass + port（港口）——"让你通过港口的东西"。

## 5. 裂缝标注

### 常见误用场景

**❶ pass 和 past 搞混**

这是最高频的拼写错误。规则很简单：
- **pass** 是动词（或相关名词）："We passed the store."
- **past** 是介词/形容词/名词/副词："We drove past the store." / "in the past"

判断方法：如果你能换成 "walked by"，用 **past**（介词）；如果你能换成 "went through / handed over"，用 **passed**（动词过去式）。

**❷ "pass the exam" vs. "take the exam"**

中文"考试"一个词包含了"参加"和"通过"两个动作。英文要分开：
- *take / sit / write an exam*（参加考试）
- *pass an exam*（通过考试）

"I passed the exam" 不是"我考了试"，是"我考过了"。

**❸ pass away 的语域**

pass away 是**委婉语**，正式且温和。但它不是最正式的表达（正式场合用 "He died" 反而更直接得体），也不适合医学/法律语境（用 die / death / deceased）。它最适合的场景是：对亲近的人谈论亲近的人的死亡——带有关怀和避讳的温度。

### 易混近义词辨析

**pass vs. go through**
- *pass* 强调**越过某个点**，画面是线性的、有一个关键节点
- *go through* 强调**经历某个过程**，画面是有持续时间的

"She passed the checkpoint"（她过了检查站）——一个瞬间动作
"She went through a difficult time"（她经历了一段艰难时期）——一段持续体验

**pass vs. hand / give**
- *pass* 暗含**距离**——东西需要跨越一段空间才能到对方手里
- *hand* 暗含**近距离直接递交**
- *give* 最通用，不暗含任何物理动作细节

"Pass me that wrench"（把扳手递过来）——你们之间有距离
"Hand me that wrench"（把扳手给我）——你就在我旁边

### 中文母语者陷阱

**❶ "通过"的过度映射**

中文"通过"能覆盖 pass 的大部分义项，这导致中文母语者倾向于在所有"通过"语境中都用 pass。但英语中：
- "通过法律" = pass a law ✅
- "通过努力" = **through** effort ❌ 不是 pass
- "通过朋友介绍" = **through** a friend ❌ 不是 pass

**❷ "过"的假朋友陷阱**

中文的"过"和 pass 有大量重叠但不完全对应：
- "吃过了" ≠ "I passed eating"（应说 "I've eaten"）
- "看过这部电影" ≠ "I passed this movie"（应说 "I've seen"）
- "过来" ≠ "pass here"（应说 "come here/over"）

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境说明 |
|------|---------|
| **pass judgment (on)** | 下判断、评判。常带负面暗示——"你凭什么对人下判断"。*Don't pass judgment until you know the full story.* |
| **pass the time** | 消磨时间。注意这不是"时间过去了"（time passes），而是主动地"让时间过去"——一般指做些不太重要的事打发时间。 |
| **pass the buck** | 推卸责任。buck 在这里是扑克牌中标记庄家的筹码，把它递给别人 = 让别人来负责。杜鲁门桌上那块著名的牌子 "The buck stops here" 就是说"责任到我这里为止"。 |
| **pass muster** | 达标、过关。muster 是军队点名检阅。能在检阅中"过关"= 符合标准。 |
| **pass out** | ① 昏倒 ② 分发。两个意思差很远但都常用：昏倒是意识"过去了"；分发是把东西"传出去"给在场的每个人。 |
| **a passing remark/thought** | 随口一说的话/一闪而过的念头。强调短暂性——它从你脑子里"经过"但没停留。 |
| **pass for** | 被当作、冒充。*He could easily pass for a local.* 他很容易被当成本地人。 |
| **in passing** | 顺便提一句。信息像路人一样"经过"你——不是专门说的，是顺路带到的。 |

### 语域标注

pass 是一个**全语域词**——从最日常的口语（"Pass the ketchup"）到最正式的法律/政治语言（"The Senate passed the bill"），它在任何场合都不违和。这种全能性来自它的极度基础性——就像中文的"过"一样，太基本了，没有正式或非正式的标签。

但特定搭配有语域限制：
- **pass away**：半正式，日常表达同理心时用
- **pass muster**：偏书面/正式
- **pass the buck**：偏口语，但商业写作中也常见
- **I'll pass**：纯口语

### 活用示范

> *"The moment passed, and with it, whatever we might have been."*
> 那个瞬间过去了，连同我们本可能成为的一切。

——这里 pass 同时承载了"时间流逝"和"机会错过"两层含义，一个词干了两份活。moment 是那个"城门"，你没有穿过去，它自己关上了。

> *"He had one of those faces that could pass anywhere — forgettable in the most useful sense."*
> 他的脸属于那种走到哪里都不会被注意的类型——在最实用的意义上，令人过目即忘。

——pass anywhere = 在任何地方都能"通过"，不引起注意。把 pass 的"穿越而不被拦截"和"被接受"两个义项叠在一起用。

## 7. 跨语言映射

**中文「过」**——pass 最接近的中文对应物。覆盖范围惊人地相似：过去、过关、过日子、过世、过手。但"过"的方向感更弱——"过"可以是从任何方向的穿越，而 pass 更倾向于**线性的、有一个明确节点的穿越**。另外中文"过"作为助词（"吃过""去过"）表示经验态，这是 pass 完全没有的功能。

**日语「通る」（とおる）**——和 pass 的物理穿越义高度重合（道を通る / pass through the road），但日语另有「渡す」（わたす，递交）和「受かる」（うかる，考试合格）来分担 pass 的其他义项，不像英语一个 pass 包打天下。

**法语「passer」**——pass 的亲妈。现代法语的 passer 义项密度和英语的 pass 几乎一样高（passer un examen = take an exam，注意！法语里 passer un examen 是"参加考试"而不是"通过考试"——"通过"要说 réussir un examen。英语的 pass an exam 反而走了法语没走的路）。这个法英分歧本身就是一个绝佳的假朋友案例。

**拉丁语 transire**（trans- + ire，走过去）——罗马人表达"经过、穿越"更常用 transire 而不是 passus 的动词形式。transire 后来给了英语 **transit**、**transition**、**transient**——这些词和 pass 是表亲关系，共享"穿越/过渡"的语义内核，但来自不同的拉丁语动词。

---

**最后的记忆锚点：** pass 就是那道门框。不管是你走过去、东西递过去、时间流过去、标准线被越过去、还是生命走到了"那边"——永远有一个你正在穿越的点。记住那道城门就够了。
