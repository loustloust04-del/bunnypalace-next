# similar

---

## 1. 一句话本质

**similar 是两个人穿了同款外套但尺码不同——你一眼看出它们"像"，但绝不会认错人。** 它精准地站在"像"和"是"之间的裂缝上：承认相似，同时拒绝等号。

---

## 2. 词源考古

### 词根拆解

```
similar
  ← 法语 similaire
    ← 拉丁语 similis（像的、相似的）
      ← 原始印欧语 *sem-（一、合一、一起）
```

**\*sem-** 这个根只有一个音节，意思也只有一个字："一"。但这个"一"不是数数的一，而是"合在一起、当作一体"的一。它是英语里一棵巨大的家族树的根：

| 后代 | 怎么从"一"变来的 |
|------|------------------|
| **same** | 就是同一个 |
| **seem** | 看起来是一个样 → 看起来像 |
| **simple** | *sem- + *pl-（折叠）→ 折一次 → 不复杂 |
| **single** | 只有一个 |
| **simultaneous** | *simul（同一时间）→ 同时发生 |
| **assemble** | 合到一起 |
| **resemble** | 再一次像 → 相似 |
| **simulate** | 做得跟真的一样 |
| **ensemble** | 合在一起的整体 |

similar 和 simulate 是亲兄弟——一个说"像"，一个说"装得像"。

### 历史流变

**拉丁语阶段**：similis 是个非常日常的词，罗马人用它形容一切"像"的东西。西塞罗用它做修辞学术语，亚里士多德的拉丁译本用它翻译希腊语的 ὅμοιος（homoios，同源词给了英语 homogeneous）。

**进入英语的时间点**：**1611 年左右**，文艺复兴晚期。这个时间很关键——英语里其实早就有表达"像"的本土词了（like, alike, same），similar 是作为一个更"学术、精确"的拉丁借词被引进的。它一进来就带着书卷气，不是街头用语。

**关键转折——数学意义的固化（17 世纪）**：几何学给了 similar 一个极其精确的定义——**形状相同、大小不同**。两个三角形是 similar 的，意思是所有角都相等，但边长按比例缩放。这个数学定义反过来强化了日常用法中 similar 的核心语感：**像，但不等于。**

这是一个罕见的案例：一个词的技术定义比它的日常含义更早被固定下来，然后技术定义的精确性反向塑造了人们对日常含义的直觉。

## 3. 故事 / 画面

超市货架上，两瓶洗发水并排放着。

一瓶是你一直用的牌子。另一瓶——包装几乎一模一样的配色，几乎一样的瓶型，几乎一样的字体。你拿起来一看，品牌名差了两个字母。成分表长得很像但排序不同。价格便宜三分之一。

你手里拿着的这瓶，就是 similar。

它不是假货（那叫 counterfeit）。它不是一样的东西（那叫 identical）。它不是你随便拿的一瓶不相干的东西（那叫 different）。它是——你能说出一串它们相似的地方，你也能说出一串它们不同的地方，而"相似的地方"多到你需要花一点时间才能确认它们不是同一个。

**similar 的本质就是这个"花一点时间"——** 足够像，以至于需要辨认；又足够不同，以至于辨认得出。

## 4. 多面体：核心义项展开

### 义项一：外观/性质上的相似（最常用）

> *The two houses are similar in design but differ in size.*
> 两栋房子设计上很像，但大小不同。

这是 similar 的主场。注意它天然地暗示了后半句——"像，但（有某个地方不一样）"。你说 similar 的时候，听众的大脑自动开始找"那不一样的地方在哪"。

### 义项二：可比较的、同类的

> *We've had similar problems before.*
> 我们以前碰到过类似的问题。

这里 similar 的功能是"归类"——把眼前的东西和过去的经验放进同一个抽屉。不是说问题一模一样，而是说"性质差不多，可以用类似的方式处理"。这是 similar 在工作和学术语境里最高频的用法。

### 义项三：数学/几何上的相似

> *Two triangles are similar if their corresponding angles are equal.*
> 两个三角形若对应角相等，则为相似三角形。

最精确的一个义项。**形状相同，大小不同**——这就是 similar 全部义项的浓缩公式。日常用法只是把这个公式模糊化了。

### 底层统一性

三个义项共享一个逻辑：**存在可对应的结构，但不是同一个实例。** 无论是两栋房子、两个问题还是两个三角形，similar 都在说同一件事——"我能在它们之间画出一条条对应线，但这些对应线不等于等号。"

## 5. 裂缝标注

### 介词搭配：similar **to**，不是 similar **with/as**

这是最高频的语法错误。

- ✅ *This is similar **to** what we discussed.*
- ❌ *This is similar **with** what we discussed.*
- ❌ *This is similar **as** what we discussed.*

记法：similar 来自拉丁语 similis，拉丁语里 similis 搭配的是与格（dative），英语继承了这个方向感，用 to 表达"朝向某个参照物"。

### similar ≠ same

中文"差不多"同时覆盖了 similar 和 almost the same，但英文里这两个词之间有一道硬墙：

| 场景 | 该用 | 不该用 |
|------|------|--------|
| 两杯咖啡都是拿铁，但一杯多加了糖 | similar | same |
| 你和同事穿了完全一模一样的衣服 | the same | similar |
| "我也遇到过这种事" | a similar experience | the same experience（除非真的完全一样） |

### similar vs. alike vs. like

- **similar**：最中性、最通用，适合书面和口语。暗示"有可比性"。
- **alike**：强调"看起来像"，常放在系动词后（*They look alike*），不说 ~~*alike houses*~~。
- **like**：最口语化，可以当介词用（*a car like mine*），similar 不能这么用。

一个检验法：如果你能说"在某个方面 similar"（similar **in** design），那就用 similar。如果你只是在说"看起来像"，alike 和 like 更自然。

### 中文母语者陷阱

中文的"类似"比 similar 的使用范围更宽。中文说"类似的情况下"几乎等于"在这种情况下"，but in English, *in a similar situation* 明确指的是"另一个相似但不同的情况"，不能用来指"这个情况"本身。

另一个陷阱：中文"相似度很高"可以用来形容几乎一模一样的东西，但英文如果两个东西 extremely similar，说话者的潜台词仍然是"它们不是同一个"。如果你想说"几乎一样"，用 **nearly identical** 比 very similar 更精确。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 示例 |
|------|------|------|
| **strikingly similar** | 强调像到令人吃惊 | *The two cases are strikingly similar.* — 用于新闻、法律 |
| **broadly/roughly similar** | 大方向像，细节有差 | *The results were broadly similar across groups.* — 学术论文标配 |
| **bear a similar resemblance** | ❌ 冗余错误搭配 | 这是一个常见的错误——similar 和 resemblance 重复了 |
| **in a similar vein** | "沿着同样的思路" | *In a similar vein, we could also consider…* — 书面过渡语 |
| **a similar fashion/manner** | "以类似的方式" | *The system operates in a similar fashion.* — 技术写作 |
| **similar to** | 最基础搭配 | *Her style is similar to mine.* |
| **not dissimilar** | 文人式双重否定，语气更微妙 | *His views are not dissimilar to hers.* — 暗示"有点像但我不想说得太肯定" |

### 语域

similar 是个全域词——学术论文、新闻报道、日常对话都用，没有正式度限制。但它在**学术和技术写作**中出现频率最高，因为这些场合需要精确地表达"像但不等于"。

日常口语中，人们更常用 **like**（*It's like the one I had before*）而不是 similar（*It's similar to the one I had before*）。similar 在口语里不算怪，但会让你听起来稍微更"认真"一点。

### 活用示范

> *"All happy families are alike; each unhappy family is unhappy in its own way."*
> — 托尔斯泰《安娜·卡列尼娜》开篇

注意托尔斯泰（英译）这里用的是 alike 而不是 similar——因为他要说的是"看起来一样"，而不是"可以拿来比较"。如果换成 similar，这句话会失去那种一刀切的力度，变成一个温吞的社会学观察。

而下面这句，similar 就不可替代：

> *We are building something similar, but not the same—and that difference is the whole point.*

这里 similar 和 not the same 构成一组精确的钳形语义：**像，但那个"不像"的部分才是重点。** 这正是 similar 最有力量的时刻——它承认相似性，同时为差异性腾出空间。

## 7. 跨语言映射

**中文"相似"与"类似"**：这两个词分工微妙。"相似"偏感官/直觉（*长得相似*），"类似"偏逻辑/归类（*类似的案例*）。英文的 similar 一个人干了这两个词的活。这意味着中文母语者使用 similar 时，实际上是在用一个词覆盖两个不同的中文直觉——容易丢失精度，但反过来也意味着你用 similar 很少会用错，因为它本来就宽。

**日语「似ている」**：日语表达"像"时，「似ている」（nite iru）是持续态——"正在像着"，暗示相似是一个被持续观察到的状态，而不是一个静态标签。这个视角很有趣：similar 在英文里是形容词（静态判断），但在日语的对应表达里，相似是一个动态过程。

**拉丁语 similis 的双胞胎——希腊语 ὅμοιος（homoios）**：这两个词在各自语言里几乎完全平行，但它们给英语留下的遗产分了家——similis 走日常路线（similar, resemble, simulate），homoios 走学术路线（homogeneous, homologous, homeopathy）。如果你在论文里需要说"结构上相似"，用 **homologous**；如果只是说"看起来像"，用 **similar**。

---

*similar 是语言里的一面半透明玻璃——你能透过它看到另一边的东西，认出它的轮廓，但你的手摸到的是玻璃，不是那个东西本身。every time you say "similar," you're drawing a line of connection while simultaneously respecting a boundary. 这个词的礼貌，就在这里。*
