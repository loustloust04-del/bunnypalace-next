# except

## 1. 一句话本质

**except 是一把剪刀——你先画了一个圈把所有东西圈进来，然后"咔嚓"剪掉一块。它不是拒绝，是"本来算你的，但我把你摘出去了"。**

---

## 2. 词源考古

### 词根词缀拆解

```
ex-  （拉丁语：向外、出去）
+
capere  （拉丁语：抓、拿、抓取）
=
excipere  →  exceptus（过去分词）
```

字面意思：**从一堆东西里把某个抓出来**。

`capere` 这个词根是个大家族，后代极其繁盛：
- **accept**（ad- 朝向 + capere）= 朝自己抓 → 接受
- **receive**（re- 回 + capere 变体 cipere）= 拿回来 → 收到
- **capture** = 直接抓
- **capable** = 能被抓住的 → 有能力的
- **concept**（con- 一起 + capere）= 一起抓住 → 概念

所以 except 和 accept 是**同根反义**——accept 是"把你抓进来"，except 是"把你揪出去"。这对镜像关系本身就是最好的记忆锚点。

### 历史流变

**14世纪**：从古法语 `excepter` 进入中古英语，直接继承拉丁语 `exceptus` 的含义——"被取出的"。最早的用法是法律场景：一份契约、一道命令覆盖所有人，然后某些人被"excepted"（豁免/排除）。

**15-16世纪**：从动词用法扩展出**介词**和**连词**用法。"All men except the king"——这个结构在这个时期固化下来。动词义项开始退居二线，介词/连词成了日常主力。

**16世纪起**：动词用法发展出"反对、提出异议"的意思（to take exception to something），这个义项保留至今，但已经偏正式/法律语域。

**戏剧性转折**：except 的身份从"动词为主"变成"介词/连词为主"，这在英语词类漂移史上是个典型案例。一个原本表示主动行为（"我把你摘出去"）的动词，变成了一个结构性的连接词（"除了你之外"）——行为感消失了，只剩下逻辑关系。

## 3. 故事 / 画面

想象一间教室。老师站在门口，手里拿着一份名单，大声宣布：

"全班同学——都去操场集合。"

所有人起身。椅子推开的声音此起彼伏。

然后老师的手按住了一个人的肩膀："你——留下。"

**except 就是那只按住肩膀的手。**

它不是"你不属于这个班"——你明明属于，你坐在这里，你的名字在名单上。但在这一刻，在这件事上，你被从集体中摘了出来。

这个画面精准映射了 except 的核心结构：**先有一个全称（everyone / everything / always），然后从中挖掉一块**。没有前面那个"全部"，except 就没有意义。你不能凭空 except——你只能从一个已有的整体里 except。

## 4. 多面体：核心义项展开

### 义项一：介词——"除了……之外"（最高频）

> *Everyone passed the exam **except** Tom.*
> 除了 Tom，所有人都通过了考试。

和"一句话本质"的关系：先画了"所有人通过"这个圈，然后把 Tom 剪出去。

### 义项二：连词——"除了……（这件事）"

> *I'd go with you, **except** I have a meeting at three.*
> 我本来想跟你去的，但三点有个会。

这里 except 引导一个完整的句子，功能接近 but。它的底层逻辑不变：我先给你一个"我会去"的全景，然后从中剪掉一块——那个三点的会是一把剪刀，把"我会去"这个可能性裁掉了。

### 义项三：动词——"排除、豁免"（正式/法律）

> *Present company **excepted**, most politicians are liars.*
> 在座各位除外，大多数政客都是骗子。

这是 except 最古老的用法，动词态。现在几乎只在 "present company excepted" 这个固定搭配里活着。"excepted"——被摘出去的。

### 义项四：动词——"反对、提出异议"（法律）

> *The defense attorney **excepted** to the judge's ruling.*
> 辩护律师对法官的裁决提出异议。

这个义项从"把某物揪出来"引申为"把某个判断挑出来质疑"。现代英语中基本只在法庭语境出现，日常用的是名词形式 **take exception to**（对……表示不满/反对）。

**底层统一性**：四个义项全是同一个动作——**从一个整体中把某个东西摘出来**。介词是摘人/摘物，连词是摘掉一种可能性，动词"豁免"是摘出适用范围，动词"反对"是把一个判断摘出来打问号。

## 5. 裂缝标注

### 🔴 头号陷阱：except vs. except for

很多学习者把它们当成完全可互换的同义词。**不是。**

- **except** 后面跟的东西和前面被排除的东西必须**同类**：
  - ✅ *Everyone left **except** me.* （me 和 everyone 同类——都是人）
  - ✅ *I like all fruit **except** durian.* （durian 和 fruit 同类）

- **except for** 可以跟**不同类**的东西，或用在**句首**：
  - ✅ *The essay was perfect **except for** a few typos.* （essay 和 typos 不同类——一个是整体，一个是细节）
  - ✅ ***Except for** the rain, the trip was great.* （句首用 except for）
  - ❌ ~~**Except** the rain, the trip was great.~~ （句首裸 except 不自然）

**速记**：except 是精确手术刀（同类里切一块），except for 是松一档的说法（"要不是因为……"）。

### 🔴 except vs. besides

**这是中文母语者的经典灾区。**

中文"除了"同时覆盖两个方向：
- "除了他**都**去了" = **except**（排除）
- "除了他**还**有谁去了" = **besides**（追加）

英文把这两个方向拆成了两个词：
- **except** = 减法（从全集里减掉）
- **besides** = 加法（已有的基础上还有）

> *No one came **except** Tom.* → 只有 Tom 来了（别人都没来，Tom 被"除外"）
> *Who came **besides** Tom?* → Tom 来了，还有谁来了？（Tom 之外还有吗）

**检验方法**：把"除了"换成"减掉"还是"加上"——减掉用 except，加上用 besides。

### 🔴 except + 代词的格

*Everyone went **except me** / **except I**?*

正式语法：except 是介词 → 后面跟宾格 **me**。
但你会在口语和某些文学作品中见到 *except I*，因为有人把 except 当连词理解（except [that] I [didn't go]）。

**安全选择**：一律用 **except me / him / her / them**。没人会说你错。

### 🔴 accept vs. except 混淆

发音：
- **accept** = /əkˈsɛpt/（重音在后，第一个音节弱读）
- **except** = /ɪkˈsɛpt/（重音在后，第一个音节稍清晰）

写作中混淆频率极高，尤其非母语者。记住那对镜像：accept 抓进来，except 揪出去。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境说明 |
|---|---|
| **except for** | 松散排除，可句首，可跟不同类事物。"Except for the ending, the movie was good." |
| **except that** | 引导从句，接近 but。"I'd agree, except that the data says otherwise." 偏书面/正式口语 |
| **except when / where / if** | 条件性排除。"I run every day except when it rains." 日常口语高频 |
| **no one / nothing / nobody except** | 强调"只有"。"Nothing matters except this." 注意双重否定效果 |
| **with the exception of** | except 的正式替身，学术/商务写作。"All variables were controlled, with the exception of temperature." |
| **present company excepted** | 固定客套语。"Men are idiots — present company excepted." 半开玩笑 |
| **take exception to** | 名词用法，"对……不满/反对"。"She took exception to his remark." 偏正式 |
| **without exception** | "无一例外"。"Every student, without exception, must attend." 强调无人幸免 |

### 语域

**except** 本身是**全语域通用词**——口语、书面、学术、新闻、法律全场景适用。但它的不同变体有语域偏好：

- 口语日常：*except*, *except for*, *except when*
- 书面正式：*with the exception of*, *excepting*, *save* (古雅)
- 法律专用：*except as otherwise provided*（法律文本里的"除另有规定外"）

### 活用示范

> *I'm a morning person — except I'm not, and I never have been.*

这是一种修辞手法：先立一个论断，紧接着用 except 自己拆掉它。spoken word、脱口秀、Twitter 体常见。except 在这里制造的是一种**自我否定的喜剧节奏**。

> *The room was silent except for the scratch of pen on paper.*

这是文学中经典的"以声衬静"手法。except for 在这里不是逻辑排除，是**画面聚焦**——它告诉你：把你的注意力从"安静"这个大背景收窄到那一点声响上。

## 7. 跨语言映射

**中文"除了"**：如前所述，中文的"除了"是个双向词，同时承载 except（排除）和 besides（追加）的功能，靠后面的"都/也/还"来区分方向。英文把这两个方向硬拆成两个词，这是中文母语者最大的认知错位。

**法语 "sauf"**：功能几乎完全对应 except（介词用法）。*Tout le monde est venu sauf lui.* 所有人都来了除了他。法语 "excepté" 也存在但更正式。

**日语「以外」（いがい）**：*彼以外、全員合格* ≈ Everyone passed except him. 日语的"以外"比英语的 except 更直白——字面就是"以……为外"，在外面的。

**拉丁语 "praeter"**：拉丁语中 except 的对应词，字面义"经过、越过"（走过去不带上你）。这个空间隐喻和英语 except 的"抓出去"是不同的思路：拉丁语是"路过你不停留"，英语是"本来有你但把你揪走"。

---

**收束**：except 的一切用法，从介词到连词到动词到固定搭配，全部回到同一个画面——**那只按住你肩膀的手**。先有一个"全部"，然后有一个"但你不算"。记住这只手，这个词的所有面孔你都能还原。
