# utility

---

## 1. 一句话本质

**utility 是那把你从来不夸但每天都在用的螺丝刀——它不漂亮，不性感，但你拧开任何一个盒子都得靠它。它衡量的不是"是什么"，而是"能干什么"。**

---

## 2. 词源考古

### 词根词缀拆解

```
util-  ←  拉丁语 ūtī「使用、利用」
-ity   ←  拉丁语 -itās → 古法语 -ité → 英语 -ity「……的性质/状态」
```

核心动词 **ūtī** 是个异态动词（deponent verb）——形式是被动的，意义却是主动的。拉丁语里说 *ūtor hōc instrumentō*（我使用这件工具），动词长着被动脸，干着主动事。这个语法怪癖本身就暗示了 utility 的性格：**它不张扬，它被使用，但它是真正在运转的那个东西。**

- **ūtī** → **ūtilis**（有用的）→ **ūtilitās**（有用的性质）
- 经古法语 **utilité** 进入中古英语，14 世纪首次出现在英文文献中

### 历史流变

| 时间 | 事件 | 含义状态 |
|------|------|----------|
| 古拉丁语 | ūtilitās | 纯粹指"有用性"——某事物作为工具的价值 |
| 14 世纪 | 经古法语进入英语 | 保持"有用性、实用价值"的基础义 |
| 18 世纪末 | 边沁（Bentham）创立功利主义 | **关键转折**：utility 被哲学劫持，变成可量化的"效用"——快乐减去痛苦的净值。一个朴素的日常词突然变成了伦理学的度量衡 |
| 19 世纪中叶 | 工业革命 | 第二次语义膨胀：公共基础设施（水、电、气）开始被叫 **public utilities**——因为它们是"人人都要用的东西" |
| 20 世纪 | 计算机时代 | **utility program**——小而专的功能程序，不是主角但不可或缺 |

### 文化地层

最有趣的转折发生在边沁手里。他把一个指向"物"的词（这把锤子有没有 utility）变成了指向"体验"的词（这个行为产生了多少 utility）。经济学接棒后更进一步：utility 变成了一条可以画在坐标轴上的曲线（效用函数）。

一个本来粗糙、实在、摸得到的词——"这东西有用吗？"——被一路抽象成数学符号。但在日常英语里，它从来没丢掉那层"不好看但管用"的泥土气。

## 3. 故事 / 画面

不要想豪华厨房里的铜锅和日本刀。

想一个老旧公寓的 **utility room**——洗衣机在嗡嗡转，热水器在闷声烧水，配电箱嵌在墙里，水管从天花板穿过去。没人装修它。没人在社交媒体上晒它。门常年关着。

但如果它停了——

没有热水。没有电。没有干净衣服。整栋楼每一间漂亮的房间都瘫了。

utility 就是那个房间。它是建筑的心脏，但被塞在最不起眼的角落。它的价值不是被欣赏的，是被消耗的。你注意到它的唯一时刻，就是它坏掉的时刻。

这个画面能帮你记住 utility 所有义项的底层逻辑：**它是背后在运转的东西——不华丽，但一切依赖于它。**

## 4. 多面体：核心义项展开

### ① 有用性、实用价值（最基础义）

> *The utility of this approach has been proven over decades.*
> 这种方法的实用价值已经被数十年验证过了。

与"一句话本质"的关系：最原始的那把螺丝刀——你问的不是它好不好看，而是它能不能把螺丝拧进去。

### ② 公用事业（水/电/气）

> *Utility bills have gone up 30% this winter.*
> 今年冬天公用事业账单涨了 30%。

为什么和①是同一个词：水电气就是那个 utility room——每个人每天都在用，没人在意它怎么来的，直到停了你才想起它。**人人必须用的基础设施 = 最大的"有用"。**

### ③ 经济学效用（边沁和经济学的量化版本）

> *Consumers seek to maximize utility given their budget constraints.*
> 消费者在预算约束下追求效用最大化。

为什么和①是同一个词：经济学把"有用"量化了——你吃第一口蛋糕获得的 utility 远大于第十口（边际效用递减）。本质上还是在问：这东西对你有多少用？只是把答案变成了数字。

### ④ 实用工具 / 功能程序（计算机领域）

> *I wrote a small utility to batch-rename files.*
> 我写了个小工具来批量重命名文件。

为什么和①是同一个词：utility program 就是编程世界的螺丝刀——不是操作系统本身，不是你正在开发的产品，而是帮你完成某个具体任务的小工具。小、专、不起眼、但干活。

### ⑤ 多面手（体育：utility player）

> *He's a utility player who can cover any position in the outfield.*
> 他是个多面手，外场任何位置都能补上。

为什么和①是同一个词：不是最耀眼的球星，但哪里需要就能顶上去——实用性的人格化。教练不会围绕他建战术体系，但没有他球队运转不了。

### ⑥ 形容词用法：功能性的、实用的（不讲究外观的）

> *She drives a utility vehicle — ugly but unstoppable on dirt roads.*
> 她开一辆工具车——丑，但在土路上无可阻挡。

为什么和①是同一个词：utility vehicle 几乎是"不好看但管用"的字面翻译。这个形容词义把 utility 最深层的性格直接暴露了出来——**功能压倒形式。**

## 5. 裂缝标注

### 常见误用场景

**❌ 把 utility 当 "usefulness" 的完美同义词随意替换**

utility 比 usefulness 多一层"可被测量、可被系统性利用"的含义。你可以说 *the usefulness of a friend's advice*（朋友建议的有用性），但换成 *the utility of a friend's advice* 会显得冷冰冰——好像你在算计朋友。**utility 自带一种工具理性的温度。**

**❌ 混淆 utility（不可数）和 utilities（可数，指公用事业）**

- *This has great utility.*（这很有用——抽象概念，不可数）
- *I need to pay my utilities.*（我得交水电费——具体账单，可数复数）

单复数的切换同时是意义的切换，不小心就翻错。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **usefulness** | 更日常、更温暖。"This book has great usefulness" 像在推荐给朋友；"This book has great utility" 像在写论文 |
| **function** | 强调"做什么"（职能、功能）。utility 强调"有多管用"（价值判断）。一个工具的 function 是切东西，它的 utility 是你到底需不需要切这个东西 |
| **benefit** | benefit 是结果——你得到了什么好处。utility 是属性——这个东西本身有多少可用价值。benefit 侧重接收者，utility 侧重提供者 |
| **practicality** | 强调可行性——"能不能做到"。utility 强调有用性——"做到了有没有用" |

### 中文母语者陷阱

**"实用" ≠ utility 的全貌。** 中文的"实用"偏向形容词（这很实用），但 utility 在英文里大量作名词使用，而且经常出现在抽象学术语境中（经济效用、边际效用）。中文母语者容易把所有 utility 都翻译成"实用"，但在经济学和哲学语境里，"效用"才是正确的术语。

**"公用事业" 这个翻译会让人以为 utilities 只指企业。** 但日常英语里 *pay the utilities* 就是交水电费——它指的是服务和账单，不一定指那家公司。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **utility bill** | 水电气账单——日常口语最高频的 utility 用法之一 |
| **public utility** | 公用事业（公司/服务）——新闻和政策语境 |
| **marginal utility** | 边际效用——经济学术语，几乎不会出现在非学术语境 |
| **utility function** | 效用函数——经济学/计算机双栖，极高频术语 |
| **of great/limited utility** | 有很大/有限的用处——偏书面、正式 |
| **utility knife** | 美工刀/万用刀——日常工具名，具象化了 utility 的核心含义 |
| **utility player** | 多面手球员——体育语境 |
| **utility room** | 杂物间/设备间——建筑/家居语境 |

### 语域标注

utility 是一个跨语域能力极强的词——这在英语里并不多见：

- **日常口语**：utility bill, utility room, utility knife ✅ 完全自然
- **学术/经济学**：marginal utility, expected utility, utility maximization ✅ 核心术语
- **哲学/伦理学**：utility（功利主义的核心概念）✅ 无可替代
- **技术/编程**：utility function, utility class ✅ 标准用语
- **新闻/政策**：public utilities, utility companies ✅ 常规用词

**它在正式和非正式场合都不违和，但在不同场合指向完全不同的东西。** 语境决定含义——这是 utility 的超能力，也是它的陷阱。

### 活用示范

> *"The internet has become a utility — like water or electricity, you don't think about it until it's gone."*
> 互联网已经变成了一种公用事业——就像水和电，你不去想它，直到它没了。

这句话同时激活了 utility 的两层含义——公用事业（基础设施）和实用性（不可或缺）——并用它们来描述互联网从"新奇事物"到"空气般存在"的身份转变。

> *"He's not flashy, but his utility to this team is immeasurable."*
> 他不耀眼，但他对这支球队的作用不可估量。

utility 在这里精准地传递了"不好看但管用"的核心语义——如果换成 value 或 importance，那层"朴素但不可或缺"的味道就没了。

## 7. 跨语言映射

**中文"效用"** 是 utility 在经济学/哲学语境中的标准对译，但它只覆盖了抽象的那一半。中文没有一个词能同时指"公用事业"和"有用性"——这两个概念在中文里被完全不同的词承接了。换句话说，utility 在英文里是一个词的六张脸，在中文里被拆成了至少四个不同的词："实用性""效用""公用事业""工具"。

**日文「効用」（こうよう）** 和中文"效用"走位几乎一致——学术味重，日常不会用。日常说"有用"用「役に立つ」，更接近 useful 而非 utility。

**拉丁文原词 ūtilitās** 在西塞罗的修辞学里和 *honestās*（道德高尚）形成对立——"实用但不一定高尚" vs. "高尚但不一定实用"。两千年后边沁的功利主义把这个对立关系翻转了：**utility 本身就是善，不需要 honestās 来背书。** 这场翻转是整个现代伦理学的起点之一。

**法语 utilité** 保留了和英文几乎一样的用法范围——d'utilité publique（公共事业）、utilité marginale（边际效用）——都是从同一个拉丁根分出去又长成近似形状的双胞胎。
