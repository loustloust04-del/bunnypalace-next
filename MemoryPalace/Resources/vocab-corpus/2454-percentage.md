# percentage

---

## 1. 一句话本质

**percentage 是一把尺子上刻了一百格之后，你拿它去量任何东西——不管那个东西本身有多大多小，都被压缩进"一百份里占几份"这个框架里。它不是数字本身，是一种看世界的比例眼镜。**

---

## 2. 词源考古

### 词根词缀拆解

```
per  ·  cent  ·  age
 |       |       |
 |       |       └─ -age：古法语 -age ← 拉丁语 -āticum
 |       |          表示"……的状态/集合/行为结果"
 |       |
 |       └─ cent：拉丁语 centum = 一百
 |          （同根词：century 世纪, centimeter 厘米, centurion 百夫长）
 |
 └─ per：拉丁语 per = 每、通过、按照
    （同根词：per capita 人均, per annum 每年, per se 本身）
```

所以 percentage 拆到底就是："按一百来算的那个状态/那个量"。

### 历史流变

**拉丁语 per centum**（每一百）→ 这个表达在古罗马就有，但当时没有形成固定术语。真正让它变成日常词汇的是中世纪意大利银行家。

**13-15 世纪 · 意大利商业革命**：佛罗伦萨、威尼斯的银行家们在记账时大量使用 "per cento"（每百）来计算利息和汇率。这不是数学家的发明，是账房先生的发明。你借了一百个佛罗伦萨金币，一年还多少？五个。Per cento: cinque。——百分之五利息。

**"%" 符号的演化**也发生在这一时期，极其有趣：
- 最早写作 "per 100" 或 "p 100"
- 然后缩写成 "p cento"，再缩成 "pc"
- 到15世纪，抄写员把它写得越来越潦草，"p" 和分数线混在一起，两个零变成了符号底部的两个圈
- 最终变成了我们今天看到的 **%**

一个纯粹的书写偷懒，造出了全人类最常用的符号之一。

**16世纪**：英语从意大利商业用语中借入 "per cent"（约1560年代），最初写成两个词，纯粹是商业术语。

**1780年代**：英语在 "per cent" 后面挂上了 "-age" 后缀，造出 **percentage** 这个名词。为什么需要这个后缀？因为 "per cent" 更像一个单位（"五 per cent"），而 "-age" 让它变成了一个可以独立使用的抽象名词——"比例本身"、"占比这件事"。就像 mile → mileage（不是说几英里，而是说"里程"这回事）。

### 文化地层

percentage 有一个有趣的语义漂移：它从一个**精确的数学工具**，慢慢长出了一个**日常口语含义**——"好处、利益、意义"。

"There's no percentage in arguing with him."（跟他争没好处。）

这个含义大约出现在19世纪末20世纪初的美式英语中，尤其是赌博和商业语境。逻辑链很清晰：percentage → 你的份额 → 你的利润 → 你的好处。赌场里 "the house percentage" 就是庄家的抽成，从这里引申出"做这件事你有没有抽成/好处"。

## 3. 故事 / 画面

一个中世纪佛罗伦萨的账房，坐在昏暗的灯下，面前摊着一本巨大的羊皮纸账本。他记账记到手抽筋，每一行都要写 "per cento" ——五 per cento、三 per cento、八 per cento。

写到第三百行时，他的笔开始偷工减料。"per" 缩成一竖，"cento" 缩成两个圈，中间一道斜杠。他自己看得懂就行。

五百年后，他随手的潦草，印在了全球每一张银行账单、每一份体检报告、每一个手机电池图标上。

这就是 percentage 的出身：它不是从学者的书房里走出来的，是从记账人磨出茧子的手指间漏出来的。一个关于"一百份里你占几份"的朴素问题，被一支偷懒的笔变成了全人类的公共语言。

## 4. 多面体：核心义项展开

### 义项 A · 百分比（数学意义上的比例）

> *What percentage of the population is vaccinated?*
> 人口中有多大比例接种了疫苗？

最本义的用法。把任何数量压进"一百份"的框架里去衡量。跟"一句话本质"的关系：这就是那把刻了一百格的尺子在量东西。

### 义项 B · 份额、提成（你的那一份）

> *The agent takes a percentage of every sale.*
> 经纪人从每笔交易中抽取一定比例。

从数学比例到商业利益的自然延伸。当我们说"你的 percentage"时，说的不是抽象的数字，而是你口袋里会多出来的那一份。这个含义直接继承了意大利银行家的 DNA。

### 义项 C · 好处、意义（口语，常用于否定）

> *There's no percentage in getting angry about it.*
> 为这事生气没有任何好处。

这是 percentage 最有性格的义项。它把"好处"这个概念量化了——仿佛人做每件事都在心里算一个百分比：回报率为零，那就别干。这个义项几乎只出现在否定句或疑问句里（"What's the percentage?"），因为人们通常只在质疑行为的合理性时才这么问。

### 义项 D · 少量、一部分（含蓄表达）

> *Only a small percentage of applicants are accepted.*
> 只有一小部分申请人被录取。

用"一个小的 percentage"来替代直说"很少"。这里 percentage 充当了一个优雅的缓冲——数据化的表达比直接说"几乎没人"听起来更克制、更客观。

**底层统一性**：所有义项都围绕同一个核心——**按比例从整体中切出一块**。数学切出数字，商业切出利润，日常口语切出"值不值"的判断。

## 5. 裂缝标注

### 常见误用场景

**❌ "percent" 和 "percentage" 混用**

这是最高频的错误。规则其实很简单：
- **percent** 是单位，前面要跟数字："50 percent"
- **percentage** 是名词，前面跟形容词："a large percentage"

```
✗ A high percent of students failed.
✓ A high percentage of students failed.

✗ The percentage is 50 percentage.
✓ The percentage is 50 percent.
```

助记：有数字用 percent，没数字用 percentage。

**❌ "percentage" 不等于"小比例"**

很多人下意识觉得 "a percentage" = "一小部分"。不对。99% 也是 a percentage。如果要表达"少量"，必须加限定词：a **small** percentage。

### 易混近义词辨析

**percentage vs. proportion vs. ratio vs. fraction**

| 词 | 核心区别 | 场景 |
|---|---|---|
| **percentage** | 以100为分母的比例 | "40% 的学生通过了" |
| **proportion** | 部分与整体的关系（不一定是百分比） | "女性占了很大比例" |
| **ratio** | 两个量之间的对比关系 | "师生比是1:20" |
| **fraction** | 强调"一小部分"，且暗示小 | "只有一小部分人关心" |

关键区别：proportion 是最通用的，percentage 是 proportion 的一种具体表达方式。ratio 是两个东西之间的比，不是部分对整体。fraction 自带"小"的暗示。

### 中文母语者陷阱

**⚠️ "百分比" vs. "百分点"（percentage vs. percentage point）**

这是一个中英文共有的致命混淆：

> 利率从 5% 涨到 8%。
> - 涨了 3 **percentage points**（百分点）✓
> - 涨了 3 **percent**（百分之三）✗（这意味着涨到了 5.15%）
> - 涨了 60 **percent**（百分之六十）✓（5 的 60% 是 3，5+3=8）

中文里"涨了三个百分点"和"涨了百分之三"口语中经常混着说，但在英语学术/新闻写作中，percentage point 和 percent 是性质完全不同的东西。弄错了数据会差几个数量级。

**⚠️ 中文"比例"不等于 percentage**

中文说"这个比例很大"可以泛指，但英文 percentage 暗含了"已经或可以换算成百分数"的意思。如果你想泛泛地说"比例"，proportion 是更安全的选择。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 说明 |
|---|---|---|
| **a high/low percentage** | 通用 | 最基础搭配，注意不说 big/small percentage（可以但不如 high/low 地道） |
| **a large/small percentage of** | 通用 | 强调数量多少 |
| **percentage point(s)** | 财经/学术 | 绝对差值，不是相对比例 |
| **express as a percentage** | 学术/教学 | "用百分比来表达" |
| **percentage increase/decrease** | 新闻/商业 | 增幅/降幅的百分比 |
| **what percentage** | 通用 | 提问句式，"占多少比例" |
| **the percentage of... who/that** | 正式写作 | "……中……的比例" |

### 语域标注

percentage 是一个**全语域通行**的词——口语、书面、学术、新闻、日常全能用。它没有正式程度的限制，从央行行长的讲话到妈妈看体检报告都会用。

不过义项 C（"好处/意义"的口语含义，如 "no percentage in it"）偏**非正式口语**，在学术写作中不会出现。

### 活用示范

> *"In this business, the percentage is always with the house."*
> "在这行当里，庄家永远是赢的那个。"

赌场用语，但经常被借用到商业和政治评论中。这里的 percentage 同时踩着"数学比例"和"好处/优势"两个义项，语义双关。

> *"She's playing the percentages — not brilliant, but she won't lose."*
> "她在打安全牌——不出彩，但也不会输。"

"play the percentages" = 按概率行事，不冒险，选统计学上最有利的选项。这个搭配在体育评论和策略讨论中很常见。

## 7. 跨语言映射

**中文"百分比"**几乎是 percentage 的完美对照：百（百）分（分）比（比例）= per（每）cent（百）age（的比例）。结构一模一样，连构词逻辑都对称。这在跨语言对照中是罕见的高度一致。

但中文有一个 percentage 没有的东西：**"成"**。"三成把握"、"七成新"。一成 = 10%，一种以十为单位的粗略百分比系统。英语里没有这个中间档——要么用 percent 精确到个位，要么用 "a third / a quarter" 这种分数表达。中文的"成"是一种模糊但顺手的比例直觉，英语必须绕路。

**日语「割」（わり）**也是类似的十进制比例系统：三割 = 30%。日本棒球里打击率用「割・分・厘」，三割二分五厘 = .325。这套系统比 percentage 更精致，但也更封闭——只在特定文化语境里用。

**拉丁语 "per mille"（千分之）**→ 符号 ‰。当 percentage 的颗粒度不够时就上这个——金融、人口统计学常用。有趣的是，percentage 如此深入人心，以至于人们经常把千分之几的数据也先换算成百分比再理解——"0.3‰" 说了没人有感觉，"0.03%" 大家能直觉理解。这说明 per centum（一百格的尺子）已经成了人类默认的比例感知尺度。
