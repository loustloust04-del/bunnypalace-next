# class

## 1. 一句话本质

**class 是一把分拣刀——罗马国王拿它把人按钱包厚度切成六堆，然后这把刀被借去切了一切：学生、物种、风格、代码对象，甚至"品味"本身。**

这个词的内核不是"类别"，而是**带权力意味的分拣行为**。每一次说 class，底层都有一个隐形动作：有人站在上面，把下面的东西分成"够格的"和"不够格的"。

---

## 2. 词源考古

### 词根拆解

**class** 不可再拆（单语素），但它的拉丁源头有故事：

- **拉丁语 classis**（/ˈklas.sis/）：一群被召集起来的人
- 来自动词 **calāre**（召唤、大声喊），原始印欧语词根 **\*kelh₁-**（呼喊、召唤）
- 同根词：**calendar**（calare → calendae，每月初一由祭司"喊出"的日子）、**claim**（经由古法语，从"喊叫"到"主张"）、**exclaim**

所以 **classis 的本义 = 被喊到一起的一群人**。

### 历史流变：从点名册到阶级

**公元前 6 世纪——罗马起源**

传说中的罗马第六任国王 **塞尔维乌斯·图里乌斯**（Servius Tullius）搞了一件大事：按财产多少把全体公民分成 **六个 classis**，决定你出多少兵、交多少税、有多少投票权。

| classis | 门槛 | 义务 |
|---------|------|------|
| prima（第一等）| 最富 | 出 80 个百人队，全副武装 |
| secunda – quinta | 递减 | 兵力和装备递减 |
| **infra classem**（等外）| 无产者 | 不够格上战场 |

注意最后一行：**infra classem**——"在 class 之下"，连被分类的资格都没有。这些人后来有了个专属名字：**proletarii**（无产者）——对，就是马克思用的那个词。

**所以 class 从诞生第一天起就不是中性的"分类"，而是一套权力排序系统。**

**2 世纪——从人到文学**

罗马学者 **奥卢斯·盖利乌斯**（Aulus Gellius）在《阿提卡之夜》里写了一句影响千年的话：他把好作家叫 **classicus scriptor**（"第一等的作家"），把烂作家叫 **proletarius scriptor**。

这是 **classic**（经典）一词的直接来源——"经典"的本义是"有钱人级别的"，是从财富等级到品质等级的隐喻跳跃。

**16 世纪——进入英语，分裂出"课堂"义**

- 英语从拉丁语直接借入 class，最初就是"一组人、一个等级"
- **耶稣会学校**率先把学生按水平分成不同的 classis（班级），class 的"课堂"义由此而来
- 到 17 世纪，自然科学家（林奈等）把 class 借去做生物分类学术语

**18–19 世纪——社会阶级概念爆发**

工业革命让"阶级"成为炸药词。working class / middle class / upper class 在这个时期固化为英语的基本社会词汇。马克思的 Klassenkampf（阶级斗争）进一步把 class 钉在了权力与冲突的十字架上。

**20 世纪——程序员又借了一次**

1967 年，挪威人搞出了 **Simula** 语言，需要一个词表示"一类对象的模板"。他们选了 **class**——这个词的"分类学"义完美匹配：class 定义属性，instance（实例）继承属性。此后 C++、Java、Python 全部沿用。

### 文化地层小结

```
[被召集的人] → [按财富分的军事等级] → [品质等级/经典]
                                    → [学校班级]
                                    → [科学分类]
                                    → [社会阶级]
                                    → [编程模板]
                                    → [优雅/品味] (classy)
```

一个词，两千五百年，从罗马广场到 Python 终端，核心动作始终没变：**把一堆东西按某种标准切开，然后宣布哪堆在上面**。

## 3. 故事 / 画面

公元前 550 年的罗马。一个巨大的露天广场。

国王的文书官站在高台上，手里攥着卷轴，面前排着一条长队——每个罗马公民都必须走到台前，报出自己的财产。

文书官皱着眉头，大喊一个名字。一个农民走上来，搓着手，报了个数字。文书官拿笔在卷轴上划了一道，冷冷地说：**"Tertia classis."**（第三等。）

农民松了口气——至少他还在名单上。身后传来低声的骚动，那些连名字都不会被喊到的人，缩在队伍最后面，知道自己的归类是：**infra classem**。连被刀切的资格都没有。

两千五百年后，这把刀还在切。

一个高中生走进教室："What class are you in?"（你在哪个班？）
一个社会学家写论文："Class determines access."（阶级决定准入。）
一个程序员敲键盘：`class User: ...`（定义一个模板，所有实例必须服从。）
一个人夸另一个人："She's got class."（她有品味——她是"上等的"。）

场景不同，动作相同：**有人在分，有人被分。**

## 4. 多面体：核心义项展开

### 义项 A：社会阶层

> *"The text appealed to readers across class lines."*
> 这篇文章吸引了不同阶层的读者。

与本质的关系：最直系的后代。罗马按财富分等 → 现代按经济/文化资本分层。class 在这个义项里从来不是中性描述——它自带电压。

### 义项 B：课堂 / 班级 / 一节课

> *"I have a class at nine."*
> 我九点有课。

> *"The class of 2025 broke enrollment records."*
> 2025 届打破了招生纪录。

与本质的关系：学校把学生按水平/年龄"分拣"到不同组，每组就是一个 class。注意 class 既可以指"一群人"（这个班），也可以指"一段时间"（这节课）——容器和内容的转喻。

### 义项 C：类别 / 种类

> *"Dolphins belong to the class Mammalia."*
> 海豚属于哺乳纲。

与本质的关系：科学分类学借用了 class 的"分拣"本能。林奈体系里 class（纲）是 phylum（门）之下的一级。

### 义项 D：品质 / 优雅（常用 classy）

> *"That restaurant has real class."*
> 那家餐厅真有格调。

与本质的关系：直接传承了盖利乌斯的隐喻——classicus = 第一等的。"有 class"= 你看起来像是被分到了最上面那一堆的人。这个义项本质上是**阶级审美的语言化石**。

### 义项 E：编程中的类

> *"`class` defines a blueprint; an object is an instance of that class."*
> class 定义蓝图；对象是该 class 的实例。

与本质的关系：分类学义的精确工程化。一个 class 规定"凡是属于这个类别的东西，必须具备这些属性"——塞尔维乌斯如果写代码，大概就是 `class Citizen(wealth: Int)`。

### 义项 F：等级（交通/服务）

> *"We flew business class."*
> 我们坐的商务舱。

与本质的关系：最赤裸的"按钱分等"——first class / business class / economy class，和罗马六等几乎是同构关系。

## 5. 裂缝标注

### 常见误用

**❌ "I have a class of English"**
→ ✅ "I have an English class" 或 "I'm taking an English class"
class 前面放科目时，科目做定语修饰 class，不用 of 结构（a glass of water 的逻辑不适用于此）。

**❌ 把 class 和 lesson 完全等同**
→ class 侧重"一门课"或"一群学生"，lesson 侧重"一次教学内容"。"I learned a lesson" ≠ "I learned a class"。

### 易混近义词辨析

| 对比 | 区别 |
|------|------|
| **class vs. category** | class 暗含等级高低（first class / lower class），category 更中性客观（把东西放进格子，没说哪个格子更好） |
| **class vs. type** | type 偏日常口语，没有 class 的社会/学术味。"What type of music?" 很随意，"What class of music?" 暗示有高低之分 |
| **class vs. grade** | grade 强调层级评分（A/B/C），class 强调归属群体。"He's in my class"（同班），"He got a good grade"（成绩好）不能互换 |
| **class vs. kind / sort** | kind/sort 最随意，几乎没有分类学或社会学色彩。"What kind of person are you?" 是闲聊；"What class of person are you?" 是挑衅 |

### 中文母语者陷阱

**1. "阶级"vs"班级"vs"课" 的义项切换**
中文用三个完全不同的词（阶级、班级、课）翻译 class 的三个义项。中文思维里这三件事毫无关联，但英语里它们是同一个词——因为底层逻辑相通。不理解这个统一性，就会觉得 class 是个"多义词大杂烩"。

**2. "经典"≠ class**
中文"经典"对应的是 classic（形容词/名词），不是 class。"This is a class movie" 不成立，要说 "This is a classic movie"。

**3. "有品味"的 class 没有冠词**
"She has class" ✅ / "She has a class" = 她有一节课。加不加 a，意思截然不同。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **working class / middle class / upper class** | 社会学、政治、日常——最高频的 class 用法之一，注意通常做形容词时加连字符：working-class family |
| **class action** (lawsuit) | 法律——集体诉讼，一"类"人共同起诉 |
| **world-class** | 新闻/体育——"世界级的"，最高赞美之一 |
| **class of + 年份** | 教育——"XX 届毕业生"，美国文化中有强烈身份认同感 |
| **first-class / second-class** | 交通/邮政/隐喻——头等/二等，隐喻用法："treat someone as a second-class citizen" |
| **class struggle / class warfare** | 政治——阶级斗争，马克思术语的英语版 |
| **class act** | 口语——"了不起的人/事"，褒义 |
| **in a class of its/one's own** | 口语/书面——"独一档"，高于所有分类 |

### 语域

class 是**全语域通吃**的词——口语（"She's got class"）、学术（"class structure"）、法律（"class action"）、编程（`class MyComponent`）、日常（"I have class"）都活跃。正式程度中性偏正式，但 classy 偏口语。

### 活用示范

> *"In a society that claims to be classless, class is the elephant in the room."*
> 在一个自称无阶级的社会里，阶级是房间里的大象。

——三个 class 在一句话里各用不同义项（无阶级的/阶级/等级），展现了这个词的自我指涉能力。

> *"The class clown turned out to be a class act."*
> 班上的小丑后来成了真正了不起的人。

——class clown（班级小丑）和 class act（一流角色）里的 class 分别取"班级"和"品质"义，构成精巧的语义反转。

## 7. 跨语言映射

这是 class 最值得做跨语言对照的地方，因为**中文把它拆成了至少四个毫不相干的词**：

| 英文义项 | 中文 | 映射精度 |
|---------|------|---------|
| 社会阶层 | **阶级**（阶=台阶，级=等级） | 高度对应，但中文"阶级"带更强的政治色彩（马克思术语引入后固化），日常说"阶层"更温和 |
| 班级 | **班** | 精确对应，但中文"班"不含任何"等级"暗示 |
| 一节课 | **课** | 精确对应 |
| 品质/优雅 | **格调、品位** | 近似，但中文没有从"阶级"到"品味"的词内漂移——格调是格调，阶级是阶级 |
| 分类 | **类、纲** | 对应 |

**关键洞察：** 英语 class 保留了从"权力分拣"到"审美判断"的完整语义链条——一个词里能感受到罗马广场、维多利亚客厅和硅谷办公室的叠影。中文则把这条链条切断了，每段给了个独立的名字。这既是中文的精确，也是英文的记忆——class 这个词本身就是一部浓缩的社会史。

**日语** 也有类似的分裂：クラス（kurasu，直接借自英语，主要指班级）、階級（かいきゅう，社会阶级）、品格（ひんかく，品质/格调）。

**法语 classe** 基本保留了英语 class 的全部义项，因为法英两语都从同一个拉丁源继承。但法语里 **classe** 说某人 "avoir de la classe"（有品味）的用法比英语更日常、更高频——法国人对 class 的审美义项更敏感，可能和法国社会对阶级品味的执念有关（布尔迪厄的《区隔》写的就是这个）。
