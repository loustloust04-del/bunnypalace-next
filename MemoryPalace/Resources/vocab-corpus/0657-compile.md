# compile

---

## 1. 一句话本质

**compile 是一个掠夺者的手提箱——从四面八方抢来的东西，塞进一个包里，扣上锁，变成"一件行李"带走。**

不管你是从十本书里摘抄拼成一本新书，还是把人类写的代码压成机器能跑的二进制——底层动作都一样：**从散落各处搜刮，压成一个密实的整体**。

---

## 2. 词源考古

### 词根词缀拆解

```
com-（一起，together）+ pilāre（掠夺；压紧）
```

**pilāre** 这个词根是关键，也是争议所在：

- **一派**认为 pilāre 来自 **pila**（柱子、压实的球状物），本义是"压在一起"——英语 **pile**（堆）就是这个亲戚。
- **另一派**认为 pilāre 来自 **pilus**（毛发），pilāre = 拔毛 = 剥光 = 抢劫掠夺。

两条线索在 compilāre 身上汇合，形成了一个精妙的双重画面：**抢过来，然后压到一起**。

### 历史流变

| 时期 | 含义 | 发生了什么 |
|------|------|-----------|
| 古典拉丁语 compilāre | **掠夺、洗劫** | 这是个贬义词。Cicero 用它描述总督搜刮行省财物 |
| 中世纪拉丁语 compilāre | **从多种来源汇编文本** | 修道院抄书匠从各种手稿里摘录段落，拼成新的合集。"掠夺"的动作结构保留了，但道德色彩从"抢"变成了"博采" |
| 14世纪中古英语 compilen | **编纂、汇编** | 经古法语 compiler 进入英语，已完全中性化。掠夺义消失 |
| 1950年代 compile | **编译（计算机）** | Grace Hopper 团队创造了 "compiler" 一词——把人类语言编写的源代码"汇编压缩"成机器可执行的指令 |

### 文化地层：从小偷到学者

这个词的翻转堪称西方词汇史上最成功的"洗白"之一。

古罗马人说 compilāre，脑子里浮现的画面是：士兵冲进城市，从这家抢一个花瓶，从那家扯一幅壁画，全塞进麻袋扛走。

到了中世纪修道院，同一个词描述的是：修士坐在书桌前，翻开十本手稿，从这本摘一段教父论述，从那本抄一段圣徒传记，汇成一部新的读本。

**动作结构完全一样——从分散的来源中提取，汇聚成一个新整体。** 变的只是道德判断：抢劫变成了学问。

到了 1950 年代，Grace Hopper 需要一个词来命名她的程序——它做的事情是：读入人类写的指令，从各种子程序库里调取对应的机器码片段，拼装成一个可执行文件。她选了 compiler。这个选择精准得吓人：**它确实在"搜刮"各处的代码片段，"压"成一个密实的二进制包。**

## 3. 故事 / 画面

中世纪，一间修道院的抄写室。

桌上摊着七八本手稿，来自不同年代、不同修院。抄写修士的工作不是原创——他从第一本里剪下一段关于草药的记述，从第二本里取一段关于天文的观测，从第三本里抄一段祷告词。他用自己的判断决定顺序、取舍、衔接，最终把这些散落在各处的碎片装订成一本新书。

**这本书里没有一个字是他自己写的，但这本书是他的作品。**

因为他做的事情不是复制——是**选择、排列、压合**。原材料从"分散在七张桌子上"变成了"封在一个书脊下"。

现在把画面快进到一台 1950 年代的计算机前。程序员写了一页纸的 FORTRAN 代码。compiler 做的事和那个修士一模一样：读这一页纸，识别每一行指令，去库里找到对应的机器码片段，按正确的顺序排列好，解决所有内部引用，最后输出一个单一的可执行文件。

**从散到聚，从人能读到机器能跑。中间那个"压"的动作，跨越了一千年没变过。**

## 4. 多面体：核心义项展开

### 义项一：汇编、编纂（从多源收集整理成一个文本/产品）

> *She spent three years compiling a dictionary of regional dialects.*
> 她花了三年时间编纂一部方言词典。

最古老的存活义项。和"一句话本质"的关系最直接：从各处搜刮素材，压成一本书。注意 compile 暗含的前提——**你不是原创者，你是整合者**。compile a dictionary ≠ write a dictionary。前者强调的是"从田野调查、文献、访谈中收集词条然后组织起来"，后者可以是坐在书房里编定义。

### 义项二：汇总、整理（数据/信息/清单）

> *The report compiles data from 200 hospitals across the country.*
> 这份报告汇总了全国 200 家医院的数据。

从"编书"泛化到"编任何东西"。compile a list / compile statistics / compile a report——核心动作不变：**从分散的来源收拢到一处**。这个义项在日常英语中频率最高。

### 义项三：编译（计算机术语）

> *The code compiled without errors on the first try.*
> 代码第一次编译就没报错。

计算机义。源代码（人类可读）→ 目标代码（机器可执行）。这个义项和"掠夺"根源的距离最远，但和"压合"根源的距离最近：编译器确实在做"把高层指令拆散，从底层库里捞出对应的机器码碎片，重新压成一个密实整体"的工作。

### 义项之间的统一性

三个义项的底层公式：

**输入：散落在各处的碎片 → 过程：选择 + 排列 + 压合 → 输出：一个密实的、可独立使用的新整体**

编书是这样，编报告是这样，编译代码也是这样。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 compile 当 write 用**

> ❌ *He compiled a novel about his childhood.*

compile 的前提是**素材来自多个已有来源**。小说是原创的，用 write / compose。如果是"从多篇日记和采访稿中整理出一本回忆录"，那可以用 compile。

**❌ compile 和 compose 混用**

compile 强调"收集整合"，compose 强调"创作构建"。一首交响乐是 composed 的，不是 compiled 的。一张精选辑是 compiled 的，不是 composed 的。

### 易混近义词辨析

| 词 | 核心差异 | 场景对比 |
|---|---|---|
| **compile** | 从多源收集 → 压成整体 | compile a report（从各部门数据汇总） |
| **compose** | 从无到有创作 | compose a letter（自己写一封信） |
| **assemble** | 把部件按结构装配 | assemble furniture（按说明书组装家具） |
| **collect** | 单纯收集，不一定整合 | collect stamps（集邮，不压成新产品） |
| **aggregate** | 数据层面的汇总，偏统计 | aggregate user feedback（汇总用户反馈数据） |

关键区分：**collect 是捡回来放一堆，compile 是捡回来之后还压成了一个新东西。** 你 collect coins 但不 compile coins——因为硬币收回来还是一枚一枚的，没有被"压"成新产品。

### 中文母语者陷阱

**"编译"的"编"会误导。** 中文"编"可以指"编故事""编程序""编辑"，范围很宽。但 compile 的"编"严格限于"从已有素材中汇编"。你"编了一个借口"不能用 compile（那是 make up / fabricate）。

**"汇编"vs"编译"的技术歧义。** 在中文计算机术语里，"汇编"特指 assembly language，"编译"才是 compile。但在非技术语境里，compile 的中文对应恰恰是"汇编"而非"编译"。小心上下文。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 说明 |
|------|------|------|
| **compile a list** | 通用 | 最常见搭配。整理清单 |
| **compile a report** | 职场/学术 | 汇总各方信息写报告 |
| **compile data/statistics** | 研究/新闻 | 汇总数据 |
| **compile a dictionary/anthology** | 出版 | 编纂辞典/选集——compile 最传统的用法 |
| **compile from sources** | 学术 | "从多种来源汇编"——compile 的灵魂搭配 |
| **compile code / compile successfully** | 编程 | 编译代码 / 编译通过 |
| **compile a record/dossier** | 法律/情报 | 整理档案——带一点"搜罗"的味道，最接近拉丁语"掠夺"的气息 |
| **fail to compile** | 编程 | 编译失败——程序员的日常噩梦 |

### 语域标注

compile 是个**中性偏正式**的词。日常口语中不太会说"I compiled a shopping list"（太重了，直接说 made a list）。它的自然栖息地是：

- **学术/出版**：编纂、汇编
- **职场**：整理报告、汇总数据
- **编程**：编译（这个领域里它是日常词，频率极高）
- **新闻**：compile evidence / compile a timeline（记者调查报道常用）

### 活用示范

> *Years of surveillance footage, witness statements, and financial records were painstakingly compiled into a case that finally brought the cartel down.*
> 多年的监控录像、证人证词和财务记录被艰苦地汇编成了一份档案，最终扳倒了这个贩毒集团。

——这句话里 compile 带着它拉丁语祖先的全部力量："从各处搜刮"（监控、证词、财务）+"压成一个致命的整体"（the case）。几乎能闻到"掠夺"的古义。

> *"It compiles" is the programmer's equivalent of "it's alive" — a Frankenstein moment where scattered pieces of logic suddenly become a breathing, running thing.*

——程序员文化里的黑色幽默。"It compiles" 是弗兰肯斯坦式的时刻：零散的代码碎片突然变成了一个能跑的活物。

## 7. 跨语言映射

**中文"纂"** 是 compile 在中文世界里最精确的对应字。"纂修"（纂修国史）、"编纂"（编纂词典）——都是从已有材料中选取、组织、成书。但"纂"在现代中文里已经半死不活了，日常用"编"或"汇总"替代，而这两个词都比 compile 宽泛。

**日语「編纂」（へんさん）** 直接对应 compile 的学术义，用法几乎一致。日语另有「コンパイル」（konpairu）作为计算机术语的外来词。

**拉丁语的原始画面值得保留：** compilāre 在古罗马语境里的"掠夺"义，和中文"搜刮"几乎完美对应——"他把各种材料搜刮到一起"。这个"搜刮"的粗暴感，比"汇编"的文雅感更接近 compile 的词源真相。

---

**最后的记忆锚点：**

下次看到 compile，想那个中世纪修士——桌上摊着七本别人的书，手里拿着剪刀和浆糊，剪剪贴贴，最后装订成一本"新"书。他不是作者，他是**压合者**。从掠夺者到编纂者到编译器，一千年来，compile 干的事从没变过：**从四面八方搜刮碎片，压成一个能独立行走的新整体。**
