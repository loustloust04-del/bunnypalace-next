# commit

## 1. 一句话本质

**commit 是把手里的东西推过门缝——推过去那一刻，你就再也够不着了。** 不管是交出信任、做出行为、还是锁死选择，commit 的内核永远是同一个动作：越过不可逆的临界点。

---

## 2. 词源考古

### 词根词缀拆解

```
com-（一起 / 加强语气）+ mittere（送出、放手、投掷）
```

- **mittere** 是拉丁语里一个巨大的词根家族的祖先。mission（派遣）、missile（导弹——被投射出去的东西）、emit（发射）、submit（sub- 下 + 送 = 从下方递上去 = 屈服/提交）、permit（per- 通过 + 送 = 让它通过 = 允许）、transmit（trans- 跨越 + 送 = 传输）——全是 mittere 的后代。
- **com-** 在这里是强化前缀，不是字面的"一起"。它把 mittere 的"送"加了一层力度：不是随手递，是**郑重地交出去**。

### 历史流变

**拉丁语 committere**（公元前）：最初的意思相当宽——"使结合、使碰撞、使发生"。罗马人说 *committere proelium*（发动战斗），意思是让两支军队"碰到一起"。同时也有"委托、托付"的意思——把某物 *送进* 某人的保管之中。

**古法语 commettre**（12世纪前后）：保留了拉丁语的双面性——既是"托付"，也是"做出（某种行为）"。法语里 *commettre un péché*（犯罪/犯罪过）的用法在这个时期已经稳固。

**中古英语 committen**（14世纪）：进入英语后，最先站稳的两个义项恰好是一正一负——

- 正面：**entrust**（托付）。"I commit my soul to God."
- 负面：**perpetrate**（犯下）。"commit murder / treason."

这两个看似矛盾的义项其实共享同一个动作结构：你把某样东西（你的灵魂/一桩罪行）**从自身推出去、送进世界**。送出去了，就成了既成事实。

**16-17世纪关键漂移：** "commit oneself"出现——把自己送出去，等于 **锁死立场、绑定承诺**。"He committed himself to the cause." 这个反身用法是现代最常用义项"承诺、投入"的直系祖先。

**19世纪：** "commit to an asylum/prison"（把人送进精神病院/监狱）大量出现。这里的 commit 回归了最原始的"把某物送入某个收容之地"。

**20世纪末-21世纪（计算机时代）：** git commit。版本控制系统里的 commit，意思是"将改动正式写入仓库"——你改了一堆文件，但在 commit 之前，这些改动还是浮着的、可撤销的；commit 一敲，它们就被固化进历史记录了。这个用法精准地复活了拉丁语 committere 的原始语义：**郑重地将某物交付到一个不可轻易撤回的存储之中。**

### 文化地层

commit 最戏剧性的特征是它的**道德两面性**：同一个词，既装着人类最庄重的承诺（commit to love, to justice, to truth），也装着最黑暗的行为（commit murder, commit atrocities）。这不是巧合——两者共享的深层结构是 **"不可逆的释放"**。发誓效忠和实施暴行，在语言的眼睛里，都是同一个动作：你把某种东西从自身推入了世界，它就不再只属于你了。

## 3. 故事 / 画面

一扇老式邮局的铜投信口。

你站在那儿，手里攥着一封信。信里写的东西——可能是辞职信、可能是情书、可能是自首书——内容不重要。重要的是那道窄缝。

你把信封对准缝口。推进去一半，信封还卡着，你还能抽回来。这一半的你还没有 commit。

然后指尖最后一推。信封的重量脱离手指，你听到它落进铁箱的闷响。

那声响就是 commit。

不是"我决定了"——决定还在脑子里，可以翻。是"它已经落下去了"——物理性的、不可逆的、你的手现在是空的。

所以 commit a crime：罪行从你手里落进了世界，成了事实。
commit to a relationship：你把自己推过了那道缝，不再给自己留退路。
commit to memory：你把信息推进了记忆的铁箱，让它在那里存着。
git commit：你的改动落进了仓库，成了历史的一部分。

**每一个 commit，都是那声闷响。**

## 4. 多面体：核心义项展开

### 义项一：犯下（做出不可撤回的行为——通常是坏事）

> *He was convicted of committing three armed robberies.*
> 他因犯下三起持械抢劫而被定罪。

和"一句话本质"的关系：行为一旦做出，就像信落进了铁箱——你没法把一场抢劫"取消"。commit 在这里强调的不是道德判断，而是 **既成事实的不可撤销性**。注意：英语里几乎不说 commit a good deed（做好事），commit 的"做出"义项天然偏向严重的、不可挽回的行为。

### 义项二：承诺、投入（把自己锁进某条路）

> *She's not ready to commit to a long-term relationship.*
> 她还没准备好投入一段长期关系。

和"一句话本质"的关系：把自己推进去。你在说 commit to 的时候，暗含的前提是"一旦进去就不容易出来"。所以人们对 commit 会犹豫——不是因为那件事不好，而是因为它意味着关上身后的门。

### 义项三：托付、交付（把某物送入某人/某处的保管）

> *She committed the instructions to memory before destroying the note.*
> 她把指示记在脑子里，然后销毁了纸条。

和"一句话本质"的关系：commit to memory = 把信息推进记忆的铁箱保管。commit someone to prison = 把人送进监狱收容。commit a body to the ground = 把遗体交付给大地。每一个都是"交出去、让那个容器接管"。

### 义项四：拨付、调配（正式将资源投入某处）

> *The government committed $2 billion to disaster relief.*
> 政府拨付了 20 亿美元用于救灾。

和"一句话本质"的关系：钱一旦 commit，就从你的自由资金变成了"已锁定"的资金——你不能再拿它干别的了。和承诺义项同构：资源层面的不可逆。

### 义项五：（计算机）提交、固化变更

> *Make sure the tests pass before you commit.*
> 确保测试通过再 commit。

和"一句话本质"的关系：这个义项对在座各位最亲切。改动在 staging area 时还是暧昧的，commit 是那个"落进铁箱"的动作。而且 git 的设计哲学本身就体现了 commit 的深层语义——一旦 commit，历史就有了这条记录，即使你 revert，那个 commit 依然存在于 log 里。**真正的不可逆。**

## 5. 裂缝标注

### 常见误用场景

**❌ commit to do something**
很多人会说 "I commit to finish this by Friday"。错。commit to 后面接 **动名词或名词**：
- ✅ I commit to **finishing** this by Friday.
- ✅ I'm committed to **the project**.

commit 后面直接跟动词原形（commit + do）只出现在"犯下"义项：commit murder, commit suicide。

**❌ 把 commit 当轻量词用**
"I committed an error" 在语法上没问题，但语感上 commit 自带"严重、正式、不可挽回"的重量。打错一个字不叫 commit an error，那叫 make a mistake。你 commit 的东西，得配得上那扇铜投信口的仪式感。

### 易混近义词辨析

| | commit | promise | pledge | dedicate |
|---|---|---|---|---|
| **核心** | 越过不可逆临界点 | 口头保证 | 正式、庄重的誓约 | 把时间/精力奉献给 |
| **重量** | 重——暗含"退不出来" | 轻——人们经常 break promises | 中到重——有仪式感 | 中——强调持续性 |
| **反悔成本** | 高 | 低 | 高 | 中 |

场景对比：
- "I **promise** I'll be there." — 朋友间随口说的。
- "I **commit** to being there." — 你在表明：我把自己锁定了，不会临时变卦。
- "She **pledged** allegiance to the flag." — 庄严仪式。
- "He **dedicated** his life to science." — 强调长期的奉献，不强调不可逆。

### 中文母语者陷阱

1. **"承诺" ≠ commit 的全部。** 中文的"承诺"只覆盖了 commit 的"承诺/投入"这一张脸。"犯下""托付""拨付"这几张脸在中文里分别对应不同的词，但英语只用一个 commit。不要把 commit 等同于"承诺"——它比"承诺"硬得多、宽得多。

2. **"做"的陷阱。** 中文说"犯罪"自带贬义（犯 = 违反），但 commit 本身没有贬义，贬义来自它后面的宾语。commit murder 的 commit 和 commit to justice 的 commit 是同一个中性动作。中文母语者容易因为"犯"的联想而觉得 commit 本身是负面词。

3. **commit suicide 的语言政治。** 近年英语世界大量讨论：commit 这个词暗含"犯罪"的联想（commit a crime → commit suicide），将自杀等同于犯罪行为，有污名化效果。心理健康领域越来越多地改用 **"die by suicide"** 或 **"take one's own life"**。这是 commit 的"犯下"义项产生的语义辐射——知道就好。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 备注 |
|---|---|---|
| **commit a crime / murder / fraud** | 法律/新闻 | 最经典的"犯下"用法，后面几乎永远是严重行为 |
| **commit to (doing) sth** | 日常/商务/关系 | 承诺投入，最高频的日常义项 |
| **commit to memory** | 书面/正式 | 记住。比 memorize 更有仪式感 |
| **commit resources / funds / troops** | 政治/商务 | 正式调配资源，暗含"一旦投入不能轻易撤回" |
| **fully committed** | 工作/关系 | "全身心投入"——常见于简历和分手对话 |
| **commit oneself** | 正式 | 反身用法，强调是你主动把自己推进去的 |
| **without committing** | 谈判/关系 | "不做出承诺地"——试探阶段的外交辞令 |

### 语域标注

commit 横跨多个语域，但每个义项有自己的领地：
- **"犯下"**：新闻报道、法律文书、正式叙述。口语里说 "he did it" 比 "he committed it" 更自然。
- **"承诺/投入"**：全语域通用——从 "Are you gonna commit?" (口语) 到 "We remain committed to our partners" (企业公关)。
- **"托付"**：偏书面和正式。commit to memory, commit to the earth (葬礼用语)。
- **"git commit"**：技术行话，但已经渗透到程序员的日常隐喻里——"I'm not ready to commit to this architecture" 在技术讨论中兼具字面和隐喻义。

### 活用示范

> *"The moment you commit to the turn, the motorcycle leans with you. Hesitate halfway, and the physics will punish you."*
> "你一旦 commit 进弯道，摩托车会跟着你倾斜。半途犹豫，物理定律会惩罚你。"

——这是 commit 最漂亮的隐喻场景。骑摩托过弯时，你必须全身心倾斜进去，半推半就反而最危险。这精确地映射了 commit 的核心：**要么全力推过去，要么别推。卡在中间最致命。**

> *"Don't commit to a framework before you've committed to understanding the problem."*

——程序员圈子里 commit 的双关：别先选框架（承诺），先把问题搞明白（投入精力去理解）。

## 7. 跨语言映射

**中文"犯"**：只覆盖了 commit 的负面行为义项，而且"犯"自身带贬义（违犯），而 commit 本身是中性动作词。

**中文"托付"**：相当精准地对应 commit 的 entrust 义项，甚至在语感重量上也接近——"托付"也暗含"交出去了就由你了"的不可逆感。

**日语「コミットする」（komitto suru）**：直接借用英语 commit，但在商务日语中几乎只用"承诺/投入"这一个义项，且带有"对结果负责"的强烈暗示。"結果にコミットする"（对结果 commit）——某健身品牌的广告语，让这个词在日本大众文化中和"说到做到"绑定了。

**德语 begehen**：对应 commit 的"犯下"义项——*ein Verbrechen begehen*（commit a crime）。有趣的是 begehen 的本义是"走过、行走"（gehen = go），"犯罪"的隐喻是"走上了那条路"。和 commit 的"推过去"不同，德语的暗喻是"走过去"——**一个是手的动作，一个是脚的动作，但都指向同一个结果：你已经过了那条线。**

**拉丁语 committere** 本身在现代罗曼语族中的后裔也值得一提：法语 commettre、西语 cometer、意语 commettere，全都保留了"犯下"的义项，但"承诺/投入"的义项几乎消失了——那个义项被其他词（法语 s'engager，西语 comprometerse）接管了。**"承诺"义项是英语独自发展出来的演化分支。**
