# repaint

---

## 1. 一句话本质

repaint 是**在旧墙皮上刷新漆的那一道**——旧的不铲掉，新的盖上去，世界看起来焕然一新，但底下的裂缝还在。

---

## 2. 词源考古

### 词根词缀拆解

```
re-  +  paint
再次     涂色
```

**re-**：拉丁前缀，"再一次、重新"。英语里最高产的前缀之一，但 re- 有两种微妙的语感：一种是"修复性的再"（repair, restore——因为坏了所以重来），另一种是"覆盖性的再"（rewrite, repaint——不是因为坏了，是因为想换一层）。repaint 属于后者。

**paint**：从古法语 *peindre*（画、涂），更早来自拉丁语 **pingere**（描绘、着色）。拉丁语的 *pingere* 是个非常肥沃的根，它的过去分词 *pictus* 繁殖出一整个家族：

| 后代 | 含义 | 和 paint 的血缘关系 |
|------|------|---------------------|
| **picture** | 图画 | pictus 的直系 |
| **depict** | 描绘 | de- + pictus，"画下来" |
| **pigment** | 色素 | 用来画的原料 |
| **pictorial** | 图画的 | 形容词化 |
| **Pictor** | 画架座（星座名） | 拉丁语"画家" |

所以 paint 的本质不是"刷墙"，而是**"让颜色附着在表面上"**。刷墙只是它最常见的体力活形态。

### 历史流变

**paint** 进入英语是 13 世纪的事，从盎格鲁-法语 *peinter* 借来的。中古英语写作 *painten*。最初就是"涂颜色"的意思，既可以指画画（艺术），也可以指刷漆（实用）。

**repaint** 作为合成词出现得相当晚——大约 17 世纪。因为在此之前，人们如果要说"重新刷漆"，直接说 *paint again* 就够了。re- 前缀被固化成一个独立词条，说明"重新涂刷"这件事变成了一个足够常见的独立概念——这和欧洲建筑维护文化有关，石造建筑的外墙需要定期粉刷。

**20 世纪末的关键转折：计算机接管了这个词。**

在 GUI（图形用户界面）编程中，**repaint** 获得了一个全新的技术含义：**屏幕重绘**。当浏览器或操作系统需要更新屏幕上的某个区域——因为内容变了、窗口被拖动了、动画要播下一帧了——它执行的操作就叫 repaint。

这个隐喻选择极其精准：屏幕就是画布，像素就是颜料，每次更新就是在旧画面上重新涂一遍。而且和物理世界一样，**repaint 的代价不低**——它需要重新计算每个像素该是什么颜色。前端性能优化的核心议题之一就是"减少不必要的 repaint"。

## 3. 故事 / 画面

一间出租屋。

每换一任租客，房东就来刷一遍墙。不是因为墙坏了——是因为上一个人在墙上留了痕迹。指甲挂过的刮痕、胶带撕下后的印子、某个角落被烟熏黄的一小块。房东不修这些，也不铲旧漆。他只是站在梯子上，蘸满白漆的滚筒从上到下推一遍。

啪，干净了。

但你要是掀开新漆的边缘——那底下是七层颜色。2019 年的米白，2017 年的浅灰，2014 年的奶黄……每一层都是一段别人的生活。repaint 就是这件事：**不处理问题，只刷新表面。** 有时候这就够了。有时候不够——底下的水渍迟早会渗上来。

这个画面同时对应物理和计算机两个义域：浏览器每次 repaint 也不是从零建画面，它是在旧的渲染结果上"刷新"变化的部分。而如果你的 DOM 结构有问题（底下的裂缝），再多的 repaint 也救不了性能。

## 4. 多面体：核心义项展开

### 义项 A：物理层面的"重新刷漆/重新绘画"

最直觉的用法。给旧东西涂上新颜色。

> *We need to **repaint** the fence before winter — the old coat is peeling off.*
> 入冬前得把栅栏重新刷一遍——旧漆已经起皮了。

和"一句话本质"的关系：旧漆起皮 = 底下的问题浮上来了，新漆盖上去 = 覆盖性的再。

### 义项 B：比喻层面的"重新描绘/改写形象"

把 paint 的"描绘"义项激活后，repaint 就变成了"重新塑造某事物的形象"。

> *The documentary **repaints** him not as a villain, but as a man trapped by circumstances.*
> 这部纪录片重新描绘了他——不是一个恶棍，而是一个被环境困住的人。

和"一句话本质"的关系：不是揭露真相，是在旧印象上刷新的一层叙事。底下的事实没变，变的是颜色。

### 义项 C：计算机领域的"屏幕重绘"

GUI 编程中最核心的概念之一。当界面元素的外观需要更新时，系统触发 repaint。

> *Avoid triggering a full **repaint** on every scroll event — batch your DOM mutations instead.*
> 别在每次滚动事件都触发一次完整的重绘——把你的 DOM 变更攒起来批量处理。

和"一句话本质"的关系：屏幕重绘 = 在旧画面上刷新的一层像素。底层结构（DOM/layout）不变，只是重新"涂"外观。

**底层统一性**：三个义项共享同一个结构——**在已有的表面上覆盖新的视觉层，不触碰底层**。无论是墙面、叙事、还是屏幕。

## 5. 裂缝标注

### 常见误用场景

**把 repaint 当"修复"用。** repaint 不修任何东西。它是**外观层操作**。如果墙体有裂缝，repaint 只是让你暂时看不到裂缝。写 "We repainted the relationship" 是个有意味的表达——它暗示你们只是在表面上装没事，没有真正解决问题。如果你想表达"修复"，用 repair / restore / mend。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **redecorate** | 范围更大。repaint 只是刷漆，redecorate 是"重新装修"——可能包括换家具、换窗帘、改布局。你 repaint 一面墙，但你 redecorate 一个房间。 |
| **retouch** | 精度更高。retouch 是"修图/润色"——只改局部瑕疵，不是整面重来。你 retouch 一张照片的一个斑点，但你 repaint 整面墙。 |
| **refinish** | 材质层面。refinish 指重新处理表面涂层（打磨、上清漆、抛光），常用于木头和金属。你 refinish 地板，但 repaint 墙面。 |
| **redraw**（计算机） | 在 UI 编程中，repaint 和 redraw 经常混用，但严格来说：repaint 偏重"重新渲染像素"，redraw 偏重"重新执行绘图指令"。实际使用中差异极小。 |

### 中文母语者陷阱

**"重画"≠ repaint。** 中文的"重画"暗示"从零开始画一幅新的"，但 repaint 的语义核心是**在旧的上面覆盖**，不是另起炉灶。如果你真的要"从头画一张全新的画"，那是 paint a new one / start over，不是 repaint。

**计算机语境下的翻译陷阱。** 中文技术文档常把 repaint 译为"重绘"，这个翻译还算准确。但要注意 repaint 和 **reflow**（重排/回流）是两个不同阶段：reflow 是重新计算布局位置，repaint 是重新绘制外观。改颜色只触发 repaint，改宽高会先 reflow 再 repaint。"重绘"和"重排"千万别搞混。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **repaint the walls/house/room** | 最基本的物理用法，家居维护 |
| **repaint the car** | 汽车美容/修复——车漆补喷或全车改色 |
| **repaint in a different color** | 换颜色重刷——强调"覆盖"性质 |
| **need to repaint** | 口语高频："得重新刷了"，暗示旧漆已经不行了 |
| **trigger a repaint** | 计算机——触发一次屏幕重绘 |
| **avoid unnecessary repaints** | 前端性能优化的经典表述 |
| **repaint the picture/narrative** | 比喻用法——重新描绘某种叙事/形象 |

### 语域标注

- **日常口语** ✅：说 "I'm gonna repaint the bedroom this weekend" 完全自然
- **技术文档** ✅："The browser performs a repaint when CSS properties change" 是标准技术语言
- **正式写作** ✅ 但低频：文学或新闻中更常用比喻义（repaint someone's image）
- **学术** △：偶见于艺术史（repaint an old canvas）和计算机科学

这是一个**语域横跨度很大的词**——从装修工人的嘴巴到前端工程师的文档都用得上，而且在两个场合都不违和。

### 活用示范

> *Every regime change **repaints** history — same events, different palette.*
> 每次政权更替都重新粉刷历史——同样的事件，不同的调色盘。

这个用法把 repaint 的"覆盖性"和 paint 的"palette（调色盘）"意象同时激活，暗示历史本身没变，变的只是当权者选择的颜色。

> *The browser was **repainting** 60 times a second, and each one was a full-page render — no wonder the fan was screaming.*
> 浏览器每秒重绘 60 次，每次都是全页渲染——难怪风扇在尖叫。

技术语境下的活用——"风扇在尖叫"给冰冷的性能问题加了体感。

## 7. 跨语言映射

**中文"粉饰"** 和 repaint 的比喻义高度重叠。"粉饰太平"——用一层白粉（新漆）遮掩真实问题。repaint the narrative ≈ 粉饰叙事。但"粉饰"在中文里几乎只用于贬义，而 repaint 本身是中性的——你 repaint 卧室是完全正常的维护行为，没有任何"掩盖"的暗示。只有在比喻用法中，repaint 才可能带上"粉饰"的意味。

**日语「塗り替える」（ぬりかえる）** 直译就是"重新涂"，和 repaint 几乎一对一。日语里这个词也有比喻义——「歴史を塗り替える」（改写历史）和英语的 repaint history 结构完全平行。有趣的是两种语言独立发展出了同样的隐喻路径：涂料 → 表面 → 叙事覆盖。

**计算机领域** 各语言基本直接借用 repaint 不翻译，或者用直译（中文"重绘"、日语"再描画"）。这个词在技术语境中已经是全球通用术语。
