# evaluation

## 1. 一句话本质

evaluation 是把手伸进一团混沌里，摸出那根叫"值多少"的骨头——不是随便看一眼，是系统性地把价值从事物内部**掏出来**摆在台面上。

## 2. 词源考古

**词根词缀拆解：**

```
e-     +    valu-      +    -ation
(ex-)       (valēre)        (过程/结果)
出、向外     强壮、值得       名词后缀
```

- **valu-**：核心。拉丁语 *valēre*——"有力量、有价值"。这个词根是个大家族的族长：value, valid, valor, prevail, equivalent, available 全是它的后代。原始意象是"站得住"——有力量所以站得住，站得住所以有分量。
- **e- (ex-)**：向外。不是"给予价值"，是"把已有的价值从里面**抽取出来**让你看见"。
- **-ation**：拉丁语动名词后缀，标记"做这件事的过程"或"做完的结果"。

**历史流变：**

```
拉丁语 valēre (强壮/有价值)
  → 古法语 value (价值)
    → 中古法语 évaluer (估定价值) [15世纪]
      → 法语 évaluation [16世纪]
        → 英语 evaluation [1755年首次记录]
```

关键转折：这个词进入英语的时间相当晚——1755年。它不是从日常口语里长出来的，而是被知识阶层从法语里**移植**过来的，一出生就带着正式、系统、专业的气质。这解释了为什么到今天，evaluation 听起来就是比 judgment 正式一个档次——它从来没在街头混过。

**文化地层：**

18世纪进入英语时，evaluation 主要用于财产估值——你有一块地，我来 evaluate 它值多少钱。19世纪扩展到教育和军事——考核学生、评估战略。20世纪它彻底抽象化，成了所有"系统性判断"的通用容器。从"这块地值多少"到"这个人的表现怎么样"到"这个政策的效果如何"——物理的秤变成了心智的秤，但"掏出内在价值"这个动作结构从未变过。

## 3. 故事 / 画面

一个矿石鉴定师的工作台。

面前摆着一块表面看不出名堂的石头。他不是瞄一眼说"不错"就走。他拿起锤子敲开一角看截面纹理，用酸滴上去观察反应，拿放大镜看晶体结构，称重量，测硬度，查比重表。每一步都在从石头**内部**把信息拽出来。最后他在纸上写下一个数字——这块矿石含金量多少、品级几何、市价几许。

这整个过程——不是看表面，而是用方法把内在价值从混沌中剥离出来、量化出来、说清楚——就是 evaluation。

注意：他不是在**赋予**这块石头价值，石头本身有没有金子是客观的。他做的事是**发现并陈述**那个已经在里面的价值。这就是 e-（向外）+ value 的精确含义。

## 4. 多面体：核心义项展开

### 义项一：系统性判断过程

> *The evaluation of the new drug took three years of clinical trials.*
> 这种新药的评估历时三年临床试验。

和"一句话本质"的关系：把药物内在的疗效和副作用——那些藏在分子结构里、必须经过系统测试才能显形的东西——一项项掏出来。

### 义项二：评估的结果（报告/文档）

> *I received my annual performance evaluation yesterday — three pages of detailed feedback.*
> 我昨天收到了年度绩效评估——三页详细反馈。

和"一句话本质"的关系：掏出来的价值凝固成了一份可交付的文档。过程完成后留下的固体产物。

### 义项三：数学/计算中的"求值"

> *The evaluation of this expression at x=2 gives 17.*
> 这个表达式在 x=2 时求值得 17。

和"一句话本质"的关系：表达式里的值是被符号**包裹**着的，你代入具体数字后把那个隐藏的数值**抽取出来**——完全是同一个动作结构：向外取值。

### 义项四：价值判断（略偏正式）

> *Her evaluation of the situation proved remarkably accurate.*
> 她对局势的评判证明惊人地准确。

和"一句话本质"的关系：面对复杂局面，做出"这到底值得担心还是不用管"的判断——从混沌中提取信号。

## 5. 裂缝标注

### 常见误用场景

**❌ 用 evaluation 替代所有"评价"：**
"What's your evaluation of this restaurant?" 语法没错，但过度正式——像穿西装去吃烧烤。日常场合用 opinion 或 take 就好。evaluation 自带"系统化、有方法论"的暗示，随口闲聊用它会很违和。

**❌ 动词形式 evaluate 后面直接跟 about：**
~~evaluate about the results~~ → evaluate the results。evaluate 是及物动词，直接带宾语，不需要介词中介。

### 易混近义词辨析

| 词 | 核心差异 | 场景对比 |
|---|---|---|
| **assessment** | 偏"测量现状"，诊断性质 | 医生做 assessment（诊断你现在什么状况），老板做 evaluation（判断你的表现值几分） |
| **appraisal** | 偏"估价"，常用于资产和表现 | 房产 appraisal（这房子值多少钱）/ performance appraisal ≈ evaluation，但 appraisal 更口语化 |
| **judgment** | 个人主观决断 | evaluation 暗示有标准有流程，judgment 可以纯凭直觉 |
| **review** | 偏"回顾检视"，未必给出价值判断 | code review 是看代码有没有问题，code evaluation 是判断这段代码质量等级 |

### 中文母语者陷阱

**"评价"≠ evaluation。** 中文的"评价"覆盖范围极广——从"你评价一下这道菜"到"历史评价"到"用户评价"全能用。但英文里：
- 餐厅评价 → review / rating
- 用户评价 → feedback / review
- 历史评价 → legacy / reputation / how history judges...
- evaluation 只对应"有系统有方法有标准的那种评估"

见到中文"评价"就写 evaluation 是中式英语重灾区。

## 6. 搭配与语域

**高频搭配：**

| 搭配 | 语境 |
|---|---|
| **performance evaluation** | 职场年度考核，几乎是固定术语 |
| **critical evaluation** | 学术写作中对来源/论点的审视 |
| **risk evaluation** | 金融/工程/医学中的风险量化 |
| **self-evaluation** | 自我审视，教育和心理学中常见 |
| **ongoing/continuous evaluation** | 持续性评估，非一次性 |
| **thorough/comprehensive evaluation** | 强调全面深入 |
| **independent evaluation** | 第三方独立评估，强调无偏见 |
| **summative evaluation** | 教育术语，终结性评估（对应 formative 过程性评估） |

**语域标注：**
- 正式度：**中高**。学术论文、商务报告、医学诊断、教育考核的标配词。
- 不适合的场合：朋友间随口聊天、社交媒体口语化表达。
- 注意：美式英语中 evaluation 在职场语境下频率极高（每个打工人一年至少经历一次 performance evaluation），所以它虽正式但不生僻——是那种"穿衬衫但不打领带"的正式度。

**活用示范：**

> *Three months in, and I'm still withholding evaluation — some things need time to reveal what they actually are.*
> 三个月了，我仍然保留评判——有些东西需要时间才能显露本质。

这里 withholding evaluation 用得漂亮：暂时不把手伸进去掏——承认此刻还不是掏的时候。

> *Every metric is an evaluation compressed into a number, and every number is a lie that tells the truth.*
> 每个指标都是一次评估被压缩成的数字，而每个数字都是一个说出真相的谎言。

## 7. 跨语言映射

**中文"评估" vs evaluation：** 覆盖高度重合，都强调系统性。但中文"评估"可以很轻量（"你评估一下时间够不够"），英文 evaluation 不行——轻量级的场合英文会用 estimate 或 figure out。

**日语「評価」(ひょうか)：** 几乎是 evaluation 的镜像借词——同样可以指过程也可以指结果，同样偏正式。但日语「評価」还承担了"好评/差评"的意思（高い評価 = 高评价），这个用法英文的 evaluation 不太做——英文会说 high rating / favorable review。

**德语 Bewertung vs Auswertung：** 德语把 evaluation 拆成了两个词——Bewertung 偏"赋予价值判断"，Auswertung 偏"从数据中提取结论"。英语的 evaluation 一个词扛了两份活。
