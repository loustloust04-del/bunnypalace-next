# decimal

---

## 1. 一句话本质

**decimal 是人类低头看了一眼自己的十根手指，然后决定用它们丈量整个宇宙。**

它不是一个数学概念——它是一种文明选择：因为我们恰好长了十根手指，所以整个计量系统、货币系统、度量衡系统都被这个生物学偶然锁死了。decimal 的底色是"十进制"，但它的潜台词是"人体决定了数学的长相"。

---

## 2. 词源考古

### 词根词缀拆解

```
decimal
├── decim-  ← 拉丁语 decimus「第十的」← decem「十」
│            ← 原始印欧语 *déḱm̥「十」
└── -al     ← 形容词后缀「与……有关的」
```

**decem** 这个根极其古老，几乎在所有印欧语系里都能认出来：

| 语言 | 词形 | 备注 |
|------|------|------|
| 梵语 | *dáśa* | 印度-伊朗语支 |
| 希腊语 | *déka* (δέκα) | → decade（十年） |
| 拉丁语 | *decem* | → December（原本的第十个月） |
| 古英语 | *tīen* | 日耳曼语支音变，t 对应 d |
| 哥特语 | *taíhun* | 同上 |

一个有趣的语音学线索：英语 **ten** 和拉丁语 **decem** 看起来完全不像，但它们是同源词。印欧语 *d 在日耳曼语支里规律性地变成了 *t（格林定律），所以 d→t，这就是 decem 变成 ten 的路径。**decimal 和 ten 是失散多年的亲兄弟。**

### 历史流变

**公元前——计数的起源**

*\*déḱm̥* 在原始印欧语中就已经是"十"，学界主流观点认为这个词直接来源于手指计数。人类最早的"计算器"就是两只手，数完十根手指就"满"了，需要进位。这不是隐喻——这是字面意义上的"数字"（digit 同时意味着"手指"和"数字"，不是巧合）。

**拉丁语时代——税收与惩罚**

拉丁语 *decimus*（第十的）衍生出两个方向：

- **decimāre**：抽十分之一。最初用于**什一税**（tithe）——上交十分之一的收成。后来被罗马军队借用为一种惩罚手段：**decimation（十一抽杀令）**——每十个士兵抽一个处死，用来惩罚哗变或怯战的军团。这个词今天被泛化成"大量毁灭"，但原义精确得冷酷：不是屠杀，是**按比例抽样处决**。

- **decimālis**：与十相关的。这个形容词在古典拉丁语中并不常用，真正活过来是在中世纪。

**16-17世纪——数学意义的诞生**

关键转折点。1585 年，荷兰数学家 **Simon Stevin** 发表《De Thiende》（《论十进制》），系统性地推广了小数的使用。在此之前，欧洲人用分数、六十进制（巴比伦遗产）、十二进制混着算，日常计算极其痛苦。Stevin 说：**把一切都折算成十的幂次，用一个点隔开整数和小数部分。**

"decimal" 一词在英语中的数学用法大约从 **1600 年代**开始固定下来。1608 年英语首次记录 "decimal fraction"（小数分数）的用法。

**18世纪——法国大革命的野心**

法国大革命不只是政治革命，也是度量衡革命。革命者要把**一切**十进制化：
- 米制（metric system）：成功了
- 十进制时间（一天10小时，一小时100分钟）：失败了
- 十进制日历（一周10天）：失败了

decimal 在这个时期从纯数学概念升格为一种**意识形态**——"理性的、统一的、可计算的世界"的象征。

### 文化地层

最有趣的张力在于：decimal（十进制）在数学上**不是最优解**。

十二进制（duodecimal）更好除——12 能被 2、3、4、6 整除，而 10 只能被 2 和 5 整除。这就是为什么英制单位里到处是 12（一英尺 = 12 英寸，一先令 = 12 便士，一打 = 12 个）。巴比伦人用六十进制——60 的因子更多，这就是为什么我们的时钟是 60 分钟、60 秒。

但十进制最终赢了。不是因为它数学上更优雅，而是因为**人类的手指就是十根**。decimal 这个词本身就是人类生物学对抽象数学投下的否决票。

## 3. 故事 / 画面

一个罗马百夫长站在沙地上画线。

他面前站着一百个士兵——昨天的战斗中，这个百人队溃逃了。军法已定：decimation。

他让士兵们报数。一、二、三……每数到十，那个人被拖出队列。没有争辩的余地，没有考量谁勇敢谁怯懦——**纯粹是位置的暴政**。你站在第十的位置，你就死。

一千五百年后，一个荷兰学者在烛光下写字。他要解决的问题没那么血腥，但同样是关于"十"的切割——他要说服全欧洲：**任何量都可以被切成十份、百份、千份，无限地切下去**。0.1, 0.01, 0.001……每一刀都精确十倍于上一刀。

百夫长的十是一把屠刀——粗暴、整数、一刀切。
Stevin 的十是一把手术刀——可以无限细分，逼近任何精度。

但它们共享同一个根：**decem**。数到十，然后做决定。

这就是 decimal 的全部性格——**以十为刻度去丈量、去分割、去组织**。有时候切的是麦子（什一税），有时候切的是人命（十一抽杀），有时候切的是无穷（小数点后的世界）。

## 4. 多面体：核心义项展开

### 义项一：十进制的（形容词，最常用）

> *The metric system is based on **decimal** units.*
> 公制系统基于十进制单位。

和"一句话本质"的关系：最直接的映射——以十为基数的计数方式。

### 义项二：小数（名词）

> *Pi to two **decimals** is 3.14.*
> 圆周率取两位小数是 3.14。

这个义项是 "decimal fraction" 的缩略。小数点右边的数字——本质上就是"十分之几、百分之几、千分之几"。和本质的关系：**十的幂次在小数点之后继续向下切割**，0.1 是十分之一，0.01 是百分之一。每多一位，就多切一刀。

### 义项三：小数点（= decimal point，口语省略）

> *Move the **decimal** two places to the left.*
> 把小数点往左移两位。

口语中经常省略 point，直接说 "the decimal"。和本质的关系：小数点是"整"与"碎"的分界线——点左边是完整的十进制单位，点右边是被十的幂次切碎的部分。

### 义项四：每一位/每个小数位（引申义）

> *The result is accurate to three **decimal** places.*
> 结果精确到三位小数。

"decimal place" 是精度的度量单位。和本质的关系：每多一个 decimal place，就是多切了一刀——精度提高十倍。

**底层统一性：** 所有义项都指向同一件事——**以十为刻度的切割系统**。形容词义是这个系统本身，名词义是这个系统切出来的碎片，"小数点"是切割的那把刀，"小数位"是你切了几刀。

## 5. 裂缝标注

### 常见误用

**❌ 把 decimal 当成"小数"的万能翻译**

"This number has decimals" 是对的（这个数有小数部分），但 "0.5 is a decimal" 严格说应该是 "0.5 is a decimal number / a decimal fraction"。单独说 "a decimal" 在口语中可以，但在学术写作中要补全。

**❌ decimal ≠ fraction**

decimal 和 fraction 不互斥。0.25 既是 a decimal 又是 a fraction（= 1/4）。decimal 强调的是**表示法**（用十进制小数点表示），fraction 强调的是**概念**（一个不完整的量）。

### 易混近义词

| 词 | 区别 |
|---|---|
| **numeral** | 指数字符号本身（0-9 是 Arabic numerals） |
| **digit** | 指单个数字位（3.14 有三个 digits） |
| **fraction** | 指分数概念（1/3），decimal 是分数的一种表示法 |
| **binary** | 二进制，以 2 为基数（decimal 的竞争对手） |
| **hexadecimal** | 十六进制（hex- 六 + decimal 十 = 十六），缩写 hex |

### 中文母语者陷阱

**"小数" vs "decimal"**

中文"小数"字面意思是"小的数"，会让人觉得 decimal 就是指"很小的数"。但 decimal 的核心不是"小"，而是"十进制"。3.0 也是 a decimal number，尽管它一点都不"小"。

**"十进制"这个翻译本身**

中文"进制"是个极好的翻译——"每满十就进一位"。但 decimal 在英语中还承载了"小数"的含义，而中文的"十进制"和"小数"是两个不挨着的词。英语母语者说 decimal 时，这两个含义是一个词的两张脸；中文母语者容易把它们当成两个不相关的概念。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **decimal point** | 小数点。最基础的搭配，日常/学术通用 |
| **decimal place** | 小数位。"accurate to N decimal places" 是精度的标准说法 |
| **decimal system** | 十进制系统。数学/历史语境 |
| **decimal fraction** | 小数分数（0.75 而非 3/4）。偏学术 |
| **decimal notation** | 十进制记数法。数学/计算机科学 |
| **decimal expansion** | 小数展开（如 1/3 = 0.333...）。纯数学 |
| **recurring/repeating decimal** | 循环小数（0.333...）|
| **decimal-to-binary** | 十进制转二进制。计算机科学入门必修 |

### 语域

**通用词。** 从小学数学课到量子物理论文都能出现。既不高雅也不低俗——它是个**工具词**，在哪个语域都不显得突兀。

唯一的语域限制：在纯口语中，人们更倾向于说具体的数字（"three point one four"）而不是讨论 "decimal" 这个概念本身。decimal 作为讨论对象出现时，语境几乎一定是教学、技术或正式写作。

### 活用示范

> *"In a world of clean decimals, pi is the drunk guy who won't leave the party — 3.14159265... stumbling on forever, never resolving."*
> 在一个干净小数的世界里，π 是那个赖着不走的醉鬼——3.14159265... 永远踉跄着往前走，永远不收场。

> *"The stock dropped to four decimals of relevance."*
> 这支股票跌到只剩小数点后四位的存在感了。（夸张用法——精度越高，数值越微不足道。）

## 7. 跨语言映射

**中文"小数"与"十进制"** —— 如前所述，英语用一个词 decimal 统摄的两个概念，中文拆成了两个不搭界的词。这不是翻译问题，是**概念切割方式不同**。英语使用者眼中，"小数"和"十进制"是一枚硬币的两面（小数就是十进制在整数以下的延伸）；中文使用者更容易把它们当成两个独立的数学工具。

**法语 *décimal*** —— 直系后裔，用法几乎一致。法国人对这个词有额外的感情——法国大革命是十进制全球化的最大推手，米制就是法国人送给世界的礼物（不管世界要不要）。

**日语「十進法」(じっしんほう)** —— 和中文"十进制"一样，只覆盖了 decimal 的"十进制系统"义项。小数的说法是「小数」(しょうすう)，和中文同源。

**拉丁语遗产链** —— decimal 属于一个庞大的拉丁语家族：
- **December**（十二月）：古罗马历法的第十个月（后来加了 January 和 February，挤到了第十二位，但名字没改）
- **decimate**（大量毁灭）：原义"杀十分之一"
- **dime**（一角硬币）：美元的十分之一
- **dean**（院长/系主任）：源自希腊语 *dekanos*，原义"管十个人的头头"
- **dozen**（一打）：这个倒是反过来——源自拉丁语 *duodecim*（二加十 = 十二），是 decimal 系统里的叛徒

---

这个词的全部故事浓缩成一句话就是：**你的手有十根手指，所以你的文明选择了十进制，所以小数点后面的世界长成了现在这个样子。** 一个生物学事实，塑造了整个数学表达系统。Decimal 不只是个数学术语——它是人类身体在抽象世界留下的指纹。
