# repeat

---

## 1. 一句话本质

**repeat 是脚步折返——走出去，再走回起点，然后沿同一条路再走一遍。** 不是原地踏步，是有一个"回去"的动作藏在里面。每一次 repeat，都先有一次无声的返回。

---

## 2. 词源考古

### 词根词缀拆解

```
re-    +   pet(ere)
再/回      冲、奔、扑、寻
```

- **re-**：拉丁前缀，"回、再"。这个太常见不多说。
- **petere**：拉丁语动词，意思远比你想的凶猛——**"冲过去、扑向、攻击、寻求"**。来自原始印欧语词根 ***pet-***，核心含义是"飞冲、猛扑"。

所以 **repetere** 的字面意思不是温柔的"再说一遍"，而是——**"冲回去再来一次"**。

### petere 的家族：一棵凶猛的树

这个词根藏在一堆你认识的词里，而且每个都带着"冲/扑/求"的底色：

| 词 | 拆解 | 字面义 |
|---|---|---|
| **compete** | com-(一起) + petere(冲) | 一起冲向同一个目标 → 竞争 |
| **appetite** | ad-(朝向) + petere(扑) | 朝食物扑过去的冲动 → 食欲 |
| **petition** | petitio(寻求) | 去寻求、去请求 → 请愿 |
| **impetus** | in-(向内) + petere(冲) | 冲进去的力量 → 冲力、推动力 |
| **perpetual** | per-(穿过/始终) + petere(奔) | 始终在奔跑、不停歇 → 永恒 |
| **centripetal** | centri-(中心) + petere(奔) | 朝中心奔去 → 向心的 |

看出来了吗？repeat 和 appetite 是亲兄弟——一个是"再冲一次"，一个是"朝那东西冲过去"。这个家族的气质是**主动的、带动能的**。

### 历史流变

1. **拉丁语 repetere**（公元前）：含义极宽——"夺回、索回、攻击第二次、回忆、重新走过一条路"。注意"夺回"这层意思：罗马法里 *repetere pecuniam* 是"追回欠款"。
2. **古法语 repeter**（13世纪）：含义收窄到"重新说、排练"。法律里保留了"追诉"义。
3. **中古英语 repeten**（约15世纪）：进入英语时，主要带着"再说一次""再做一次"的意思。"夺回""攻击"义基本脱落。
4. **现代英语 repeat**（16世纪至今）：稳定为"重复做/说"。名词用法（a repeat, on repeat）是后来发展出来的。

**关键漂移**：从"猛冲回去夺"变成"平静地再来一遍"——暴力感全部蒸发了。这就像一个年轻时打架的人，老了变成一个在公园里绕圈散步的老头。路径还在，力道没了。

### 文化地层

一个有趣的分岔：法语里 **répéter** 至今保留了"排练"的意思（*une répétition* = 一次排练），而英语的 repeat 没走这条路——英语用的是 rehearse。所以法国人说"我们去 répétition"，不是去重复，是去排练。同一个词，过了海峡就换了脸。

## 3. 故事 / 画面

一个唱片的针——到达唱片末尾，抬起来，**被一只手拨回去**，放到起点的沟槽里，然后沿着同样的螺旋轨迹再走一遍。同样的旋律、同样的沙沙声、同样的杂音，一圈一圈。

这就是 repeat 的物理结构：**不是复制一份新的，是回到原处，沿原路再走。** 唱片本身没变，针走的路没变，但每一次回到起点的那个"啪嗒"——那是 re- 的声音。

这也是为什么 **on repeat** 这个短语天然带着一种机械感、一种不由自主的味道：不是你想走，是有一只手把你拨回去的。

## 4. 多面体：核心义项展开

### 义项 A：再说一遍（最基础义）

> *Could you repeat that? I didn't catch it.*
> 你能再说一遍吗？我没听清。

→ 回到刚才的起点，把同样的话再"走"一遍。最直觉的用法。

### 义项 B：再做一遍 / 重复动作

> *She repeated the experiment three times to confirm the results.*
> 她把实验重复了三次来确认结果。

→ 回到实验的初始状态，沿同样的步骤再走。科学语境里的 repeat 强调的是**条件不变、路径不变**。

### 义项 C：历史/模式的重演

> *History doesn't repeat itself, but it often rhymes.* — 常被归于马克·吐温
> 历史不会重复自身，但常常押韵。

→ 这是 repeat 最有哲学味的一面：不是有人按了回放键，而是某种结构性力量把事物拨回了类似的轨道。repeat 在这里暗示一种**不可避免性**。

### 义项 D：名词——重播/重复出现的事物

> *The show is a repeat — I've seen this episode.*
> 这集是重播的，我看过了。

→ 那个"再走一遍"的结果本身变成了一个东西：一个 repeat。注意这个名词用法带着轻微的贬义——"又是这个，没新的了"。

### 义项 E：（纺织/音乐/设计中的）重复单元

> *The wallpaper has a 24-inch repeat.*
> 这壁纸的图案循环单元是 24 英寸。

→ 一个图案走完一段路，回到起点，再走同样一段。repeat 在这里是那个**被反复走过的最小单元**。音乐里的反复记号 𝄇 也是这个逻辑。

**底层统一性**：所有义项都共享同一个动作结构——**回到起点 → 沿原路再走**。区别只在于"走"的是嘴巴（说）、手（做）、时间（历史）、还是图案（设计）。

## 5. 裂缝标注

### 常见误用

**❌ "repeat again"**
严格来说是冗余的——repeat 里已经有"再"了。但口语中极其常见，已经成了半合法表达。正式写作里避免，口语里没人会纠你。类似中文"再重复一遍"——也冗余，但大家都说。

**❌ 把 repeat 当 "replay" 用**
> ❌ *Can you repeat the video?*（想表达"回放视频"）
> ✅ *Can you replay the video?*

repeat 通常用于言语和行为，机器回放用 replay 更准确。

### 易混近义词辨析

| 词 | 核心区别 | 场景 |
|---|---|---|
| **repeat** | 主动地再做/再说 | "请再说一遍" / "重复实验" |
| **recur** | 自己又发生了（无主语控制） | "头痛反复发作" → *The headache recurred.*（你没让它复发，它自己来的） |
| **replicate** | 精确复制（科学/技术语境） | "复制实验结果" → *replicate the findings*（强调精确还原条件） |
| **reiterate** | 再次强调（通常用于观点/立场） | "我再强调一下" → *Let me reiterate*（比 repeat 正式，带"我知道说过了但这很重要"的语气） |

**一句话区分**：repeat 是你按回放键，recur 是它自己跳回来，replicate 是你拿尺子量着做一个一模一样的，reiterate 是你拍桌子再说一遍。

### 中文母语者陷阱

**"重复"≠ repeat**——中文的"重复"经常带贬义（"你在重复啊""内容太重复了"），但英文的 repeat 本身是中性的。*Could you repeat that?* 一点不礼貌问题都没有，而中文说"你重复一下"听着就怪，通常说"再说一遍"。

**"复读机"**——中文互联网的"复读机"（无脑重复别人的话）翻成英文不是 repeater（这是电子信号中继器），口语里更接近 *parrot*（鹦鹉学舌）。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **repeat the process / procedure** | 技术/操作文档——"重复该流程" |
| **repeat offender** | 法律——累犯。offense 的"冲回来再犯"，和词源里的"攻击"义暗暗呼应 |
| **on repeat** | 日常口语——循环播放。*I've had this song on repeat all day.* |
| **repeat after me** | 教学——"跟我念"。全世界英语课堂最高频的句子之一 |
| **history repeats (itself)** | 评论/议论——历史重演。几乎是固定表达 |
| **repeat performance** | 口语/新闻——同样的表现再来一次（可褒可贬） |
| **repeat prescription** | 英式英语/医疗——续方（不用再看医生，直接拿同样的药） |
| **bear repeating** | 正式——值得再说一遍。*It bears repeating that…* |

### 语域

**全域通吃。** 这是英语里最"透明"的词之一——日常对话、学术论文、法律文书、音乐术语、编程（repeat loop）都用。没有正式度限制，没有语域壁垒。正因为如此，它几乎没有"风格感"——你不会因为用了 repeat 而显得特别书面或特别口语。

### 活用示范

> *"The mistake that keeps repeating is not the mistake itself — it's the refusal to see the pattern."*
> 一直在重复的错误本身不是错误——拒绝看到这个模式才是。

这种用法里 repeat 的主语是抽象事物（mistake），带出了"自我重演"的哲学感——本来需要人来 repeat 的东西，变成了自己在 repeat，暗示一种结构性的宿命。

> *She caught herself repeating her mother's words — the exact ones she'd sworn never to say.*
> 她发现自己在重复母亲的话——正是她发誓绝不会说的那些。

这是 repeat 最有叙事力的用法之一：跨代重复。一个人变成了她抗拒的人——repeat 在这里不是机械的"再说一遍"，是命运的回旋。

## 7. 跨语言映射

**中文"重复"**：如前所述，"重复"比 repeat 更容易带贬义色彩。repeat 的中性-积极用法（"请重复""重复实验"）在中文里更自然的对应其实是"再来一遍""重新做一次"——动作感更强，没有"冗余"的暗示。

**日语「繰り返す」(kurikaesu)**：字面是"抽回来再翻转"，画面感极强——像抽丝一样把线拉回来再绕一圈。和 repeat 的"回到起点再走"异曲同工，但日语版本多了一层"缠绕"的触感，更像毛线团而不是唱片针。

**法语 répéter**：前面说过，法语保留了"排练"义。一个法国演员说 *je répète*（我在 répéter），意思是"我在排练"，不是"我在重复自己"。英语的 repeat 丢掉了这层含义，但如果你想想——排练本质上不就是把同一段反复走，直到走熟吗？repeat 的骨架还在那里。

**拉丁语 iterum**（"再一次"）→ 英语 **reiterate**：拉丁语另起炉灶造了一个"再"，没用 repetere。所以 repeat 和 reiterate 在英语里是两条拉丁血脉的后裔——repeat 带着"冲回去"的动能，reiterate 带着"再走一轮"的沉稳。

---

**收束**：repeat 这个词的全部秘密就在那个被人遗忘的 petere 里——它不是一个温吞的"再来"，它骨子里是一次**折返冲刺**。每一次 repeat，都有一个你看不见的急刹车、一个掉头、一次重新起跑。那个唱片针被拨回起点时的"啪嗒"——记住那个声音，你就记住了这个词。
