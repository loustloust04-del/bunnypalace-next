# pretend

---

## 1. 一句话本质

**pretend 是在真相前面拉一道幕布——你知道幕布后面是什么，但你选择让别人（或自己）只看到幕布上画的那个版本。**

不是"不存在"，是"存在，但被挡住了"。这块幕布可以是恶意的伪装，也可以是孩子过家家时那块快乐的花床单。

---

## 2. 词源考古

### 词根词缀拆解

```
pre-  （拉丁 prae-：在前面，在……之前）
tend  （拉丁 tendere：拉伸、伸展）
```

**pretend = 在前面拉伸一样东西 = 把什么东西撑开挡在前面。**

这个 -tend 家族极其庞大，每个成员都是"拉"的不同方向：

| 词 | 拉丁构成 | 拉的方向 |
|---|---|---|
| ex**tend** | 向外拉 | 把东西拉长、扩展 |
| in**tend** | 向内拉（瞄准） | 把注意力拉向目标 |
| at**tend** | 拉向（朝某人拉近） | 关注、照料 |
| con**tend** | 一起拉（拔河） | 竞争、争辩 |
| dis**tend** | 往两边拉 | 膨胀 |
| pre**tend** | 在前面拉 | 挡住真相 |

所以 pretend 的物理画面是：你拿起一块布，在别人面前 **撑开**，让它成为别人看到的全部。

### 历史流变

**拉丁语 praetendere**（公元前）：
最初是纯物理动作——"在前面伸出、展开"。比如罗马人说"把盾牌 praetendere（举在身前）"。没有任何欺骗含义。

**中世纪拉丁语 → 古法语 pretendre**（12-13世纪）：
含义从物理动作漂移到抽象——"把一个理由/声明摆在前面"。法语里 prétendre 至今的核心义仍是 **"声称、宣称"**，而不是"假装"。法国人说 "Il prétend être expert"，意思是"他声称自己是专家"——可能是真的，也可能是假的，这个词本身不判断真伪。

**中古英语（14世纪起）**：
英语从法语借入后，最初也是"声称"的意思。"The Duke pretends the crown" = 公爵声称王位归他所有。这里没有"假装"的意味，是正经的政治宣言。

**关键转折——15-16世纪**：
英语开始给 pretend 加上一层暗示：**你声称的那个东西，可能不是真的**。从"宣称"滑向"虚假宣称"，再滑向"装出来的"。这个语义恶化（semantic deterioration）大约花了两百年完成。

到莎士比亚时代，pretend 已经基本定型为"假装"——但"声称"的古义还没完全消亡。

### 文化地层：pretender 的政治余震

**Pretender**（王位觊觎者）保留了这个词最古老的灵魂。英国历史上的 "Old Pretender"（老觊觎者）和 "Young Pretender"（小觊觎者）——詹姆斯党人——并不是"假冒者"，而是"宣称自己才是合法继承人的人"。这个词在政治语境里是中性的，取决于你站哪边：你的 pretender 是我的 rightful king。

这是 pretend 最迷人的化石层：它提醒你，这个词最初不带道德判断。"在前面撑起一面声明"——至于这声明是真是假，那是后来的事。

## 3. 故事 / 画面

一个五岁的小孩拿着纸板做的宝剑，站在沙发垫搭成的城堡里，对你大喊："我是骑士！你是龙！"

她知道自己不是骑士。你知道你不是龙。纸板不是钢，沙发垫不是城墙。但在她撑起来的那个世界里——那块她在现实前面拉开的幕布上——一切都是真的。她不是在"骗"你。她是在 **tend**（撑开）一个世界，然后邀请你走进来。

现在换一个场景。

一个成年人坐在饭桌对面，笑着说"我挺好的"。他的眼眶是红的。他知道自己不好。你也知道。但他选择在"不好"前面拉起一道叫做"挺好"的幕布。这一次，幕布不是邀请，是屏障。

**同一个动作——在前面撑起一样东西。区别只在于：你撑的是一扇窗，还是一堵墙。**

这就是 pretend 的全部频谱：从孩子的魔法，到成人的面具。

## 4. 多面体：核心义项展开

### 义项 A：假装、佯装（最高频）

> *She pretended not to hear him, but her hands were shaking.*
> 她假装没听到他的话，但手在发抖。

"在前面拉起幕布"——幕布上画的是"我没听到"，幕布后面是颤抖的手。这是 pretend 最核心的用法：你知道真相是什么，但选择展示另一个版本。

### 义项 B：（孩子）假扮、过家家

> *Let's pretend we're astronauts and the bed is our spaceship.*
> 我们假装自己是宇航员，床是飞船吧。

同样是"在前面拉幕布"，但这次的幕布是游戏规则，不是谎言。所有参与者都知道幕布是幕布，而且自愿走进去。Pretend 可以做形容词用：**a pretend sword**（假装的剑），**pretend money**（假装的钱），偏口语/童趣。

### 义项 C：声称、自称（正式/书面，残留古义）

> *I don't pretend to be an expert on this topic.*
> 我不敢自称是这个领域的专家。

这是 pretend 最古老的灵魂露出的尾巴。注意这里的 pretend 不是"假装"，而是"宣称"。"I don't pretend to understand" = 我不敢说我懂。这个用法在正式英语里还活着，但很多学习者不认识它。

**统一性**：三个义项的底层逻辑一模一样——**在真相前面撑起一个版本**。A 是对别人撑，B 是大家一起撑着玩，C 是对自己撑（或者谦虚地说"我不撑"）。

## 5. 裂缝标注

### 常见误用

**❌ pretend 后面直接加名词当"伪造"用**
> ~~He pretended the documents.~~

pretend 不等于 forge/fake。你不能"pretend 一份文件"。你可以 pretend **that** the documents were real，但不能把 pretend 当及物动词直接作用于实物。

**❌ 把 pretend 用在机器/系统上**
> ~~The software pretends to be loading.~~

pretend 暗示 **有意识的选择**。软件不会"假装"在加载——它要么在加载，要么在显示一个加载动画（simulate）。对无意识主体，用 simulate / mimic / appear to。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **pretend** | 知道真相但选择呈现另一个版本。重点在"拉幕布"。可以是善意的（过家家），可以是恶意的（欺骗） |
| **feign** | 比 pretend 更书面，更冷，更有控制力。feign 是精心设计的假象——feign surprise（装出惊讶的样子），带有表演技巧的含义 |
| **fake** | 比 pretend 更粗暴直接，口语感更强。fake 是"造假"，指向结果（一个假的东西），pretend 指向过程（一个假装的行为） |
| **simulate** | 中性技术词，不含道德判断。simulate 是"模拟"——可以是飞行模拟器，也可以是模拟一种症状。没有"欺骗"的暗示 |
| **act** | "表演"——可以是舞台上的（中性），也可以是生活中的（接近 pretend，但 act 更强调外在表现，pretend 更强调内在的"我知道这不是真的"） |

**场景对比**：
- 小孩拿棍子当枪：**pretend**（过家家，双方都知道）
- 间谍伪造一份护照：**fake**（造出实物）
- 面试时装出自信：**feign / pretend**（feign 更精密，pretend 更日常）
- 用软件模拟地震效果：**simulate**（技术行为，无欺骗）

### 中文母语者陷阱

**"假装"≈ pretend，但不等于 pretend。**

中文的"假装"几乎总是带贬义或至少带"不真实"的暗示。但 pretend 在 **义项 B**（过家家）和 **义项 C**（声称）中是中性甚至正面的。

- "Let's pretend!" 翻译成"我们来假装吧！"在中文里听着怪怪的，但英文里这是孩子最自然的一句话。
- "I don't pretend to know everything" 翻译成"我不假装知道一切"会误导——这里的 pretend 是"自称"，不是"假装"。正确翻译是"我不敢妄称无所不知"。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **pretend to be** + 身份 | 最基础的结构：pretend to be asleep / pretend to be brave / pretend to be someone else |
| **pretend (that)** + 从句 | pretend that nothing happened（装作什么都没发生） |
| **pretend not to** + 动词 | pretend not to care / pretend not to notice（装作不在意/没注意到） |
| **stop pretending** | 别装了——戳破幕布的动作 |
| **let's pretend** | 游戏邀请：我们来假装…… |
| **just pretending** | 安慰/解释：别怕，我只是装的 |
| **can't pretend** | 承认：I can't pretend I'm not disappointed（我没法假装不失望） |
| **pretend it never happened** | 默契协议：当这事没发生过 |

### 语域

pretend 是一个 **全语域通吃** 的词——从幼儿园到法庭都能用。它没有正式程度的限制，这在英语里其实不太常见（大多数词会偏书面或偏口语）。

不过要注意：义项 C（声称）偏正式/书面，日常口语里几乎不用。

### 活用示范

> *"We're all just pretending to be adults, aren't we?"*
> "我们都在假装自己是大人，不是吗？"

——这句话在英语世界几乎是一种共识性的自嘲。它精准地抓住了 pretend 的双重性：我们知道幕布后面是什么（一个不确定、不成熟、还在摸索的人），但我们每天早上起来，依然选择把那块叫"成年人"的幕布撑起来。

> *"I'm tired of pretending that this is fine."*
> "我已经装不动'这没事'了。"

——当代英语里极高频的情绪表达。pretend that this is fine 已经变成了一个 meme 级的短语（配合"This is fine"着火狗的表情包），指一种崩溃前最后的体面。

## 7. 跨语言映射

**法语 prétendre**：同源词，但含义停留在更古老的阶段——"声称、宣称"。法语要表达"假装"，用的是 **faire semblant**（做出样子）。这是一个完美的案例：同一个词从同一个起点出发，在两种语言里走向了不同的终点。英语的 pretend 走向了"虚假"，法语的 prétendre 留在了"宣称"。

**日语「ふりをする」（furi wo suru）**：字面意思是"做出……的姿态"。和 pretend 的"在前面撑幕布"异曲同工——ふり（振り）本身就有"姿态、样子"的意思，你做出一个姿态，挡住真实的自己。

**中文"装"**：一个字就完成了 pretend 的核心工作。"装睡""装傻""装不知道"——但中文的"装"比 pretend 更口语、更带情绪判断。"你装什么装"这种句式里，"装"已经带了愤怒和鄙视，而 "Stop pretending" 的语气可以从温柔到暴怒，频谱更宽。

**中文"佯"**：佯攻、佯装、佯怒——更书面，更冷静，更接近 feign 而不是 pretend。但有趣的是，"佯"的本义也是"假装"，只不过它活在军事和古文的语域里，和 pretend 活在日常口语的语域形成了镜像。

---

**收尾一句话**：pretend 的全部秘密就藏在它的骨头里——**pre + tend**，在前面拉开。拉开的可以是孩子的魔法、大人的面具、政治家的宣言。但不管拉开什么，幕布后面那个真的东西，始终在。
