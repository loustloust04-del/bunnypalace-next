# crude

---

## 1. 一句话本质

**crude 是刚从地里挖出来、还带着泥和血的东西——不是坏，是还没被人手碰过、还没被文明驯化。**

---

## 2. 词源考古

### 词根拆解

crude 不可再拆，它是一个完整的拉丁借词，但它的根系很深：

- **拉丁语 crūdus**：生的、带血的、未煮熟的。罗马人说肉 crūdus，是那种切开还在渗血、纤维还没被火改变的状态。
- **更深的根：cruor**（拉丁语）：流出的血，特指伤口渗出的鲜血（不是静脉里安静流动的 sanguis，是暴露在空气中的、让人不舒服的血）。
- **PIE 词根 \*krewh₂-**：原始印欧语，意思就是"生肉、鲜血"。这个根还长出了一个你绝对想不到的亲戚——**cruel**（crūdēlis，"像生肉一样让人难受的"→残忍的）。

### 历史流变

| 时间 | 发生了什么 |
|------|-----------|
| 拉丁语时期 | crūdus = 生的、未熟的、带血的。纯粹的物理描述。 |
| 14世纪 | 进入中古英语，保留"生的、未加工的"核心义。当时主要用于食物和材料。 |
| 15-16世纪 | **关键漂移**：从"物理上未加工"扩展到"行为上未打磨"——crude manners（粗鄙的举止）出现了。一个描述物质状态的词，开始描述人的状态。 |
| 19世纪 | crude oil（原油）一词定型。石油工业给了这个词一个巨大的现代锚点——从地下抽出来的、黑乎乎的、还没进炼油厂的东西。 |
| 20世纪至今 | "crude joke"（粗俗笑话）成为高频用法。这条线走到了最远：从"肉没熟"到"人没教养"到"话没分寸"。 |

### 文化地层

**最有意思的一条线是 crude → cruel 的亲缘关系。**

拉丁语里 crūdus（生的）和 crūdēlis（残忍的）是同根词。罗马人的逻辑是：生肉让人不舒服、让人本能地想回避——这种"让人不适的生猛感"被抽象化，就变成了"残忍"。

所以 crude 和 cruel 是同胞兄弟。一个走了"未加工"的路，一个走了"令人不适"的路。它们共享同一个身体记忆：看到生肉时胃里那一下轻微的翻搅。

## 3. 故事 / 画面

一口刚打出来的油井。

黑色的液体从地下涌上来，带着硫磺味，粘稠得像糖浆，沾在工人手套上洗不掉。它不是汽油，不是柴油，不是润滑油——它什么都不是，又什么都是。所有那些精致的石化产品，都藏在这团黑色的混沌里，但此刻你看不出来。它需要被加热、蒸馏、分离、纯化，才能变成对你有用的东西。

但——它不是废物。它是**所有精炼产品的前身**。

这就是 crude 的人格：**不是垃圾，是原材料。不是没有价值，是价值还没被释放。**

一个 crude joke 不是一个烂笑话——是一个没经过"社交炼油厂"过滤的笑话，荤素不忌，直接从人的本能里喷出来。一个 crude sketch 不是一幅差画——是还没上色、没修边、只有最原始线条的底稿。

crude 这个词自带一种矛盾感：它承认事物的"原始"，但不否认事物的"存在"。

## 4. 多面体：核心义项展开

### 义项 A：未加工的、天然状态的

> *crude oil must be refined before it can be used as fuel.*
> 原油必须经过提炼才能用作燃料。

→ 最贴近拉丁语原义的用法。东西从自然界出来，人的手还没碰过它。和"一句话本质"的关系：带着泥和血，刚挖出来。

### 义项 B：粗糙的、简陋的（技艺/工具/方法）

> *They built a crude shelter from branches and leaves.*
> 他们用树枝和树叶搭了一个简陋的棚子。

→ 从"材料没加工"平移到"成品没打磨"。棚子能住人，但你一看就知道没有建筑师参与过。和本质的关系：人手碰过了，但碰得很少——驯化刚刚开始。

### 义项 C：粗俗的、下流的（言行）

> *His crude remarks made everyone at the table uncomfortable.*
> 他粗俗的言论让在座所有人都不舒服。

→ 漂移最远的义项，但逻辑一脉相承：一个人的言行没有经过"社会化精炼"。文明就是那座炼油厂——crude 的人绕过了它，直接把本能端上了台面。和本质的关系：话从嘴里出来时还带着"血"，没有被礼貌和分寸过滤。

### 义项 D：粗略的、大致的（数据/估算）

> *A crude


 estimate puts the cost at around $2 million.*
> 粗略估计成本大约在200万美元。

→ 信息存在，但没有被精细处理。你有一个数字，但这个数字还没经过反复校验和修正。和本质的关系：数据的"原油"——有用，但需要进一步提纯。

**四个义项的底层统一性：crude 永远描述同一件事——精炼过程尚未发生（或被跳过了）。**

## 5. 裂缝标注

### 常见误用

❌ **把 crude 当 "bad" 用。**
crude ≠ 差。一个 crude tool 可能非常有效，只是做工粗糙。crude 包含的判断是"未精炼"，不是"无价值"。说 "The movie was crude" 意思不是电影烂，是电影粗鄙/不讲究——可能它反而因此有一种生猛的力量。

❌ **crude 和 raw 混用。**
两者在"未加工"义上有重叠，但 raw 的情感色彩更中性甚至偏正面（raw talent = 天赋原石，褒义），crude 几乎总带一点"该精炼却没有"的遗憾感或批判感。你会说 raw beauty（未经修饰的美），但 crude beauty 极其少见，因为 crude 暗示"需要被改善"。

### 易混近义词辨析

| 词 | 核心区别 |
|----|---------|
| **raw** | 中性到褒义的"原始"。raw emotion = 真挚的情感（好事）。crude emotion = 未经控制的情感（有点失控）。 |
| **rough** | 偏向触感和表面质地。rough draft（草稿）强调还需打磨。crude 更强调"还没进入精炼流程"，rough 更像"已经在流程里但还没做完"。 |
| **vulgar** | 专指社交上的低俗。crude joke 和 vulgar joke 接近，但 vulgar 更重——vulgar 是"故意往下三路走"，crude 可能只是"没意识到自己过线了"。 |
| **primitive** | 时间轴上的"早期"。primitive tools 是人类早期的工具（历史判断），crude tools 是做工粗糙的工具（质量判断）。 |

### 中文母语者陷阱

⚠️ **"原始"的多义干扰。** 中文"原始"可以是褒义（原始森林 = 没被破坏的，好事），但 crude 几乎不承担这种正面含义。不要把"原始的美好"翻成 crude beauty。

⚠️ **"粗"字的映射偏差。** 中文里"粗犷"是褒义（粗犷的嗓音），但 crude voice 是贬义（粗鄙的声音）。crude 比中文里的"粗"更靠近负面。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **crude oil** | 石油工业术语，crude 最高频的搭配对象，几乎是固定短语 |
| **crude joke / humor** | 日常口语，形容荤段子或不雅笑话 |
| **crude estimate / approximation** | 学术/商业语境，"粗算"，不带贬义只表示精度低 |
| **crude method / tool / weapon** | 描述工具/方法的简陋，强调缺乏精细设计 |
| **crude attempt** | 第一次笨拙的尝试，暗示后续会改进 |
| **crude form / version** | "最初的粗糙版本"，常见于学术写作 |
| **crude but effective** | 固定搭配感很强——粗糙但管用，几乎是一个 idiom |

### 语域标注

- **正式度：中等。** crude 在学术论文（crude estimate）和日常聊天（crude joke）里都出现，但在非常正式的外交/商务文件中较少见（会用 unrefined 或 rudimentary 替代）。
- **特殊场域：** 在石油/化工行业，crude 是纯技术术语，不带任何情感色彩。

### 活用示范

> *There's something **crudely** honest about the way children draw — no perspective, no proportion, just the truth as they see it.*
> 孩子画画有一种**粗粝的诚实**——没有透视，没有比例，只有他们眼中的真相。

这个用法把 crude 的"未加工"和"真实"拧在一起——精炼会带来美，但也会带来伪装。有时候不精炼反而更接近真相。

## 7. 跨语言映射

**中文"粗"字家族：** 中文用"粗"造了一整个光谱——粗糙、粗俗、粗犷、粗暴、粗略。英文的 crude 大约覆盖了"粗糙"（义项B）、"粗俗"（义项C）、"粗略"（义项D），但不覆盖"粗犷"（那是 rugged）和"粗暴"（那是 brutal）。有趣的是，中文用同一个字"粗"统摄了更宽的区间，而英文把这些分给了不同的词。

**日语「生（なま）」：** 日语的"生"有类似的双重性——生ビール（生啤，未加工=好事）和 生意気（生意气，未经世事=傲慢）。跟 crude 一样，"未加工"这个概念可以滑向褒义也可以滑向贬义。

**拉丁语 cruor → 法语 cru：** 法语 cru 直接继承了拉丁语的"生"义（viande crue = 生肉），而且法语里 cru 也有"粗俗"的义项（une plaisanterie crue = 一个粗俗的笑话）。crude 和 cru 是同源同义的平行进化。
