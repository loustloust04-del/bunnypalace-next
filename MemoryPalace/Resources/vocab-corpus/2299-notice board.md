# Notice Board

## 1. 一句话本质

**Notice board 是一个村子的嘴巴长在一块木板上。** 它不说话，但谁路过都得看一眼——因为上面贴的是"你应该知道但还不知道的事"。不是对话，是单向广播；不是私信，是钉在公共视线里的宣告。

---

## 2. 词源考古

这个复合词要拆成两半挖。真正有故事的是 **notice**。

### notice：从"认识"到"被看见"

词根链条：

> **PIE \*ǵneh₃-**（知道）→ 拉丁语 **nōscere**（开始认识、学会）→ 过去分词 **nōtus**（已被认识的）→ 抽象名词 **notitia**（被知道的状态、名声、知识）→ 古法语 **notice**（通知、告知）→ 中古英语 **notice**（15 世纪借入）

这条根 \*ǵneh₃- 是个超级根，后代遍布英语：

| 同根词 | 怎么来的 |
|--------|---------|
| **know** | 日耳曼路线直传 |
| **cognition** | 拉丁 co- + gnōscere（一起认识→认知） |
| **recognize** | re- + cognōscere（再次认出） |
| **noble** | nōbilis = "众所周知的"→ 有名望的 → 贵族 |
| **ignore** | in- + gnōscere（不去认识→忽视） |
| **notion** | 和 notice 同母，notio = 概念 |
| **notorious** | 同根，但漂成了贬义："出了名的"→ 臭名昭著 |

**关键漂移——notice 的四次变身：**

1. **15 世纪**：借入时 = **知识、认知本身**。"to have notice of" = 知道某事的存在。很抽象，像脑子里的一盏灯。
2. **16 世纪**：漂向 **关注、注意力**。"to take notice" = 把注意力投过去。灯从脑子里移到了眼睛上。
3. **16–17 世纪**：具象化为 **正式告知、通告**。从"你应该注意"变成"这是要你注意的那个东西"。灯变成了一张纸。
4. **18 世纪起**：进一步物化成 **贴出来的公告**——钉在板上、墙上、门上的那张纸。灯变成了钉在木板上的图钉。

注意这条线索：**从内心状态 → 感官行为 → 信息载体 → 物理实体**。一个词从"你脑子里的知道"一路走到"钉在墙上的一张纸"，走了三百年。

### board：一块平的东西

这边简单得多：

> **原始日耳曼语 \*burdam**（木板、平板）→ 古英语 **bord**（木板、桌面、盾牌、船舷）

Board 的核心意象就是 **一个平面**。所有义项都是这块平面的不同用法：
- 桌面 → board and lodging（食宿，桌上有饭）
- 会议桌 → board of directors（董事会，围着桌子坐的人）
- 游戏面板 → board game
- 展示平面 → **notice board**、whiteboard、blackboard
- 登上（甲板）→ on board、boarding pass

### 合体：notice board

两个词粘在一起就是字面意思：**贴通知的那块平板**。英式英语写 **notice board** 或 **noticeboard**，18–19 世纪成型为固定搭配。

美式英语更常说 **bulletin board**——bulletin 来自意大利语 bullettino，是 bulla（教皇印章/文书）的小称形式，本质是"小公文"。同一块板子，英国人从"被注意的东西"命名，美国人从"小公文"命名——视角不同，指向相同。

## 3. 故事 / 画面

不用想象。回忆就行。

你上过学。

教室外面的走廊里，或者教学楼大厅的墙上，有一块被软木或绒布包住的矩形区域。上面用图钉和透明胶带钉着——

考试安排。社团招新。失物招领。某个你不认识的人拿了奖的红头通知。一张过期三个月但没人撕的讲座海报。角落里有人偷偷贴的"求购二手教材"小纸条，用手撕了一排电话号码，被撕走了两三条。

没有人专门去"看"它。但每个路过的人都会扫一眼。

**这就是 notice board 的本质结构：它不追着你跑，但它站在你必经的路上，面朝人流，被动地等你自己来看。**

它和广播不同——广播是你想不听也得听。它和私信不同——私信是只给你一个人的。Notice board 是 **公共的、静态的、被动的、非定向的**：信息在那里，谁需要谁来看，看不看是你的事。

这也是为什么这个词能活进互联网时代——BBS（Bulletin Board System）、论坛、Slack 的 #general 频道、公司内网的公告页……结构上都是 notice board：一个公共平面，谁都能贴，谁都能看，信息不追人，人追信息。

## 4. 多面体：核心义项展开

Notice board 本身义项不多，但它的两个组成词各自多面。重点展开 **notice** 的几张脸——因为这是中国学习者真正会在阅读中反复遇到的词。

### 义项 A：注意、留意（不可数名词/认知状态）

> *The changes were implemented without notice.*
> 这些变更在没有引起注意的情况下就执行了。

和"一句话本质"的关系：最古老的含义——脑子里"知道了"那一下。Notice board 上的东西，就是要引起你这个 notice。

### 义项 B：通知、公告（可数名词/信息载体）

> *A notice on the board said the meeting had been postponed.*
> 板上的一则通知说会议推迟了。

和本质的关系：从"注意力"具象化为"引起注意力的那个东西"。这是 notice board 里 notice 的直接含义。

### 义项 C：预告、提前通知（正式/法律语境）

> *She handed in her notice last Friday.*
> 她上周五递了辞呈。

> *The landlord gave 30 days' notice.*
> 房东给了 30 天的搬离通知。

和本质的关系：提前把你"应该知道但还不知道"的事告诉你。Notice 在这里不是贴在板上的，是递到你手里的——但底层逻辑一样：**让未知变成已知，给你反应时间**。

### 义项 D：注意到（动词）

> *Did you notice the scratch on the door?*
> 你注意到门上的划痕了吗？

和本质的关系：回到词源最初——nōscere，开始认识。你的感官捕捉到了一个信息，从"不知道"跳到"知道了"。

**底层统一性：** 不管是名词还是动词，notice 永远在描述同一个瞬间——**一个信息从"不可见"翻到"可见"的翻转**。Notice board 是让这个翻转发生的物理装置。

## 5. 裂缝标注

### 英美差异陷阱

| 概念 | 英式 | 美式 |
|------|------|------|
| 公告板 | notice board / noticeboard | bulletin board |
| 网络论坛 | notice board（少见） | bulletin board / message board |
| 软木钉板（文具） | notice board / pin board | bulletin board / corkboard |

在美式英语语境里说 notice board 不算错，但会暴露你的英式背景。反过来在英国说 bulletin board 也一样。写作时注意统一。

### 中文母语者陷阱

**"通知"≠ notice。** 中文的"通知"偏向主动行为（"我通知你"），英文的 notice 偏向被动状态（"信息在那里等你注意到"）。中文说"我通知你"用 **notify / inform**，不用 notice。

**"注意到"的语法坑：** notice 做动词时，后面的结构容易出错——
- ✅ I noticed **him leave**.（notice + 宾语 + 不带 to 的不定式）
- ✅ I noticed **him leaving**.（notice + 宾语 + 现在分词 = 强调正在进行）
- ❌ ~~I noticed him to leave.~~（不接 to do）

这和 see / hear / watch 一样，是感官动词的特权语法。中文母语者容易按"我注意到他去离开"的逻辑写出 to leave。

### notice 与 notification 的边界

- **notice** = 更宽泛，可以是一张纸、一个认知状态、一段提前告知期
- **notification** = 更正式、更系统化的通知行为或结果（手机推送就叫 notification，不叫 notice）

你手机弹出的是 notification。学校门口贴的是 notice。前者追着你跑，后者等你来看——这正好映射了 notice board 的被动性。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|------|------|
| **pin sth to / on the notice board** | 把东西钉上公告板——最物理的动作 |
| **check the notice board** | 去看一眼公告板——日常口语 |
| **post a notice on the board** | 贴公告——比 pin 正式一点 |
| **community notice board** | 社区公告栏——住宅区、教堂、图书馆门口 |
| **online notice board** | 线上公告板——有点过时，现在更常说 forum / message board |
| **the notice board says…** | 公告板上写着……——口语中拟人化表达 |
| **staff notice board** | 员工公告栏——职场标配 |
| **take sth down from the notice board** | 从板上撤下来——信息过期了 |

### 语域

Notice board 是 **中性偏日常** 的词。学术论文不太会用（会说 announcement system / public posting），法律文书也不用（会说 public notice 本身）。它活跃在：

- 日常口语 ✅
- 学校/职场/社区场景 ✅
- 新闻报道 ✅
- 英式英语 ✅✅（美式偏好 bulletin board）
- 数字语境 ⚠️（正在被 forum / feed / channel 替代）

### 活用示范

> *"Social media is just a global notice board where everyone's pinned up their highlight reel."*
> 社交媒体就是一块全球公告板，每个人都把自己的精彩集锦钉了上去。

> *"Her fridge door was a notice board of her children's lives — report cards, drawings, photos, all held up by magnets shaped like fruit."*
> 她家冰箱门就是孩子们人生的公告栏——成绩单、画、照片，全被水果形状的冰箱贴撑着。

## 7. 跨语言映射

**日语 掲示板（けいじばん / keijiban）**——最值得说。字面"揭示之板"，和 notice board 结构完全平行。但它在互联网时代获得了第二生命：2channel（2ch）把自己叫做"掲示板"，于是这个词在日语里同时指物理公告板和网络论坛，而且后者的使用频率远超前者。英语的 bulletin board 也走了类似的路（BBS），但没有日语里那么深入日常。

**中文的"公告栏"/"布告栏"**——功能对等，但中文的"栏"暗示了一种边界感（栏杆的栏），notice board 的 board 暗示的是平面感。一个是"圈出来的区域"，一个是"一块可以钉东西的板"。物理想象不同，指向相同。

**法语 tableau d'affichage**——"张贴的画板"。Afficher（张贴）来自古法语 aficher（固定、钉住），最终追溯到拉丁语 figere（钉、固定）。英语 fix 也是这个根。法语人看这块板，看到的是"钉"的动作；英语人看到的是"被注意到"的状态——动作视角 vs 结果视角。
