# version

---

## 1. 一句话本质

**version 是同一块泥被不同的手捏出的不同形状——泥没变，但每一次"转手"都留下了新的指纹。**

---

## 2. 词源考古

### 词根词缀拆解

```
vers-  （拉丁语 vertere = to turn，转动）
-ion   （名词后缀 = 行为或其结果）
```

**version = 一次"转"的结果。**

这个 `vert-/vers-` 是英语中最高产的拉丁词根之一，它的后代遍布各处：

| 词 | 拆法 | 本义 |
|---|---|---|
| **reverse** | re-(回) + verse | 转回去 |
| **convert** | con-(一起) + vert | 转化 |
| **divert** | di-(离开) + vert | 转开 → 分散注意力 |
| **universe** | uni-(一) + verse | 万物转为一体 |
| **verse** | vers- | 犁到头转弯 → 诗的一行 |
| **versatile** | vers- + -atile | 能转来转去的 → 多才多艺 |
| **vertebra** | vert- | 能转动的骨头 → 脊椎 |
| **vertigo** | vertig- | 天旋地转 |

这一大家子的基因密码就一个字：**转**。

### 历史流变

**拉丁语 vertere**（转动）→ 晚期拉丁语 **versio**（一次转动；翻译）→ 古法语 **version** → **1580年代**进入英语。

关键转折点：

**第一站：翻译（16世纪）。** version 进入英语时，几乎是"翻译"的专用词，尤其指**圣经翻译**。King James Version（钦定译本，1611）至今仍是这个词最古老用法的活化石。为什么翻译叫"转"？——你把一种语言的意思**转**进另一种语言，原料不变，容器换了。这个隐喻精准到不需要解释。

**第二站：各说各话（17世纪）。** 从"语言之间的转换"滑移到"视角之间的转换"。同一件事，每个人都有自己的 version——每个人把事实**转**过自己的棱镜，折射出不同的颜色。"Tell me your version"不是在问"你怎么翻译"，是在问"这件事转过你的眼睛之后长什么样"。

**第三站：变体/版本（19-20世纪）。** 工业时代需要标记"同一产品的不同迭代"，version 顺理成章地接下了这个任务。从书的修订版到软件的 v2.0，每一个 version 都是对原型的一次**转**动——保留内核，改变表层。

**注意这条线的统一性：** 翻译 → 各人说法 → 产品变体，底层逻辑从未断裂——都是"同一个东西被转了一下，变成了另一个样子"。

### 文化地层

version 在中世纪欧洲是个**宗教战场词**。谁有权做圣经的 version？天主教坚持拉丁语武加大译本（Vulgate）是唯一合法 version；新教改革者说每种语言都该有自己的 version。围绕这个词，人被烧死过——William Tyndale 因为做了英语 version 的圣经被处以火刑（1536）。一个关于"转"的词，自己也被历史转了好几圈。

## 3. 故事 / 画面

一张黑胶唱片在转盘上转。

同一首歌，原唱是一个 version。有人翻唱了，换了编曲，是另一个 version。有人把歌词翻成了法语，又是一个 version。有人在法庭上被问"那天晚上发生了什么"，他讲出了自己的 version——同一段旋律转过他的喉咙，音色变了。

唱片一直在转。每转一圈，针头划过的沟槽微微不同。但唱片还是那张唱片。

**version 的本质就是这个转盘：东西没换，角度在转。每一个落针的位置，都是一个 version。**

---

## 4. 多面体：核心义项展开

### 义项 A：变体 / 版本（最高频）

> *The latest **version** of the app fixes several bugs.*
> 最新版本的 app 修复了几个 bug。

同一个产品转了一圈迭代，出来的新形态。和"一句话本质"的关系：泥还是那块泥（同一个 app），手捏了一次（开发者改了代码），形状变了。

### 义项 B：（某人的）说法 / 叙述

> *The witness gave a very different **version** of events.*
> 证人对事件的描述截然不同。

事实经过一个人的认知棱镜"转"了一下，出来的叙述。这是 version 最有人味的一个义项——它暗示**没有人能给出"不转的"原版**，每个叙述都是某种程度的 version。

### 义项 C：翻译 / 译本

> *She read the


*New International **Version** of the Bible.*
> 她读的是《新国际版圣经》。

最古老的用法，至今在宗教和学术语境中活着。把一种语言的意思"转"进另一种语言。

### 义项 D：改编 / 演绎

> *The film is a modern-day **version** of Romeo and Juliet.*
> 这部电影是《罗密欧与朱丽叶》的现代改编版。

原作被"转"进了一个新的时代、新的媒介。核心故事是那块泥，导演是新的手。

**四个义项的底层统一性：** 全部都是"同一个内核经过某种转换后的产物"。区别只在于**转什么**——转代码（版本）、转视角（说法）、转语言（翻译）、转媒介（改编）。

## 5. 裂缝标注

### 常见误用

❌ **把 version 当 "edition" 用。**
- *version* 强调的是"内容经过了变化"——v1 和 v2 的代码不同。
- *edition* 强调的是"同一内容的不同发行"——精装版和平装版内容一样，包装不同。
- 一本书的 *revised edition*（修订版）改了内容，这时候 version 和 edition 确实重叠。但 *limited edition*（限量版）绝不能说 *limited version*——内容没变，只是印少了。

### 易混近义词

| 词 | 核心区别 |
|---|---|
| **version** | 同一内核的不同转化形态（暗示内容有变） |
| **edition** | 同一作品的不同发行形态（可能内容没变） |
| **variant** | 同一类别中的不同个体（偏分类学/生物学） |
| **iteration** | 强调"重复改进过程中的一次"（偏工程） |
| **rendition** | 一次表演性的演绎（唱一首歌、弹一首曲子） |

场景对比：
- 软件 → 用 **version**（v2.1.3），不用 variant
- 新冠病毒 → 用 **variant**（Delta variant），不用 version
- 歌手翻唱 → 说 **version** 或 **rendition** 都行，但 rendition 更强调表演本身的质感
- 字典第三版 → **edition**（Third Edition），因为"第三次出版"

### 中文母语者陷阱

⚠️ **"版本"的中文语义覆盖面比 version 更宽。** 中文说"盗版版本""限量版本"，但英文的 version 不覆盖这些——pirated **copy**，limited **edition**。中文的"版本"更像英文 version + edition + copy 的并集，直译会翻车。

⚠️ **"你的版本是什么？"** 中文问这句话通常在问"你用的是哪个版本"（What version are you using?）。但英文 "What's your version?" 更常见的意思是"你怎么说这件事？"——在问叙述，不在问软件。语境不同，同一个 version 指向完全不同的义项。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 | 例 |
|---|---|---|
| **latest / newest version** | 科技 / 软件 | 几乎每个 app 更新页面都有 |
| **version control** | 软件工程 | Git 就是做这个的——管理代码的"转"的历史 |
| **version of events** | 新闻 / 法律 | 每个当事人都有自己的 version of events |
| **earlier / previous version** | 通用 | 和 latest 相对 |
| **updated / revised version** | 出版 / 学术 | 强调改过了 |
| **official version** | 政治 / 新闻 | 官方说法（暗示可能有非官方的 version） |
| **abridged version** | 出版 | 删减版——原著被"转"短了 |
| **cover version** | 音乐 | 翻唱版 |

### 语域

version 是个**全语域通吃**的词。学术论文里写 "an earlier version of this manuscript"，程序员说 "push to version 3"，法庭上说 "the prosecution's version"，朋友之间说 "OK that's YOUR version"——从最正式到最随意，version 都在。它没有正式程度的限制，因为它描述的概念（"同一事物的不同形态"）太基础了，基础到任何场合都用得上。

### 活用示范

> *"History is written by the victors"—but every conquered people carries its own version, whispered in the dark.*
> "历史由胜者书写"——但每个被征服的民族都在黑暗中低声传递着自己的 version。

这个用法精准地激活了 version 的"视角之转"义：同一段历史，转过不同民族的记忆，成为不同的版本。而"whispered in the dark"暗示了非官方 version 的脆弱性。

> *I like the restaurant version of you better—you're always so polite to waiters.*
> 我更喜欢你在餐厅里的 version——你对服务员总是那么礼貌。

把 version 用在人身上——"餐厅里的你"是你的一个 version，"家里的你"是另一个。精准、俏皮，还带着一点哲学感：我们每个人都是自己的多个 version。

## 7. 跨语言映射

**中文"版本"**：覆盖面更宽（见裂缝标注），但在"变体/迭代"这个核心义上高度对应。中文缺一个精确对应 "version of events" 的词——通常说"说法""各执一词"，拆成了不同表达。英文一个 version 就能同时激活"这是你的叙述"和"这只是众多可能中的一个"两层含义，中文需要拆开才能做到。

**法语 version**：法语直接用这个词（同源），但有一个英语没有的特殊用法——法语课上 *version* 特指"从外语翻译成法语"（反方向的翻译叫 *thème*）。这保留了 version 最古老的"翻译"义，而且精确到有方向性。

**德语 Fassung**：来自 *fassen*（抓住、容纳），一个 Fassung 是对原作的一次"把握"。和 version 的"转"不同，Fassung 的隐喻是"容器"——同一杯水倒进不同形状的杯子。殊途同归，但画面不同。

**日语 バージョン（baashon）**：直接音译英语，主要用于科技语境（ソフトウェアのバージョン）。日语自己表达"版本"更常用「版」（はん）或「改訂版」（かいていばん），但在软件领域已被音译词完全占领。

1. **version = 一次"转"的结果**
2. **那张唱片在转盘上转，每一圈针头划过的沟槽微微不同，但唱片还是那张唱片**
