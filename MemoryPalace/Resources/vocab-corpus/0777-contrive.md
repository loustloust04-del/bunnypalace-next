# contrive

## 1. 一句话本质

contrive 是鲁布·戈德堡机械——它确实能把球送到终点，但你能看见每一个齿轮、每一根绳子、每一个不自然的弯折。**能用，但看得出是硬拧出来的。**

---

## 2. 词源考古

### 词根词缀拆解

```
con-  (together, 一起)
+
-triv-  ← 古法语 trover / trouver (to find, 找到)
         ← 通俗拉丁语 *tropāre (to compose, to figure out)
         ← 拉丁语 tropus (修辞格, 比喻手法)
         ← 希腊语 tropos (转, 方式, 方向)
```

最深层的根是希腊语的 **tropos——"转"**。这个词的骨头里写着：把东西翻来覆去地转，从各个角度琢磨，直到拧出一个办法来。

### 历史流变

**12-13世纪**：从古法语 `controver / contreuver` 进入中古英语，写作 `contriven`。当时的意思非常中性甚至正面——**"想出来、发明、发现"**。你 contrive 了一个方案，说明你聪明，有创造力。

这里有个有趣的亲戚关系：法语 `trouver`（找到）跟 contrive 同源。而 `troubadour`（吟游诗人）也来自同一个根——"找到旋律的人、编出歌的人"。所以 contrive 最初的血统是**创作者、发明者**的血统。

**14-15世纪**：含义开始漂移。从"聪明地想出来"滑向"刻意地安排、精心算计"。**转折点在于：当人们开始注意到"想出来"背后的用力程度时，这个词就开始带上了"费劲""不自然"的味道。**

**16-17世纪**：贬义加速。contrive 越来越多地出现在阴谋、诡计、人为操纵的语境中。莎士比亚用它描述密谋（*contrive the means of meeting*）。到这个时期，"contrived"作为形容词基本定型为**"做作的、人为的、不自然的"**。

### 文化地层

这个词的语义漂移本身就是一面镜子：

> 英语文化对"刻意"的态度从欣赏走向了怀疑。中世纪时，人工的巧妙（artifice）是被赞美的——大教堂、钟表、城堡，都是 contrivance。但到了浪漫主义时期，"自然"（natural）被抬到了至高的位置，一切看得出人为痕迹的东西都成了 contrived。

这个转变不是 contrive 一个词的事——artificial、affected、studied 都经历了类似的从中性到贬义的漂移。但 contrive 漂得最远：它从"发明"一路滑到了"做作"。

## 3. 故事 / 画面

一个编剧在凌晨三点改第七稿。

他的主角需要在第三幕跟反派相遇。但按照故事的自然逻辑，这两个人没有任何理由出现在同一个房间里。编剧试了很多办法——让主角的车抛锚？太老套。让反派恰好去同一家餐厅？太巧合。让一个共同朋友牵线？但这个朋友是谁，前面两幕完全没铺垫。

最后他写了：主角在超市买牙膏时，反派恰好站在隔壁货架。他们对视。反派说了一句意味深长的话。剧情由此推进。

他看着这场戏，知道它**能用**——逻辑上说得通，人在超市确实会偶遇。但他也知道，任何看到这一幕的观众都会感觉到那根看不见的线：**不是角色自己走到这里的，是作者把他们拎起来放到这里的。**

这就是 contrive。

不是"假"——超市偶遇不是不可能发生。是**"真得不够自然"**——你闻得到汗味，看得到针脚，感觉得到背后那只使劲的手。

## 4. 多面体：核心义项展开

### 义项一：策划、密谋（带算计感）

> *They contrived a plan to overthrow the board of directors.*
> 他们密谋了一个推翻董事会的计划。

和"一句话本质"的关系：**齿轮都是刻意咬合的，每一步都是算好的**——不是自然发生，是人为编排。

### 义项二：设法做成（尽管有困难）

> *She contrived to finish the project despite losing half her team.*
> 尽管团队走了一半人，她还是想办法把项目做完了。

这是 contrive 最中性、甚至略带正面的用法。关键结构：**contrive to do something**。这里的味道不是"做作"，而是"硬挤出办法来"——条件不够，但就是拧出来了。

和"一句话本质"的关系：还是那个鲁布·戈德堡机械——**不优雅，但确实把球送到了终点**。重点落在"做成了"而不是"做得多不自然"。

### 义项三：发明、构造（有人工痕迹的）

> *He contrived a makeshift shelter out of branches and tarp.*
> 他用树枝和防水布凑出了一个临时避难所。

和"一句话本质"的关系：**看得出是拼凑的**，不是天然长出来的。功能上可以用，但绝不会有人觉得它浑然天成。

### 底层统一性

三个义项的共同基因是：**人为施力，让本来不会自然发生的事情发生了。** 差别只在于说话者的目光落在哪里——落在"施力的意图"上，就是密谋；落在"做成了"上，就是设法完成；落在"人工痕迹"上，就是拼凑。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 contrive 当中性的"创造"用**

> ❌ *She contrived a beautiful painting.* （听起来像说这幅画很做作）

contrive 自带的"人工痕迹"含义会污染你想表达的正面意思。如果想说"创造了一幅美丽的画"，用 create / produce / craft。

**❌ 把 contrived 当"复杂"用**

> ❌ *The system is very contrived.* （你想说复杂，但听者理解的是"做作、故意搞复杂"）

想说复杂用 complex / intricate / elaborate。contrived 不是"客观上复杂"，是"**主观上觉得不必要地刻意**"。

### 易混近义词辨析

| 词 | 核心差别 |
|---|---|
| **devise** | 中性的"想出、设计"。*devise a plan* = 设计了一个方案（不带做作感）。contrive a plan = 算计了一个方案（有阴谋味） |
| **invent** | 创造出原本不存在的东西，正面为主。contrive 强调的是拧的过程，invent 强调的是从无到有的结果 |
| **fabricate** | 偏向"捏造"（尤其是谎言、证据），比 contrive 更直接指向造假。contrive 的假不在内容，在于手法的不自然 |
| **concoct** | 和 contrive 最近的表亲。concoct 有"混搭、调配"的画面（词根是"一起煮"），contrive 有"拧、翻转"的画面。concoct a story（编故事，有点瞎编的味道），contrive a meeting（安排一次碰面，有点心机的味道） |
| **manage to** | 功能上可以替代 *contrive to do*，但没有"硬拧出来"的画面感。manage to 是中性的"设法做到"，contrive to 暗示过程不太优雅 |

### 中文母语者陷阱

**"精心策划"≠ contrive。** 中文的"精心策划"是正面词——精心意味着用心、细致。但 contrive 的"精心"是带引号的——更接近"**费心机地安排**"。如果你想表达正面的精心策划，用 carefully plan / meticulously design。

**"想方设法"≈ contrive to，但少了一层。** 中文"想方设法"是很正面的——强调努力。contrive to 虽然也表达"设法做到"，但底色里永远有一丝"不太光彩"或"不太自然"的暗影。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **contrive a plan / scheme** | 策划（通常暗示阴谋或刻意性） |
| **contrive to do sth** | 设法做成某事（最常用结构，也是最中性的用法） |
| **contrive a meeting / encounter** | 安排一次看似偶然的碰面（刻意伪装成巧合） |
| **contrived plot / ending** | 做作的情节 / 结局（影评书评中的高频差评词） |
| **seem / feel contrived** | 感觉不自然（比直接说"是假的"温和，但杀伤力不小） |
| **contrived example** | 刻意编造的例子（学术写作中常见批评） |
| **a contrivance** | 名词形式：一个精巧的装置 / 一个人为的安排 |

### 语域标注

**书面 > 口语。** 日常口语中很少用 contrive——你更可能说 "it felt fake" 或 "that was so forced" 而不是 "that was contrived"。contrive 主要活跃在：

- **文学 / 影视评论**：*"The plot twist felt contrived."*——这是影评里的高频判决。
- **正式写作 / 学术**：*"The author contrives a scenario in which..."*
- **新闻 / 政论**：*"Critics accused the government of contriving a crisis."*

口语中如果有人说出 contrived，通常说明这个人措辞比较讲究，或者**真的很想精准表达"不是假，但不自然"这层意思**——因为英语里没有太多词能替代这个位置。

### 活用示范

> *The coincidence was so perfect it could only have been contrived.*
> 这个巧合完美得只有刻意安排才能做到。

这句话的力量在于：它不说"是假的"，只说"太完美了，不像是真的"——contrive 在这里像一把手术刀，精准地切开了"真实"和"自然"之间的缝隙。

> *He somehow contrived to be both charming and deeply untrustworthy.*
> 他不知怎么做到了同时让人觉得迷人又完全不可信。

这是 contrive to 最毒的用法之一——表面在说"他做到了"，实际在说"这种矛盾的并存本身就不自然"。

## 7. 跨语言映射

**中文"矫揉造作"**覆盖了 contrived 的一部分——但矫揉造作更重，几乎是骂人了。contrived 的语气更冷静，像一个评委在评分卡上打分："artificial — 7/10"。

**日语「わざとらしい」**（故意的、做作的）和 contrived 的重合度相当高——都是指"能看出有人在刻意操作"，都不是指"假"而是指"不自然"。但「わざとらしい」更日常，contrived 更书面。

**法语 `controuver`** 是 contrive 的直系祖先，但在现代法语中基本已死。不过法语保留了 `trouvaille`（意外的发现、神来之笔）——这个词和 contrive 共享词根 trouver，但走向了完全相反的方向：trouvaille 是自然涌现的灵感，contrived 是硬拧出来的安排。**同一个"找到"的根，一个方向长出了天才，另一个方向长出了做作。**

这组对比本身就是最好的记忆锚点：

> **trouvaille = 找到了，像是命运安排的。**
> **contrive = 找到了，像是你安排的。**
