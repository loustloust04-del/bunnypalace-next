# generalise

---

## 1. 一句话本质

**generalise 是把镜头从微距拧到广角的那一下——你终于看见了全景，但花瓣上的纹路也在同一秒消失了。**

这个词天生带着一对矛盾：它是人类最强大的认知能力（看到一百只鸟后总结出"鸟会飞"），也是最常见的思维懒惰（"所有程序员都不爱说话"）。同一个动作，做得好叫归纳，做得差叫以偏概全。

## 2. 词源考古

### 词根词缀拆解

```
generalise = general + -ise
           = gener(genus 的词干) + -al + -ise
```

三层建筑，从地基往上看：

- **gener-**：来自拉丁语 *genus*（种类、出身、家族），更深处是原始印欧语 *\*ǵenh₁-*（生、产出）。这个词根你已经在 **gene**（基因）、**gender**（性别）、**general**（一般的）里反复见到了——它们全是同一棵树上的果子。

- **-al**：拉丁形容词后缀，"属于……的"。*generalis* = "属于整个种类的"，对比 *specialis* = "属于特定个体的"。

- **-ise / -ize**：来自希腊语 *-ízein*（使之成为、使之变成），经由拉丁语 *-izāre*、法语 *-iser* 进入英语。这个后缀的核心功能是**把形容词变成动词**——"general"是个静态的形容词，加上 *-ise* 就获得了动力：**使之变得 general**，把具体的东西往"种类"的方向推。

> 🇬🇧 vs 🇺🇸 拼写：**-ise** 是英式偏好，**-ize** 是美式标准。但这不是英美之争那么简单——牛津大学出版社（OUP）一直坚持用 **-ize**，因为词源上 *-ízein* 是希腊语，*-ize* 更忠于源头。所以"牛津拼写"(Oxford spelling) 写 *generalize*，而大部分英国媒体写 *generalise*。两种都正确，取决于你跟哪套风格。

### 历史流变

**14世纪晚期**：英语从古法语 *generaliser* 借入，最初的意思很具体——"使之适用于整个类别"，是逻辑学和修辞学的术语。你在学院里辩论时说"把这个论点 generalise 到所有情况"，是一种有技术含量的智识操作。

**17世纪**：科学革命。*generalise* 成了归纳法（induction）的核心动词。弗朗西斯·培根的方法论本质上就是：观察个案 → generalise → 建立自然法则。这是这个词的黄金时代——它和"发现真理"站在一起。

**18-19世纪**：贬义色彩开始生长。随着实证主义兴起，人们越来越警惕**没有充分证据的 generalisation**。"Don't generalise" 开始成为一种批评。这个词从"科学家的工具"多了一层"懒人的习惯"。

**20世纪至今**：双面性彻底固化。学术场合它是中性甚至褒义的（"This finding generalises to other populations"），日常对话里它常常是指控（"You're generalising!"——你在以偏概全）。

### 文化地层

注意一个有趣的反转：

*genus*（种类）→ *generalis*（属于整个种类的）→ *generalise*（把个体归入种类）

**这个词的运动方向和 gene（基因）、generate（生成）刚好相反。** gene 和 generate 是从种子往外长——从一到多，从抽象到具体。而 generalise 是从枝叶往回收——从多到一，从具体到抽象。同一个词根 *\*ǵenh₁-*，一个方向是**繁殖**，另一个方向是**归类**。它们是同一枚硬币的正反面：生命先分化出无穷个体（generate），人脑再把个体收回去找共性（generalise）。

## 3. 故事 / 画面

一个植物学家走进热带雨林。

第一天，她蹲在地上画一朵花的素描——五瓣，橙红色，萼片上有微小的锯齿，花蕊向左偏 12 度。每一条纹路都记录在案。这是**具体**。

第一个月，她画了 300 朵。笔记本已经画不下了。她开始发现：这 300 朵虽然每一朵都不一样，但它们共享某些东西——五瓣结构、特定的花蕊排列方式、同一种虫会来授粉。她把 300 朵合并成一个描述："本属植物具有五瓣对称花冠，雄蕊数目恒定……"

这个合并的动作，就是 **generalise**。

她得到了什么？一个能装进论文的简洁描述，一个能和全世界同行分享的分类框架。

她失去了什么？第 147 朵花的萼片上那条独一无二的裂纹。第 203 朵花瓣边缘那抹比所有同类都深半个色号的红。

**Generalise 的本质就是这笔交易：用分辨率换覆盖面。** 每一次 generalise 都是一次有意识的模糊——你故意忘掉个体差异，以便看见群体规律。做得好，你发现万有引力；做得差，你发明种族偏见。工具本身无罪，但这把刀的两面都能切人。

## 4. 多面体：核心义项展开

### 义项 A：从个别推出普遍（归纳推理）

> *"It's dangerous to generalise from a single case."*
> 从一个案例就做出普遍推断是危险的。

这是最经典的用法。从具体观察出发，往更大的范围推。本质上就是"一句话本质"里那个镜头拧广角的动作——你把一个 case 的结论拉宽到整个 category。

### 义项 B：笼统地说 / 以偏概全（贬义）

> *"You're generalising — not all millennials are like that."*
> 你在以偏概全——不是所有千禧一代都那样。

同样是"拧广角"，但拧过头了。你在明明分辨率不够的情况下强行拉宽。这个义项和 A 的区别不在动作本身，而在**证据是否够格撑起那个广角**。

### 义项 C：使之通用化 / 推广（技术 / 学术）

> *"We need to generalise this algorithm so it works on any input type."*
> 我们需要把这个算法泛化，使它能处理任意输入类型。

程序员和数学家最熟悉的义项。"泛化"——把一个只在特定条件下管用的东西改造成在更广条件下都管用。和义项 A 的关系：A 是认知上的拉宽（从个别到普遍），C 是工程上的拉宽（从特例到通用）。底层都是**从 specific 移向 general**。

### 义项 D：扩散 / 蔓延（医学 / 技术）

> *"The infection generalised rapidly, spreading from the wound to the bloodstream."*
> 感染迅速扩散，从伤口蔓延到了血液。

一个物理意义上的"从局部到全局"。和前三个义项的统一性很明显：A/B/C 是抽象概念的"扩散"，D 是物理实体的扩散。**核心运动方向永远是 local → global。**

## 5. 裂缝标注

### 常见误用

**❌ 把 generalise 和 summarise 搞混。**

Summarise 是压缩：把 10 页的内容变成 1 段，但不改变适用范围。
Generalise 是扩展：把对 3 个案例的观察拉宽到对 3000 个案例的判断。

"Can you generalise this report?" ← 大概率你想说的是 summarise。除非你真的想让对方从报告里提炼出适用于更多场景的普遍规律。

**❌ "generalise about" vs "generalise from" vs "generalise to" 搞不清。**

- *generalise **about*** something：对某事物做笼统论断（"Don't generalise about an entire country."）
- *generalise **from*** something：从某事物出发做推断（"You can't generalise from one experiment."）
- *generalise **to*** something：推广到某范围（"These results generalise to the broader population."）

三个介词画出三段不同的运动轨迹：about 指你在评论什么，from 指你从哪里出发，to 指你要到达哪里。

### 易混近义词

| 词 | 核心区别 |
|---|---|
| **generalise** | 从具体到抽象，从个别到普遍 |
| **simplify** | 减少复杂度，但不一定改变适用范围。你可以 simplify 一个只适用于单一场景的东西 |
| **extrapolate** | 从已知数据向**未知区间**延伸推断，强调的是"超出已有数据范围"的预测。generalise 不一定涉及预测 |
| **stereotype** | generalise 的恶性肿瘤版——不仅扩大范围，而且固化为刻板印象。generalise 还能被修正，stereotype 已经凝固了 |
| **abstract** | 提取本质特征、去掉具体细节。和 generalise 很近，但 abstract 更强调"提纯"（distill），generalise 更强调"扩大适用范围"（widen）|

### 中文母语者陷阱

**"概括"这个翻译会误导你。**

中文里"概括"偏向"总结提炼"（closer to summarise），但 generalise 的核心不是提炼，是**扩大适用范围**。你 generalise 一个结论，不是在缩短它，而是在宣称它对更多情况成立。

另一个常用翻译"一概而论"只覆盖了贬义用法。学术语境里的 generalise 是完全中性甚至正面的——"This theory generalises well" 是夸它，绝不是在说"这个理论一概而论"。

比较安全的中文映射：
- 学术/技术语境 → **泛化、推广**
- 日常贬义语境 → **以偏概全、一概而论**
- 不要用一个中文词去覆盖所有义项

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **generalise from** (limited data / a single case) | 学术写作，强调推断的起点不够充分 |
| **generalise to** (other populations / broader contexts) | 研究论文的 Discussion 部分标配句式 |
| **broadly generalise** | 强调推断幅度大，可褒可贬 |
| **difficult / hard to generalise** | 学术谦虚——"我们的结论不一定普适" |
| **tend to generalise** | 温和的批评——"你有过度概括的倾向" |
| **overgeneralise** | 直接指出推断过度，心理学术语（认知偏差名称之一） |
| **safely generalise** | "可以放心地推广到……" |
| **generalise findings / results** | 论文里把实验结论往外推 |

### 语域

**中高正式度。** 日常口语里人们更常说 "Don't lump everyone together" 或 "That's a sweeping statement" 而不是 "Don't generalise"。但 "Don't generalise" 也完全可以出现在口语中——它不像 *extrapolate* 那么学术感重。

核心领地：学术论文（尤其社科和医学的外部效度讨论）、逻辑辩论、政治评论。

### 活用示范

> *"Every model generalises; the question is whether it generalises to the right things."*
> 每个模型都在泛化；问题是它泛化到了正确的东西上吗。

这句话（机器学习语境）把 generalise 的双面性压缩到了极致：泛化本身不是优点也不是缺点——**方向**才是。这恰好呼应了一句话本质里说的：同一个动作，做得好是牛顿，做得差是偏见。

> *"She had a gift for generalising without losing the texture of the particular."*
> 她有一种天赋——能做出概括，却不丢失个体的质感。

这是对一个思想家的最高赞美：她能拧广角，但画面没有糊。

## 7. 跨语言映射

**日语「一般化する」(ippanka suru)**：结构上和 generalise 完美对应——"一般" + "化" + "する"。但日语里这个词几乎只出现在学术和技术语境，日常贬义的"以偏概全"用「一括りにする」(hitokuturi ni suru，一把抓在一起) 或「決めつける」(kimetsukeru，擅自断定)。英语的 generalise 横跨了这两个语域，日语把它们分成了不同的词。

**德语 *verallgemeinern***：ver- (使之成为) + allgemein (一般的、普遍的) + -ern (动词化)。有趣的是 *allgemein* 本身 = all + gemein (共同的)，所以德语版本的字面意思是"使之成为对所有人共同的"——比英语的 generalise 更直白地暴露了"从个别到全体"的运动方向。

**中文的"举一反三"**：这不是 generalise 的翻译，但它捕捉了 generalise 最优雅的那个面向——从一个具体案例出发，推导出更广泛的理解。区别在于"举一反三"暗示的是聪明和灵活，而 generalise 是中性的，既可以聪明也可以粗暴。

### 🧬 家族备忘

你现在已经考古了 *\*ǵenh₁-* 家族的五个成员：

| 词 | 方向 | 做的事 |
|---|---|---|
| **gene** | 内 → 外 | 蓝图本身 |
| **gender** | 分类 | 按生育功能分的第一刀 |
| **gelatin** | 凝固 | 从骨头里"生"出来的胶 |
| **general** | 个别 → 整体 | "属于整个种类"的状态 |
| **generalise** | 个别 → 整体 | 把东西**推向**"属于整个种类"的动作 |

general 是形容词——一张静态的广角照片。generalise 是动词——你手指拧镜头的那个动作。一个是结果，一个是过程。
