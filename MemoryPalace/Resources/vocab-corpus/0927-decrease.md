# decrease

---

## 1. 一句话本质

**decrease 是月亮从满月往回走的那个过程——不是消失，是正在变少、正在退潮、正在从丰盈滑向稀薄。**

不是"没了"，是"还在，但比刚才少了"。它自带一个时间箭头：你知道之前更多，现在更少。

---

## 2. 词源考古

### 词根词缀拆解

```
de-     +  crease
↓            ↓
向下/离开    生长（拉丁 crescere）
```

- **de-**：拉丁前缀，表示"向下、远离、反向"。在这里是"反向生长"——生长的倒带。
- **crescere**：拉丁语"生长"。来自原始印欧语 *\*ḱer-*（生长、使增长）。

直接来源是古法语 **descreistre**（现代法语 décroître），经由盎格鲁-法语进入中古英语，14 世纪左右定型为 **decrease**。

### crescere 家族——一棵大树上的兄弟姐妹

这个词根极其高产，认清它等于认清一整个家族：

| 词 | 拆法 | 含义 |
|---|---|---|
| **increase** | in-(向内/加强) + crescere | 向上生长 = 增加 |
| **crescent** | crescere 的现在分词 | 正在生长的 = 新月（月亮在"长大"） |
| **crescendo** | 意大利语，同根 | 音乐术语：声音越来越大 |
| **concrete** | con-(共同) + crescere | 一起凝固生长 = 混凝土/具体的 |
| **accrue** | ad-(朝向) + crescere | 朝着你长过来 = 积累（利息 accrues） |
| **recruit** | re-(再次) + crescere | 重新生长 = 补充新兵 |

**decrease 和 increase 是亲兄弟**，共享同一副骨骼，只是前缀方向相反：一个向上长，一个向下退。

### 文化地层

14 世纪进入英语时，decrease 几乎只用于描述自然现象——水位退了、日照短了、月亮亏了。莎士比亚时代开始大量用于抽象概念——权力、影响力、热情的减退。工业革命之后，它被数据和报表彻底驯化，变成了图表上那条往下走的线。

有趣的是，**crescent（新月）这个词暴露了 crescere 的本义**。为什么新月叫"正在生长的"？因为古罗马人看新月的视角是：它在变大、在长胖——月亮的 increase 阶段。那满月之后呢？月亮在 decrease。这组词最古老的画面，就是月相盈亏。

## 3. 故事 / 画面

一个沙漏。

你盯着上半格，沙子一粒粒往下漏。上面的沙面在降，肉眼可见地降。你知道总量没变——沙子没有蒸发，只是从"这里"流到了"那里"——但你盯着的那个局部世界，确实越来越空了。

这就是 decrease 的质感：**不是爆炸式的消失，是沙漏式的流失。匀速的、可测量的、你看得见进度条的"变少"。**

它跟 disappear 的区别在这里——disappear 是灯啪地灭了，decrease 是调光旋钮在慢慢往回拧。跟 decline 的区别也在这里——decline 暗示走下坡路（有方向感，有"衰落"的叹息），decrease 更冷静，更像在读仪表盘上的数字。

## 4. 多面体：核心义项展开

decrease 的义项不多，但有一个关键的动词/名词双面：

### 义项 A：动词——变少、减少（不及物）

> *The temperature decreased sharply after sunset.*
> 日落后气温急剧下降。

事物自己在变少。沙漏在漏，你没碰它。

### 义项 B：动词——使减少（及物）

> *The company decreased its workforce by 15%.*
> 公司裁减了 15% 的员工。

有人伸手去拧那个旋钮了。是主动的"让它变少"。

### 义项 C：名词——减少的量 / 减少的过程

> *There has been a significant decrease in crime rates.*
> 犯罪率出现了显著下降。

名词用法几乎只出现在正式语境——报告、新闻、论文。注意介词搭配：**a decrease in** something（某方面的减少），**a decrease of** 20%（减少了 20%）。

**底层统一性**：三个义项都是同一幅画面的不同视角——沙漏在漏（A），有人把沙漏翻过来让它漏（B），漏掉了多少沙子（C）。核心永远是 **crescere 的反向：生长的倒带**。

## 5. 裂缝标注

### 常见误用场景

**❌ 把 decrease 用在不可量化的东西上**

> *~~My happiness decreased.~~*

语法上没错，但极度生硬。decrease 天然带"可以量化、可以测量"的语气。happiness 这种模糊的情感，更自然的说法是 *faded* / *diminished* / *waned*。decrease 更适合 temperature, population, revenue, speed 这类"仪表盘上有数字"的对象。

**❌ decrease 和 reduce 混用**

很多学习者以为它们完全一样。核心区别：

- **reduce** 几乎总是**及物的**——是"你"去减少它。*We need to reduce costs.* 你不太会说 *Costs reduced.*（虽然偶尔口语里有）
- **decrease** 及物和不及物都很自然——事物可以自己 decrease，也可以被 decrease

所以："成本自己降下来了"用 *Costs decreased.*；"我们要把成本压下去"用 *We need to reduce costs.* 而不是 *We need to decrease costs.*（后者语法对但不如 reduce 地道）。

### 易混近义词辨析

| 词 | 核心区别 |
|---|---|
| **decline** | 带感情色彩，暗示"走下坡、衰落"。*The empire declined.* 有叹息感。decrease 是中性读数。 |
| **diminish** | 暗示"变得微不足道"，终点是"几乎没了"。*His influence diminished.* decrease 没有暗示终点。 |
| **dwindle** | 强调"越来越少直到快没了"。*Supplies dwindled.* 有焦虑感、有紧迫感。decrease 不焦虑。 |
| **reduce** | 强调"有人在动手削减"。主语通常是人。decrease 的主语经常是数据本身。 |
| **drop** | 口语化，暗示速度快、幅度大。*Sales dropped 40%.* decrease 更缓，更正式。 |

### 中文母语者陷阱

**"减少"的覆盖面比 decrease 宽得多。** 中文说"减少浪费""减少错误""减少痛苦"都很自然，但英文里这三个分别更倾向用 reduce waste / minimize errors / alleviate pain。decrease 在英文里的使用场景比你以为的窄——它最舒服的位置是**跟数字、跟可量化指标待在一起**。

## 6. 搭配与语域

### 高频搭配

- **a decrease in** + 名词（*a decrease in productivity* 生产力下降）——最标准的名词搭配结构
- **a sharp / significant / slight / gradual decrease**（急剧/显著/轻微/逐渐的减少）——形容词几乎都是描述幅度和速度的
- **decrease by** + 百分比/数量（*decreased by 20%*）——表示减少的幅度
- **decrease from X to Y**（*decreased from 500 to 300*）——表示起止点
- **on the decrease**（在减少中）——比 on the decline 更中性
- **steadily decrease**（稳步减少）——学术论文最爱

### 语域标注

**偏正式，偏书面。** 日常对话里你更可能说 *go down*、*drop*、*get less*。decrease 是写报告、读新闻、做 presentation 时的词。学术论文里它出现的频率是日常口语的 8-10 倍。

如果你在跟朋友聊天时说 *The temperature has decreased*，对方会觉得你在播天气预报。正常说法是 *It got colder* 或 *The temp dropped*。

### 活用示范

> *As daylight decreases, so does our will to stay productive.*
> 日照在缩短，我们想高效工作的意志也在缩短。

这句话漂亮在：用 decrease 的冷静语气写了一件很人性的事。冷静本身成了幽默——把"天黑了不想干活"说得像在读研究报告。

> *Every year, the distance between what we promise and what we deliver decreases — but never reaches zero.*
> 每年，我们的承诺和交付之间的差距都在缩小——但永远不会归零。

decrease 在这里的精确度是别的词替代不了的：它暗示"在量化地靠近"，而 never reaches zero 制造了一个数学式的遗憾。

## 7. 跨语言映射

**拉丁语 decrescere** → 意大利语 **decrescendo**（音乐术语：渐弱）。如果你学过音乐，这是最好的锚点：**decrease 就是 decrescendo 的日常版**——声音越来越轻，音量旋钮在往回拧。

**法语 décroître** 依然活跃，用法和英文 decrease 几乎一一对应。法语里还保留了名词 **décroissance**，近年被环保运动征用为"去增长"概念（degrowth），指主动缩减经济规模——这个词在法语政治语境里非常有存在感。

中文的"减少"比 decrease 更万能，但也因此更模糊。decrease 自带"从某个更高点往下走"的方向感和"可以拿尺子量"的精确感，"减少"没有这层暗示。更接近的中文表达可能是**"下降"**——"气温下降""销量下降"——同样偏数据、偏正式、偏可量化。
