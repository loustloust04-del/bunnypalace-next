# metric

## 1. 一句话本质

**metric 是一把看不见的尺子——你往任何混沌的东西上一贴，它就把模糊变成了数字，把"感觉"变成了"可以比较"。**

不是尺子本身，是「用尺子去量这件事」的那个动作和标准。世界本来是一团浆糊，metric 是你决定从哪里下刀、用什么刻度去切它。

---

## 2. 词源考古

### 词根词缀拆解

```
metr-  ←  希腊语 μέτρον (metron) = 度量、尺度
-ic    ←  形容词后缀，"与……有关的、具有……性质的"
```

结构极其干净：**"与度量有关的"**。没有任何多余零件。

μέτρον (metron) 是希腊语里一个根基级的词，它同时管两件事：
- **物理的量**：长度、重量、容积——一切可以用数字表达的尺度
- **诗歌的律**：音节的长短、轻重、节奏——韵律本质上就是"测量声音的节拍"

这两层含义在希腊人看来是同一件事：**给无形之物施加秩序**。

### 历史流变

**公元前 5 世纪·希腊**
μέτρον 是哲学核心词汇。普罗塔戈拉说过那句著名的 "πάντων χρημάτων μέτρον ἐστὶν ἄνθρωπος"——"人是万物的尺度（the measure of all things）"。这里的 metron 不是一把物理尺子，是**判断标准本身**。

**拉丁语时期**
希腊语 metron → 拉丁语 **metricus**（"关于韵律的"），主要活在修辞学和诗学里。物理度量那层含义由拉丁语自己的 *mensura*（→ 英语 measure）承担了。所以在很长一段时间里，metric 在欧洲语言中主要是个**文学术语**。

**1791 年·法国大革命——关键转折**
法国科学院需要一个"去皇权化"的长度单位，不再用国王的脚（foot）或手臂（yard）。他们取地球子午线长度的千万分之一，命名为 **mètre**（直接从 metron 来）。于是 **metric system**（公制）诞生——metric 从文学术语一脚踏进了物理科学，从此和"标准化度量"绑死。

**20 世纪末 → 21 世纪·数据时代——第二次漂移**
metric 从物理度量扩展到**抽象指标**。"What are your metrics?" 不是问你用英制还是公制，是问你**拿什么数字来衡量成败**。DAU、转化率、留存率——这些都是 metrics。这层含义在硅谷文化中爆炸式扩散，现在几乎是商业和技术领域的空气词。

### 文化地层

有趣的是，metric 的两次大漂移都和**权力**有关：
- 法国大革命用它推翻旧度量衡（"国王的尺子不算数了，我们用地球的"）
- 数据时代用它定义成败（"你的 metric 是什么"本质上是在问"谁说了算"）

普罗塔戈拉两千五百年前说"人是万物的 metron"，今天改成"KPI 是万事的 metric"，结构一模一样。

## 3. 故事 / 画面

一间面包房。

老师傅做面包凭手感——面团软硬捏一下就知道，发酵好没好闻一下就知道，烤箱温度伸手进去感受一下就知道。四十年功力，炉火纯青。

有一天新来了个合伙人，要开连锁店。他说：我们需要 **metrics**。

于是面团的含水率变成了 65%。发酵时间变成了 90 分钟 ± 5。烤箱温度变成了 220°C。出炉后的内部温度变成了 96°C。外壳褐变程度变成了色卡 #7B4A2D。

老师傅的手感没有错——但手感不能复制、不能传授、不能同时存在于三十家店里。metric 做的事情就是：**把一个人的直觉翻译成所有人都能执行的数字**。

代价是什么？那个"伸手进烤箱感受热浪"的瞬间，消失了。

这就是 metric 的双面性：它让世界变得**可控、可传递、可比较**，同时也让世界变得**扁平**。每一个 metric 都是一次简化，一次选择性失明——你量了温度，就选择了不量"面包师的心情"。

## 4. 多面体：核心义项展开

### 义项 A：公制的（形容词）

> *The metric system is used in virtually every country except the United States.*
> 除了美国，几乎所有国家都使用公制。

和本质的关系：公制就是法国大革命时期创造的那把"标准尺子"——用地球本身作为度量基准，取代了各国各地乱七八糟的旧单位。**metric system = 一套统一的"怎么量"的规则**。

### 义项 B：指标、衡量标准（名词，常用复数 metrics）

> *User retention is the most important metric for this product.*
> 用户留存率是这个产品最重要的指标。

和本质的关系：从物理度量延伸到抽象度量。你选择用"留存率"而不是"用户满意度"来衡量产品，这个选择本身就是在决定"拿什么尺子量"。**每一个 metric 背后都是一个价值判断**：你觉得什么值得被量化。

### 义项 C：度量（数学/几何术语）

> *A metric space is a set equipped with a notion of distance between its elements.*
> 度量空间是一个集合，其元素之间定义了距离的概念。

和本质的关系：数学中的 metric 是最纯粹的形态——不是任何具体的尺子，而是**"距离"这个概念本身的抽象定义**。满足三个公理（非负性、对称性、三角不等式）的函数就是一个 metric。你可以在任何集合上定义不同的 metric，同一组点在不同 metric 下"距离"完全不同。这恰恰呼应了核心：**metric 不是客观真理，是你选择的度量方式**。

### 义项 D：格律的（诗学术语，较古旧）

> *The metric structure of a Shakespearean sonnet is iambic pentameter.*
> 莎士比亚十四行诗的格律结构是抑扬格五音步。

和本质的关系：这是 metric 最古老的面孔——对声音节拍的度量。轻音和重音的交替模式就是诗歌的"尺子"。和物理度量看似风马牛不相及，底层是同一件事：**给无序施加可识别的模式**。

## 5. 裂缝标注

### 常见误用

**❌ "The metric of this room is 20 square meters."**
这里该用 measurement 或 area，不是 metric。metric 是**衡量标准/方式**，不是**测量结果**。你不能说"这个房间的 metric 是 20 平米"，就像你不能说"这个房间的尺子是 20 平米"——尺子是工具，20 平米是读数。

**❌ 把 metric 当万能筐**
"What's the metric for happiness?" 语法没错，但暗含一个危险假设：幸福可以被一个数字捕获。在批判性写作中，故意使用 metric 来暗示"过度量化"是一种修辞手段——但如果你不是在做修辞，别这么用。

### 易混近义词辨析

| 词 | 区别 |
|---|---|
| **metric** | 你选择**用什么尺子量**——衡量标准本身。"Our key metric is DAU." |
| **measure** | 更宽泛：既可以是度量标准，也可以是度量行为，还可以是应对措施（take measures）。日常用词，metric 的非技术版。 |
| **measurement** | 度量的**结果/读数**。"The measurement showed 37.5°C." |
| **indicator** | 间接信号。metric 可以直接量，indicator 往往是推断。"GDP is an economic indicator"——GDP 不直接等于经济好坏，是间接指示。 |
| **criterion** | 判断标准，但不一定是数字化的。"The criterion for admission is creativity"——创造力不容易变成数字，所以它是 criterion 而不是 metric。 |

**实战场景：**
- 你在做产品——"What metrics are we tracking?"（我们在追踪哪些指标）✅
- 你在做产品——"What measurements are we tracking?" ← 也通，但 measurements 暗示更偏物理/精确读数，metrics 暗示偏商业/抽象指标
- 医生量体温——"The measurement is 38.2°C" ✅ / "The metric is 38.2°C" ❌（metric 是"用体温计量体温"这个标准，不是 38.2 这个数字）

### 中文母语者陷阱

**"指标"的陷阱：** 中文"指标"既指衡量标准也指具体数值（"完成指标"= 达到目标数值）。但英文 metric 只是**标准/方式**，不是目标数值。"We need to hit our metrics" 在硅谷口语中勉强能说，但严格来讲应该是 "hit our targets/goals"。

**"公制"的窄化：** 很多中文学习者一听 metric 就只想到"公制"（米/千克那套），忘了它在商业语境中"指标"的用法才是今天的高频义。

## 6. 搭配与语域

### 高频搭配

| 搭配 | 语境 |
|---|---|
| **key metric** | "关键指标"——几乎是 metric 最常见的搭档。"DAU is our key metric." 用在产品/商业讨论中。 |
| **metric system** | "公制"——固定搭配，指米/千克/秒那套度量体系。 |
| **performance metric(s)** | "绩效指标"——用于评估人、系统、产品的表现。 |
| **vanity metric** | "虚荣指标"——看起来好看但没有实际意义的数字（如总注册量 vs. 活跃用户）。硅谷味很浓的搭配。 |
| **metric ton** | "公吨"——1000 千克。注意和 ton（短吨/长吨）的区别。 |
| **track a metric** | "追踪某个指标"——最常见的动词搭配。 |
| **north star metric** | "北极星指标"——整个团队/公司最核心的那一个衡量标准。出自增长黑客话术。 |
| **actionable metric** | "可执行指标"——看了之后知道该做什么的指标，和 vanity metric 对立。 |

### 语域标注

- **学术/数学**：metric space, metric tensor（度量张量，广义相对论核心概念）——高度专业
- **商业/科技**：metrics, key metric, north star metric——中等正式，会议/报告/文档的标配词
- **日常口语**：较少单独使用。日常更可能说 "How do you measure that?" 而不是 "What's the metric?"
- **新闻**：常见于科技报道、经济分析。"by every metric, the economy is improving"

总体来说，metric 是一个**中高语域**的词，在技术和商业场合是空气词，在日常闲聊中偏正式。

### 活用示范

> *"Not everything that counts can be counted, and not everything that can be counted counts."*
> ——常被归于爱因斯坦（实际出处存疑）

这句话是对 metric 思维最精准的反击。它说的就是：你选择了什么 metric，你就选择性地忽略了什么。

> *"When a measure becomes a target, it ceases to be a good measure."*
> ——Goodhart's Law（古德哈特定律）

当一个 metric 变成了目标，人们就会为了数字而优化，而不是为了数字背后的东西。这就是为什么 vanity metrics 会存在——metric 本身被 hack 了。

## 7. 跨语言映射

**中文「度」：** 古汉语的"度"和 metron 有惊人的结构对称。"度"既是长度单位，也是"度量衡"的度（度量方式），还是"气度""风度"里的度（抽象尺度），甚至是"揣度"的度（用内心的尺子去量别人的心思）。从物理到抽象到心理，漂移轨迹和 metron 几乎一致。但"度"比 metric 多了一层温度——"己所不欲勿施于人"的"度"是带伦理的，metric 冷冰冰的。

**日语「尺度（しゃくど）」：** 和中文"尺度"同源，但日语中更常用于"衡量标准"的抽象义，接近 metric 的商业用法。

**德语 Maßstab：** Maß（度量）+ Stab（杆/棒），字面意思是"量杆"——一根用来量东西的棍子。比 metric 更有画面感，更接近"尺子"的具象。德语思维里，标准是一根你能握在手里的棍子；希腊思维里，标准是一个你在脑子里施加的抽象概念。

**法语 métrique：** 直接亲戚，用法基本对等。但法国人对 le système métrique 有一种民族自豪感——毕竟是他们发明的。在法语语境中说 métrique 带着一丝"我们用科学取代了迷信"的启蒙余韵。
