#### 不能伪装成“≤1pt”的项目

- **最大宽度**：官方长消息只能证明观测下界，没有撑满上限。按车头授权保留299pt / 对侧留62；本方六行实拍主体289pt，没有把它叫作最大宽度。LONG来源、换算与反证见plan §1b。
- **多行圆角**：本方拟合20.267pt，落在官方缩图三个样本19.18–21.02pt内；原图约0.57pt/像素并有JPEG噪声，不任选一个半径制造精确一致。
- **高度与padding**：AI单行41pt，比目标高⅔pt，来自共用Markdown文字视图整pt向上取整；在容差内，不改全局取整而破坏文章。多行平均padding是主体扣去六行自然行框后的反推，不冒充直接读取苹果布局值。
- **绝对消息y**：四句话来自不同参考上下文，42还含投票、贴纸、语音与Delivered，25还含照片和系统通知。本方不伪造这些内容；只比较相同连发段的相对y与间距，JSON保留所有绝对框。第二时间分隔的18pt上空白采用核准候选，参考上方是系统通知、本方是普通泡，不能称为同内容直接对拍。
- **渐隐**：全屏180pt处恢复到与更下方相同的实色；曲线不能判为≤1pt。原图浅色、蓝泡/灰泡与本方深色主题的颜色投影并不等于同一alpha；约20阶有效对比度的1阶量化已约5%，不足以反推1pt的位置差。保留实测偏差，不据蓝泡投影硬改主题或强拟合遮罩。以下比值为无字填充区投影，基准取本方y600/700/800px，不用y540自证100%。
