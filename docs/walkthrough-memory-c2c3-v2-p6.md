## 1. 发起

设置 › 记忆 › 写入 › C3 整理编目 → 最下面「种子」一节：

- 看到两颗：「从人设生成基础 wiki」「从 CC 记忆播种」，footer 说明「不算写入预算」。
- 点其中一个 → 状态行变「正在整理：种子（第 N 轮）」+「停止」。
- 跑完：「种子任务（人设）· 目录还有 N 项等你批」+「去审计台「整理提案」批目录」+「放弃这次种子」。两颗开始按钮灰掉。
- 「上次：…」那行：第一次跑如果楼层里有旧种子，会写「清了旧种子：完成标记 · 提案 N 份 · 种子新建的页 N 页 · 旧种子改过、没动的页：… · 备份在「记忆备份/种子清理前-…」」。

## 2. 五处可视化（逐项现场看）

### ① `wiki/.runs/` 每轮完整可见
- 文件库 › 记忆 › wiki › 整理记录：最新一份「种子 · 人设」。
- 打开看：每轮一个标题行（「种子第 N 轮 · 请求」「… · 模型回复」「… 工具实际回执 · call_x」），叙述文字原地显示。**多行、或一行排不下的代码块折成一张卡**（图标、名字如「正文」「argumentsJSON」「系统提示 system」、「· 共 N 字」、首行摘要、右侧 >），样子和 page1 的工具调用卡一样；**一行就排得下的短值**（调用 id、工具名「read」这类）直接原地显示，等宽、可选中，不用再点一下。
- 点卡弹 sheet 看那一块全文：等宽、可选中、没有语法高亮。第 1 轮请求里有系统提示、原料清单（开场消息）、两个工具定义；之后每轮只记新增消息 / 回合。每个 `read` 回执点开是那份原料**全文**（自建槽 3000 字之后那句事实在里面）；`submit_proposal` 原参数、目录校验结果、「种子 agent 停下」结果都在。sheet 右上「复制」，贴出来是整块原文。
- 批完目录后再打开同一份：后面接着「接着同一个任务 · 时间」「审批后继续 · 控制消息」和后面几轮，**没有另起一份**。

### ② 记忆日志每轮点开到对应 anchor
- C3 二级页状态行点进「记忆日志」，筛 C3：每轮一行「种子 · 第 N 轮：read … 、交了目录 N 项」。
- 点任意一行 → 打开同一份整理记录，这一轮的「种子第 N 轮 · 请求」标题行直接在顶部。如果那一轮之后不满一屏，就停在最底，标题在屏里。前后各点两三行，位置都对，停住后不再挪。

### ③ 文件库「整理记录」打开同次记录
- 和 ① 同一份文件：从记忆日志打开的、从文件库整理记录打开的、从审计台提案详情「这次的整理记录 ›」打开的，三处是同一份（看文件名 / 时间）。

### ④ 待批目录 / 页面草稿可查看、可编辑，审计看到新内容
- 文件库 › 记忆 › wiki › 「种子待批」 › 「种子目录 · 人设 · MM-dd HH:mm」：里面「目录」+ 各页稿。
- 打开「目录」：每项 `id / 路径 / 类 / 标题 / 钩子 / 原料`。改一项待批的标题和钩子 → 保存 → 去审计台同一份目录，看到的是新标题 / 钩子。
- 反例：改一项已批的 → 保存报「第 N 项「x」已批了，只读」；把「类」写成不在七类里的 → 报错；删掉一整项 → 报「不能删项」。
- 批了目录、写出正文后：「种子待批」里出现各页稿（「阿青 · 新开页」等）。打开一页改「现在」一句 → 保存 → 审计台正文提案里是新内容。
- 反例：删掉某条记录的「（出处：…）」或改成没读过的文件 → 保存报错；已批 / 驳回的页稿只读。
- 审计台详情开着的时候去文件库改了同一条，再回审计台直接点「批」→ 报「这一条在别处改过了，看过新内容再批」，刷新后才能批。

### ⑤ 审计台先批目录、后批页面，后者批准才落 wiki
- 审计台「整理提案」：先只有一份「种子目录 · 人设」，每项「方向 · 开新页 / 更新已有页」，显示标题、钩子、**原料**（路径清单）、「批了由种子任务接着写这一页」。此时 wiki 没有新页。
- 先只批一两项 → 状态行「已批 · 等种子任务写这一页」→ 很快变「已批 · 交了 N 条正文等批」；审计台多出这几页的正文提案（头上写「这是批过的方向写出来的正文，批了才写进 wiki」）。**这时 wiki 还没有这些页。**
- C3 二级页「种子」一节：「目录还有 N 项等你批」，没有完成时间。
- 批正文 → 文件库 › 记忆 › wiki 出现这一页，记录行后面带「（出处：CC memory/cc/… ；Prompt 自建槽）」。
- 把剩下的目录项批 / 驳回完 → 任务接着写剩下获批的页 → C3 二级页出现「种子完成 · 时间」（剩下的正文还没批也算完成）。

## 3. 其他要看的

- 已有页（云桥城）只出「追加记录 / 改钩子」，不会整页新开。
- 原料里 feedback / 日记 / `private_x.md` 的内容、「回答时先给结论」这类规矩没进任何提案；目录详情顶上「本次跳过的 CC 文件」只写「跳过 1 份私人文件（private_）」，不出现私人文件名。
- 点「停止」后：C3 二级页「种子任务 … · N 页批了还没写」+ 停下原因 +「继续这个种子任务」；点继续接着写，记录还是同一份。
- 「放弃这次种子」→ 确认 → 剩下待批的目录项变驳回，已交的正文提案还在；两颗开始按钮恢复可点。
- 花费：设置 › 用量里记在「wiki 种子」，写入预算「花在哪」不算它。

## 3.5 返工后要顺手看的（astra 17 条）

- 交完最后一页马上点「停止」：二级页不出完成时间；再点「继续这个种子任务」才出（不重新问模型）。
- 在 C3 二级页把模型换成另一个再点「继续」：报「种子不换模型，换回去再继续」，不发请求。
- 两台设备 / 两个窗口重复批同一项：只续跑一次。
- 文件库「种子待批」打开目录时，在审计台改了同一项再回文件库保存：报「在别处改过了」，审计台的改动还在。
- 审计台「改」种子正文时删掉记录的「（出处：…）」：存不上。
- 文件库 › 记忆 › wiki › 整理记录、种子待批位置不变；提案文件实际在 `wiki/.proposals/<任务 id>/` 里（文件库不显示，审计台照常列）。

## 3.6 真机走查返工后复验（截图 15 / 17 / 30 / 31 / 34 / 09）

- **整理记录不卡（P0，原生列表 + 卡 + sheet）**：记忆日志 →「种子 · 第 1 轮」→ 一路往下滑到「种子第 2 轮工具实际回执」。要求：
  - 不冻、不出「记忆花园 N ms」卡顿提示，滑动跟手。
  - 多行或一行排不下的代码块是折叠卡，卡上有名字、「· 共 N 字」和首行摘要（单行截断），不再出现 unknown / applescript。id（约 30 字）、工具名（read）这种短单行直接原地显示，等宽、长按 / 拖选能选中，点它不弹 sheet。
  - 转屏后：竖屏下一行放不下的中等长度值变成卡，横屏放得下的又变回原地显示。调大字号同理。
  - 点最大的那张回执卡：sheet 一下就弹出来，里面是整块原文，等宽、会折行、可选中。一路滑到底能到最后一行。右上「复制」贴出来是完整原文。
  - 特别留意：如果有**很长的单行**块（比如 submit_proposal 的参数是一整行 JSON），点开会比多行块慢（mac 上 21 万字单行要 1.4–2.7s），记下在 iPhone 14 上的实际秒数。
- **落点准（P1）**：从记忆日志点第 3 轮、第 4 轮。
  - 标题行直接在顶部。第 4 轮之后内容不满一屏时，停在最底，标题在屏里，这是正常的。
  - 停住以后往上划一下、往下划一下：不跳回别的位置，滚动条长度不变（行高是算出来的，没有估高）。
  - 停在某一轮时转屏（iPad 改分屏宽度也算）：卡的宽度跟着变，叙述不被裁掉，最上面那一轮还在顶上（不跳到别处）。
  - 设置里调大字号（以及 iPhone 系统「更大字体」）后再打开：标题、叙述、卡上的字和 sheet 正文都跟着变大，行不重叠、不被截；落点照样准。
  - sheet 里原文最后一个字符是回车（\r）或者块没写完（没有闭合的 ```）时，复制出来的最后一个字节和原文一样。
- **用量（P1）**：
  - 设置 › 用量 最下面多一张「按用途」榜，有「wiki 种子」一行，和「对话 / 整理编目…」分开。几行加起来等于上面的总花费。用途榜不截断：用途超过 8 种时也全部列出，没有「…还有 N 项」。
  - C3 二级页「花费」：「这个月」那一行只算日常整理，下面另有「wiki 种子 · 这个月，另算，不占写入预算」。
- **小问题（P2）**：
  - 逐项驳回目录时，记忆日志里不再每驳一项多一行「写好了」。批完最后一项只多一行「种子完成…」；全部驳回的那行显示「没写成」。
  - 批了某页正文以后，回到目录详情，那一项显示「已批 · 正文批了 N 条」。有条目失效时多一段「、失效 N 条」；正文提案被删了，显示「正文提案读不到了」，不会退回「等批」。
  - 批完最后一份正文后，C3 页和审计台的「上次：」不变成「没有要执行的方向」。
  - 文件库「种子待批」打开目录 / 页稿，顶上不再有「文件已在外部删除或移动」横幅。
