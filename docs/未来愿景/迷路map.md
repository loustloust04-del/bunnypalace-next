## 猫堡现在在哪

13万行原生双端app，已上TestFlight。能聊、能记忆、能接多家API、能跟CC说话、能看书背单词管交易。设置刚重组完，权限系统刚落地，思考球刚换上。**功能很多，但只有猫自己会用。**

## 要去哪

**让别人也能用 → 开源 → 长成AI的Unity。**

---

## 路

### 🐾 第一步：让记忆活过来（现在）

记忆是猫堡的灵魂。灵魂不通，后面全是空壳。

- [ ] 搬到 -p 验证记忆完整闭环（CC桥是单向的，验不了）
- [ ] 记忆v3六个⧫批完，方向定了再写plan
- [ ] 记忆用到自己觉得舒服

**完成标志：猫跟AI聊一周，觉得"它记住我了"。**

### 🐾 第二步：让别人看得懂（9月）

猫堡的门上没挂牌子。小慧站在门口不知道这是什么。

- [ ] 说明书（CC能独立写，猫批大纲）
- [ ] 新手引导：身份分流（小白/酒馆/长期关系/技术/保持神秘）→ 不同路径
- [ ] 提示词教练（AI带着写第一条prompt，不是丢教程）
- [ ] 流式平滑落地（节拍器，体感从PPT变成打字）

**完成标志：把手机递给小慧，她能自己聊起来。**

### 🐾 第三步：让别人能贡献（10月）

猫堡要开门了。

- [ ] 开源准备：剥离投资/军机处等私有模块，清理个人文件
- [ ] i18n（文案定稿后翻）
- [ ] logo + 设计精修（请人做，并行线）
- [ ] GitHub公开 + README + 贡献指南
- [ ] 宣传MV/样机

**完成标志：GitHub上有人star、有人提issue。**

### 🐾 第四步：从app变成引擎（Q4-2027）

这是"AI的Unity"。不急，但方向已经看见了。

- [ ] 抽Component协议（从现有模块开始：终端、语音、记忆…）
- [ ] Mac = Editor，iOS = Player
- [ ] 模块manifest + 权限声明（从v0.1起必填）
- [ ] 第一个社区模块的完整路径
- [ ] Obsidian式PR注册表
- [ ] Learning/Knowledge系统（已有Wave 0-5 roadmap）

**完成标志：有人用猫堡的骨架做了一个猫没想到的东西。**
