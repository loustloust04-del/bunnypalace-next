小芽 v2 · 设计小稿

目标：打开小芽的窗口，感觉是「一个小人在跟我说话」，不是「在用一个工具」。她的表情跟着状态变；她能提议改很多东西，但每一笔都得你盖章，盖完还能撤。

配色守老规矩：奶白纸底 + 墨绿线 + 浅灰薄荷只点一层。表情图是深墨绿，只压在奶白上，绝不压薄荷（禁止深绿套浅绿）。你的气泡用浅薄荷 + 深色字。

01窗口布局 · 三选一

同一段对话，三种放法。我推荐 A：她的脸在最上面、足够大，情绪一眼可见；消息区干净得像读信。B 最可爱但挡内容、键盘弹起时没地方待；C 最稳妥但就是个普通 IM。

C · 头像跟消息

普通 IM，每组消息一个圆头像，头像就是那一刻的表情。稳，但 38pt 头像里表情细节看不清，形象的魅力浪费掉大半。

02表情跟着状态走

小模型不靠谱，所以表情由 app 按事件切，不指望模型自己记得换。模型可以附一个可选情绪标签，有就用，没有也不影响。切换时 0.25s 淡入 + 轻微弹一下。

03提案 → 盖章 → 可撤销

「应用 / 丢弃」改成「不要 / 盖章」。卡里是旧→新对照（旧的划掉、新的荧光笔），不是一段纯文字说明。盖章后按钮消失，椭圆邮戳「啪」地落下，左下出现「撤销」。删除类提案盖章后还要再确认一次。

放权：外观试穿

外观类提案卡里直接画「现在 / 盖章后」两块小屏，用 app 里真的主屏渲染出来（这里是示意）。看见效果再盖章，蠢模型挑错了你一眼就知道。

04放权范围 · 设置里按包开关

「放权」= 让她能提议更多种改动；「必须批准」= 每一笔都走盖章，没有例外。关掉的包，工具连定义都不发给模型（顺带给小模型减负）。

只读：查记忆 / 读预设 / 读世界书自动执行，不用盖章
创作：角色卡 / 预设插槽 / 采样参数 / 世界书每一笔盖章；删除要再确认一次
外观：主屏壁纸 / 图标外观 / 明暗 / 大图标 / 单个图标每一笔盖章，卡里带试穿预览
她自己的窗口：纸色 / 墨色 / 表情大小每一笔盖章
三档规则

只读 → 直接跑。
可逆写 → 提案卡 → 盖章 → 落地 → 进账本（可撤销）。
破坏性（删条目、覆盖整份预设）→ 提案卡 → 盖章 → 再确认 → 落地 → 进账本。

代码层面：写工具只会「产出提案」，真正落库的函数只在你按盖章的回调里被调用。模型没有任何一条路能直达数据。

05账本 · 她改过什么，一键撤回

舞台头右上 ☰ 进入。每次盖章都存一份「改前快照」。就算你手快批错了，也能退回去——给「小模型蠢」的第二道保险。

06本地大脑 · 下载卡

第一次打开小芽（或在设置 › 小芽里）出现。不会自己开下，1 GB 要你点。下完之后不联网也能聊，也不花楼层 API 的钱。模型放在 app 自己的目录里，不进 iCloud 备份，可以一键删掉。
