## 一句话

设置 → 记忆 最底下的调试区，把「按新规则重写…」换成「搬成新样子…」：先整份备份，然后这一层起点以后的窗口一个一个搬——第一代摘要落成 A2 的第 0 段，第二代的老收尾段拿掉、那截按 v5 补成 A2 正式段，每个窗口写一遍尾段，再把整个窗口重压成一段约 300 字的 A3。一个窗口要么全搬好，要么原样不动；搬不成的列出来；不满意一键恢复。时间轴已经是新格式的不动。另外记忆 app 的「窗口总结」格改成你说的样子：点进一个窗口，上面 A3，下面 A2 一段一段。

## 一、A2 和 A3 到底是什么（你的话）

- **A2 上下文摘要**：还是之前那个。一个窗口聊长了，挤出视野的那截记一段，**一点描述 + 原文**：标题、【经过】（三百字以内，发生了什么、我当时怎么想）、【原话】（两边关键的几句逐字抄，不是全文）。聊得越久段越多，**有很多次**。最后那截还没被挤出去的叫**尾段**，也放在 A2 里，每次收尾整段重写，等它真被挤出去了换成正式段。改造前那份大摘要，原样当 A2 的**第 0 段**放最前面。
- **A3 窗口总结**：**就是把 A2 再压一遍**。读这个窗口 A2 的全部段 + 尾段，压成一段，约 300 字。一个窗口只有一段 A3。
- 所以每个对话里放的就是：一份 A2（很多段）+ 一份 A3（一段）。时间轴 A4 另算，按天记，不在窗口里面。

## 二、三代现在长什么样、各自搬成什么

| | 现在是什么 | 搬成什么 | 花钱吗 |
|---|---|---|---|
| **第一代** · 改造前的累计摘要 | 一整块旧摘要，单独放在一个老文件夹里；有的窗口已经被抄进 A2 当第 0 段了，有的还没有（这些窗口在记忆 app 的窗口总结格里**根本看不见**） | 还没抄进去的，抄进 A2 当第 0 段（原文一字不改）。老文件夹不动 | 不花 |
| **第二代 · A2 那边**：第三刀写的老收尾段 | 和 A2 混在同一个文件里，不注入、不进 A3，只是挂着 | 拿掉；它盖的那截：已经挤出视野的按 v5 写成 A2 正式段，还在视野里的进尾段 | 花 |
| **第二代 · A2 那边**：第三刀写的老式压缩段（带【待续】、爱用「这个窗口」开头） | 主楼层 v4-1 那次已经重写过起点以后的；少数没重写成的还在 | 这个窗口起点以后的 A2 整段按 v5 重写一遍（同 v4-1 的做法）。段里的【待续】不搬进待续本子（见第六节） | 花 |
| **第二代 · A3 那边**：v4-1 的窗口总结 | 是 A2 的**抄本** + 最后那截（最多 150 条）一段，所以一个窗口好几段 | 扔掉抄本，按 v5 重压成一段约 300 字 | 花（每窗口 1 次） |
| **第三代** · v5 | 已经是新样子 | 写到最新那条了就跳过；后来又有新消息的，补一遍尾段 + A3 | 少量 |

**每个要搬的窗口，固定顺序**：① 第 0 段落位 → ② A2 补正式段（有老收尾段 / 老式段才有这步）→ ③ 写尾段 → ④ A3 重压 →（⑤ 时间轴，只给极少数窗口，见第五节）。**全成才换这个窗口的文件**，有一步没成，这个窗口整个留原样，列进「没搬成」。

**哪些窗口算「要搬」**：这一层里，「记忆从哪天开始」以后还有消息的窗口。起点以前的窗口一个字不改（第一代那种只落第 0 段，不花钱，见 Q3）。

## 四、一次搬完的流程

1. **先算**：数窗口、分类、估钱估时（不调模型）。
2. **备份**：整个 A2、A3、时间轴、待续本子、第一代老摘要五个文件夹拷一份，逐个核对大小，核对完才算数；核不上就停，什么都不改。
3. **暂停日常写手**：跑的时候自动收尾、上下文摘要、「现在写」都先停（碎片池 C2 照跑，它不碰这些文件）。
4. **一个窗口一个窗口搬**（按顺序，不并发）：每个窗口先在旁边写好，全成了才换进去。
5. **断了怎么办**：断网、切后台、App 被杀——**已经搬好的留着**，正在搬的那个原样不动，剩下的没碰。再点一次「搬成新样子…」，搬好的会被认出来跳过，只搬剩下的（Q2）。
6. **预算闸**：不看写入预算（同「现在写」），全局预算闸照查；连着 3 个窗口被闸拦下就停，告诉你是预算的事。
7. **结果列表** + 放开日常写手。
8. **一键恢复**：「从备份恢复…」→ 选「v5搬迁-时间」→ 恢复。现在的文件先挪进「回滚前-时间」再拷回去。**注意**：恢复是整个换回备份那一刻，搬完以后日常新写的（A2 新段、A3、时间轴、待续）也会一起撤回。

## 五、时间轴 / 待续 / C2 怎么处理

**时间轴（A4）：推荐这次基本不动。**
- 理由：v4-1 那次已经把起点以后的时间轴按 v2 重写过；v5 的时间轴条目和 v2 是**同一个格式**，唯一变的是待续挪进了单独的本子，而本子在第一次用的时候已经从每个窗口最新那条里拆出来了。再重写一遍要按「每天 × 每窗口」花钱，还会把待续本子搅乱（同一件事换个说法就多一条）。
- **唯一例外**：某个窗口起点以后**一条新格式条目都没有**（只有老格式那种一大段话的，或者完全没有）——这种窗口的「时间轴写到哪了」现在是靠 A2 里的老收尾段记着的，老收尾段一拿掉，下次收尾会从倒数 150 条重写、和老条目重叠。所以这种窗口顺手把起点以后的天按 v5 写成新条目（新冒出来的待续进本子，一字不差的不重复加）。你主楼层跑过 v4-1 重写，这种窗口应该很少；没跑过重写的楼层（比如 CC 楼层）会多。
- 如果你的 v4-1 那次其实没跑成，这条例外会自动兜住，不用另外处理。

**待续本子：不动，不会重复。** 搬迁本身不往本子里加东西；只有上面那条例外里的窗口会按 v5 的规矩「只加、不重复」。第三刀老式段里的【待续】（「仍未问到」「上段遗留」那种）不搬进本子——v4-1 验收时就认定那是噪音，v5 的待续只从时间轴来。

**C2 碎片池：不动，不会重复。** 它只读新消息，不读 A2 / A3 / 时间轴；搬迁不产生消息。代价：老对话不会补碎片（C2 只从上线那天起记），要补得另开一单。

## 六、记忆 app「窗口总结」格（你 10-16 补的）

- **列表每行「记了 N 段」= 这个窗口 A2 的段数**（第 0 段、正式段、尾段都算）。现在数的是窗口总结那份文件的段数：v4-1 抄本是 A2 段数 + 1，v5 是 1，三种口径对不上。改成统一数 A2。
- **点进一个窗口**：最上面一张卡 **A3 窗口总结**（约 300 字、写到哪天）；下面 **A2 上下文摘要**，一段一段从早到晚排，每段：时间 · 标题 · 经过 · 原话。**第 0 段**标「改版前的累计摘要」，**尾段**标「尾段 · 还在聊，会整段重写」。
- 还没有 A3 的窗口（起点以前的、还没收过尾的）：上面那张卡写「还没压成窗口总结」，下面照样列 A2。
- 起点以前没搬的窗口里还挂着的老收尾段：放在最下面一组灰字「老收尾段（v4，起点以前没搬）」（Q4）。
- 对话 ⋯「上下文摘要」那页现在把尾段藏了（尾段的类型和老收尾段一样），改成显示尾段并标出来。
- 「正在记」那行：现在还在看旧的「上下文摘要」开关、文案写「上下文摘要和窗口总结」——v5 收尾看的是 A3 / A4 两个写入开关，改成按 A3 / A4 判、文案用编号（例：「A3 窗口总结、A4 时间轴都关着，窗口收尾不跑」）。

## 七、开关关着怎么办（你截图里写入都关着）

- **搬之前、验之前，先去 设置 → 记忆 → 写入，把 A2、A3、A4 打开**（或者把「复杂度」拖到「中」，一次开好）。验收单第一步也写了。
- **推荐：A2 / A3 / A4 单项关着，搬迁照样能搬**——搬迁是一次性整理旧数据，不是日常写。确认框里多一行提醒：「A2 / A3 关着：搬完以后不会自动跟上新消息，打开后才接着写」。
- 搬完的东西进不进 prompt：A2 看 设置 → 记忆 → 注入 →「开窗口带什么」里 A2 那一勾；A3 本来就不进 prompt，只给 recall 和记忆 app 看。
- **总开关关着：按钮灰**（同 v4-1）。总开关 = 你明确说「记忆整个别在后台花钱」，搬迁也算。

## 八、要你拍板（推荐在前，一句一个）

1. **时间轴**：已经是新格式的不动，只给「起点以后一条新格式条目都没有」的窗口补写 ／ 全部重写一遍 ／ 完全不动（那就在这种窗口里留着老收尾段当记号）。**推荐第一个。**
2. **中途断了**：搬好的留下、再点一次接着搬 ／ 全部撤回（v4-1 的做法，已花的钱白花）。**推荐第一个。**
3. **起点以前的窗口**：只有第一代老摘要的，落成第 0 段（不花钱，窗口总结格会多出这些行）、别的不动 ／ 全都不动。**推荐第一个。**
4. **起点以后的窗口里、起点以前那截只有老收尾段记着的**：留着、标「老收尾段」（不注入、不进 A3，只有它记着那截）／ 拿掉（同 v4-1，备份里有）。**推荐留着。**
5. **开关**：A2 / A3 / A4 单项关着照样能搬、总开关关着灰 ／ 单项关着也不让搬。**推荐第一个。**
6. **楼层**：一次搬当前这一层（确认框写楼层名，换楼层再点）／ 所有楼层一次跑完。**推荐当前这一层**：每层人设、模型不一样，先搬一层验了再搬别的。
7. **老按钮**：「按新规则重写…」换成「搬成新样子…」一个按钮 ／ 两个都留。**推荐换掉**（全量重写的本事留在搬迁里面用，只给带老式段的窗口）。
8. **Release 要不要也有**：先只在 DEBUG ／ Release 也给。**推荐先只在 DEBUG**（同 v4-1 Q10）；别的用户的老数据 v5 都读得了，不会坏。
9. **第三刀老式段里的【待续】**：不搬进待续本子 ／ 搬进去。**推荐不搬。**
10. **窗口总结格**：按第六节（上面 A3、下面 A2、数 A2 段数、标第 0 段 / 尾段）。**推荐就这样**；要不要把老收尾段那组也藏掉，你看着定。

## 九、花多少钱 / 多久：怎么估

- **次数**：每个要搬的窗口 = A2 补写份数（要补的那截按 60 条一份）+ 尾段 1 次 + A3 1 次（+ 例外窗口的时间轴：每天每 60 条一份）。再乘 1.15 算格式不对重写的。
- **钱**：先不调模型，把每次要喂给模型的东西真拼出来数字数（人设 + 提示词 + 上一段全文 + 这截消息，每条消息最多 1500 字；A3 = A2 全部段 + 尾段之后的原文），换算 token；输出按每次 1500 token 的上限算（偏贵的估法，和预算闸同一个口径）；乘各写手自己选的模型单价。A3 的输入要等尾段写出来才知道，先按每段尾段约 800 字估。
- **时间**：次数 × 每次 25 秒先估一个；开跑后按真实平均每次多久随时改「还要约几分钟」。
- **最贵的三个窗口**列在确认框里，嫌贵可以先把那几个窗口的「记忆参与」关了再搬（关了的窗口不搬）。
