## 机制要点（从整理 prompt 逆出）

- **schema 冻结**：表的增/改/删 PROHIBITED，`freezeSchema: true`，只许 `valueInsertion` + `contentOptimization` → **列是契约，AI 只填不改**
- **四步流水线**：SUPPLEMENT（补）→ SIMPLIFY（精简）→ CORRECT（纠错）→ SUMMARY（总结）
- **入表阈值**（不是什么都记）：`plotCriticality≥3`、`emotionalShift≥2`、物品 `symbolicImportance≥5`；连续 3 个相似事件触发急停
- **分层压缩**：10 条原始事件 → 一级摘要（模板「[角色]在[时间段]通过[动作链]展现[特征]」，≤200 字，生成后锁定）；3 条一级摘要 → 高级综合（关注 growthArc / worldRules）
- **保护标记**：`[TIER1]` `[MILESTONE]` 免疫清理；关键特征（异色瞳等）关键词命中≥2 即锁
- **清理规则**：精确重复、时间线冲突（级联删）、空行（时空表除外）、过期任务（>20 天归档）；触发阈值 1000 事件或 85% 存储
- **冲突处理**：时间悖论 → freezeAndHighlight + `⚠️REQUIRES_ADMIN` 人工介入标记
- **AI 每轮重写整张表**（输出完整 JSON 表格），不是增量 patch

## 三个参照物的差异

| 维度 | Claude 官方 Memory files | ST 表格插件 | Unity |
|---|---|---|---|
| 最小单元 | markdown 文件 | 表格行 | GameObject |
| 结构 | 分组（You/Topics/Areas/People）+ bullet 列表 | 固定列 schema | Component 组合 |
| 元数据 | 一行 description | enable/Required/asStatus/toChat/note | 类型 + 序列化字段 |
| 谁维护 | AI（用户自然语言指令改） | AI 每轮全量重写 | 人 + 脚本 |
| 编辑入口 | 「Tell Claude what to change or remove」 | 表格 UI 直接改 + AI 改 | Inspector |
| 强项 | 自由、人可读、易增删类别 | 结构化、可查询、可比较、有阈值纪律 | 类型系统、引用、实例化 |
| 弱项 | 无结构 → 难查询/难聚合 | schema 冻结 → 不适应新领域 | （非记忆系统） |
