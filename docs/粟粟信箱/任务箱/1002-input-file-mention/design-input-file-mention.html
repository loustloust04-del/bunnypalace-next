输入框 @ 文件 · 最近文件横条

page1 日常聊天 · 10-02 小样 · 研究见 research-input-file-mention.md

A打 @ 找文件库里的文件

  • 输入框末尾出现 @+字，文字框正上方浮出候选（最多 5 条），和 CC 斜杠命令浮板同一个位置。
  • 只比文件名（再加文件夹名）：名字开头命中排最前，其次名字里含，最后文件夹含；同档新的在前。@嗷 → 嗷呜嗷呜.md 排第一。
  • 拼音输入法组字期间不出候选，字上屏才出。
  • 点选后：输入框里的「@嗷」被删掉，附件条里多一张文件卡（推荐）——不在字里塞小药丸。

B📎 变成「最近文件」横条

  • 点「＋」面板里的 📎 不再直接弹系统文件单，像相册那样在下方换成一条横滑：文件库里最近改过的文件。
  • 图片显示缩略图，其他显示扩展名小方块（MD / PDF / TXT…）+ 名字。点一下勾选，可多选，工具栏出「附加 N 个」。
  • 下面两个入口：文件库（搜索 + 浏览全部，多选）、手机里的文件（就是原来的系统文件单）。

发发给 AI 的样子

  • 文件库文件当普通文件附件发，和从手机选文件完全一样，发送那条路不动。
  • 普通模型：文字类（md / txt / pdf 抽字）拼在消息后面，最多 6 万字；图片走看图；CC：收原文件。
  • 发出去的是那一刻的内容，之后在文件库改了不影响这条消息。
  • iCloud 里还没下载到本机的文件暂时搜不到（文件库 iCloud 默认关）。

mac电脑上

  • 输入框是同一个，@ 候选两端都有；mac 加键盘：↑↓ 选、回车 / Tab 确定、Esc 关（候选打开时回车不发送）。
  • 📎 同样换成最近文件横条，第二个入口叫「电脑上的文件」；拖文件进输入框照旧。
