怎么看，二选一：
- **看图**（快）：9 张实拍在 `[wt-mac] docs/shots/mac-fullscreen/`，`v2-01` ~ `v2-06` 是六种状态，`v2-09-同窗缩放-1000/1200/1345` 是同一实例缩放三张。我可以直接发给你。
- **上手**（准）：从 `worktree-mac` build 一版，拖窗口走一遍 980 → 1440 → 1600。

重点看这四条（都是设计取舍，不是 bug，你觉得不对我就改）：
1. **两侧面板都开着时窗口再宽，卡两边只是留白变宽**——格子只长在收起那一侧的空地上（09-17 你裁的）。觉得空的话，下一刀可以裁「双开时也给卡外留格子」。
2. **列数是跳变的**——空地够一列时 lane 跳 180pt，卡跟着跳。滞回只防抖不防跳。
3. **桌面组件视觉上移 48pt**——停靠壳格子从 16 起（原来 64），索引不变、组件没搬家，但你第一眼会觉得位置变了。
4. **标题可能被右侧按钮压住**——卡靠右且很窄时标题右端会伸到按钮底下，现在靠截断兜一半。
