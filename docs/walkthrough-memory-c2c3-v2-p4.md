# 走查要点 · C2/C3 v2 第 4 段「两批审批」（合并后模拟器上验）

只看虚构楼层，别用粟粟的真实数据。先在一个新楼层里造几条碎片：审计台「没看过」里点「留下」，让它们是 10-01 以后、已留的。最好有 3 条主体相同（比如都关于「灯塔航线」），再有 1 条主体能碰上一个已有 wiki 页的标题 / 触发词。

## 1. 自动：先只提方向

- 从哪进：mac 跨 05:00 / iOS 新的一天第一次打开 app；模拟器上可以先 `xcrun simctl spawn <模拟器id> defaults delete <iOS bundle id（带 .ios）> mem_c3_ran.<楼层id>` 清掉这层「今天跑过」，再把 app 切到后台又切回来。然后 设置 → 记忆 → 审计台 → 第四段「整理提案」。
- 看什么：
  - 列表多一张「定时整理 · 方向 N 个」的卡，下一行「待批 N」。
  - 记忆日志（C3）有一行「自动提方向（只看碎片标题和 wiki 索引，没调模型）：更新已有页 a 个 · 开新页 b 个」；C3 本期花费没有增加（没有分组调整时）。
- 点进去：每条是「方向 · 开新页」或「方向 · 更新已有页」，显示标题、钩子（已有页才有）、「为什么」（几条碎片的标题）、「线索碎片（只看标题）」、「批了以后查一次原料、写一次，写好的正文再交你批」。没有正文。
- 点「改」：能改目标页路径 / 标题 / 钩子；路径改成不以「工程/」「楼层/」开头的，存后不生效（还是原路径）。

## 2. 批方向 → 自动开始写 → 正文另一份提案

- 点某条方向的「批」：
  - 这条下方变成「已批 · 正在查原料、写」，顶上操作区出现「正在整理：<标题>」+「停」。
  - 跑完这条显示「已批 · 交了 N 条正文等批」（或「没有可写的材料：…」「单条就够 N 条，留在碎片池」「被拦…」「出错…」）。
  - wiki 里还**没有**这一页（记忆 app → 记忆格 wiki，或文件库「记忆 › wiki」）。
- 回列表：多一张同标题的正文提案，点进去头上写「这是批过的方向写出来的正文，批了才写进 wiki」。
- 批这份正文：这时 wiki 才出现这一页；线索碎片在审计台卡上变「已整理进《页名》」。
- 只批一条方向、驳回另一条：被驳回方向的线索碎片卡上**不**出现「整理时驳回」。
- 同一条方向连点两次「批」/ 批完退出再进来：不会再跑第二次（C3 花费只涨一次）。

## 3. 确认已覆盖

- 让一条碎片碰上已有页、而页上已经写了这件事：批方向后，正文提案里是一条「确认已覆盖」（没有「改」按钮），说明「页上已经写过这些碎片，不改页；批了只把它们标成已整理进这页」。
- 批它：页内容不变（文件库打开页面对比），碎片卡变「已整理进《页名》」。

## 4. 手动：说一次就开始

- 「整理一个主题…」输入一个主题 →「开始」：**不**出现待批方向，直接「正在整理：<主题>（第 N 轮）」；跑完是一份「整理主题「X」」正文提案，头上写「你说的：整理一个主题：X」；批了才落页。
- 「现在整理」：同上，每个主题一份「现在整理」正文提案，头上「你说的：现在整理」；整理中点「停」，后面的主题不再跑。

## 5. {助手}提方向（默认直接给）

- 从哪进：Prompt 页的「工具抽屉」→ 记忆组，能看到「suggest_wiki_direction · {助手} 给记忆 wiki 提整理方向（{用户}批了才去查、写）」，默认开着、是「直接给」。
- 聊天里请{助手}「把云桥城整理进 wiki」之类：聊天里出现「整理方向」工具卡，回执说「已经交给用户…」。
- 审计台出现一张来源是{助手}名字的提案，里面一条方向（执行方式「批了自己查原料再写（最多几轮）」）。批了才开始查、写，正文再批一次。
- 这场对话 ⋯ 关掉「记忆参与」后再让它提：回执「这场对话关了记忆参与，不能提整理方向」。
- 抽屉里关掉：工具清单里不再有它。

## 6. 宽度 / 外观

- iPhone 宽度下方向卡的「为什么」「线索碎片」多行能折行、不溢出；「已批 · …」那行结果文字长时不和右侧按钮重叠（批过后右侧没有按钮）。
- 深色主题下新文字颜色跟随主题（没有写死颜色）。

## 7. 返工新增（10-22）

- 「确认已覆盖」条目下列出「页上已经写过的碎片」（点了跳原消息），再点「对照这一页现在的样子 ›」弹出这一页全文。
- 方向「改」里把钩子改成一句新的再批：正文提案里新开页的「钩子」就是这句；已有页会多一条「改钩子 / 触发词」（旧 → 这句），照样等批。
- 设置里关掉 C3 后去批一条方向：这条马上显示「已批 · C3 关着，没执行」，重新打开 C3 也不会再跑。
- 方向正在写时强退 app 再打开：这条显示「已批 · 上次运行中断，没交正文」（或已交时「交了 N 条正文等批（上次运行中断前已交）」），不会自动重跑。
