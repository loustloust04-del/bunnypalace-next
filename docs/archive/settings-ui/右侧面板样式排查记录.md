# 右侧日历面板样式排查

## 问题

日历面板（右侧 inspector）的外观和左侧栏不完全一致。用户希望两边看起来一样。

## 当前实现

### 左侧栏
- 在 `NavigationSplitView` 的 `sidebar` 列里
- `SidebarView` 末尾有 `.background(Theme.sidebarBg)` — 不透明暖米色 `#F8F4EF`
- 内部区块用 `RoundedRectangle(cornerRadius: 16).fill(Theme.mainBg.opacity(0.6))` 做浮卡
- **系统处理**: NavigationSplitView 的 sidebar 列会自动应用 `NSVisualEffectView` + `.sidebar` material，但被 `.background(Theme.sidebarBg)` 的不透明色覆盖了

### 右侧面板
- 用 `.inspector(isPresented:)` 修饰符（macOS 14+ 原生）
- `CalendarPanelView` 内部同样用 `RoundedRectangle(16).fill(Theme.mainBg.opacity(0.6))` 浮卡
- **没有** `.background(Theme.sidebarBg)`，所以显示的是 inspector 的系统默认背景（可能是半透明 material）

## 可能的差异原因

1. **背景不同**：左侧是不透明 `sidebarBg`，右侧是系统 inspector 默认背景（translucent material）
2. **系统 material 不同**：NavigationSplitView sidebar 用的是 `.sidebar` material，inspector 用的可能是不同的 material
3. **titlebar 延伸**：左侧栏上方和 titlebar 无缝连接，inspector 面板可能有不同的 titlebar 处理
4. **分隔线样式**：NavigationSplitView 自动生成的列分隔线 vs inspector 的分隔线样式可能不同

## 待尝试方案

### 方案 A：给 CalendarPanelView 加回 sidebarBg 背景
最简单。让两边都用同样的不透明背景色，视觉一致。
```swift
// CalendarPanelView body 末尾
.background(Theme.sidebarBg)
```
**缺点**：覆盖了系统 material，可能失去原生质感。

### 方案 B：用 NSVisualEffectView 统一两边背景
给 CalendarPanelView 用和 NavigationSplitView sidebar 一样的 `.sidebar` material：
```swift
struct SidebarMaterialBackground: NSViewRepresentable {
    func makeNSView(context: Context) -> NSVisualEffectView {
        let view = NSVisualEffectView()
        view.material = .sidebar
        view.blendingMode = .behindWindow
        view.state = .followsWindowActiveState
        return view
    }
    func updateNSView(_ nsView: NSVisualEffectView, context: Context) {}
}
```
然后 `.background(SidebarMaterialBackground())` 同时用在左右两边。
**优点**：真正统一。**缺点**：需要改 SidebarView 也换成这个。

### 方案 C：不用 .inspector()，改用三列 NavigationSplitView
NavigationSplitView 支持三列（sidebar + content + detail）。把日历放在其中一列，系统自动处理所有列的样式一致性。
```swift
NavigationSplitView {
    SidebarView(...)         // sidebar 列
} content: {
    // 把当前的 detail 放这里
} detail: {
    CalendarPanelView(...)   // 第三列
}
```
**缺点**：三列的角色映射不太自然（sidebar=对话列表, content=气泡流, detail=日历），而且第三列不能折叠。

### 方案 D：放弃系统 inspector，用 HSplitView + NSVisualEffectView
完全手工控制右侧面板，用 NSVisualEffectView `.sidebar` material 做背景，HSplitView 做分栏。
```swift
HSplitView {
    // 主内容
    CalendarPanelView(...)
        .background(SidebarMaterialBackground())
}
```
**优点**：完全控制外观。**缺点**：失去 inspector 的系统行为（如自动适应窗口大小、和 toolbar 集成）。
