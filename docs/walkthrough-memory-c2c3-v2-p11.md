# 走查要点 · C2/C3 v2 第 11 段「新用户三问」（合并后模拟器 / 😷 iPhone 14 上验）

只用虚构楼层和虚构答案，别用粟粟的真实数据。三问只在新用户引导里出现，走查从「从头放一遍引导」或设置「?」→ 新手引导进。

## 0. 怎么进

- 设置 → 调试（Debug 包）→「从头放一遍引导」：和新装一样从开场白放起，会真的写园丁类型、钥匙、新楼层。
- 或设置页搜索框旁「?」→「新手引导」：从分流卡重走（主动重走才会再问三问）。
- 先看卡长什么样：设置 → 调试 →「小芽卡片样张」，往下翻到「第 11 段 · 新用户三问」。

## 1. 陪伴线：建好 Ta 之后、出口卡之前问

- 选「长期陪伴」→ 配钥匙（或跳过）→ 起名卡填 Ta 名和「Ta 怎么称呼你」→「建好 Ta 的楼层」。
- 看什么：
  - 先说「X……好名字」那句，然后舞台「想多认识你一点」，再一句「再问你三个小问题…都能空着～」，出三问卡。**出口卡这时还没出**。
  - 卡上三格：想让我叫你什么（已经预填起名卡里填的称呼）/ 平时在做什么（工作 / 学习 / 创业）/ 有没有我应该知道的（可跳过）；底下一行说明「先列个目录给你批…」；按钮「就这些」「都跳过」。
  - 点「就这些」：卡收起成一行摘要，你那边多一个气泡（同一句摘要）。有钥匙时她说「记下了。我照这几句先列个目录放进审计台…」；接着才出新楼层出口卡（去找 X / 继续问我 / 导入以前的聊天记录），含义和以前一样。
  - 点「去找 X」：照样收尾并切到 Ta 的楼层；不会再问第二次。

## 2. 酒馆线：导完卡之后问

- 选「酒馆用户」→ 导一张卡 →「读好了」那句之后出三问卡，答完才出出口卡（导入世界书 / 导入预设）。

## 3. 小白 / 技术线：没建 Ta，收尾之前问

- 「我是小白」→ 挑头像（称呼填一个名字）→ 钥匙「先跳过」：在「搞定啦」待办卡之前出三问卡，称呼预填挑头像时填的名字。答案落**当前楼层**。
- 「都跳过」：她说「好，都空着也没关系，我什么都不记」；审计台、C3 页都没有新东西。
- 「保持神秘」：不出三问卡。

## 4. 答完以后：两批审（切到答案落的那层看）

- 设置 → 记忆 → C3 →「种子」那节：出现「种子任务（新用户三问）· …」。
  - 有钥匙、C3 开着：几十秒后状态变「目录还有 N 项等你批」。
  - 生成不了的时候：状态「还在读原料、没交目录」，下面一行灰字「还没生成：<原因>。<怎么恢复>」，小芽那句是「现在<原因>，可以稍后生成：<怎么恢复>」，引导照常走完、能直接聊天。按原因各验一次：
    - 没钥匙：提示先去「设置 › 模型和API」配钥匙；配好后点「继续这个种子任务」才开始出目录。
    - C3 关着：提示去「设置 › 记忆」把 C3 打开（这时「继续」按钮是灰的，打开 C3 后才亮）。
    - 记忆总开关关着：提示打开记忆总开关。
  - C3 选的是 CC 桥接模型（没有钥匙）：答完应当直接开始出目录，不是「没有能用的模型」。
- 审计台 → 整理提案：一张「种子目录 · 新用户三问」。
  - 点进去：每项是路径 / 类 / 标题 / 钩子 / 原料；她本人的页在「楼层/<你的称呼>/…」下、类是「用户」，页名是模型起的；原料只有 `问卷/称呼`、`问卷/在做什么`、`问卷/应该知道的`。
  - 这时 wiki 里**还没有**这些页（记忆 app 的 wiki 格 / 文件库「记忆 › wiki」）。
  - 「这次的整理记录 ›」打开：开头一节「问卷答案」能看到你填的原话，标题里写着答题日期和原答案文件 `wiki/.survey/<任务 id>.json`。
- 批一项、驳回一项：过一会儿出现获批那页的正文提案，驳回的不写。正文里记录行以答题日期开头（不出现「日期未注明」「时间未注明」），末尾是「（出处：问卷「在做什么」2026-10-22#1A2B3C4D）」，出处小字是「问卷 · 2026-10-22 · 在做什么」。
- 页数：三条普通回答一般只出一两页（她本人一页，答案里另有能写几句的项目再一页）；只出现一次的地名、名字写进相关那页，不单开。拆碎了就在目录里驳回，这是目录审批该挡的。
- 批正文：这时 wiki 才出现这一页。C3 页种子那节变「完成了」；**不会**出现「种子完成 · 时间」那一行（那行只给「从人设 / 从 CC」的种子）。

## 5. 同名页、切楼层、中途恢复

- 同名页：先在这层楼手建一页「楼层/<称呼>/在做的事」，再重走引导答三问。目录里这一项显示为更新已有页；正文只有「追加记录」（可能带一条「改钩子」），原来的「现在」和旧记录不动，批之前文件一个字不变。
- 切楼层：三问卡出来以后，先切到别的楼层，再回小芽答。答案落在问的时候那层（Ta 的楼层或当时的当前楼层），不是现在所在的楼层。
- 中途恢复：三问卡出来以后杀掉 app 再开，小芽里还是停在这张卡上（不重复出两张）；答完、在「记下了…」那句出来之前杀掉，重开后不会在审计台多出第二个三问任务。
- 称呼：三问里改了称呼，目标楼层的「我的名字」和默认称呼跟着变；已有的记忆、wiki 页不改。

## 6. 两个种子任务

- 已有一个「从人设生成基础 wiki」没批完时重走引导答三问：C3 页种子那节先显示三问那个；三问那个结束（完成 / 放弃 / 目录全驳回）后，旧的那个和它的「继续 / 放弃」再出来。审计台两份目录都在、都能批。
