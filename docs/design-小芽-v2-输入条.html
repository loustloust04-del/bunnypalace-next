小芽 · 输入条小样

现在的问题（你说丑）：输入框是一个描边圆角框，旁边单独飘着一个圆钮；没字时圆钮是 30% 的灰绿实心球，像坏掉的按钮。四个方向，每个画三态：空 / 打字中 / 她在说话（停止）。我推荐 A。

A一体信纸条 推荐

钮收进框里，整条是一张浮起的纸（去掉描边，换成很淡的投影 + 发丝边）。没字时只剩一个灰色箭头、不画底；有字时变墨绿实心圆；她说话时是墨绿停止方块。跟主聊天输入条的「钮在框内」手感一致。

B信纸横线

没有框，只有一条墨线，像在信纸上写字；字用宋体。发送是文字「递给她」。最「手帐」，但可点区域不明显，多行时横线跟着往下走。
