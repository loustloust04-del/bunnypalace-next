## 先认清：mac 和 iOS 不一样的地方

iOS 冲刺治的是「操作本身慢」。mac 的现场（research §1.3）是：
- **她停用那一刻**（09-28 10:04）：Code 详情开着一条正在被写的 CC 会话，主线程被 SwiftUI 渲染风暴占满，后台在整份重解析那条会话；2 秒节流只管 flush 不管渲染，背靠背跑成「一直卡」；重开 app 又被自动带回 Code。
- **常驻后台活抢主线程**：CC 会话文件一被写，Code 列表就在主线程整表重查 SQLite（Code 没开也查）；同步引擎每 5 秒数 4 遍全库；编程会话索引每小时脏写约 2GB；花园本机终端的输出解析也在主线程。

所以 mac 的主指标除了「操作到能用」，必须有**后台负载下的卡顿率**，而且要能复现「打开 Code 必死」。

## 核心操作与「能用」的定义

主指标 5 个（★），其余作探针。T0 / 终点都在 app 内由测量台判定，口径见 plan §2。M1–M8 都在「写入器关」（M9-L0）下测。

| # | 操作 | 起点 T0 | 终点（真的能用） | 主看 |
|---|---|---|---|---|
| ★M9-L1c | **打开 Code 必死验收**：Code 详情开着一条 100MB 级、正在被写的会话 | bench 写入器按 CC 节奏追加开始，窗口在前台 | 固定 10 分钟窗（基线预期超时，超时本身就是读数） | 主线程 >250ms 块次数率（泊松 CI）、最长块分位数、写盘 MB/h |
| ★M9 其余档 | 后台负载下的前台卡顿：L1a Code 关 / L1b Code 列表开 / L-term 本机终端吐 TUI / 后台态（窗口被遮、切回来点第一下的激活延迟）；L0 对照 | 同上 | 固定 10 分钟窗 | 同上 + CPU%、footprint 峰值 |
| ★M2 | 打开对话到能用 | 侧栏点行（驱动器调与行点击同一函数；`sendEvent` 合成点击交叉验证一次） | 目标对话已加载、路径完整、最新气泡上屏、异步排版在途 0、输入框可成为第一响应者 + 500ms 安静窗 | readyMs、busyMs、最长块 |

## 不能动的东西

- **视觉**：mac 玻璃标题栏 / 薄荷外观 / 红绿灯对齐 / Dock 与面板布局 / 外观控制台参数（09-24 定稿）。看得见的变化附前后截图或录屏给她拍板。
- **行为**：Code 阅读「上翻不跳、到底才跟」与失败保留旧内容（09-24）；CC 桥回执与尾部跟随；mac 草稿归属；楼层隔离；⌘K 结果；菜单栏「最近活跃」；mp-code / MCP 看到的会话新鲜度。改刷新节奏的刀（包括止血里的详情限流）写明「最多晚几秒」，交她定。
- **数据**：测量与回归**一律不碰她的东西**——不只 `~/Library/Application Support/MemoryPalace`、`~/Library/Caches/MemoryPalace`、偏好域，还有 `~/Documents`、`~/Library/Mobile Documents/iCloud~com~susu~MemoryPalace`（含时间机器备份）、`~/Desktop/cc-rp`、`~/.claude`、`~/Library/LaunchAgents`、她的钥匙串 / CC 凭据、生产 hub。bench 包越界即 trap，隔离用 marker + `find -newer` + 网络侧核对实证（plan §3.2）；没实证前不跑任何测量。不对生产 hub 发流量。
- **她自用的东西**：只进 Debug 的自用功能照旧只进 Debug。

## 目标

- **止血（R0.5，待她拍板）**：她日常包「打开 Code 不死」——她手摸为第一验收，HangProbe（补时长 + 包身份后）前后对比为数据。
- **M9**：判据三样——>250ms 次数率（带泊松 95% CI）相对基线降一个数量级；写盘 MB/h 降到系统阈值以下（这个包的限额折合 ≈25KB/s ≈90MB/h，现在约 600KB/s）——**不再出 disk writes 报告**；最长块分位数下降。「>1s = 0 次」只作目标，不作判据。
- **M1 / M2 / M8**：p75 各降一半（探索目标）；边际收益变小时把「还值不值得爬」交给她。
- 口径：MacBook Air M5（Mac17,4，24GB，60Hz 内屏），Release + `PERF_BENCH` 的隔离 bench 包，进程冷启（文件缓存热），每组 ≥12 进程，p50 / p75 / p95；结论用两包 ABBA；主线程忙段**双观察者**（`Int.min` 开 / `Int.max` 收），`harnessRevision` 从 `macV1-r1` 起。
- **负载门 + 时间预算**：只在编译锁空闲、负载与内存压力在线内、她不在用、屏幕未锁时测；测量块拿全机编译锁有上限（每块 ≤15 分钟、每晚 ≤2 小时）；基线约 5.5 小时测量窗口，每刀 ABBA 约 1–1.5 小时（plan §3.4）。

## 上线与回滚

- 批准：粟粟。工位 `zone/mac`，一刀一 commit、每刀挂开关（止血刀 `mp.stanch.<刀>`，可 `defaults write … -bool NO` 关回；测量刀 `MP_PERF_<刀>`），合 master 走 merge-queue，她点头才交。
- 装她日常包：/Applications 是指向主工作区 Debug 产物的软链（管家在主工作区编 mac 后她重开即生效），不往 /Applications 拷包。
- 回滚：`git revert <commit>`（每刀独立）；默认开关一行可关。
